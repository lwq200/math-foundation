# 第 07 章 · 幂级数与泰勒——用无穷多项式"冒充"函数，误差有多大

> 本章从哪个问题出发：上一章你学会了"无穷项相加什么时候有结果"（级数与判别法）。现在的问题更野：**能不能把函数本身展开成无穷和？** 比如 sin x、eˣ、ln(1+x)——能不能写成"1 + x + x²/2! + …"这种无穷多项式？**用多项式"冒充"一个复杂函数，误差有多大？这个"冒充"到哪一步还有意义？**
> 推导到哪个结论：你会得到**泰勒定理**——若 f 在 a 附近足够光滑，则 f 可写成"泰勒多项式 + 余项"，其中**拉格朗日余项 Rₙ(x) = f^(n+1)(c)(x−a)^(n+1)/(n+1)!**（c 介于 a 与 x 之间）告诉你"冒充"的误差有多大。你还会看到**收敛半径**——幂级数在哪些 x 有意义，以及**ln(1+x) 的收敛半径恰好 = 1**。
>
> 核心认知：**泰勒定理 = "反复用中值定理"（衔接你写的 Ch3）把函数展开成多项式 + 拉格朗日余项**。余项不是摆设——它精确告诉你怎么控制误差，让"用多项式冒充函数"从"近似"变成"有界的近似"。**这一章把"函数"和"无穷和"焊在一起，是数值计算、误差分析、以及后面一切近似算法的理论根基。**

## 引子

老谟在白板上写下一个数：**e = 2.718281828…**，然后又在旁边写：

```text
1 + 1 + 1/2! + 1/3! + 1/4! + …
```

"你算算这个无穷和，"老谟说，"1 + 1 + 1/2 + 1/6 + 1/24 + …"

我加了几个：1、2、2.5、2.6667、2.7083……**"好像越来越靠近 2.71828…？这不就是 e 吗！"**

"**对。e 这个'看不见'的数，居然等于一个无穷多项式在 x=1 处的值。** 那问题来了——**既然 1+x+x²/2!+… 在 x=1 处给出 e，那它在别的 x 处给出什么？** 你猜，这个无穷和对应的函数是谁？"

"……eˣ？因为 (xⁿ/n!) 这个形状，展开起来像 eˣ 的……啊，**eˣ 的导数还是 eˣ，所以它在 0 处的各阶导数都是 1**，正好凑出 1 + x + x²/2! + x³/3! + …！"

"**你摸到泰勒展开的魂了——用函数在一点的所有导数，拼出一个无穷多项式。** 可两个问题马上来了：**第一，这个无穷和'在哪些 x 有意义'？第二，如果我只用'前几项'（不取无穷），误差有多大？** 这一章，就是回答这两个问题。"

### 第 1 轮：怎么"猜"函数的无穷多项式——从导数说起

**老谟**："你刚才靠'eˣ 的导数都是自己'凑出了 eˣ 的展开。**那换成别的函数，比如 ln(1+x)，我怎么猜它的无穷多项式？** 提示你：一个多项式 1 + a₁x + a₂x² + a₃x³ + …，它的每一项系数，能不能从'在 0 处的各阶导数'反推出来？"

**造物主**："……让我试试。**如果 f(x) = c₀ + c₁x + c₂x² + c₃x³ + …，那 f(0)=c₀，f'(0)=c₁，f''(0)=2c₂，f'''(0)=6c₃=3!c₃。** 所以 **cₖ = f^(k)(0)/k!**！每一项的系数，就是'该阶导数除以 k!'。"

**老谟**："**你摸到泰勒公式的核心了——cₖ = f^(k)(a)/k!。** 那 ln(1+x) 在 0 处的各阶导数是？"

**造物主**："……f'(x)=1/(1+x)，f''(x)=−1/(1+x)²，f'''(x)=2/(1+x)³……**在 0 处：f'(0)=1，f''(0)=−1，f'''(0)=2，f⁗(0)=−6。** 所以 ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + … = **Σ(−1)^(n+1) xⁿ/n**！"

**老谟**："**展开拼出来了。** 可你马上撞上一个问题——**这个展开，是不是对'所有 x'都等于 ln(1+x)？** 你试试 x=2 会怎样？"

### 📐 知识锚点：泰勒展开的"系数反推"——cₖ = f^(k)(a)/k!
<blockquote style="background:#fff8e1">

【概念深挖】**泰勒多项式（Taylor polynomial）**：设 f 在 a 附近有 n 阶导数，则
$$f(x) \approx \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k.$$
- **系数反推**：若 f(x)=c₀+c₁(x−a)+c₂(x−a)²+…，则 cₖ = f^(k)(a)/k!（在 x=a 处逐阶求导可反解）。
- **n 阶泰勒多项式** Tₙ(x) = Σₖ₌₀ⁿ f^(k)(a)(x−a)ᵏ/k!，**是"在 a 处与 f 前 n 阶导数都相同"的多项式**——"冒充"f 的最优局部近似。

**麦克劳林展开（Maclaurin）**：a=0 时的泰勒展开，f(x)=Σ f^(k)(0)xᵏ/k!。
- 常用：eˣ=Σ xⁿ/n!；sin x=Σ(−1)ⁿx^(2n+1)/(2n+1)!；ln(1+x)=Σ(−1)^(n+1)xⁿ/n（|x|<1）。

**直觉**：**"在 a 处导数都相同的多项式，最接近 f"**——泰勒展开用"一点的信息"去拟合"整个函数"，靠的是"各阶导数"这个"局部指纹"。

【工程实践】泰勒展开是**一切近似算法的源头**：**数值计算、物理近似（小角度 sinθ≈θ）、优化里的局部二次近似**，本质都是"用泰勒多项式冒充函数"。**你后面学的牛顿法、梯度下降，靠的都是在某点做泰勒展开然后取低阶项。**
</blockquote>

### 第 2 轮：收敛半径——"冒充"到哪一步还有意义

**老谟**："你展开出了 ln(1+x) = x − x²/2 + x³/3 − …。**你试试 x=2：2 − 4/2 + 8/3 − 16/4 + …** 这会怎样？"

**造物主**："……2 − 2 + 2.6667 − 4 + …，好像**乱成一团，根本不收敛！** 可 x=0.5：0.5 − 0.125 + 0.0417 − …，好像收敛到一个数。**同一个展开，为什么 x=0.5 行、x=2 不行？**"

**老谟**："**因为幂级数有'收敛半径'。** 幂级数 Σcₙxⁿ 一定存在一个数 R（收敛半径），使得 **|x|<R 时收敛、|x|>R 时发散**。ln(1+x) 的这个展开，收敛半径是 R=1——**所以 |x|<1 才收敛，x=2（|x|=2>1）就发散**。**而判断 R 用哪招？你上一章刚学的比值判别。** 完整证明在走廊。下一轮，我们看'误差有多大'——拉格朗日余项。"

### 📐 知识锚点：幂级数与收敛半径
<blockquote style="background:#e3f2fd">

【概念深挖】**幂级数（power series）**：Σₙ₌₀^∞ cₙ(x−a)ⁿ（以 a 为中心）。
- **收敛半径 R**：存在 R∈[0,∞]（或 ∞），使 |x−a|<R 时幂级数收敛、|x−a|>R 时发散。R 称为收敛半径。
- **收敛域**：|x−a|<R 绝对收敛；|x−a|>R 发散；**端点 x=a±R 需单独讨论**（可能收敛/条件收敛/发散）。
- **求 R 的方法**：比值判别——R = lim |cₙ/cₙ₊₁|（若比值极限 L，则 R=1/L）；或根值判别。
  - 例：Σxⁿ/n，|cₙ/cₙ₊₁|=|(1/n)/(1/(n+1))|= (n+1)/n →1，故 R=1。
- **收敛半径=1 的几何意义**：以 a 为圆心、半径 R 的圆内收敛（复数视角：收敛圆）。

【历史溯源】**收敛半径的概念与判定，由柯西（Cauchy）与阿达玛（Hadamard）等确立**（柯西-阿达玛公式）。**幂级数理论在 19 世纪随严格化而成熟**——它把"函数展开成无穷多项式"从"形式操作"变成"有严格收敛域的数学"。
</blockquote>

### 第 3 轮：只用前几项——误差有多大（拉格朗日余项）

**老谟**："收敛半径管'取无穷多项'时对不对。**可现实中你不可能真取无穷多项——你只能用'前 n 项'（泰勒多项式 Tₙ）去近似 f。** 那误差 f(x) − Tₙ(x) 有多大？**这个误差，叫余项 Rₙ(x)。** 你猜，它长什么样？提示你：把'近似到 n 阶'想成'还差一点没近似到'，而那一'点'，可以看作'余下的变化率'——它和'在 a 和 x 之间某点的 (n+1) 阶导数'有关。"

**造物主**："……直觉上，误差应该和'更高阶的导数'有关？**因为我用前 n 阶导数去拟合，没用到 (n+1) 阶导数，所以误差由 (n+1) 阶导数控制。** 那是不是 Rₙ(x) = f^(n+1)(c)·(x−a)^(n+1)/(n+1)!，其中 c 在 a 和 x 之间？"

**老谟**："**你几乎把拉格朗日余项猜出来了——它就是那个形式。** 而'为什么恰好是那个 (n+1) 阶导数和 (x−a)^(n+1)/(n+1)!'，靠的是**反复用中值定理**（衔接你 Ch3 写的柯西中值定理）。**这个证明是本章最硬的一块，完整可复写版在走廊定理 1。** 下一轮，我们看这个余项能拿来干嘛——估误差、算近似。"

### 📐 知识锚点：泰勒定理与拉格朗日余项
<blockquote style="background:#fff8e1">

【概念深挖】**泰勒定理（Taylor's theorem，带拉格朗日余项）**：若 f 在包含 a 和 x 的区间上有 n+1 阶连续导数，则存在 c 介于 a 与 x 之间，使
$$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x),\qquad R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}.$$

- **余项 Rₙ(x) 的意义**：用 n 阶泰勒多项式 Tₙ 近似 f 的**误差**。它由 (n+1) 阶导数在区间内某点 c 的值决定。
- **用法**：若 |f^(n+1)(x)|≤M 于该区间，则 |Rₙ(x)|≤M|x−a|^(n+1)/(n+1)!——**误差有界，可控制**。
- **n=0 时**：f(x)=f(a)+f'(c)(x−a)——这就是拉格朗日中值定理！**泰勒定理是中值定理的推广。**

【工程实践】拉格朗日余项是**误差分析的终极工具**：**用有限阶多项式近似一个函数，误差上界 M|x−a|^(n+1)/(n+1)!** 让你能"倒推要算到多少阶才能把误差压到给定精度"。**数值积分、数值微分、牛顿法的误差界，全是这个余项的直接应用。**
</blockquote>

### 第 4 轮：余项怎么用——估误差、定阶数

**老谟**："余项 Rₙ = f^(n+1)(c)(x−a)^(n+1)/(n+1)!，它怎么用来估误差？**我给你个具体的：用 eˣ 的泰勒展开算 e^0.1，取前 4 项（n=3），误差最大是多少？** 你先想——e^(n+1) 阶导数是 eˣ，在 [0, 0.1] 上它的最大值是谁？"

**造物主**："……eˣ 在 [0,0.1] 上单调增，最大值在右端 e^0.1。**但 e^0.1 我还没算出来……可以用 e^0.1<e<3（或更紧 e^0.1<2）来界。** 那 |R₃(0.1)| = |e^c|·0.1⁴/4! ≤ e^0.1·0.0001/24 < 2·0.0001/24 ≈ 8.3×10⁻⁶。**所以取前 4 项，误差不到 1e−5！**"

**老谟**："**你摸到余项的用法了——'先界住 (n+1) 阶导数的大小，再乘 (x−a)^(n+1)/(n+1)!'，就得到一个误差上界。** 这也回答了'要算多少阶'：**要误差 < 1e−6，就解 M|x−a|^(n+1)/(n+1)! < 1e−6，求出需要的 n。** 具体怎么倒推阶数，计算训练场里练。"

**造物主**："……所以余项不是摆设——**它精确告诉我'冒充'的误差有多大，让我能'按需取阶'。**"

### 📐 知识锚点：用余项估误差与"按需取阶"
<blockquote style="background:#e3f2fd">

【概念深挖】**用拉格朗日余项估误差的"三步"**：
1. **写余项**：Rₙ(x) = f^(n+1)(c)(x−a)^(n+1)/(n+1)!。
2. **界住导数**：在该区间上找 (n+1) 阶导数的上界 M（通常看单调性/最大点）。
3. **得误差界**：|Rₙ(x)| ≤ M|x−a|^(n+1)/(n+1)!。

**"按需取阶"**：要误差 < ε，解 M|x−a|^(n+1)/(n+1)! < ε 求最小的 n——**这就是"用泰勒算近似时取多少项"的严格依据**。

**常用展开（麦克劳林，a=0）**：
- eˣ = Σxⁿ/n!（收敛半径 ∞，全数轴）。
- sin x = Σ(−1)ⁿx^(2n+1)/(2n+1)!（收敛半径 ∞）。
- ln(1+x) = Σ(−1)^(n+1)xⁿ/n（收敛半径 1）。

【工程实践】"误差界 M|x−a|^(n+1)/(n+1)!"是**所有"算多少位/算多少项"问题的通用答案**：**物理近似（sinθ≈θ 的误差 ≤|θ|³/6）、数值积分、优化停止准则**，背后都是"用泰勒余项定误差、按需取阶"。
</blockquote>

### 第 5 轮：ln(1+x) 的收敛半径为什么恰好是 1

**老谟**："你展开过 ln(1+x) = Σ(−1)^(n+1)xⁿ/n。**它的收敛半径 R=1。** 你上一章刚学过比值判别——**用它，把 R=1 算出来。** 注意 Σ(−1)^(n+1)xⁿ/n 的系数 cₙ=(−1)^(n+1)/n。"

**造物主**："……|cₙ/cₙ₊₁| = |((−1)^(n+1)/n)/((−1)^(n+2)/(n+1))| = (n+1)/n → 1。**所以 R = 1**（因为收敛半径 R = lim|cₙ/cₙ₊₁|=1）。那端点呢？x=1：Σ(−1)^(n+1)/n，交错级数，收敛（莱布尼茨）=ln2；x=−1：Σ(−1)^(n+1)(−1)ⁿ/n=Σ(−1)^(2n+1)/n=−Σ1/n，调和，发散。**所以收敛域是 (−1,1]，x=1 条件收敛。**"

**老谟**："**R=1 你亲手算出来了，端点也讨论清了。** 你发现没有——**收敛半径 R=1 意味着：ln(1+x) 的泰勒展开只在以 0 为中心、半径 1 的圆内（|x|<1）才等于 ln(1+x）。** 这个"展开只在收敛半径内成立"是幂级数的铁律——**别在 |x|>1 时还拿它冒充 ln(1+x)。** 完整证明在走廊定理 2。"

### 📐 知识锚点：收敛半径的求法与"只在半径内成立"
<blockquote style="background:#fff8e1">

【概念深挖】**求收敛半径 R**：对幂级数 Σcₙ(x−a)ⁿ，用比值判别：若 lim|cₙ₊₁/cₙ|=L，则 **R=1/L**（L=0 时 R=∞，L=∞ 时 R=0）。
- 例 ln(1+x)：cₙ=(−1)^(n+1)/n，lim|cₙ₊₁/cₙ|=lim n/(n+1)=1，故 R=1。

**收敛半径的意义**：**幂级数只在以 a 为中心、半径 R 的开区间内收敛于其和函数**；端点需单独讨论。**"展开 = 原函数"只在收敛半径内成立，出了半径，级数不是那个函数。**（例：ln(1+x) 的展开在 x=2 发散，故不能把级数在 x=2 处当 ln3。）

**为什么"半径"是圆的**：复数视角下，|x−a|<R 是复平面上的开圆盘，幂级数在圆盘内收敛——"收敛半径"由此得名。

【历史溯源】**收敛半径与柯西-阿达玛公式**由柯西与阿达玛（Hadamard）确立；**幂级数理论**在 19 世纪（魏尔斯特拉斯、阿贝尔等）严格化。**"展开只在收敛半径内成立"是幂级数最容易被误用的一条铁律**——本书特别强调。
</blockquote>

### 第 6 轮：落点——函数被"无穷多项式"钉住，误差有界

**老谟**："把这章收一遍。你最初只会'猜' eˣ 的展开，现在你会怎么完整说？"

**造物主**："……我会说：**泰勒定理**——f(x) = Σₖ₌₀ⁿ f^(k)(a)(x−a)ᵏ/k! + Rₙ(x)，其中**拉格朗日余项 Rₙ = f^(n+1)(c)(x−a)^(n+1)/(n+1)!**（c 在 a、x 之间）控制误差。而幂级数有**收敛半径 R**（比值判别 R=lim|cₙ/cₙ₊₁|），只在 |x−a|<R 内等于原函数，端点单独讨论——ln(1+x) 的 R=1。"

**老谟**："那这个'展开'能拿来干嘛？"

**造物主**："**估误差**：界住 (n+1) 阶导数，得 |Rₙ|≤M|x−a|^(n+1)/(n+1)!，按需取阶；**算近似**：用有限阶泰勒多项式逼近函数，误差可控。"

**老谟**："**这一章，你拿到了微积分'用多项式冒充函数'的完整理论——泰勒定理 + 拉格朗日余项 + 收敛半径。** 它是数值计算、误差分析、以及下一册（多元微积分）里多元泰勒与最优化方法的共同地基。**你这一册从'变化'（导数）走到'累积'（积分）再走到'展开'（泰勒），微积分的三大支柱，全立起来了。** 把余项和收敛半径刻进脑子——它们是'近似'能有多准、'展开'到哪有效的判官。"

**造物主**："……好。函数能被无穷多项式钉住，而且误差有界——这让我敢放心地'冒充'了。"

### 定义：幂级数、收敛半径、泰勒多项式（精确表述）

- **幂级数**：Σₙ₌₀^∞ cₙ(x−a)ⁿ（以 a 为中心）。
- **收敛半径 R**：存在 R∈[0,∞]，使 |x−a|<R 时级数收敛、|x−a|>R 时发散。
- **n 阶泰勒多项式**：Tₙ(x) = Σₖ₌₀ⁿ f^(k)(a)(x−a)ᵏ/k!。

> **证明类型标注**：本章的核心证明——**定理 1（泰勒定理）用构造性证明 + 反复柯西中值定理**（构造余项 Rₙ 与 (t−a)^(n+1)，反复用柯西 MVT n+1 次）；**定理 2（ln(1+x) 收敛半径=1）用直接证明（比值判别）**。都衔接册03 前六章：泰勒定理反复用 Ch3 柯西中值定理，收敛半径用 Ch6 比值判别。收敛半径概念本身用"比值判别"直接给出。
>
> **关于对话**：本章第 3、5 轮是读者**第一次**正式接触"拉格朗日余项"与"收敛半径"的证明，对话做了"引导式推导"（为什么余项和 (n+1) 阶导数有关、为什么比值判别求 R）。**正式的可复写证明（每一步标依据）在本走廊定理 1、2**。对话负责"为什么会想到这步"，走廊负责"怎么把它写标准"——与册03 前六章口径一致。

### 定理 1（泰勒定理，带拉格朗日余项）：若 f 在包含 a、x 的区间上有 n+1 阶连续导数，则存在 c 介于 a 与 x 之间，使 f(x)=Σₖ₌₀ⁿ f^(k)(a)(x−a)ᵏ/k! + f^(n+1)(c)(x−a)^(n+1)/(n+1)!

**前提**：f 在含 a、x 的开区间上有 n+1 阶连续导数。

**证明类型**：构造性证明 + 反复柯西中值定理（衔接 Ch3 定理 3）。

**证明**：
- 第 1 步：**定义余项函数**：设 t 介于 a 与 x 之间（若 x>a 取 t∈[a,x]；若 x<a 取 t∈[x,a]），记
  $$R_n(t) = f(t) - \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(t-a)^k.$$
  （依据：Rₙ(t) 是 f(t) 与 n 阶泰勒多项式之差，即"冒充"的误差。）
- 第 2 步：**验证 Rₙ 在 a 处前 n 阶导数为 0**：对 k=0,1,…,n，
  $$R_n^{(k)}(a) = f^{(k)}(a) - f^{(k)}(a) = 0.$$
  （依据：泰勒多项式第 k 项求导 k 次得 f^(k)(a)，其余项求导后含 (t−a) 的正幂，代 t=a 为 0。故 Rₙ(a)=Rₙ'(a)=…=Rₙ⁽ⁿ⁾(a)=0。）
- 第 3 步：**构造第二个函数 G(t)=(t−a)^(n+1)**：则
  G(a)=G'(a)=…=G⁽ⁿ⁾(a)=0（含 (t−a) 正幂），且 G⁽ⁿ⁺¹⁾(t)=(n+1)!（常数）。（依据：(t−a)^(n+1) 求 n+1 阶导得 (n+1)!。）
- 第 4 步：**反复用柯西中值定理（关键）**。**先设 x>a**（x<a 的情形见本步末尾的说明）：
  - 第 1 次：因 Rₙ(a)=G(a)=0，由柯西 MVT（Ch3 定理 3，Rₙ、G 在 [a,x] 连续、在 (a,x) 可导，且 G'(t)=(n+1)(t−a)ⁿ 在 (a,x) 非 0），存在 c₁∈(a,x) 使 Rₙ(x)/G(x) = Rₙ'(c₁)/G'(c₁)。
  - 第 2 次：因 Rₙ'(a)=G'(a)=0，对 Rₙ'、G' 在 [a,c₁] 用柯西 MVT，存在 c₂∈(a,c₁) 使 Rₙ'(c₁)/G'(c₁)=Rₙ''(c₂)/G''(c₂)。
  - ……（反复 n+1 次，每次消去一阶导数与一阶 (t−a)。）
  - 第 n+1 次：存在 c∈(a,x) 使
    $$\frac{R_n(x)}{G(x)} = \frac{R_n^{(n+1)}(c)}{G^{(n+1)}(c)}.$$
  （依据：柯西 MVT 可反复应用——每次分子分母都在左端点取 0，满足柯西 MVT 前提。这是"反复用中值定理"的严格表达。）
  - **x<a 的情形（闭合循环）**：对 [x,a] 用柯西 MVT（Rₙ、G 在 [x,a] 连续、在 (x,a) 可导，G'(t)=(n+1)(t−a)ⁿ 在 (x,a) 非 0，因 t≠a）。因 Rₙ(a)=G(a)=0，得 Rₙ(x)/G(x) = Rₙ'(c₁)/G'(c₁)（c₁∈(x,a)）。再因 Rₙ'(a)=G'(a)=0，对 [x,c₁] 继续用柯西 MVT……逐层同理（每次都在含 a 的区间上、左端点处分子分母同取 0），反复 n+1 次后同样得到 Rₙ(x)/G(x)=Rₙ⁽ⁿ⁺¹⁾(c)/G⁽ⁿ⁺¹⁾(c)，c 介于 x 与 a 之间。**分子分母同负（[−Rₙ(x)]/[−G(x)]）与比值不变，符号不构成障碍。**（依据：柯西 MVT 对任意"含 a 的区间"成立，只要两端在 a 的函数值都是 0；x<a 与 x>a 只是区间方向相反，推导逐字相同。）
- 第 5 步：**代值**：Rₙ⁽ⁿ⁺¹⁾(t) = f⁽ⁿ⁺¹⁾(t)（泰勒多项式是 n 次多项式，求 n+1 阶导为 0）；G⁽ⁿ⁺¹⁾(t)=(n+1)!；G(x)=(x−a)^(n+1)。故
  $$R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}.$$
  （依据：代入第 4 步比例式，交叉相乘。）
- 第 6 步：由第 1 步定义，f(x) = Σₖ₌₀ⁿ f^(k)(a)(x−a)ᵏ/k! + Rₙ(x)，代入第 5 步即得泰勒定理。∎

> **依据标注**：步 1 用余项定义（f 减泰勒多项式）；步 2 用泰勒多项式性质（前 n 阶导数与 f 相同）；步 3 用 G(t)=(t−a)^(n+1) 的导数性质；步 4 用柯西中值定理**反复 n+1 次**（衔接 Ch3 定理 3，每次消一阶，最终得到 (n+1) 阶导之比；**x>a 与 x<a 两方向都在步 4 末尾闭合**——x<a 时对含 a 的区间 [x,a] 逐字同样推导，分子分母同负不改变比值）；步 5 用代值化简；步 6 用定义收束。
> **读法**：泰勒定理证明的发动机是第 4 步的"反复柯西中值定理"——**把"误差比上 (x−a)^(n+1)"逐次消去一阶，最终得到 (n+1) 阶导数之比**。这正是你 Ch3 学的柯西中值定理的"连环套用"。**n=0 时它退化为 f(x)=f(a)+f'(c)(x−a)，就是拉格朗日中值定理**——所以泰勒定理是"中值定理的任意阶推广"。**余项 Rₙ=f^(n+1)(c)(x−a)^(n+1)/(n+1)! 的意义：误差由 (n+1) 阶导数在区间内某点 c 的值决定，故可被 M=sup|f^(n+1)| 界住。**

### 定理 2（ln(1+x) 的收敛半径）：Σₙ₌₁^∞ (−1)^(n+1)xⁿ/n 的收敛半径为 1，收敛域为 (−1,1]

**前提**：幂级数 Σ(−1)^(n+1)xⁿ/n（这是 ln(1+x) 的麦克劳林展开的系数）。

**证明类型**：直接证明（比值判别求 R，衔接 Ch6 定理 1）+ 端点讨论（莱布尼茨、调和）。

**证明**：
- 第 1 步：**写系数**：cₙ=(−1)^(n+1)/n。（依据：Σ(−1)^(n+1)xⁿ/n 的第 n 项系数。）
- 第 2 步：**用比值判别求 R**：lim |cₙ₊₁/cₙ| = lim |((−1)^(n+2)/(n+1))/((−1)^(n+1)/n)| = lim n/(n+1) = 1。由幂级数收敛半径公式 R = 1/(lim|cₙ₊₁/cₙ|) = 1/1 = **1**。（依据：比值判别 + R=1/L 公式，衔接 Ch6。）
- 第 3 步：**开区间**：|x|<1 时级数绝对收敛，|x|>1 时发散。（依据：比值判别，R=1。）
- 第 4 步：**讨论端点**：
  - x=1：Σ(−1)^(n+1)/n，aₙ=1/n 单调递减且→0，由莱布尼茨交错判别**收敛**（条件收敛，因 Σ1/n 发散）。
  - x=−1：Σ(−1)^(n+1)(−1)ⁿ/n = Σ(−1)^(2n+1)/n = Σ(−1)/n = −Σ1/n，调和级数，**发散**。
  （依据：莱布尼茨判别 + 调和级数发散，衔接 Ch6 引理 1。）
- 第 5 步：**收敛域**：(−1,1]（|x|<1 绝对收敛，x=1 条件收敛，x=−1 发散）。∎

> **依据标注**：步 1 用系数定义；步 2 用比值判别求 R（R=1/L）；步 3 用比值判别的敛散结论；步 4 用莱布尼茨判别（端点 x=1）与调和级数发散（端点 x=−1）；步 5 收束。
> **读法**：收敛半径=1 的证明很"短"，但每一步都有据——**R 由比值判别一步算出，端点各用一条 Ch6 的判别法**。它强调幂级数铁律：**展开只在收敛半径内等于原函数，端点必须单独讨论。** 别在 |x|>1 时把该级数当 ln(1+x)。

### 幂级数与泰勒的书写格式模板（可复写卡片——对着空白纸照写）

> 这是本章要你抄进脑子的卡。**以后你遇到"展开 + 收敛半径 + 余项估误差"，就照这个骨架走**：

```text
命题：将 f 在 a 附近展开并用余项估误差。
计算：
  1. 求泰勒多项式：Tₙ(x)=Σₖ₌₀ⁿ f^(k)(a)(x−a)ᵏ/k!（先算 f 的各阶导数在 a 的值）。
  2. 写余项：Rₙ(x)=f^(n+1)(c)(x−a)^(n+1)/(n+1)!（c 在 a、x 之间）。
  3. 若为幂级数 Σcₙ(x−a)ⁿ：用比值判别求 R=1/(lim|cₙ₊₁/cₙ|)，再讨论端点 a±R。
  4. 估误差：界住 |f^(n+1)|≤M，得 |Rₙ|≤M|x−a|^(n+1)/(n+1)!。
  5. 收束（必要时"按需取阶"：解 M|x−a|^(n+1)/(n+1)!<ε 求 n）。∎
```

**填写时的三个检查点**：① **系数 = f^(k)(a)/k!，别漏 k!**；② **收敛半径 R=1/L，端点 a±R 必须单独讨论**；③ **余项里是 (n+1) 阶导数 × (x−a)^(n+1)/(n+1)!，阶数别错**（用了 n 阶多项式，误差是 n+1 阶）。

### 反例/边界：幂级数与泰勒的适用边界

1. **"展开=原函数"只在收敛半径内**：ln(1+x) 的展开在 |x|>1 发散，不能拿它在 x=2 处当 ln3。**出了半径，级数不是那个函数。**
2. **收敛半径端点需单独讨论**：Σ(−1)^(n+1)xⁿ/n 在 x=1 条件收敛、x=−1 发散——**不能凭 R=1 就说收敛域是 (−1,1)，必须看端点。**
3. **泰勒定理要求"n+1 阶可导"**：若 f 只有 n 阶导数（无 (n+1) 阶），拉格朗日余项不成立。**余项的阶数依赖可导阶数。**
4. **余项是"存在 c"，不是"知道 c"**：拉格朗日余项给的是"存在某 c"使等式成立，我们常不知 c 具体是谁，只能界住 |f^(n+1)| 得误差上界。**估误差用上界 M，不是用 c 的精确值。**
5. **"泰勒展开收敛于 f"不总是"处处"**：即使收敛半径 ∞（如 eˣ、sin x），也只是"全数轴收敛于原函数"；对一般函数，收敛半径内收敛到谁还需验证。**别把"幂级数收敛"等同于"收敛到原函数"（这是收敛半径+解析性的主题，本书聚焦展开与余项）。**

## 知识点总结

### 知识点（本章推出的核心概念）

- **泰勒多项式**：Tₙ(x)=Σₖ₌₀ⁿ f^(k)(a)(x−a)ᵏ/k!，**系数 cₖ=f^(k)(a)/k!**（"在 a 处与 f 前 n 阶导数相同"的多项式）。
- **麦克劳林展开**：a=0 时的泰勒展开。eˣ=Σxⁿ/n!、sin x=Σ(−1)ⁿx^(2n+1)/(2n+1)!、ln(1+x)=Σ(−1)^(n+1)xⁿ/n。
- **泰勒定理（拉格朗日余项）**：f(x)=Tₙ(x)+Rₙ(x)，Rₙ=f^(n+1)(c)(x−a)^(n+1)/(n+1)!。**误差由 (n+1) 阶导数决定，可被 M 界住。**
- **泰勒定理 = 中值定理的推广**：n=0 时退化为拉格朗日中值定理；证明靠**反复用柯西中值定理**（衔接 Ch3）。
- **幂级数与收敛半径 R**：Σcₙ(x−a)ⁿ，|x−a|<R 收敛、>R 发散；**R=1/(lim|cₙ₊₁/cₙ|)**（比值判别）；端点单独讨论。
- **ln(1+x) 收敛半径 = 1**：R=1，收敛域 (−1,1]。
- **用余项估误差**：界住 |f^(n+1)|≤M ⟹ |Rₙ|≤M|x−a|^(n+1)/(n+1)!；**按需取阶**解不等式求 n。

### 历史结论（本章涉及的史料）

- **布鲁克·泰勒（Brook Taylor，1715）**：提出泰勒定理（泰勒展开），用"有限差分"表述，后人以他命名。
- **柯西（Cauchy）**：给出收敛半径的严格理论，建立幂级数的收敛性判据。
- **阿达玛（Hadamard）**：柯西-阿达玛公式，给出收敛半径的计算。
- **魏尔斯特拉斯、阿贝尔（19 世纪）**：幂级数理论严格化，确立"展开在收敛半径内成立"的铁律。
- **收敛半径的"圆盘"直觉**：复数视角下 |x−a|<R 是收敛圆盘，故称"半径"。

### 工程实践结论（本章知识在真实工程里怎么用）

- **泰勒展开 = 一切近似算法的源头**：小角度近似（sinθ≈θ）、局部线性化、优化里的二次近似，都是泰勒低阶项。
- **拉格朗日余项 = 误差分析的终极工具**：M|x−a|^(n+1)/(n+1)! 让"算多少项/多少位"有严格依据（数值积分、数值微分、牛顿法误差界）。
- **收敛半径 = "近似在什么范围有效"**：把函数用多项式近似，必须知道在哪个区间内可靠——收敛半径就是这个"可靠范围"。
- **"按需取阶" = 精度控制**：解 M|x−a|^(n+1)/(n+1)!<ε 求 n，就是工程里"要误差小于 ε 需算到多少阶"的标准答案。

> 位置说明：对话负责"为什么泰勒展开/余项/收敛半径成立"，这里负责"怎么算"。下面三题**必须动笔**，每题 10 分钟以上，先自己写再对答案。**难度递进：易→中→难。** 重点是"求收敛半径与收敛域 + 泰勒展开到指定阶并用余项估误差"。

### 题 1（易→中）：求三个幂级数的收敛半径与收敛域

**题干**：老谟给了三个幂级数，让造物主求收敛半径 R 与收敛域：
(a) Σₙ₌₀^∞ xⁿ/n!；(b) Σₙ₌₁^∞ xⁿ/n；(c) Σₙ₌₁^∞ xⁿ/n²。

**完整分步解答：**

**(a) Σ xⁿ/n!**：
- 第 1 步：比值判别：lim|cₙ₊₁/cₙ| = lim|(1/(n+1)!)/(1/n!)| = lim 1/(n+1) = 0。
- 第 2 步：R = 1/0 = **∞**。全数轴收敛。
- **答 (a)**：R=∞，收敛域 ℝ（=eˣ 的展开）。

**(b) Σ xⁿ/n**：
- 第 1 步：lim|cₙ₊₁/cₙ| = lim n/(n+1) = 1，R=1。
- 第 2 步：端点：x=1 时 Σ1/n 调和发散；x=−1 时 Σ(−1)ⁿ/n 交错收敛（条件）。
- **答 (b)**：R=1，收敛域 [−1,1)（x=−1 条件收敛，x=1 发散）。

**(c) Σ xⁿ/n²**：
- 第 1 步：lim|cₙ₊₁/cₙ| = lim n²/(n+1)² = 1，R=1。
- 第 2 步：端点：x=1 时 Σ1/n²（p=2>1）收敛；x=−1 时 Σ(−1)ⁿ/n² 绝对收敛（Σ1/n² 收敛）。
- **答 (c)**：R=1，收敛域 [−1,1]（闭，两端都收敛）。

**答**：(a) R=∞，ℝ；(b) R=1，[−1,1)；(c) R=1，[−1,1]。

**常见错误**：① (a) 把 R 算成有限值——lim 1/(n+1)=0，R=∞；② 三题收敛半径都是 1 但端点不同——**端点必须单独讨论，不能只写 R**；③ (b) x=−1 是条件收敛（不是绝对收敛），(c) 两端是绝对收敛——别混。

### 题 2（中）：泰勒展开到指定阶——eˣ 在 0 处的麦克劳林到 3 阶

**题干**：老谟让造物主求 f(x)=eˣ 在 a=0 处的麦克劳林展开到 n=3 阶（写 T₃ 与拉格朗日余项 R₃），并写出各阶导数。

**完整分步解答：**

- 第 1 步：**算各阶导数**：f^(k)(x)=eˣ（eˣ 的导数还是自己），故 f^(k)(0)=e⁰=1（k=0,1,2,3,…）。
- 第 2 步：**写泰勒多项式**：
  T₃(x) = Σₖ₌₀³ f^(k)(0)xᵏ/k! = f(0)/0! + f'(0)x/1! + f''(0)x²/2! + f'''(0)x³/3! = **1 + x + x²/2 + x³/6**。
- 第 3 步：**写拉格朗日余项**（n=3，需 (n+1)=4 阶导数）：
  R₃(x) = f⁗(c)x⁴/4! = **e^c·x⁴/24**，其中 c 介于 0 与 x 之间。
- **答**：eˣ = 1 + x + x²/2 + x³/6 + e^c·x⁴/24（c 在 0 与 x 之间）。

**常见错误**：① 系数漏 k!（把 x²/2! 写成 x²，或漏 /2）；② 余项阶数写错——用了 3 阶多项式，余项是 **4 阶**导数（e^c·x⁴/4!），不是 3 阶；③ 忘了 c 在 0 与 x 之间这个条件。

### 题 3（难）：用余项估误差 + 按需取阶——算 e^0.1 并控误差

**题干**：老谟让造物主用 eˣ 的麦克劳林展开：
(a) 取到 n=3 阶近似 e^0.1，并用拉格朗日余项估误差上界。
(b) 若要误差 < 1×10⁻⁶，需要取到多少阶 n？

**完整分步解答：**

**(a) 取 n=3 近似 e^0.1 并估误差**：
- 第 1 步：T₃(0.1) = 1 + 0.1 + 0.1²/2 + 0.1³/6 = 1 + 0.1 + 0.005 + 0.001/6 = **1 + 0.1 + 0.005 + 0.0001667 = 1.1051667**。
- 第 2 步：**余项**：R₃(0.1) = e^c·0.1⁴/4! = e^c·0.0001/24，c∈(0,0.1)。
- 第 3 步：**界住 e^c**：c∈(0,0.1)，e^c<e^0.1<2（因 0.1<1，e^0.1<e<3，取更紧 e^0.1<2）。
- 第 4 步：**误差上界**：|R₃(0.1)| < 2·0.0001/24 ≈ **8.33×10⁻⁶**。
- **答 (a)**：e^0.1 ≈ 1.1051667，误差 < 8.33×10⁻⁶。（实际 e^0.1≈1.1051709，误差≈4.2×10⁻⁶，在上界内 ✓。）

**(b) 要误差 < 1×10⁻⁶ 取多少阶**：
- 第 1 步：**余项通式**：Rₙ(0.1)=e^c·0.1^(n+1)/(n+1)!，|Rₙ|<2·0.1^(n+1)/(n+1)!。
- 第 2 步：**试 n**：n=4：2·0.1⁵/5! = 2·0.00001/120 = 2×10⁻⁵/120 ≈ 1.67×10⁻⁷ < 1×10⁻⁶ ✓。n=3 时 8.33×10⁻⁶ > 1×10⁻⁶ ✗。
- 第 3 步：**取 n=4**（因 n=3 不够，n=4 已够）。
- **答 (b)**：取到 **n=4**（误差 < 1.67×10⁻⁷ < 1×10⁻⁶）。

**答**：(a) e^0.1≈1.1051667，误差<8.33×10⁻⁶；(b) 取 n=4。

**常见错误**：① 估误差忘了"界住 e^c"这一步（c 是未知的，只能取上界 M=2）；② 余项阶数用错（n 阶多项式误差是 n+1 阶，0.1^(n+1)/(n+1)!）；③ (b) 解"按需取阶"时没逐个试 n，或误取 n=3（其误差 8.3×10⁻⁶>1×10⁻⁶）。

## 向导便签

> 这一章咱们干了什么：把你那句"e 等于一个无穷多项式"的直觉，钉死成了一整套理论——**泰勒多项式**（系数 cₖ=f^(k)(a)/k!）、**泰勒定理**（带**拉格朗日余项** Rₙ=f^(n+1)(c)(x−a)^(n+1)/(n+1)!，反复用中值定理证明）、**幂级数收敛半径**（比值判别 R=1/L，端点单独讨论），以及 **ln(1+x) 收敛半径=1**。

>
> 记住：**"展开只在收敛半径内等于原函数，端点单独讨论"是幂级数铁律；余项是'能算多准'的判官。** 这一册从"变化"（导数）到"累积"（积分）再到"展开"（泰勒），微积分三大支柱全立起来了。下一册（多元微积分），你要把这套"在某点展开+控误差"的看家本领，推广到多变量——**多元泰勒与最优化**。把余项和收敛半径带上，那是最优化的理论根基。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：收敛半径与收敛域**

求 Σₙ₌₁^∞ (−1)^(n+1)xⁿ/n 的收敛半径与收敛域（这就是 ln(1+x) 的展开）。

**完整解答**：比值判别 lim|cₙ₊₁/cₙ|=lim n/(n+1)=1，R=1。端点：x=1 时 Σ(−1)^(n+1)/n 交错收敛（=ln2）；x=−1 时 Σ(−1)^(n+1)(−1)ⁿ/n=−Σ1/n 发散。故收敛域 **(−1,1]**（x=1 条件收敛）。

**题 B（计算，中→难）：泰勒展开 + 余项估误差**

用 sin x 的麦克劳林展开，取到 n=3 阶（即 x−x³/6）近似 sin(0.5)，并用拉格朗日余项估误差上界（提示：sin 的 4 阶导数绝对值 ≤1）。

**完整解答**：sin 的麦克劳林：sin x=x−x³/3!+…，取到 n=3：T₃(x)=x−x³/6。T₃(0.5)=0.5−0.5³/6=0.5−0.125/6=0.5−0.0208333=**0.4791667**。余项 R₃(0.5)=f⁗(c)·0.5⁴/4!，其中 f⁗(x)=sin x（四阶导），|f⁗(c)|=|sin c|≤1。故 |R₃(0.5)|≤1·0.5⁴/24=0.0625/24≈**0.002604**。所以 sin(0.5)≈0.4792，误差<0.0026。（实际 sin0.5≈0.47943，误差≈0.00026，在上界内 ✓。）

**题 C（概念，检查理解）**

(a) 泰勒多项式系数为什么是 f^(k)(a)/k!？
(b) 收敛半径 R=1 意味着什么？端点为什么要单独讨论？
(c) 拉格朗日余项为什么能用来估误差？估误差时要"界住"什么？

**完整解答**：
(a) 因为若 f(x)=Σcₖ(x−a)ᵏ，则 f^(k)(a)=k!·cₖ（第 k 项求导 k 次得 k!cₖ，其余项代 x=a 为 0），故 cₖ=f^(k)(a)/k!。
(b) R=1 意味着幂级数在 |x−a|<1 内收敛、|x−a|>1 发散。端点 x=a±1 处比值判别失效（L=1），需单独用交错/调和等判别——不同级数在端点可能收敛或发散（如 Σxⁿ/n 在 −1 条件收敛、Σxⁿ/n² 两端绝对收敛）。
(c) 拉格朗日余项 Rₙ=f^(n+1)(c)(x−a)^(n+1)/(n+1)! 给出了误差的精确表达式（含某 c），估误差时只需"界住"|f^(n+1)|≤M（在 a 与 x 之间的区间上），得 |Rₙ|≤M|x−a|^(n+1)/(n+1)!——不必知道 c 是谁。
