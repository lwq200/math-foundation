## 2. 交互组件验证表（11 个，含画布渲染 + 读数）

通用判定（对每个组件）：
- **无 pageerror / console.error**：监听 `page.on('pageerror')`、`page.on('console')`（type=error）。
- **画布 svg 渲染**：容器内出现 JSXGraph 注入的 `<svg>`，且非空（`svg path/circle/line` 数量 > 0）。
- **深色模式**：切换 `.dark` 后（见 §6）画布 svg 仍在、读数 DOM 不变。

### 2.1 EpsNSequences（册02-03 数列极限）
- 画布选择器：`.epsn-canvas .epsn-board svg`
- 读数选择器：`.epsn-canvas .epsn-readout`（含 `ε = …`、`门槛 N(ε) = ⌈1/ε⌉ = …`、`n > N 后落入带内的点数 = …`）
- 默认期望（ε=0.30）：
  - `ε = 0.30`
  - `门槛 N(ε) = ⌈1/ε⌉ = 4`（⌈1/0.3⌉ = ⌈3.333⌉ = 4）
  - `n > N 后落入带内的点数 = 31`（n=5..35 共 31 个点，均满足 |1/n|<0.3）
- 附加：拖动 ε 滑杆后 N 变化（可省）。

### 2.2 LimitEpsilonDelta（册02-04 函数极限）
- 画布选择器：`.eps-canvas .eps-board svg`
- 读数选择器：`.eps-canvas .eps-readout`（含 `ε = …`、`δ = …`、状态文案）
- 默认期望（ε=0.80, δ=1.20，lim_{x→2}x²=4）：
  - `ε = 0.80`、`δ = 1.20`
  - 状态为 **out**（文案含 `✗ 曲线穿出 ε 带！δ 还不够小`）——因为在 x∈[0.8,3.2] 上 y=x²，x=3.2 时 y=10.24 > L+ε=4.8，穿出
  - 参考值 `δ = min(1, ε/5) = 0.16`

### 2.3 TangentExplorer（册03-01 导数）
- 画布选择器：`.tangent-canvas .tan-board svg`
- 读数选择器：`.tangent-canvas .tan-readout-static`（含 `切点 a = …，差商 = …，f'(a) = …`）
- 默认期望（a=1, h=1, 函数 x²）：
  - `切点 a = 1.00`
  - `差商 = 3`（(f(2)−f(1))/1 = (4−1)/1 = 3）
  - `f'(a) = 2`（(x²)'=2x @ x=1 → 2）
- 附加：切到 `|x|` 且 a→0 时差商符号冲突（可省）。

### 2.4 RiemannSum（册03-04 积分与FTC）
- 画布选择器：`.riemann-canvas .riemann-board svg`
- 读数选择器：`.riemann-canvas .riemann-readout`（含 `n = …`、左/右/中点和、`真值 = 8/3 ≈ 2.6667`、`|M(n) − 真值| = …`）
- 默认期望（n=8，∫₀²x²dx = 8/3）：
  - `n = 8`
  - 文案含 `真值 = 8/3 ≈ 2.6667`
  - 中点 `M(8) ≈ 2.6667`（|M−真值| 极小，≤0.03 视为通过）

### 2.5 DotProduct（册04-01 向量）
- 画布选择器：`.dp-canvas .dp-board svg`
- 读数选择器：`.dp-canvas .dp-readout`（含 `|u|`、`|v|`、`u·v`、`cosθ`、`θ`、`投影 |u|cosθ`）
- 默认期望（u=(3,1), v=(1,2.2)）：
  - `|u| = 3.162`、`|v| = 2.417`
  - `u·v = 5.200`（3×1 + 1×2.2）
  - `cosθ = 0.6804`、`θ = 47.1`
  - `投影 |u|cosθ = 2.152`（5.2/2.4166）

### 2.6 MatrixTransform（册04-06 特征值与特征向量）
- 画布选择器：`.mt-canvas .mt-board svg`
- 读数选择器：`.mt-canvas .mt-matrix`（含 `A = [[a, b], [c, d]]`）
- 默认期望（a=1, b=0, c=0, d=1，恒等）：
  - `A = [[1.0, 0.0], [0.0, 1.0]]`
- 附加：点「缩放 (2,1)」按钮 → `A = [[2.0, 0.0], [0.0, 1.0]]`（可省）。

### 2.7 GradientDescent（册05-06 梯度下降）
- 画布选择器：`.gd-canvas .gd-board svg`
- 读数选择器：`.gd-canvas .gd-readout`（含 `η = …`、`步数 = …`、`当前点`、`f = …`、状态）+ 按钮 `.gd-canvas .gd-btn`
- 默认期望（η=0.06, 起点 (1.5,1.5), 未走步）：
  - `η = 0.06`、`步数 = 0`
  - `当前点 (1.500, 1.500)`、`f = 22.5000`（1.5²+9·1.5² = 2.25+20.25 = 22.5）
  - 状态 `迭代中…`

### 2.8 CDFExplorer（册06-03 随机变量与分布）
- 画布选择器：`.cdf-canvas .cdf-board svg`
- 读数选择器：`.cdf-canvas .cdf-readout`（含 `x`、`PDF f(x) = φ(x)`、`CDF F(x) = Φ(x)`）
- 默认期望（x=0.5，标准正态）：
  - `x = 0.50`
  - `PDF f(x) = φ(x) = 0.3521`（e^{−0.125}/√(2π) ≈ 0.3521）
  - `CDF F(x) = Φ(x) = 0.6915`（Φ(0.5) ≈ 0.6915）

### 2.9 CLTSampling（册06-05 频率派统计）
- 画布选择器：`.clt-canvas .clt-board svg`
- 读数选择器：`.clt-canvas .clt-readout`（含 `n = …`、`已采样均值数`、`理论 σ = √(1/12n)`）
- 默认期望（n=5）：

  - `理论 σ = √(1/12n) = 0.1291`（√(1/60) ≈ 0.1291）

### 2.10 NormalDistSlider（册06-07 常见分布族）
- 画布选择器：`.nds-canvas .nds-board svg`
- 读数选择器：`.nds-canvas .nds-readout`（含 `μ`、`σ`、`峰值 f(μ)`、`曲线下面积恒 = 1`）

  - `μ = 0.00`、`σ = 1.00`

### 2.11 KLDivergence（册06-09 互信息与KL散度）

## 6. 深色模式验证

- 触发：`await page.evaluate(() => document.documentElement.classList.add('dark'))`（等价于 VitePress 主题切换）。
- 断言（对每个含组件的页面，见 §2 全部 11 组件）：
  - 切换后 `.xxx-board svg`（画布 svg）**仍存在且非空**（MutationObserver 未把画布弄丢）。
  - 读数 DOM `.xxx-readout` 文本不变。
  - 不产生新的 pageerror。
- 公式可读：含 KaTeX 的页面（如 P7 册03-04、P10 册04-06）切换后 `.katex` 仍在且无 `.katex-error`。
- mermaid：切换后 `.mermaid svg` 仍存在（颜色走 CSS 变量，无需重渲染）。
- **知识锚点块（美学审查反馈，已知内容层问题）**：册02/03/04 的知识锚点块大量使用内联
  `<blockquote style="background:#fff8e1/#e3f2fd/#e8f5e9">`，内联 style 优先级高于 custom.css 的
  `--vp-c-bg-soft` 处理，深色模式下会保持刺眼亮块。重点抽查：
  - P4 册02-04 函数极限（`#fff8e1` 系）
  - P6 册03-01 导数（`#fff8e1` 系）
  - P9 册04-01 向量（`#e3f2fd`/`#e8f5e9` 系）
  验证方式：切换到 `.dark` 后，取 `blockquote[style*="background"]` 的 computed `background-color`，
  若仍为浅色（亮度高）即标记为**内容层问题（需主笔改正文，非 CSS 可救）**，记录但不阻断其他断言。
  > 注意：册05/06 为裸 blockquote（正常），不在本检查内。
  > 建议在 diag-all.mjs 的 `checkDarkMode` 中对含此类 blockquote 的页面追加采集 `blockquote[style*="background"]` 的个数与背景色。
