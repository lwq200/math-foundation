# 第 03 章 · 中值定理——平均速度，途中某点真的会达到吗

> 本章从哪个问题出发：你开车从 A 到 B，共 60 分钟走了 60 公里，平均速度 60 km/h。一个看似平凡却深刻的问题：**途中某个时刻，你的瞬时速度一定恰好是 60 km/h 吗？** 换句话说——**一段路程的平均变化率，函数在途中某点真的会"达到"吗？**
> 推导到哪个结论：答案是"会"，而且这是微积分最深刻的定理之一。你会从**费马引理**（局部极值处导数为 0）出发，一步步搭起一座阶梯：**罗尔定理 → 拉格朗日中值定理 → 柯西中值定理**。拉格朗日的证明靠"构造辅助函数 + 罗尔"，而那个辅助函数的几何意义，正是"曲线到割线的竖直距离"。中值定理是下一章积分（FTC）与后面泰勒展开的共同地基。
>
> 核心认知：**中值定理 = "平均变化率 = 某点的瞬时变化率"。** 它把"整体平均"和"局部瞬时"连成一句话：在 (a,b) 内至少存在一点 c，使 f'(c) = (f(b)−f(a))/(b−a)。**这条链（费马→罗尔→拉格朗日→柯西）是"导数能反推函数行为"的钥匙——用它证不等式、判常数、估误差，全是微积分的看家本领。**

## 引子

老谟把两把尺子摆在我面前：一把是直的，另一把是一段弯的塑料软尺，我把软尺两端按在直尺上，中间拱起一条弧。

"你看，我把软尺两端压到直尺的 0 和 6 两个刻度上，"老谟说，"**弧线两端的'高度'一样（都在直尺上），但中间是拱起来的。** 你说，这条弧线在 0 到 6 之间，有没有一个点的'切线是水平的'？"

我盯着那道拱起来的弧。"……有吧？拱到最高的那个点，切线不就是水平的吗？可你说这个干嘛？"

"这个'拱起来的弧'，数学里叫**连续函数**。**而'两端同高、中间必有一个水平切线的点'，就是本章第一座定理——罗尔定理。**"老谟把直尺抽走，"可如果两端**不同高**呢？比如起点海拔 100，终点海拔 120，中间有个平均坡度——**你敢不敢说，途中某个点的'瞬时坡度'，正好等于这个平均坡度？**"

我心里隐隐觉得"应该对"，可嘴上说不清"凭什么"。老谟看出我的犹豫，把那道弧轻轻一按："你把这问题记下——**它叫中值定理，是微积分最值钱的一个'为什么'。**"

## 对话引擎

### 第 1 轮：平均速度会被"达到"吗——一个深刻的直觉

**老谟**："先回到开车。**你 60 分钟走 60 公里，平均 60。** 我问你——**会不会出现这种情况：你一路有时快有时慢，但'从来没有任何一个时刻'瞬时速度恰好是 60？** 你凭直觉说。"

**造物主**："……直觉上不会。你都平均 60 了，从慢到快（或从快到慢）总得'穿过'60 吧？**就像你从 0 加速到 100，中间一定会经过 60。** 可要我证明'为什么一定会经过'，我又觉得无从下手。"

**老谟**："你的直觉叫**中值定理**，你的无从下手叫**证明还没搭起来**。**先把'速度'换成数学——设 s(t) 是 t 时刻的位置，平均速度是 (s(b)−s(a))/(b−a)。** 那问题变成：**能不能找到某个 t=c，使 s'(c) = 平均速度？** 这一章，我们搭三座台阶从'局部极值'走到这个结论。**第一座台阶，叫费马引理——'如果函数在某点取到局部最大或最小，那这点的导数是 0'。** 你说，拱起来的弧，最高点切线为什么水平？"

---

### 📐 知识锚点：问题的数学化与"变化率"的桥梁
<blockquote style="background:#fff8e1">

【概念深挖】**问题数学化**：设 f 在 [a,b] 上连续、在 (a,b) 上可导。平均变化率 = (f(b)−f(a))/(b−a)。**中值定理问：是否存在 c∈(a,b) 使 f'(c) = (f(b)−f(a))/(b−a)？**——"平均变化率在某点被瞬时达到"。

**为什么要先看"局部极值"**：平均速度要"被达到"，最自然的突破口是——**如果某点取到局部最大/最小，它的导数是 0（切线水平）**。而"水平切线"（f'=0）正是"平均变化率=0"的特例。**从"局部极值导数为 0"（费马）出发，再推广到"任意平均斜率"，是一条阶梯。**

【工程实践】"平均某点被达到"在工程里的直觉：**一段行程的平均油耗、一批产品的平均质量，通常在某一点/某一时刻会被'个别'地实现**。中值定理给这种"平均必有代表点"的直觉以严格保证——**它是"用平均值反推局部性质"的理论根基**（误差分析、数值算法都靠它）。
</blockquote>

### 第 2 轮：费马引理——局部极值处的切线为什么是水平的

**老谟**："先钉第一座台阶。**设 f 在 c 取到局部最大值**（c 附近的所有 f(x) ≤ f(c)）。我们想证 **f'(c) = 0**。**你先想：f'(c) 是差商的极限，那这个差商，在 c 的'左边'和'右边'，符号会怎样？**"

**造物主**："……如果 c 是局部最大，那 c 右边的 x>c 有 f(x)≤f(c)，所以分子 f(x)−f(c)≤0，分母 x−c>0，**差商 ≤ 0**。而 c 左边的 x<c，分子 f(x)−f(c)≤0，分母 x−c<0，**差商 ≥ 0**。"

**老谟**："**漂亮。所以右差商（h>0）≤ 0，左差商（h<0）≥ 0。** 可 f'(c) 是极限，左右差商极限都要等于它。你说，**一个数要同时满足'右边逼来的 ≤0'和'左边逼来的 ≥0'，它只能是谁？**"

**造物主**："……只能等于 0！**因为右极限 ≤0 且左极限 ≥0，两者相等，就只能都是 0。** 所以 f'(c)=0。我懂了——局部极值处的切线必然是水平的。"

**老谟**："**费马引理你亲手推出来了。** 注意它用的是'局部'——只在 c 的一个小邻域里最大/最小就行，不要求全局。**下一轮，我们把这条引理用来证明'两端同高必有水平切线'（罗尔定理）。**

### 📐 知识锚点：费马引理——"局部极值 ⟹ 导数 0"
<blockquote style="background:#e3f2fd">

【概念深挖】**费马引理（Fermat's theorem）**：设 f 在 c 处可导，且 f 在 c 取**局部极大值或极小值**（即存在 δ>0，使对 |x−c|<δ 有 f(x)≤f(c) 或 f(x)≥f(c)）。则 **f'(c) = 0**。

**证明思路（左右差商符号夹逼）**：
- 若 f 在 c 取局部最大：h>0 时差商 (f(c+h)−f(c))/h ≤ 0；h<0 时差商 ≥ 0。
- 由于 f'(c) = lim 差商存在，右极限 ≤0、左极限 ≥0 且相等，故 f'(c)=0。
- 局部最小同理（不等号反向，结论相同）。

**为什么"局部"够用**：只要求"c 的一个小邻域内"是极值，不要求全局最大/最小。**这放宽了条件，让费马引理应用极广。**

【历史溯源】**皮埃尔·德·费马（Pierre de Fermat，17 世纪）**用"取极小间隔"求切线极值，是导数思想的先驱——他其实已经摸到"极值处导数为 0"的边。**这个引理后来成为严格证明的基石**：它把"极值"这个几何直觉，落成了"导数=0"这个代数事实。
</blockquote>

### 第 3 轮：罗尔定理——两端同高，中间必有水平切线

**老谟**："现在用费马引理证罗尔定理。**设 f 在 [a,b] 连续、在 (a,b) 可导、且 f(a)=f(b)。** 要证：存在 c∈(a,b) 使 f'(c)=0。**你手上现在有：费马引理（局部极值⟹导0），还差一个'确定存在局部极值'的前提。** 你说，怎么保证 f 在 [a,b] 上一定有局部极值？"

**造物主**："……**f 在闭区间 [a,b] 上连续，那它一定有最大值和最小值**（这是册02 的极值定理/完备性的推论）！可最大最小值可能在端点……端点上 f(a)=f(b)，那如果最大最小都在端点，就说明 f 是常数，处处导数 0，也成。**如果最大或最小在内部点 c，那 c 就是局部极值，由费马引理 f'(c)=0。**"

**老谟**："**你分情况把罗尔定理证完了。** 分两种：① f 是常数 ⟹ 处处 f'=0；② f 非常数 ⟹ 至少一个极值在内部点 c，费马引理给 f'(c)=0。**注意你用了'闭区间连续 ⟹ 有最大最小值'这条——它是册02 完备性（上确界公理）的直接后果，是罗尔定理的'存在性'根基。** 完整可复写证明在走廊定理 2。"

**造物主**："……我有个疑问：**为什么必须'闭区间连续 + 开区间可导'？** 端点为什么不算？"

**老谟**："**好问题。可导只在开区间要求**，是因为端点处'导数'没定义（差商只能单边）——我们在 (a,b) 内找极值点，所以只要求开区间可导。**而'闭区间连续'是保证最大最小值存在（极值定理需要闭区间）。** 这两个条件各管一件事，缺一不可。下一轮，我们把'两端同高'推广到'两端任意高'——拉格朗日中值定理。"

### 📐 知识锚点：罗尔定理——"两端同高 ⟹ 内部有水平切线"
<blockquote style="background:#fff8e1">

【概念深挖】**罗尔定理（Rolle's theorem）**：设 f 在 [a,b] 上连续、在 (a,b) 上可导、且 f(a)=f(b)。则存在 c∈(a,b)，使 **f'(c) = 0**。

**证明思路（费马引理 + 极值定理）**：
1. f 在 [a,b] 连续 ⟹ 有最大值 M 与最小值 m（极值定理，册02 完备性）。
2. **若 M=m**：f 是常数，任取 c∈(a,b) 都有 f'(c)=0。
3. **若 M>m**：因 f(a)=f(b)，M 和 m 不可能都只在端点取到（否则 f(a)=f(b) 会推出 M=m）。故至少一个极值在内部点 c∈(a,b) 取到。
4. 由费马引理，f'(c)=0。

**几何意义**：两端同高的连续曲线，中间至少有一个点的切线是水平的（平行于两端连线）。

【历史溯源】**米歇尔·罗尔（Michel Rolle，1691）**最初用这个结果研究多项式方程根的分布（他本人是代数专家，曾批评微积分）。**后来它成为分析的基本定理**，被用来证明拉格朗日中值定理——虽然罗尔当年并未把它当作"中值定理"来用。
</blockquote>

### 第 4 轮：拉格朗日中值定理——构造辅助函数，把"不同高"转成"同高"

**老谟**："罗尔要求'两端同高'，可一般函数两端**不同**高。**怎么把'不同高'变成'同高'？** 提示你：把函数"拉平"——**想象一条割线（连接 (a,f(a)) 和 (b,f(b)) 的直线），把曲线'减去'这条割线。** 你说，减完之后的函数，两端会怎样？"

**造物主**："……减完割线后，**两端的高度都变成 0**？因为割线在 a 处等于 f(a)、在 b 处等于 f(b)，曲线减割线，两端就是 f(a)−f(a)=0 和 f(b)−f(b)=0——**两端同高了！那就能用罗尔！**"

**老谟**："**你抓到了拉格朗日证明的钥匙——辅助函数 g(x) = f(x) − (割线)。** 割线在 x 处的高度是 f(a) + [(f(b)−f(a))/(b−a)](x−a)。**所以 g(x) = f(x) − f(a) − [(f(b)−f(a))/(b−a)](x−a)。** g 满足罗尔（g(a)=g(b)=0），于是存在 c 使 g'(c)=0。**你说，g'(c)=0 能推出什么？**"

**造物主**："……g'(x) = f'(x) − (f(b)−f(a))/(b−a)。**那 g'(c)=0 ⟹ f'(c) = (f(b)−f(a))/(b−a)——这正是中值定理！**"

**老谟**："**成了。** 那个辅助函数 g(x) 的几何意义，就是'曲线到割线的竖直距离'——把它压平到两端同高，再用罗尔。**完整证明在走廊定理 3。** 下一轮，我们把这条定理再推广一步，得到柯西中值定理。"

### 📐 知识锚点：拉格朗日中值定理——"平均斜率 = 某点瞬时斜率"
<blockquote style="background:#e3f2fd">

【概念深挖】**拉格朗日中值定理（Lagrange's Mean Value Theorem, MVT）**：设 f 在 [a,b] 上连续、在 (a,b) 上可导。则存在 c∈(a,b)，使
$$f'(c) = \frac{f(b)-f(a)}{b-a}.$$

**几何意义**：连接两端点的**割线**斜率 = (f(b)−f(a))/(b−a)，定理说**至少有一个点的切线平行于这条割线**。

**辅助函数方法（证明核心）**：构造
$$g(x) = f(x) - f(a) - \frac{f(b)-f(a)}{b-a}(x-a).$$
- **g(a)=g(b)=0**（把"不同高"压成"同高"）；
- g 连续可导（由 f 与线性函数组合）；
- 对 g 用罗尔 ⟹ 存在 c 使 g'(c)=0 ⟹ f'(c)=(f(b)−f(a))/(b−a)。

**"构造辅助函数"的思维**：**把不满足定理前提的题目，通过加减一个"补偿函数"，改造成满足前提的形式。** 这是分析里最通用的一招——后面泰勒定理、FTC 都会反复用到。

【历史溯源】**约瑟夫-路易·拉格朗日（Joseph-Louis Lagrange，1797）**在《解析函数论》里系统化这个结果（尽管罗尔已先有特例）。**它把"导数"与"函数在区间上的整体变化"连起来**——从此"知道导数 ⟹ 反推函数增量"成为可能，这是泰勒展开与误差估计的基石。
</blockquote>

### 第 5 轮：柯西中值定理——两个函数"同步"的平均斜率

**老谟**："MVT 推广一步，就是柯西中值定理。**有时候你不只关心一个函数 f 的变化，还关心它'相对'另一个函数 g 的变化——比如 f 对 y、y 对 x。** 柯西定理说：如果 f、g 都在 [a,b] 连续、在 (a,b) 可导、且 g' 在 (a,b) 不为 0，则存在 c，使
$$\frac{f'(c)}{g'(c)} = \frac{f(b)-f(a)}{g(b)-g(a)}.$$
**你能不能猜——它怎么证？** 还是老套路：构造辅助函数，让两端同高，用罗尔。"

**造物主**："……**还是'减去割线'？** 只是这次要同时压平 f 和 g？我构造 h(x) = f(x) − f(a) − [(f(b)−f(a))/(g(b)−g(a))](g(x)−g(a))。**h(a)=f(a)−f(a)−0=0，h(b)=f(b)−f(a)−[(f(b)−f(a))/(g(b)−g(a))](g(b)−g(a))=f(b)−f(a)−(f(b)−f(a))=0。** 两端同高！用罗尔，存在 c 使 h'(c)=0 ⟹ f'(c) − [(f(b)−f(a))/(g(b)−g(a))]g'(c)=0 ⟹ **f'(c)/g'(c) = (f(b)−f(a))/(g(b)−g(a))**。成了！"

**老谟**："**你把柯西中值定理也证出来了——和拉格朗日同一个辅助函数套路，只是'压平'的对象从'单个 f 对 x'变成了'f 对 g'。** 你注意到没有，**g'(x)≠0 保证了分式有意义**（不然 g(b)−g(a) 可能为 0，且 g' 在分子分母都出现）。**下一轮，我们看看这一整座阶梯能拿来干嘛——它是'证明不等式''判常数''估误差'的万能钥匙。**"

### 📐 知识锚点：柯西中值定理——"两个函数的平均斜率之比"
<blockquote style="background:#fff8e1">

【概念深挖】**柯西中值定理（Cauchy's Mean Value Theorem）**：设 f、g 在 [a,b] 连续、在 (a,b) 可导，且 g'(x)≠0 对一切 x∈(a,b)。则存在 c∈(a,b)，使
$$\frac{f'(c)}{g'(c)} = \frac{f(b)-f(a)}{g(b)-g(a)}.$$

**证明思路**：构造 h(x) = f(x) − f(a) − [(f(b)−f(a))/(g(b)−g(a))](g(x)−g(a))，则 h(a)=h(b)=0，对 h 用罗尔。

**前提 g'≠0 为什么重要**：① 保证 g(b)≠g(a)（否则由罗尔，存在 c 使 g'(c)=0，矛盾）；② 保证 f'/g' 和 (f(b)−f(a))/(g(b)−g(a)) 都有意义。**当 g(x)=x 时，柯西定理退化为拉格朗日中值定理**（g'=1、g(b)−g(a)=b−a）。

**用途**：它比 MVT 更强，是**证明洛必达法则、泰勒定理的余项、以及各种比值型不等式**的关键工具。

【历史溯源】**奥古斯丁-路易·柯西（Augustin-Louis Cauchy，1823）**给出这个"比值形式"的中值定理。**它与拉格朗日、罗尔一起，构成"导数反推函数"的完整阶梯**——柯西版本把 MVT 的"差值"升级成"比值"，为后面的极限求解（洛必达）与误差估计铺路。
</blockquote>

### 第 6 轮：中值定理能干什么——证不等式、判常数、估误差

**老谟**："这座阶梯搭起来了。**那它到底能干嘛？** 给你三个现场——**第一个：证不等式。** 老谟举了个例子：对 x>0，证明 **ln(1+x) < x**。你想想，怎么用 MVT？提示：对 ln(1+t) 在 [0,x] 上用 MVT。"

**造物主**："……设 f(t)=ln(1+t)，在 [0,x] 上连续、在 (0,x) 可导（x>0）。MVT：存在 c∈(0,x) 使 f'(c) = (f(x)−f(0))/(x−0) = ln(1+x)/x。而 f'(t)=1/(1+t)，所以 **ln(1+x)/x = 1/(1+c)**。因为 c>0，1/(1+c)<1，所以 ln(1+x)/x<1，即 **ln(1+x)<x**！"

**老谟**："**对，MVT 把'对数不等式'转化成了'对 1/(1+c) 的大小判断'。** 第二个现场——**判常数**：如果 f'(x)=0 对 (a,b) 内一切 x 成立，你能推出 f 是常数吗？"

**造物主**："……**能！** 任取 x₁<x₂∈(a,b)，MVT：存在 c 使 f(x₂)−f(x₁)=f'(c)(x₂−x₁)=0，所以 f(x₂)=f(x₁)。**任意两点函数值相等，f 就是常数！**"

**老谟**："**对。第三个现场——估误差**：对任意 a<b，证明 **|sin b − sin a| ≤ |b−a|**。用 MVT。"

**造物主**："……对 sin 在 [a,b] 用 MVT：存在 c 使 (sin b − sin a)/(b−a) = cos c，所以 sin b − sin a = cos c·(b−a)，取绝对值：**|sin b−sin a|=|cos c|·|b−a|≤|b−a|**（因 |cos|≤1）。这就是'sin 是 1-Lipschitz'的意思！"

**老谟**："**三个现场全打通了——证不等式、判常数、估误差。** 这就是中值定理的'用途'。完整证明放走廊，下一轮我们收章。"

### 📐 知识锚点：中值定理的三大用途
<blockquote style="background:#e3f2fd">

【概念深挖】**中值定理的三大用途**：
1. **证不等式**：把"函数不等式"转化为"导函数在某点的大小"。例：ln(1+x)<x（对 ln(1+t) 用 MVT，得 ln(1+x)/x=1/(1+c)<1）。
2. **判常数/单调**：若 f'(x)=0 于 (a,b)，则 f 在 (a,b) 为常数（任取两点用 MVT）；若 f'(x)>0，则 f 严格递增（f(x₂)−f(x₁)=f'(c)(x₂−x₁)>0）。
3. **估误差 / Lipschitz 界**：若 |f'(x)|≤M，则 |f(b)−f(a)|≤M|b−a|（Lipschitz 连续）。例：|sin b−sin a|≤|b−a|。

**常用不等式库（由 MVT 推出）**：
- x>0：x/(1+x) < ln(1+x) < x。
- e^x ≥ 1+x（对 e^t 在 [0,x] 或 [x,0] 用 MVT）。
- |sin b − sin a| ≤ |b−a|（sin 的 1-Lipschitz 性）。

【工程实践】中值定理是**数值误差分析的地基**：**数值方法（差分、积分、根逼近）的误差上界，几乎都来自中值定理/泰勒余项**。比如"用割线近似函数在某点误差多少"，靠的就是 MVT 的"平均等于某点瞬时"。**工程师估误差、定步长、分析算法收敛速度，背后都是这条定理。**

### 定义/引理：费马引理（精确表述）

**费马引理（Fermat's theorem）**：设 f 在 c 处可导，且 f 在 c 取局部极大值或极小值（存在 δ>0，使 |x−c|<δ ⟹ f(x)≤f(c) 或 f(x)≥f(c)）。则 **f'(c) = 0**。

**证明类型**：直接证明（左右差商符号夹逼 + 极限唯一性）。

**证明（费马引理）**：
- 第 1 步：设 f 在 c 取局部最大（局部最小同理，不等号反向）。则存在 δ>0，使 |h|<δ 时 f(c+h)≤f(c)。（依据：局部最大定义。）
- 第 2 步：对 h>0（h<δ），差商 (f(c+h)−f(c))/h ≤ 0（分子≤0、分母>0）。（依据：代数符号 + 局部最大。）
- 第 3 步：对 h<0（−h<δ），差商 (f(c+h)−f(c))/h ≥ 0（分子≤0、分母<0）。（依据：代数符号。）
- 第 4 步：因 f'(c) = lim_{h→0} 差商存在，左右极限必须都等于 f'(c)。由第 2 步，右极限 ≤ 0；由第 3 步，左极限 ≥ 0。故 f'(c) ≤ 0 且 f'(c) ≥ 0，即 **f'(c) = 0**。（依据：极限的保序性 + 左右极限等于导数。）
- 第 5 步：局部最小情形同理（第 2、3 步不等号反向，结论相同）。∎

> **依据标注**：步 1 用局部极值定义；步 2、3 用"分子符号 × 分母符号"的代数；步 4 用"导数=左右极限且极限保序"（左右同时夹出 0）；步 5 对称情形。

### 定理 1（罗尔定理）：f 在 [a,b] 连续、在 (a,b) 可导、f(a)=f(b) ⟹ 存在 c∈(a,b) 使 f'(c)=0

**前提**：f 在 [a,b] 上连续、在 (a,b) 上可导、f(a)=f(b)。**（需用"极值定理"：f 在 [a,b] 连续 ⟹ 有最大值 M、最小值 m——这由册02 上确界公理（完备性）保证。）**

**证明类型**：直接证明（极值定理 + 费马引理，分"常数/非常数"两情形）。

**证明**：
- 第 1 步：由极值定理（f 在闭区间 [a,b] 连续），f 在 [a,b] 上有最大值 M 与最小值 m。（依据：极值定理，册02 完备性。）
- 第 2 步：**情形一：M = m**。则 f 在 [a,b] 恒等于常数 M，故对任意 c∈(a,b)，f'(c)=0。（依据：常函数导数为 0，或直接差商恒 0。）
- 第 3 步：**情形二：M > m**。因 f(a)=f(b)，M 与 m 不可能都只在端点 {a,b} 取到（若都在端点，则 f(a)、f(b) 同为最大或最小，会推出 M=m）。故至少存在一个内部点 c∈(a,b)，使 f(c)=M 或 f(c)=m（即 c 是 f 在 [a,b] 上的全局极值点，从而也是局部极值点）。（依据：极值定理 + f(a)=f(b) 排除"极值全在端点"。）
- 第 4 步：由费马引理，f'(c)=0。（依据：费马引理——c 是局部极值点且 f 在 c 可导。）
- 第 5 步：两情形都得到存在 c∈(a,b) 使 f'(c)=0。∎

> **依据标注**：步 1 用极值定理（闭区间连续 ⟹ 有最大最小值，册02 完备性）；步 2 用常函数；步 3 用"f(a)=f(b) 排除极值全在端点"（关键：保证内部存在极值点）；步 4 用费马引理；步 5 收束。
> **读法**：罗尔定理的两情形划分是核心——**"常数"情形直接过，"非常数"情形靠"f(a)=f(b)"逼出至少一个内部极值点**，再交给费马。**注意它用到了册02 的完备性（极值定理）**——这是"内部极值点存在"的根基，没有闭区间连续就没有最大最小值。

### 定理 2（拉格朗日中值定理，MVT）：f 在 [a,b] 连续、在 (a,b) 可导 ⟹ 存在 c∈(a,b) 使 f'(c)=(f(b)−f(a))/(b−a)

**前提**：f 在 [a,b] 上连续、在 (a,b) 上可导。

**证明类型**：构造性证明 + 罗尔定理（构造辅助函数压平到两端同高，对辅助函数用罗尔）。

**证明**：
- 第 1 步：**构造辅助函数**（关键）：
  $$g(x) = f(x) - f(a) - \frac{f(b)-f(a)}{b-a}(x-a).$$
  （依据：g(x) 表示"曲线 f 到割线"的竖直距离——割线在 x 处高度为 f(a)+[(f(b)−f(a))/(b−a)](x−a)。）
- 第 2 步：**验证 g 满足罗尔条件**：
  - g(a) = f(a)−f(a)−0 = 0；g(b) = f(b)−f(a)−[(f(b)−f(a))/(b−a)](b−a) = f(b)−f(a)−(f(b)−f(a)) = 0。故 **g(a)=g(b)=0**。（依据：代入化简。）
  - g 在 [a,b] 连续（f 连续 + 线性项连续）、在 (a,b) 可导（f 可导 + 线性项可导）。（依据：连续性/可导性对加减与数乘保持。）
- 第 3 步：由罗尔定理（定理 1），存在 c∈(a,b) 使 **g'(c)=0**。（依据：罗尔定理，g 满足全部前提。）
- 第 4 步：计算 g'(x)：
  $$g'(x) = f'(x) - \frac{f(b)-f(a)}{b-a}.$$
  （依据：逐项求导——f'(x) 减去常系数 [(f(b)−f(a))/(b−a)]·1。）
- 第 5 步：由 g'(c)=0 代入第 4 步：f'(c) − (f(b)−f(a))/(b−a) = 0，故 **f'(c) = (f(b)−f(a))/(b−a)**。（依据：代数移项。）
- 第 6 步：结论成立。∎

> **依据标注**：步 1 用辅助函数构造（把"不同高"压成"同高"）；步 2 用代入化简 + 连续/可导的线性保持；步 3 用罗尔定理；步 4 用逐项求导（常数因子提出）；步 5 用代数移项。
> **读法**：整个证明的钥匙是第 1 步的辅助函数——**用"减割线"把 f 的"两端不同高"压成"两端同高（0）"，从而能用罗尔**。**这个"构造辅助函数把问题改造成可套用已知定理"的套路，是本章乃至全册最重要的证明方法**——泰勒定理、FTC 都靠它。

### 定理 3（柯西中值定理）：f、g 在 [a,b] 连续、在 (a,b) 可导、g'≠0 于 (a,b) ⟹ 存在 c∈(a,b) 使 f'(c)/g'(c) = (f(b)−f(a))/(g(b)−g(a))

**前提**：f、g 在 [a,b] 上连续、在 (a,b) 上可导，且 g'(x)≠0 对一切 x∈(a,b)。

**证明类型**：构造性证明 + 罗尔定理（构造辅助函数压平 f 对 g，用罗尔）。

**证明**：
- 第 1 步：**先证 g(b)≠g(a)**：反证。若 g(b)=g(a)，则 g 满足罗尔条件（连续、可导、两端同高），由罗尔存在 c 使 g'(c)=0，与前提 g'≠0 矛盾。故 g(b)≠g(a)。（依据：罗尔定理 + 前提 g'≠0。）
- 第 2 步：**构造辅助函数**（关键）：
  $$h(x) = f(x) - f(a) - \frac{f(b)-f(a)}{g(b)-g(a)}\big(g(x)-g(a)\big).$$
  （依据：类比拉格朗日，把"压平"对象从"x"换成"g(x)"。由第 1 步，分母 g(b)−g(a)≠0，定义合法。）
- 第 3 步：**验证 h 满足罗尔**：
  - h(a) = f(a)−f(a)−0 = 0；h(b) = f(b)−f(a)−[(f(b)−f(a))/(g(b)−g(a))](g(b)−g(a)) = f(b)−f(a)−(f(b)−f(a)) = 0。故 **h(a)=h(b)=0**。（依据：代入化简。）
  - h 在 [a,b] 连续、在 (a,b) 可导（f、g 连续可导，线性组合保持）。（依据：连续/可导的线性保持。）
- 第 4 步：由罗尔定理，存在 c∈(a,b) 使 **h'(c)=0**。（依据：罗尔。）
- 第 5 步：计算 h'(x)：
  $$h'(x) = f'(x) - \frac{f(b)-f(a)}{g(b)-g(a)}g'(x).$$
  （依据：逐项求导，常系数 [f(b)−f(a)]/[g(b)−g(a)] 提出。）
- 第 6 步：由 h'(c)=0：f'(c) − [(f(b)−f(a))/(g(b)−g(a))]·g'(c) = 0，即 **f'(c) = [(f(b)−f(a))/(g(b)−g(a))]·g'(c)**。因 g'(c)≠0（前提），两边除以 g'(c)：**f'(c)/g'(c) = (f(b)−f(a))/(g(b)−g(a))**。（依据：代数移项 + g'(c)≠0。）
- 第 7 步：结论成立。∎

> **依据标注**：步 1 用反证法 + 罗尔（证 g(b)≠g(a)，保证分母合法）；步 2 用辅助函数构造（类比拉格朗日，压平 f 对 g）；步 3 用代入化简 + 连续/可导线性保持；步 4 用罗尔；步 5 用逐项求导；步 6 用代数 + g'(c)≠0。
> **读法**：柯西中值定理是拉格朗日的"比值推广"——**把辅助函数从"减 x"改成"减 g(x)"，把分母从 (b−a) 改成 (g(b)−g(a))**。它比 MVT 更强（g(x)=x 时退回 MVT），是后面证洛必达法则、泰勒余项的关键。**步 1 用反证法证 g(b)≠g(a) 是严谨性的细节——不先保证分母不为 0，定义就不合法。**

### 中值定理证明的书写格式模板（可复写卡片——对着空白纸照写）

> 这是本章要你抄进脑子的卡。**以后你用中值定理证不等式/判常数/估误差，就照这个骨架走**：

```text
命题：……（要证的不等式 / 常数性 / 误差界）。
证明（用 MVT）：
  1. 选函数与区间：挑一个合适的 f 和区间 [a,b]（或 [a,x]），验证 f 在 [a,b] 连续、在 (a,b) 可导。
  2. 套 MVT：存在 c∈(a,b)，使 f'(c) = (f(b)−f(a))/(b−a)。
  3. 转化：把要证的东西翻译成"对 f'(c) 的某种大小/等式判断"。
  4. 用已知导数性质（如 1/(1+c) 的范围、|cos c|≤1、f'=0）完成判断。
  5. 收束。∎
```

**填写时的三个检查点**：① **先验证前提**（连续 + 开区间可导）——前提不满足，MVT 不能套；② **选对区间端点**（常把 [a,x] 当区间，用变量 x）；③ **把"存在 c"利用到要证的结论上**（别证到一半把 c 丢了）。

### 反例/边界：中值定理的适用边界

1. **"开区间可导"不可少**：f(x)=|x| 在 [−1,1] 连续、在 (−1,0)∪(0,1) 可导，但在 0 不可导（0∈(−1,1)），故 MVT 前提不满足。此时平均斜率 (|1|−|−1|)/(1−(−1))=0，但 f' 在 (−1,0)∪(0,1) 上恒为 ±1，**不存在 c 使 f'(c)=0**——MVT 结论失败。**这个反例说明"开区间可导"（含所有内部点）是必要条件。**
2. **"闭区间连续"不可少**：若 f 在 [a,b] 上有间断（不连续），极值定理失效，罗尔/MVT 都不保证。例：f(x)=1/x 在 (0,1) 可导但 [0,1] 不连续（0 处无定义），MVT 不适用。
3. **费马引理要求"可导"**：局部极值点若不满足可导（如 |x| 在 0 取极小值但不可导），不能断言 f'(0)=0（事实上 f'(0) 不存在）。**"极值 ⟹ 导数 0"依赖可导前提。**
4. **柯西定理要求 g'≠0**：若 g' 在 (a,b) 某处为 0，分式 f'/g' 无意义，柯西定理不适用。**先验证 g'≠0 再套。**
5. **"平均被达到"不保证"唯一"**：MVT 保证"至少存在一个" c，不保证唯一。**别把"存在 c"误解成"唯一 c"。**

## 知识点总结

### 知识点（本章推出的核心概念）

- **费马引理**：f 在 c 取局部极值且可导 ⟹ f'(c)=0。**左右差商符号夹逼。**
- **罗尔定理**：f 在 [a,b] 连续、在 (a,b) 可导、f(a)=f(b) ⟹ 存在 c 使 f'(c)=0。**费马引理 + 极值定理（完备性）。**
- **拉格朗日中值定理（MVT）**：f'(c) = (f(b)−f(a))/(b−a)。**构造辅助函数"减割线"压平到同高 + 罗尔。**
- **柯西中值定理**：f'(c)/g'(c) = (f(b)−f(a))/(g(b)−g(a))。**MVT 的比值推广，压平 f 对 g。**
- **中值定理三大用途**：证不等式（ln(1+x)<x）、判常数（f'=0⟹常数）、估误差（|sin b−sin a|≤|b−a|）。
- **"构造辅助函数"套路**：把不满足前提的题目，加减补偿函数改造成满足前提，再用已知定理。
- **MVT 前提**：闭区间连续（保最大最小值）+ 开区间可导（含所有内部点），缺一不可。

### 历史结论（本章涉及的史料）

- **费马（17 世纪）**：求切线极值的先驱，摸到"极值处导数 0"的边（费马引理的思想）。
- **罗尔（Rolle，1691）**：最初研究多项式方程根的分布，是"两端同高必有水平切线"的早期结果。
- **拉格朗日（Lagrange，1797）**：《解析函数论》系统化 MVT，把"导数 ⟹ 函数增量"连起来，是泰勒展开与误差估计的基石。
- **柯西（Cauchy，1823）**：给出比值形式的柯西中值定理，为洛必达法则、泰勒余项铺路。

### 工程实践结论（本章知识在真实工程里怎么用）

- **数值误差分析的地基**：差分、积分、根逼近的误差上界几乎都来自 MVT/泰勒余项——"平均等于某点瞬时"是误差估计的核心。
- **Lipschitz 界 = 稳定性/收敛性保证**：|f(b)−f(a)|≤M|b−a| 说明 f 变化受控，是数值算法稳定、可收敛的前提。
- **"f'=0⟹常数"= 恒定性判定**：若系统某变化率恒为 0，则对应量恒定，常用于守恒律/平衡态判断。
- **构造辅助函数 = 约束转标准型**：工程里常把非标准问题（两端不等高）改造成标准问题（同高）再套现成工具，与"减割线"同构。

## 计算训练场

> 位置说明：对话负责"为什么中值定理成立"，这里负责"怎么用"。下面三题**必须动笔**，每题 10 分钟以上，先自己写再对答案。**难度递进：易→中→难。** 重点是"选函数→验前提→套 MVT→利用存在 c→完成结论"。

### 题 1（易→中）：用 MVT 证不等式——ln(1+x) 的双边夹

**题干**：老谟让造物主用拉格朗日中值定理，对 x>0 证明 **x/(1+x) < ln(1+x) < x**（完整书写）。

**完整分步解答：**

- 第 1 步：**选函数与区间**：设 f(t)=ln(1+t)，在 [0,x] 上连续（t+1>0）、在 (0,x) 上可导（x>0）。前提满足 ✓。
- 第 2 步：**套 MVT**：存在 c∈(0,x)，使
  f'(c) = (f(x)−f(0))/(x−0) = (ln(1+x) − 0)/x = ln(1+x)/x。
- 第 3 步：**算 f'**：f'(t)=1/(1+t)。故 f'(c)=1/(1+c)，所以
  **ln(1+x)/x = 1/(1+c)**。
- 第 4 步：**利用 c 的范围**：因 0<c<x，取倒数：
  - c>0 ⟹ 1/(1+c)<1 ⟹ **ln(1+x)/x < 1 ⟹ ln(1+x) < x**。
  - c<x ⟹ 1+c < 1+x ⟹ 1/(1+c) > 1/(1+x) ⟹ **ln(1+x)/x > 1/(1+x) ⟹ ln(1+x) > x/(1+x)**。
- 第 5 步：**合并**：x/(1+x) < ln(1+x) < x。∎

**答**：对 x>0，x/(1+x) < ln(1+x) < x。**关键**：MVT 把对数不等式转化为"对 1/(1+c) 的大小判断"，而 c∈(0,x) 给出上下界。

**常见错误**：① 忘了验证"连续 + 开区间可导"前提；② 取倒数时方向搞反（c<x ⟹ 1+c<1+x ⟹ 1/(1+c)>1/(1+x)，分母小的倒数大）；③ 只证了一边（ln(1+x)<x），漏了 x/(1+x)<ln(1+x)。

### 题 2（中）：验证定理条件 + 求 c——x³ 与 |x| 的对照

**题干**：老谟给两个函数：
(a) 对 f(x)=x³ 在 [0,2] 上验证 MVT 条件，并求出满足 f'(c)=(f(2)−f(0))/(2−0) 的 c。
(b) 对 f(x)=|x| 在 [−1,1] 上，指出它为什么不满足 MVT 条件，并验证此时 MVT 结论确实不成立。

**完整分步解答：**

**(a) f(x)=x³ 在 [0,2]**：
- 第 1 步：**验条件**：f(x)=x³ 在 [0,2] 连续（多项式）、在 (0,2) 可导（多项式），前提满足 ✓。
- 第 2 步：**算平均斜率**：(f(2)−f(0))/(2−0) = (8−0)/2 = **4**。
- 第 3 步：**求 c**：MVT 说有 c∈(0,2) 使 f'(c)=4。f'(x)=3x²，解 3c²=4 ⟹ c²=4/3 ⟹ **c=2/√3 ≈ 1.155**（取正，因 c>0）。且 2/√3≈1.155∈(0,2) ✓。
- **答 (a)**：c = 2/√3 ≈ 1.155。

**(b) f(x)=|x| 在 [−1,1]**：
- 第 1 步：**验条件**：|x| 在 [−1,1] 连续 ✓，但在 (0,1) 与 (−1,0) 可导、**在 0 不可导**（折点，左右差商 ±1 不等）。因 0∈(−1,1)，**开区间可导不满足**，MVT 前提失败。
- 第 2 步：**看结论是否成立**：平均斜率 = (|1|−|−1|)/(1−(−1)) = (1−1)/2 = 0。若 MVT 成立，应存在 c∈(−1,1) 使 f'(c)=0。但 f'(x)=1（x>0）或 −1（x<0），在 (−1,0)∪(0,1) 上恒为 ±1，**不存在 c 使 f'(c)=0**。结论确实不成立。
- **答 (b)**：MVT 前提不满足（0 处不可导），且结论确实失败——**证明"开区间可导"（所有内部点）是必要条件**。

**常见错误**：① (a) 解 c²=4/3 时忘取正根（c 在 (0,2) 必须 >0）；② (b) 只说"不可导"没具体指出"0∈(−1,1) 这个内部点不可导"；③ 以为"连续 + 端点值相等"就够用罗尔/MVT——**必须"开区间处处可导"**。

### 题 3（难）：用 MVT 证常数性 + Lipschitz 界——综合应用

**题干**：老谟让造物主用中值定理完整证明两个结论：
(a) 若 f'(x)=0 对 (a,b) 内一切 x 成立，则 f 在 (a,b) 上是常数。
(b) 对任意 a<b，|sin b − sin a| ≤ |b−a|。

**完整分步解答：**

**(a) f'=0 ⟹ f 常数**：
- 第 1 步：任取 x₁<x₂∈(a,b)。f 在 [x₁,x₂] 连续、在 (x₁,x₂) 可导（由前提，f 在 (a,b) 处处可导）。前提满足 ✓。
- 第 2 步：由 MVT，存在 c∈(x₁,x₂) 使 f(x₂)−f(x₁)=f'(c)(x₂−x₁)。
- 第 3 步：因前提 f'(c)=0（c∈(a,b)），故 f(x₂)−f(x₁)=0，即 **f(x₂)=f(x₁)**。
- 第 4 步：任意两点函数值相等，故 **f 在 (a,b) 上是常数**。∎

**(b) |sin b − sin a| ≤ |b−a|**：
- 第 1 步：设 a<b（若 a>b 交换 a、b；a=b 时不等式平凡成立 0≤0）。sin 在 [a,b] 连续、在 (a,b) 可导，前提满足 ✓。
- 第 2 步：由 MVT，存在 c∈(a,b) 使 (sin b − sin a)/(b−a) = cos c，即 **sin b − sin a = cos c·(b−a)**。
- 第 3 步：两边取绝对值：|sin b − sin a| = |cos c|·|b−a| ≤ 1·|b−a|（因 |cos c|≤1）。
- 第 4 步：**|sin b − sin a| ≤ |b−a|**。∎（这就是"sin 是 1-Lipschitz"的意思。）

**答**：(a) f'=0 ⟹ f 常数（任取两点用 MVT）；(b) |sin b−sin a|≤|b−a|（MVT + |cos|≤1）。

**常见错误**：① (a) 只说了"直觉上导数 0 就常数"没走 MVT——必须任取两点用 MVT 严格证；② (a) 忘了"对任意 x₁<x₂"——必须覆盖所有点对；③ (b) 忘了处理 a>b 或 a=b 的情形（交换或平凡）。

## 向导便签

> 这一章咱们干了什么：把你那个"平均速度会被达到吗"的直觉，钉死成了一套完整的定理阶梯——**费马引理 → 罗尔定理 → 拉格朗日中值定理 → 柯西中值定理**。你亲手走通了每一座台阶，尤其是"构造辅助函数压平到两端同高、再用罗尔"这个最关键的方法。
>
> 钉死一句话：**中值定理 = "平均变化率在某点被瞬时达到"：f'(c) = (f(b)−f(a))/(b−a)；而它的证明钥匙，是"减去割线，把不同高压成同高，用罗尔"。**
>
> 记住：**这条阶梯是微积分"由导数反推函数"的第一把万能钥匙——证不等式（ln(1+x)<x）、判常数（f'=0⟹常数）、估误差（|sin b−sin a|≤|b−a|）全靠它。** 下一章，我们要用它来打通"变化"和"累积"——**微积分基本定理（FTC）：知道每刻速度，怎么拼回总路程？**

## 造物主手记

**我曾踩的坑**：

我第一次以为"平均速度一定会被达到"是理所当然，说不清"凭什么"——被老谟逼着从"局部极值导数为 0"（费马）一点一点搭起来。证罗尔时，我差点漏了"闭区间连续保证最大最小值"这个前提，也没想到"f(a)=f(b) 排除了极值全在端点"这一层。最险的是拉格朗日：我看不懂辅助函数 g(x)=f(x)−割线 是从哪冒出来的，被点破才明白——**它是"把曲线减去割线，让两端同高"的几何操作**。还有一次我用 MVT 证 ln(1+x)<x 时，取倒数把方向搞反了（c<x 时 1/(1+c)>1/(1+x)，不是小于）。

**顿悟时刻**：

真正开窍是"构造辅助函数"那一幕——**把不满足定理前提的题目，通过加减一个补偿函数，改造成满足前提的形式**。原来拉格朗日没发明新证明，他只是"减掉一条割线"，把"两端不同高"变成"两端同高"，然后交给罗尔。这个"改造成能套用已知定理"的思维，比中值定理本身更值钱——**它是我后面读泰勒、读 FTC 时，反复看到的同一个动作**。而"平均速度会被达到"这个看似平凡的直觉，居然要一条四层的定理阶梯来钉死——**直觉是对的，但把它变成立得住的证明，需要严谨的层层递进。**

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：MVT 证不等式**

用拉格朗日中值定理证明：对 x>0，有 eˣ > 1+x。

**完整解答**：设 f(t)=eᵗ，在 [0,x] 连续、在 (0,x) 可导。MVT：存在 c∈(0,x) 使 eˣ−e⁰ = e^c·(x−0)，即 eˣ−1=e^c·x。因 c>0，e^c>1，故 eˣ−1 > x，即 **eˣ > 1+x**。（若 x<0 用 [x,0] 同理，结论改为对 x≠0 讨论。）

**题 B（计算，中→难）：验证 MVT 条件并求 c**

设 f(x)=x² 在 [1,3]。验证 MVT 条件并求满足 f'(c)=(f(3)−f(1))/(3−1) 的 c。

**完整解答**：x² 在 [1,3] 连续、在 (1,3) 可导 ✓。平均斜率 (9−1)/(3−1)=8/2=4。f'(x)=2x，解 2c=4 ⟹ **c=2**∈(1,3) ✓。

**题 C（概念，检查理解）**

(a) 罗尔定理与拉格朗日中值定理的关系是什么？
(b) 为什么"开区间可导"（含所有内部点）是中值定理的必要条件？举反例。
(c) 柯西中值定理比拉格朗日强在哪？什么时候用柯西？

**完整解答**：
(a) 罗尔是拉格朗日的特例（f(a)=f(b) 时平均斜率=0）；拉格朗日是罗尔的推广（通过"减割线"把一般情形压平成罗尔情形）。
(b) 因为 MVT 要在 (a,b) 内找一个内部点 c 使 f'(c)=平均斜率，若某内部点不可导（如 |x| 在 0），该点无法提供 f'，MVT 不保证成立。反例：|x| 在 [−1,1] 连续但 0 处不可导，平均斜率 0 但无 c 使 f'(c)=0。
(c) 柯西是"比值"形式（f'/g' 与 (f(b)−f(a))/(g(b)−g(a))），当 g(x)=x 时退化为拉格朗日。柯西更强，用于需要两个函数"比值/同步"的场景——证洛必达法则、泰勒余项、以及比值型不等式。

## 预告

你终于把"平均速度会被达到"这个直觉，钉成了一条完整的定理阶梯——**费马 → 罗尔 → 拉格朗日 → 柯西**，还拿走了它"由导数反推函数"的三大用途（证不等式、判常数、估误差）。这一章的地基，是本册微积分最深的那个"为什么"的准备。

下一章，我们要问一个与"变化率"相对的问题：**如果你知道每刻的速度，能不能把整段路程拼回来？** 这正是**积分（微积分基本定理 FTC）**——"变化"和"累积"如何互逆。你会看到，**FTC 的证明，恰恰要用到这一章的中值定理**——"平均变化率在某点被达到"是连接"导数"与"积分"的那座桥。**把中值定理练熟，它是你走进积分世界的入场券。**
