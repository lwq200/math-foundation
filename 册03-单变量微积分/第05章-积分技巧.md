# 第 05 章 · 积分技巧——换元与分部

> 本章从哪个问题出发：上一章你靠 FTC 把"算积分"变成了"找一个原函数"。可你真去找时发现：**x²、sin x、eˣ 这种熟面孔，原函数一眼能"猜"出来；可遇到 x·eˣ、x·cos x、x·ln x 这种"乘起来"的函数，或者 sin(x²)·x、e^{x²}·x 这种"套起来"的函数，原函数根本猜不出来。** "找原函数"难道只能靠运气？
> 推导到哪个结论：你会拿到两把把"猜"变成"算"的工具——**换元法（u-substitution）** 是**链式法则的积分形式**，专治"套起来的函数"；**分部积分法（integration by parts）** 是**乘积法则的积分形式**，专治"乘起来的函数"。这两把工具，正是第 02 章求导法则（链式、乘积）在积分这边的"倒影"。你还会看到，积分比求导难在**没有一条"万能链式"**——技巧的本质是"把被积函数改写成某条求导法则的痕迹"。
>
> 核心认知：**换元法 = 链式法则倒过来（把"套起来"的函数还原成外层导数乘内层导数）；分部积分 = 乘积法则倒过来（把"乘积"的积分，转嫁给一个更简单的函数）。** 没有"万能的积分公式表能一步算对"，但有了这两把工具，加上"识别它像谁（外层？乘积？）"，大多数常见积分都能算出来。**这是从"认识积分"到"会算积分"的一章——你手里的工具，从'回定义'升级成了'会拆'。**

## 引子

我站在老谟书房的白板前，手里捏着粉笔，白板上写着一行字：

**∫ x·eˣ dx**

我盯着它发了半天呆。上一章我用 FTC 算了一堆积分——x²、sin x、eˣ——都是"一眼看出原函数"。可眼前这个 x·eˣ，"猜"不出来：x 的原函数是 x²/2，eˣ 的原函数是 eˣ，可**两个乘起来**的原函数，不是它们原函数相乘那么简单。

"老谟，"我转过头，"这个我怎么猜？求导的乘积法则，给了我 (x·eˣ)' = eˣ + x·eˣ——反过来要找'积分等于 x·eˣ'的函数，好像跟那个乘积法则的影子有关系？"

老谟靠在门框上，没直接答，只是说："你先把它搁一晚上。**明天我问你：你第 02 章学了两条求导法则，一条叫'链式'、一条叫'乘积'。它们倒过来，会变成积分里的什么？**"

我握着粉笔，隐约觉得，答案就藏在那两条法则的"倒影"里。

## 对话引擎

### 第 1 轮：换元的直觉——"套起来的函数"怎么拆

**老谟**："先从'套起来'的函数说起。**第 02 章你学链式法则：(f(g(x)))' = f'(g(x))·g'(x)。** 现在积分是求导的逆，那"套起来"的函数的积分，应该从链式法则倒过来看。**给你一个具体例子：∫ 2x·cos(x²) dx。** 你先感觉一下——它像不像"某个函数的导数"？"

**造物主**："……cos(x²) 里套了个 x²。**如果设 u=x²，那 u'=2x，而 2x·cos(x²) 正好是 cos(u)·u'。** 链式法则说 (sin(u))' = cos(u)·u'——**所以 2x·cos(x²) 就是 sin(x²) 的导数！原函数是 sin(x²)+C！**"

**老谟**："你这一下，就把'换元'的直觉摸出来了——**当一个被积函数是'外层函数的导数 × 内层函数的导数'的形状，它就是一个链式法则的结果，原函数就是'外层函数的原函数套内层'。** 现在我问你：这个'设 u=x²'的动作，能不能推广成一套固定的操作？"

**造物主**："……应该能！**看到'套起来'，就先设 u=内层函数，把 dx 换成 du，看看被积函数能不能变成'外层对 u 的函数 × du'，然后对 u 求积分，最后把 u 换回 x。** 这套动作，就是把链式法则'倒着走'一遍。"

**老谟**："你把这套动作叫**换元法（u-substitution）**。但有个关键你没说清：**'把 dx 换成 du'，凭什么是合法的？** 你设 u=x²，那 du=2x dx，这是'微分'，不是'随便换'。**它的合法性，来自链式法则——严格证明在走廊定理 1。** 这一轮你先记住：换元法 = 链式法则倒过来。"

### 📐 知识锚点：换元法——链式法则的积分形式

<blockquote style="background:#fff8e1">

【概念深挖】**换元法（u-substitution）** 的核心操作：
- 看到被积函数形如 f(g(x))·g'(x)（"外层函数 × 内层导数"），**设 u=g(x)，则 du=g'(x)dx**，于是
  $$\int f(g(x))\,g'(x)\,dx = \int f(u)\,du.$$
- **做完对 u 的积分后，把 u 换回 g(x)**。

**对应定积分**（换限）：
$$\int_a^b f(g(x))\,g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du.$$
**定积分换元要换限**——把 x 的积分限 a、b 换成 u 的 g(a)、g(b)，这样就不用换回 x。

**本质**：换元法就是**链式法则的积分形式**——\(\int f(g(x))g'(x)dx=\int f(u)du\) 正是 "(f∘g)'=f'(g)·g'" 的逆。**它告诉你怎么识别"套起来"的函数：找内层 u，配出外层×内层导数。**

【历史溯源】**莱布尼茨（Leibniz）发明的微分记号 d/dx 和 dx，正是换元法的基石**——他坚持"dx 是能参与运算的量"，于是"设 u、算 du、代换"才写得顺。**牛顿的流数记号则写不了这么漂亮的换元**。**莱布尼茨的记号体系最终胜出，是微积分"能算"的关键一步**——这一章你用的换元，正是莱布尼茨记号优势的日常体现。

【工程实践】换元法在工程里是"把复杂被积函数归一化"的工具：**概率里的标准化（把任意正态 X 换成标准正态 Z=(X−μ)/σ）、物理里的量纲/坐标变换（积分换元=换坐标系）**。**工程师碰到"指数/对数里套了个复杂式子"（如 e^{−x²/2}、ln(x²+1)），第一反应就是换元，把它化成"对单个变量"的积分**——这是算期望、算能量的家常便饭。

</blockquote>

### 第 2 轮：换元的适用条件——"配出外层×内层导数"不是每次都有

**老谟**："换元好用，但你别以为它对所有'套起来'的函数都灵。**我给你一个反例：∫ sin(x²) dx。** 它也是"套起来"的（sin 套 x²），你用换元试试——能算出来吗？"

**造物主**："……设 u=x²，du=2x dx，那我需要有个 2x 在外面。**可 sin(x²) 外面没有 x ！** 我凑不出"外层×内层导数"的形状——**这个积分用换元法算不出来。**"

**老谟**："对。**换元的适用条件是：被积函数必须能写成 f(g(x))·g'(x) 的样子——也就是'内层导数 g'(x) 得作为因子出现'。** sin(x²) 里没有 x，凑不出 g'(x)=2x，所以换元失败。**那你说说，遇到这种'差一个因子'的情况，有没有补救？**"

**造物主**："……如果外面有个常数倍数，比如 ∫ 2x·sin(x²) dx，能换；可 sin(x²) 真的一分钱 x 都没有……**那我只能换别的招，或者干脆说它'不是一个初等函数的积分'？** 可如果是 ∫ x·sin(x²) dx，就恰好凑出来了。"

**老谟**："你分清了**"凑得出"和"凑不出"**。**凑得出的（外层×内层导数）→ 换元；凑不出的 → 换元这条路走不通，可能压根没有初等原函数，或要等下一章的工具。** 记住：换元法不是万能的，它只对"长得像链式法则结果"的函数生效——**技巧的本质就是'认出它像谁'。**"

### 📐 知识锚点：换元的适用条件——"差一个因子"的辨析

<blockquote style="background:#e3f2fd">

【概念深挖】**换元能否成功的判断**：
- **能换**：被积函数 = f(g(x))·g'(x) 的形状（内层导数 g'(x) 作为因子出现）。如 2x·cos(x²)（u=x²，g'(x)=2x 恰好在）、x·e^{x²}（u=x²，g'(x)=2x，剩 1/2 提到积分号外）。
- **不能换（缺因子）**：sin(x²)、e^{x²} 这类"套起来但外层没有内层导数"的，换元法失败。
- **常见"凑"的技巧**：如果 g'(x)=k（常数），k 可提到积分号外；若外面有 f(x)·g'(x) 的因子，凑出 g'(x)。

**一个重要的事实（预告，不证）**：**不是每个连续函数的积分都能写成"初等函数的组合"**——\(\int \sin(x^2)\,dx\)、\(\int e^{x^2}\,dx\) 的原函数都不是初等函数（它们有名字，如菲涅尔积分、误差函数 erf）。**"能算出来"不等于"能用初等函数写出来"**——这一章的工具，只覆盖"能化成链式/乘积法则结果"的那部分。

【工程实践】"有些积分没有初等原函数"在工程里是常态：**正态分布的累积（erf）、菲涅尔积分（光学）、椭圆积分（轨道力学）都不是初等函数**——**工程师遇到这类，直接上数值积分（下一章 Ch8），不指望"找一个原函数"。** 判断"这积分有没有初等原函数"，正是工程师决定"用手算还是上数值方法"的开关。

</blockquote>

### 第 3 轮：分部积分的直觉——"乘起来的函数"从乘积法则倒过来

**老谟**："套起来的函数用换元，那**乘起来**的函数呢？**回到白板上那个 ∫ x·eˣ dx——它是两个不同函数的乘积，不是'套起来'。** 你引子里已经猜到了：它可能跟求导的**乘积法则**有关。你说说，乘积法则的逆，该长什么样？"

**造物主**："……乘积法则说 (u·v)' = u'·v + u·v'。**两边对 x 积分：u·v = ∫ u'·v dx + ∫ u·v' dx。** 那我移一下项：**∫ u·v' dx = u·v − ∫ v·u' dx。** 咦，**把一个'乘起来'的积分，变成了'另一个'乘起来'的积分'——只不过把'谁求导、谁积分'换了一下？**"

**老谟**："你这一步，就是**分部积分（integration by parts）**的核心：**∫ u dv = uv − ∫ v du。** 它不是'直接把积分算出来'，而是**把一个积分，转嫁成一个'可能更简单'的积分**。**那问题来了：∫ x·eˣ dx 里，我该让谁当 u、谁当 dv？** 你试试两种分法。"

**造物主**："……如果让 u=x、dv=eˣdx，那 du=dx、v=eˣ，代进公式：**∫x·eˣdx = x·eˣ − ∫eˣ·1 dx = x·eˣ − eˣ + C。** 成了！可如果我反过来，让 u=eˣ、dv=x dx，那 du=eˣdx、v=x²/2，代进去：**∫x·eˣdx = eˣ·x²/2 − ∫(x²/2)·eˣ dx——不但没简化，还更复杂了！**"

**老谟**："你把分部积分最关键的一课自己走出来了——**分对 u、dv 是成败关键：要让新的积分 ∫ v du 比原来的 ∫ u dv 更简单。** x 求导会"降幂"（x→1），eˣ 积分不变形——**所以让 x 当 u（去求导降幂）、eˣ 当 dv（去积分），转嫁后 x 没了。** 下一轮我们把这个'怎么选 u'变成一套规则。"

### 📐 知识锚点：分部积分——乘积法则的积分形式

<blockquote style="background:#fff8e1">

【概念深挖】**分部积分（integration by parts）** 公式：
$$\int u\,dv = uv - \int v\,du.$$
**推导**（本质是乘积法则的积分）：由 (uv)'=u'v+uv'，积分得 uv=∫u'v dx+∫uv' dx，移项即得（令 dv=v' dx，du=u' dx）。

**怎么选 u 和 dv（关键）**：
- **u 要"求导变简单"**：如 x、x²、ln x（xⁿ 求导降幂，ln x 求导变 1/x）。
- **dv 要"积分不难"**：如 eˣ、cos x、sin x、xⁿ dx（都能轻松积分）。
- **口诀（L/IA/TE）**：按优先级让 **L（ln、log）→ I（反三角）→ A（代数/多项式）→ T（三角）→ E（指数）** 中靠前的当 u。因为"ln、多项式求导会变简单"，而"三角、指数求导不变形、积分也不难"。

**典型"乘起来"配对**：
- ∫x·eˣdx：u=x（降幂），dv=eˣdx。
- ∫x·cos x dx：u=x（降幂），dv=cos x dx。
- ∫x·ln x dx：u=ln x（求导变 1/x，好办），dv=x dx。

【历史溯源】**分部积分由乘积法则直接导出**，而乘积法则本身在牛顿/莱布尼茨时代就是"能算微积分"的基础工具。**巴罗（Barrow）1660s 已几何地见到"微分与积分互逆"，牛顿与莱布尼茨则把它发展成可计算的算法**——分部积分就是这套算法里最常用的一招。**它和换元法一起，构成了"算积分"的两根顶梁柱。**

【工程实践】分部积分在工程里无处不在：**概率里算期望 ∫x·f(x)dx（让 x 求导降幂、密度 f 积分）、信号处理里的傅里叶/拉普拉斯变换（∫e^{−st}·f(t)dt，让 e^{−st} 积分、f(t) 求导降阶）、统计里算矩**——**"让复杂的那个求导、好积的那个积分"这个套路，工程师天天在用。**

</blockquote>

### 第 4 轮：分部积分的另一面——"循环"与"组合"

**老谟**："分部积分还有一个更阴险的用法，你光看 ∫x·eˣ 还看不到。**给你一个 ∫ eˣ·cos x dx——它既不是'套起来'（不能用换元），'乘起来'但谁求导都不降幂（eˣ 和 cos x 互相换着变）。** 你试试用分部积分，看会发生什么。"

**造物主**："……那让 u=eˣ、dv=cos x dx：du=eˣdx、v=sin x，得 ∫eˣcos x dx = eˣsin x − ∫eˣ sin x dx。**又冒出个 ∫eˣsin x dx！** 再分部：让 u=eˣ、dv=sin x dx：= eˣsin x − (eˣ·(−cos x) − ∫(−cos x)·eˣ dx) = eˣsin x + eˣcos x − ∫eˣ cos x dx。**诶，∫eˣcos x dx 又回来了！**"

**老谟**："你把最漂亮的一幕演出来了——**分部积分出现了'循环'：原来的积分又出现，但前面带了个负号。** 那你现在怎么办？"

**造物主**："……把它当方程解！**设 I=∫eˣcos x dx，那 I = eˣsin x + eˣcos x − I，移项得 2I = eˣ(sin x+cos x)，所以 I = eˣ(sin x+cos x)/2 + C。** 循环不是死路，是把 I 解出来的路！"

**老谟**："这是分部积分的第二个绝活——**循环分部，然后解方程。** 以后你看到'乘起来、谁都不降幂'的函数（eˣ 配 sin/cos），就想到这一招。**那你要问了：分部积分还有没有别的坑？** 下一轮我们看'组合'——当一个积分需要换元+分部连着用。"

### 📐 知识锚点：分部积分的进阶——循环分部与多步组合

<blockquote style="background:#e3f2fd">

【概念深挖】**分部积分的三个进阶场景**：
1. **循环分部**：∫eˣcos x dx、∫eˣsin x dx 这类"谁都不降幂"的，分部两次后原积分带负号重现，**移项解方程**得结果。
2. **连用多次**：∫x²·eˣ dx 要分部两次（x²→x→1，逐步降幂）。
3. **换元+分部组合**：∫x³e^{x²}dx 这类，**先换元（u=x²，化成 ∫u e^u du），再分部**——两种工具连着用。

**判断"用哪个工具"的决策**（这一章最实用的卡片）：
- **套起来的函数**（外层×内层导数）→ **换元**。
- **乘起来、其中一方求导会降幂/变简单** → **分部**（让"变简单的"当 u）。
- **乘起来、谁都不降幂（eˣ×sin/cos）** → **循环分部解方程**。
- **两者都不是** → 可能没有初等原函数，上数值积分（Ch8）。

【工程实践】"循环分部"在工程里的实际价值：**计算 ∫e^{at}sin(bt)dt 这类"衰减振荡"（RL 电路、阻尼系统）的积分时，正是循环分部解方程**；**"换元+分部组合"则是很多概率/物理积分（如 ∫x³e^{−x²}dx 算高阶矩）的标准流程**。**工程师把这两个模式练熟，碰到'指数×三角''多项式×指数'就能条件反射地选工具。**

</blockquote>

### 第 5 轮：绝对值与对称性——"带符号面积"的处理

**老谟**："你有了换元和分部，能算很多积分了。可还有一个实际问题——**上一章说过，∫ 是'带符号面积'，那遇到绝对值函数，怎么算？** 比如 ∫₀² |x−1| dx。绝对值在 x=1 处'折'了一下，你不能当普通函数直接积。"

**造物主**："……得在折点处拆开！**x∈[0,1] 时 |x−1|=1−x；x∈[1,2] 时 |x−1|=x−1。** 用区间可加性：∫₀²|x−1|dx = ∫₀¹(1−x)dx + ∫₁²(x−1)dx = 1/2 + 1/2 = 1。**绝对值在 1 处断，我就在 1 处分段积分再相加。**"

**老谟**："对。**绝对值函数、分段函数，都在'断点'处分段积分。** 那再看对称性——**∫₋₁¹ x³ dx 和 ∫₋₁¹ x² dx，一个奇一个偶，你有捷径吗？**"

**造物主**："……有！**x³ 是奇函数，在对称区间 [−1,1] 上'负半边和正半边抵消'，积分是 0；x² 是偶函数，两边对称相等，积分是 2×∫₀¹x²dx = 2/3。** 这就是用对称性偷懒！"

**老谟**："你把这章的工具收齐了：**换元（套起来）、分部（乘起来）、循环（不降幂）、分段+对称（绝对值/奇偶）。** 下一轮，我们把'会算积分'这件事收个尾——你手里现在有几把工具了？"

### 📐 知识锚点：绝对值、分段与对称性——积分的"实战"技巧

<blockquote style="background:#fff8e1">

【概念深挖】**处理"不规整"被积函数的三招**：
1. **绝对值/分段**：在"折点/断点"处分段积分，用区间可加性 ∫ₐᵇ=∫ₐᶜ+∫ᶜᵇ，各段去掉绝对值号（依符号）后正常积分。例：∫₀²|x−1|dx = ∫₀¹(1−x)dx+∫₁²(x−1)dx。
2. **奇偶对称**：f 奇（f(−x)=−f(x)）⟹ ∫₋ₐᵃf=0；f 偶（f(−x)=f(x)）⟹ ∫₋ₐᵃf=2∫₀ᵃf。**节省一半计算。**
3. **换限的注意**：定积分换元一定要**换限**（u 的积分限 = g(原限)），否则算错；分段积分别漏段。

**为什么"带符号面积"要小心**：∫ 会把 x 轴下方算成负。**要算"曲线与 x 轴围成的总面积"（不分正负），得先找零点分段，加绝对值再积。**

【工程实践】绝对值/对称性在工程里的对应：**信号的"绝对面积"（积分取绝对值）与"净面积"（直接积分）是两回事——如交流电的平均功率（净）与整流后的功率（绝对）**；**偶函数对称常用来"只算一半、翻倍"（如对称结构的物理量）**。**工程师算积分前，先问一句"能分段吗？能利用对称吗？"——这往往把计算量砍一半。**

</blockquote>

## 严格化走廊

> 位置说明：对话负责"直觉"——为什么换元是链式倒过来、分部是乘积倒过来。本走廊负责"严谨"——把换元公式、分部积分公式落成精确形式，并给出本册两座**完整可复写**的证明：**换元公式（定理 1，由链式法则推出）** 与 **分部积分公式（定理 2，由乘积法则推出）**。每个证明都标注"证明类型 + 每一步依据"——红线 1 的硬要求，不许用"显然""感觉对"糊弄。

### 定义：不定积分、换元公式、分部积分公式

- **不定积分（antiderivative/原函数族）**：\(\int f(x)\,dx\) 表示所有满足 F'=f 的函数 F(x)+C（C 为任意常数）。**注意带 +C**（定积分 F(b)−F(a) 中 C 抵消，故定积分不必写）。
- **换元公式**：若 u=g(x) 可导且 f 有原函数，则
  $$\int f(g(x))\,g'(x)\,dx=\int f(u)\,du \quad (\text{令 } u=g(x),\ du=g'(x)dx).$$
  定积分形式（换限）：\(\int_a^b f(g(x))g'(x)dx=\int_{g(a)}^{g(b)} f(u)du\)。
- **分部积分公式**：若 u、v 可导，则
  $$\int u\,dv = uv-\int v\,du.$$

> **证明类型标注**：本章两座证明——**定理 1（换元公式）用"链式法则的直接应用"**（对 F(g(x)) 求导还原）；**定理 2（分部积分公式）用"乘积法则的直接应用"**（对 uv 求导再积分）。两座都承接第 02 章求导法则与第 04 章"积分=找原函数"的框架，是"求导法则倒过来"的严格化。
>
> **关于对话**：本章第 1、3 轮是读者**第一次**正式接触换元/分部的"链式/乘积倒过来"直觉，对话做了"引导式推导"（教学示范——为什么想到"设 u 配出外层×内层导数""乘积法则两边积分移项"）。**正式的可复写证明（每一步标依据）在本走廊定理 1、2**。对话负责"为什么会想到这步"，走廊负责"怎么把它写标准"——与第 01 章 L233-235、第 04 章口径一致。

### 定理 1（换元公式）：∫f(g(x))g'(x)dx = ∫f(u)du，其中 u=g(x)

**前提**：g 在相关区间上可导且 g'(x) 连续；f 在 g 的值域上连续（故有原函数）。

**结论**：不定积分形式与定积分形式（含换限）成立。

**证明类型**：直接证明（链式法则逆用）。

**证明**：
- 第 1 步：**设 F 是 f 的一个原函数**，即 F'(u)=f(u)。由连续函数必有原函数（第 04 章 FTC 1）。（依据：FTC 1 保证 F 存在。）
- 第 2 步：**对复合函数 F(g(x)) 求导**，由链式法则（第 02 章）：
  $$\frac{d}{dx}F(g(x))=F'(g(x))\,g'(x)=f(g(x))\,g'(x).$$
  （依据：链式法则 + 第 1 步 F'=f。）
- 第 3 步：**读出原函数**。由第 2 步，F(g(x)) 是 f(g(x))g'(x) 的一个原函数，故
  $$\int f(g(x))g'(x)\,dx = F(g(x))+C.$$
  （依据：原函数定义 + 不定积分含义。）
- 第 4 步：**右边换回 u**。由 u=g(x)，F(g(x))=F(u)，且 \(\int f(u)du=F(u)+C\)，故
  $$\int f(g(x))g'(x)\,dx=\int f(u)\,du.$$
  （依据：第 3 步 + 记号替换。）
- 第 5 步：**定积分形式（换限）**：对 x=a、b，u 的下限 u₁=g(a)、上限 u₂=g(b)，故
  $$\int_a^b f(g(x))g'(x)\,dx=F(g(b))-F(g(a))=\int_{g(a)}^{g(b)} f(u)\,du.$$
  （依据：FTC 2（第 04 章）把两边都写成 F 的端点差。）
- 第 6 步：∎

> **依据标注**：步 1 用"FTC 1（第 04 章）：连续函数有原函数"；步 2 用"链式法则（第 02 章）"——这是整个换元公式的发动机；步 3 用"原函数定义"；步 5 用"FTC 2（第 04 章）"得出换限规则。**读法**：换元公式的证明就是"对 F(g(x)) 用链式法则求导、再读回原函数"——**它没有任何新技巧，就是链式法则的忠实逆用**。这也解释了为什么换元只能对"长得像链式法则结果"的函数生效：不是 f(g(x))g'(x) 的形状，就无从"逆链式"。

### 定理 2（分部积分公式）：∫u dv = uv − ∫v du

**前提**：u、v 在相关区间上可导，且 u'v、uv' 可积。

**结论**：分部积分公式成立。

**证明类型**：直接证明（乘积法则逆用）。

**证明**：
- 第 1 步：**由乘积法则**（第 02 章）：
  $$(uv)'=u'v+uv'.$$
  （依据：乘积法则。）
- 第 2 步：**两边对 x 积分**（u'v、uv' 可积是前提）：
  $$\int (uv)'\,dx=\int u'v\,dx+\int uv'\,dx.$$
  （依据：积分的线性/和法则。）
- 第 3 步：**左边**：\(\int(uv)'dx = uv\)（uv 是 (uv)' 的一个原函数）。（依据：原函数定义，不加 C 稍后统一。）
- 第 4 步：**改写右边第二项**：用微分记号 uv' dx = u dv、u'v dx = v du，移项：
  $$\int u\,dv = uv-\int v\,du.$$
  （依据：第 2、3 步代入 + 记号替换 + 移项。）
- 第 5 步：加任意常数 C 得一般不定积分形式：\(\int u\,dv = uv-\int v\,du\)（含 +C）。∎

> **依据标注**：步 1 用"乘积法则（第 02 章）"——发动机；步 2 用"积分可积性前提 + 和法则"；步 3 用"原函数定义"；步 4 用微分记号。**读法**：分部积分的证明就是"乘积法则两边积分、移项"——**它没有任何新内容，是乘积法则的忠实逆用**。这也解释了它为什么能"转嫁"积分：把 ∫u·v' 换成 uv − ∫v·u'，本质是把"谁当 u（求导）、谁当 dv（积分）"的对调。

### 书写格式模板（可复写卡片——对着空白纸照写）

> 这是本章要你抄进脑子的两张卡。**以后碰到积分，先问"它像谁"**：

```text
卡1：换元法
  看到 f(g(x))·g'(x)（外层×内层导数）。
  设 u = g(x)，du = g'(x) dx。
  把 ∫f(g(x))g'(x)dx 写成 ∫f(u)du。
  对 u 积分 → 换回 x。定积分要换限。

卡2：分部积分
  看到"乘积"，一方求导变简单（u），一方积分不难（dv）。
  ∫ u dv = uv − ∫ v du。
  目标是：新积分 ∫v du 比原积分更简单。
  谁都不降幂（eˣ×sin/cos）→ 循环分部，移项解方程。
```

**三个检查点**：① 换元后**定积分必须换限**（u 的限 = g(x 的限)），否则数值错；② 分部选 u 要让"∫v du 更简单"，选反了会越算越复杂；③ 不定积分最后写 **+C**，定积分不写（C 抵消）。

### 反例/边界：换元与分部的适用边界

1. **换元只对"外层×内层导数"形状生效**：∫sin(x²)dx、∫e^{x²}dx 套起来但没有 g'(x) 因子，换元失败——**这些原函数不是初等函数（菲涅尔/erf），不是技巧不够，是数学上就写不出初等原函数。**
2. **分部要选对 u/dv**：选反（把 eˣ 当 u、x 当 dv）会让新积分更复杂；**分部不一定一次成功**，可能要多步（∫x²eˣdx）或循环（∫eˣcos x dx）。
3. **换限别忘、别错**：定积分换元忘换限是最高频错误；换限是 g(端点)，不是简单地写 a、b。
4. **绝对值/分段必须在断点拆**：∫₀²|x−1|dx 要在 x=1 拆两段；**不拆而直接找原函数会错**（|x−1| 在 1 处不可导，没有普通原函数在整个区间成立）。
5. **不定积分要写 +C，定积分不必**：原函数族 F+C 中 C 任意；定积分 F(b)−F(a) 中 C 抵消。

## 知识点总结

### 知识点（本章推出的核心概念）

- **换元法**：∫f(g(x))g'(x)dx=∫f(u)du（u=g(x)）。**链式法则的积分形式**，专治"套起来"的函数。
- **分部积分**：∫u dv = uv − ∫v du。**乘积法则的积分形式**，专治"乘起来"的函数（让求导变简单的当 u）。
- **循环分部**：∫eˣcos x dx 这类"谁都不降幂"的，分部两次后原积分重现，**移项解方程**。
- **换元+分部组合**：如 ∫x³e^{x²}dx，先换元再分部。
- **绝对值/分段**：在"断点"处分段积分，用区间可加性。
- **对称性**：奇函数在 [−a,a] 积分=0；偶函数=2∫₀ᵃ。**节省一半计算。**
- **"没有初等原函数"**：∫sin(x²)dx、∫e^{x²}dx 的原函数不是初等函数（erf、菲涅尔）。

### 历史结论（本章涉及的史料）

- **莱布尼茨（微分记号 dx、d/dx）**：记号体系让"设 u、算 du、代换"写得很顺，是换元法能漂亮书写的关键——**他的记号最终胜过牛顿的流数记号。**
- **牛顿/莱布尼茨**：把"积分=求导逆"发展成可计算算法，换元/分部正是这套算法里最常用的两招。
- **巴罗（Barrow，1660s）**：更早几何地见到"微分与积分互逆"，未系统化。
- **分部积分/乘积法则**：由乘积法则直接导出，是微积分"能算"的顶梁柱。

### 工程实践结论（本章知识在真实工程里怎么用）

- **换元**：概率标准化（X→Z=(X−μ)/σ）、坐标/量纲变换——把复杂被积函数归一化。
- **分部**：期望 ∫x·f(x)dx（x 降幂）、拉普拉斯/傅里叶变换（e^{−st} 积分、f(t) 求导降阶）、统计矩。
- **循环分部**：RL 电路/阻尼系统的"衰减振荡"积分。
- **"没有初等原函数"的判断**：遇到 erf、菲涅尔、椭圆积分，直接上数值积分（Ch8），不硬找原函数。

### 题 1（易→中）：换元法——套起来的函数

**题干**：老谟让造物主用换元法求：
(a) 不定积分 ∫ x·e^{x²} dx；
(b) 定积分 ∫₀¹ x·e^{x²} dx（记得换限）。

**完整分步解答：**

**(a)** 设 u=x²，du=2x dx，故 x dx = (1/2)du。
∫ x·e^{x²}dx = (1/2)∫ e^u du = (1/2)e^u + C = **(1/2)e^{x²} + C**。
（验算：((1/2)e^{x²})' = (1/2)·2x·e^{x²}=x·e^{x²} ✓。）

**(b)** 换限：x 从 0 到 1 ⟹ u=x² 从 0 到 1。∫₀¹ x e^{x²}dx = (1/2)∫₀¹ e^u du = (1/2)[e^u]₀¹ = (1/2)(e−1)≈**0.859**。

**答**：(a) (1/2)e^{x²}+C；(b) (1/2)(e−1)≈0.859。

**常见错误**：① 设 u=x² 后忘了"x dx=(1/2)du"，直接写成 ∫e^u du（丢 1/2）；② 定积分 (b) 忘了换限（直接把 0、1 当代 u 的限，会错）；③ 换回 x 时把 u 又写成别的（u 是 x²，不是别的）。

### 题 2（中→难）：分部积分——乘起来的函数

**题干**：老谟让造物主用分部积分求：
(a) ∫ x·eˣ dx；
(b) ∫ x·cos x dx；
(c) 定积分 ∫₁ᵉ ln x dx。

**完整分步解答：**

**(a)** 让 u=x（求导降幂）、dv=eˣdx（积分不变形），则 du=dx、v=eˣ。
∫x eˣdx = x eˣ − ∫eˣ dx = x eˣ − eˣ + C = **eˣ(x−1)+C**。
（验算：(eˣ(x−1))'=eˣ(x−1)+eˣ=eˣx ✓。）

**(b)** 让 u=x、dv=cos x dx，则 du=dx、v=sin x。
∫x cos x dx = x sin x − ∫sin x dx = **x sin x + cos x + C**。
（验算：(x sin x+cos x)'=sin x+x cos x−sin x=x cos x ✓。）

**(c)** 让 u=ln x、dv=dx，则 du=(1/x)dx、v=x。
∫ ln x dx = x ln x − ∫ x·(1/x)dx = x ln x − ∫1 dx = x ln x − x + C。
定积分：∫₁ᵉ ln x dx = [x ln x − x]₁ᵉ = (e·1−e) − (1·0−1) = 0 − (−1) = **1**。

**答**：(a) eˣ(x−1)+C；(b) x sin x+cos x+C；(c) **1**。

**常见错误**：① (c) 选反 u/dv（若让 u=x、dv=ln x dx，反而更复杂）——**ln x 要求导（变 1/x），所以要让它当 u**；② (a) 积分符号里漏掉 v·du 里的 v（写成 ∫eˣdx 而不是 ∫eˣ·1 dx，虽结果对但过程不规范）；③ 定积分代入时下限 ln 1=0 容易算错（ln 1=0，不是 1）。

### 题 3（难）：综合——换元+分部组合、绝对值、对称性

**题干**：老谟让造物主综合运用本章工具计算：
(a) ∫ x³·e^{x²} dx（换元+分部组合）；
(b) ∫₀² |x−1| dx（绝对值分段）；
(c) ∫₋₁¹ x³ dx 与 ∫₋₁¹ x² dx（对称性）。

**完整分步解答：**

**(a)** 先换元：u=x²，du=2x dx，x dx=(1/2)du，且 x³=x·x²=x·u，故
∫x³e^{x²}dx = (1/2)∫ u e^u du。
再对 ∫u e^u du 分部（u₁=w、dv=e^w dw，用题 2a 结论）：∫w e^w dw=(w−1)e^w+C。
代回：=(1/2)(u−1)e^u + C = **(1/2)(x²−1)e^{x²}+C**。
（验算：d/dx[(1/2)(x²−1)e^{x²}] = (1/2)[2x e^{x²}+(x²−1)·2x e^{x²}] = x[1+(x²−1)]e^{x²}=x³e^{x²} ✓。）

**(b)** 在折点 x=1 处分段：
∫₀²|x−1|dx = ∫₀¹(1−x)dx + ∫₁²(x−1)dx = [x−x²/2]₀¹ + [x²/2−x]₁² = (1−1/2) + [(2²/2−2)−(1²/2−1)] = (1−1/2) + [(2−2)−(1/2−1)] = 1/2 + [0−(−1/2)] = 1/2 + 1/2 = **1**。
（交叉验证：|x−1| 在 [0,2] 上的图像是"V 形"——从 (0,1) 降到 (1,0) 再升到 (2,1)，与 x 轴围成两个底 1 高 1 的三角形，总面积 = 2×(1×1/2)=1，与分段积分结果一致。）

**(c)** x³ 是奇函数（(−x)³=−x³），在对称区间 [−1,1] 上 ∫₋₁¹x³dx=**0**（负半与正半抵消）。x² 是偶函数，∫₋₁¹x²dx=2∫₀¹x²dx=2·(1/3)=**2/3**。

**答**：(a) (1/2)(x²−1)e^{x²}+C；(b) **1**；(c) ∫₋₁¹x³=**0**，∫₋₁¹x²=**2/3**。

**常见错误**：① (a) 换元后忘了"x³=x·x²=x·u"这一拆，写不出 ∫u e^u du；② (a) 换元与分部顺序搞反（先分部更难，应先换元化成 ∫u e^u du 再分部）；③ (b) 没在 x=1 拆段，把 |x−1| 当 x−1 直接积（在 [0,1] 上 x−1<0，会错）；④ (c) 忘了奇偶结论的适用前提（必须是对称区间 [−a,a]，且函数确为奇/偶）。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：换元法**

(a) 用换元法求 ∫ (2x+1)/(x²+x) dx；(b) 用换元法求 ∫₀^√π x·cos(x²) dx（换限）。

**完整解答**：
(a) 设 u=x²+x，du=(2x+1)dx，∫(2x+1)/(x²+x)dx=∫(1/u)du=ln|u|+C=**ln|x²+x|+C**。（验证：d/dx ln|x²+x|=(2x+1)/(x²+x) ✓。）
(b) u=x²，du=2x dx，x dx=(1/2)du；换限 x:0→√π ⟹ u:0→π。∫₀^√π x cos(x²)dx=(1/2)∫₀^π cos u du=(1/2)[sin u]₀^π=(1/2)(sin π−sin 0)=**0**。（sin π=0，sin 0=0。）

**题 B（计算，中→难）：分部积分**

(a) 求 ∫x²·eˣ dx（分部两次）；(b) 求 ∫eˣ sin x dx（循环分部）。

**完整解答**：
(a) ∫x²eˣdx，分部：u=x²、dv=eˣdx ⟹ x²eˣ−∫2x eˣdx。再分部 ∫2x eˣdx：=2(x eˣ−eˣ)+C=2eˣ(x−1)。故 ∫x²eˣdx=x²eˣ−2eˣ(x−1)+C=**eˣ(x²−2x+2)+C**。（验算：(eˣ(x²−2x+2))'=eˣ(x²−2x+2)+eˣ(2x−2)=eˣx² ✓。）
(b) 设 I=∫eˣ sin x dx。分部 u=eˣ、dv=sin x dx：I=−eˣcos x+∫eˣcos x dx。再分部 ∫eˣcos x dx：u=eˣ、dv=cos x dx ⟹ eˣsin x−∫eˣsin x dx=eˣsin x−I。故 I=−eˣcos x+eˣsin x−I ⟹ 2I=eˣ(sin x−cos x)，I=**eˣ(sin x−cos x)/2+C**。（验算：d/dx[eˣ(sin x−cos x)/2]=eˣ(sin x−cos x)/2+eˣ(cos x+sin x)/2=eˣsin x ✓。）

**题 C（概念，检查理解）**

(a) 换元法和链式法则是什么关系？为什么换元只对"外层×内层导数"形状生效？
(b) 分部积分时，为什么通常让"求导会变简单"的函数当 u？
(c) 为什么 ∫sin(x²)dx 用换元/分部都算不出初等原函数？

**完整解答**：
(a) 换元是链式法则的积分形式（逆用）：对 F(g(x)) 用链式法则得 F'(g(x))g'(x)，倒过来就是 ∫f(g(x))g'(x)dx=∫f(u)du。**只有当被积函数是"外层×内层导数"形状，才能逆链式**；缺了 g'(x) 因子（如 sin(x²)），无从"逆"。
(b) 分部 ∫u dv=uv−∫v du 会把积分"转嫁"成 ∫v du。**如果 u 求导变简单（x→1、ln x→1/x），新积分 ∫v du 就比原来简单**；如果反过来让"求导不变形"的当 u，新积分可能更复杂。
(c) sin(x²) 是"套起来"但没有内层导数 2x 作因子，无法逆链式；它不是"乘积"也无从逆乘积法则。**这类函数的原函数不是初等函数（菲涅尔积分），是数学本质，不是技巧不够。**
