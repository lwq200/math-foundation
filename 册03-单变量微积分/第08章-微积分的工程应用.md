# 第 08 章 · 微积分的工程应用——机器怎么算"算不出来"的微积分

> 本章从哪个问题出发：前几章你学会了用导数、积分、泰勒精确地"算"。可你马上撞到一个残酷的现实：**方程 x³−x−2=0 的根不是整数、不是分数，写成小数永远写不完；积分 ∫₀¹ e^{−x²} dx 的原函数根本不是初等函数——你前几章的工具，对它们"精确算不出"。** 可机器在 0.1 秒内就能给你 1.52138 和 0.7468——**机器到底是怎么算这些"算不出来"的微积分的？**
> 推导到哪个结论：机器不"精确算"，而是**逼近**——用两条腿走路：**数值求根**（牛顿法：用切线一次次逼近根，越逼近越快）和**数值积分**（梯形法则、辛普森法则：把积分切碎成一片片求和的黎曼和的"升级版"）。你会看到：**牛顿法为什么"越算越快"（二次收敛，误差每步约平方），梯形/辛普森法则为什么"切得越细越准、且辛普森比梯形准得多"（误差阶 O(h²) vs O(h⁴)）。**
>
> 核心认知：**机器算微积分，靠的不是"找精确解"，而是"用可算的逼近 + 可估计的误差"。** 牛顿法用切线（导数）逼近根，**二次收敛**；数值积分用黎曼和的"升级版"（梯形/辛普森）逼近定积分，误差阶分别是 O(h²)、O(h⁴)。**这一章把前面所有工具（导数、黎曼和、中值定理、泰勒）都拧进了一台"机器"，是微积分的工程落地——也是"能算的成人礼"的最后一颗勋章。**

## 引子

我坐在老谟书房，面前摊着两张纸。一张写着"求 x³−x−2=0 的根"，另一张写着"求 ∫₀¹ e^{−x²} dx"。

"老谟，"我指指第一张，"我试了试，x=1 代进去是负的，x=2 代进去是正的，由 IVT 我知道根在 (1,2) 里。可它到底等于几？我总不能用二分法切到天荒地老吧？"我又指指第二张，"这个积分更糟——e^{−x²} 的原函数我压根找不出来，前几章的换元、分部全试过了。"

老谟靠在椅背上，没直接答，反而问我："你觉得，**机器**会怎么对付这两道题？它也不能'切到天荒地老'，也不能'找一个不存在的原函数'。"

"……机器也是靠逼近？"我隐约有了点头绪，"它也不能精确，只能'算得越来越准'。"

"对。"老谟起身，在白板上画了一条曲线，"**机器有两个绝活：一个是'用切线去撞根'，越撞越快；一个是'把曲线下切成一片片'，切得越细越准。** 这两个绝活，就是你这一章要学的全部。**至于它凭什么'越撞越快'、'切得越细越准'——那要回到你前面几章学的中值定理、泰勒和黎曼和。**"

## 对话引擎

### 第 1 轮：二分法太慢——"能不能再快点"

**老谟**："先把'求根'这个问题摆清楚。**你有 x³−x−2=0，根在 (1,2)，你已经有二分法（第 05 章 IVT 的构造）。** 可二分法每次只把区间对折，误差减半——**慢。** 我问你：能不能利用更多信息，让每一步都'跳'得更准？"

**造物主**："……二分法只用了'符号'——这半边正那半边负，信息量太少了。**函数在那个点的'斜率'（导数）我也有啊？** 如果我知道曲线在 x=1.5 处的切线，是不是能沿着切线往下滑到 x 轴上，那个落点可能比二分法的中点更接近根？"

**老谟**："你摸到牛顿法的直觉了——**不用符号，用切线。** 可你先别急着写公式，先回答：**这个'沿切线滑到 x 轴'的动作，写成数学是什么？** 已知曲线在 xₙ 处过点 (xₙ, f(xₙ))、斜率是 f'(xₙ)，那切线方程怎么写？它和 x 轴的交点是哪个？"

**造物主**："……切线方程：y = f(xₙ) + f'(xₙ)(x − xₙ)。**令 y=0 求与 x 轴交点：0 = f(xₙ) + f'(xₙ)(x − xₙ)，解得 x = xₙ − f(xₙ)/f'(xₙ)。** 所以下一个近似 x_{n+1} = xₙ − f(xₙ)/f'(xₙ)！"

**老谟**："这就是**牛顿法（Newton's method）**的迭代格式。**每次用当前的切线，把下一个近似"顶"出来。** 下一轮我们看看：它凭什么比二分法快，快在哪里。"

### 📐 知识锚点：牛顿法——用切线"撞"根

<blockquote style="background:#fff8e1">

【概念深挖】**牛顿法（Newton–Raphson method）**：
- **迭代格式**：给定初值 x₀，反复算
  $$x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}.$$
- **几何直觉**：过点 (xₙ, f(xₙ)) 作切线（斜率 f'(xₙ)），切线与 x 轴的交点就是 x_{n+1}——**沿切线"滑"到根附近**。
- **与二分法的对比**：二分法只用符号，每步区间减半（线性收敛）；牛顿法用斜率（导数），每步误差"平方"（二次收敛）——**快得多**。

**两个前提（本册够用）**：f 在根附近足够光滑（可导、f' 连续且 f'(r)≠0），且初值 x₀ 离根 r 足够近。**这两个前提不满足，牛顿法可能发散或乱跳**（见反例/边界）。

【历史溯源】**牛顿法**：**牛顿（Newton，17 世纪）**在《流数法》里用"切线逼近"求多项式方程根；**拉弗森（Raphson，1690）**把它推广成更通用的迭代形式；两人合称"牛顿-拉弗森法"。**它是人类第一个系统性的数值求根算法，也是"用切线逼近"思想的最早工程化**——比它更早的只有"试错"和"夹逼"这类笨办法。

【工程实践】牛顿法在工程里遍地都是：**求利率的内部收益率（IRR）、校准相机参数、机器学习里求模型参数**——凡是"解一个非线性方程/优化一个目标"的问题，第一步常常试牛顿法。**它的代价是要算导数 f'(xₙ)**——这就是为什么后面会讲"梯度下降"这种"只算一阶、代价更低"的替代（见第 6 轮）。

</blockquote>

### 第 2 轮：牛顿法为什么"越算越快"——误差在平方

**老谟**："你有迭代格式了。现在我要你回答那个'凭什么快'的问题。**设真正的根是 r，你第 n 步的误差是 eₙ = xₙ − r。** 你要看的是：**下一步误差 e_{n+1} 和上一步 eₙ 是什么关系？** 我给你一个工具——**把 f(r) 在 xₙ 附近做泰勒展开（第 07 章），利用 f(r)=0**。你能顺着这个提示，看看 e_{n+1} 大约等于 eₙ 的几次方吗？"

**造物主**："……f(r)=0，而 f(r)=f(xₙ)+f'(xₙ)(r−xₙ)+(1/2)f''(ξ)(r−xₙ)²。**r−xₙ = −eₙ，所以 0 = f(xₙ) − f'(xₙ)eₙ + (1/2)f''(ξ)eₙ²，移项得 f(xₙ) = f'(xₙ)eₙ − (1/2)f''(ξ)eₙ²。** 代进迭代式：x_{n+1}−r = eₙ − f(xₙ)/f'(xₙ) = eₙ − [f'(xₙ)eₙ − (1/2)f''(ξ)eₙ²]/f'(xₙ) = (1/2)[f''(ξ)/f'(xₙ)]eₙ²。**所以 e_{n+1} 大约等于一个常数乘以 eₙ²！误差在'平方'！**"

**老谟**："你把二次收敛（quadratic convergence）自己推出来了——**每步误差 ≈ 上一步误差的平方**。这就是它比二分法快得多的原因：误差从 0.1 一步变到 0.01、0.0001、0.00000001……**小数点后面的 0 每步翻倍。** 完整可复写的推演在走廊定理 1，你去补全。这一轮你先把这个'平方'的直觉钉死。"

### 📐 知识锚点：二次收敛——"误差每步平方"

<blockquote style="background:#e3f2fd">

【概念深挖】**二次收敛（quadratic convergence）**：
- 若存在常数 C，使 \(|e_{n+1}|\le C\,|e_n|^2\)（eₙ=xₙ−r），则称牛顿法**二次收敛**。
- **直觉**：误差平方意味着"小数点后的位数约每步翻倍"。例：若 |eₙ|=0.1，则 |e_{n+1}|≈C·0.01，|e_{n+2}|≈C·0.0001……**指数式地快。**
- **对比**：二分法每步只把误差乘以 1/2（线性），牛顿法每步把误差平方（二次）——**这是数量级的差别。**

**关键结论（走廊定理 1 严格证明）**：
$$e_{n+1}=\frac{1}{2}\frac{f''(\xi_n)}{f'(x_n)}\,e_n^2 \quad\Rightarrow\quad |e_{n+1}|\le C|e_n|^2,\ C=\frac{1}{2}\frac{\max|f''|}{\min|f'|}.$$
**注意前提**：f'(r)≠0（根是"简单根"，否则退化为线性收敛），且初值够近。**前提不满足，二次收敛不成立甚至发散。**

【工程实践】"误差平方"在工程里的意义：**牛顿法一旦进入收敛区，几轮就到位**——所以工程里往往"先用笨办法（二分/网格）粗逼近到够近，再用牛顿法精修"。**"先用稳的粗调、再用快的精修"是数值算法常用的两段式**——这正是线性收敛与二次收敛各司其职的实战分工。

</blockquote>

### 第 3 轮：数值积分——"切碎求和"的升级版（梯形）

**老谟**："求根解决了，转向积分。**你第 04 章已经知道定积分 = 黎曼和的极限，也知道机器不会找原函数。** 那机器算 ∫₀¹eˣ dx 这种，会怎么做？它不能精确到无穷，只能"切有限段"。**你回想黎曼和：把 [a,b] 切 n 段，每段用个代表值乘段长。机器也这么干，但它想让'每一段'的近似更聪明一点——你说说，怎么让每段的近似比'矩形'更准？**"

**造物主**："……矩形法是每段用一个'高度'（左点/右点/中点）乘段长，像一个个长方形。**如果我用'这一段两端的平均高度'来代表，那每一段就变成一个梯形了**——两端的函数值取平均，乘段长。这比只用一端更准，因为它用了两端两个点。"

**老谟**："你造出来的就是**梯形法则（trapezoidal rule）**：每段用'两端平均高度'，整段积分 ≈ (h/2)[f(x₀)+2f(x₁)+…+2f(xₙ₋₁)+f(xₙ)]。**它是黎曼和的'升级版'。** 可问题来了——**它到底有多准？切细一倍（h 减半），误差减多少？** 下一轮我们看一个比它更聪明的。"

---

### 📐 知识锚点：梯形法则——黎曼和的升级

<blockquote style="background:#fff8e1">

【概念深挖】**梯形法则（trapezoidal rule）**：把 [a,b] 等分 n 段，段长 h=(b−a)/n，分点 xᵢ=a+ih：
$$T=\frac{h}{2}\left[f(x_0)+2f(x_1)+2f(x_2)+\cdots+2f(x_{n-1})+f(x_n)\right].$$
**直觉**：每段用两端函数值的平均作"高度"（一个梯形），比只用一端的矩形更贴合曲线。

**误差阶**（走廊定理 2 严格证明）：
$$|E_T|\le \frac{b-a}{12}\,h^2\,\max|f''| \quad(\text{即 } O(h^2)).$$
**含义**：h 减半，误差约为原来的 1/4——**"切细一倍，误差除以 4"。**

【历史溯源】数值积分的思想和微积分一样老：**阿基米德（公元前 3 世纪）**就用"夹逼多边形"算圆面积（逼近思想的鼻祖）；**黎曼（1854）**给出"分割+和式"的严格定义后，梯形、辛普森这些"具体取法"才被系统整理。**梯形法则是最朴素的一种：每段一条直线。**

【工程实践】梯形法则是"能用最笨的方式也能算积分"的保底算法：**只要采样点均匀、函数不算太野，梯形法总能给个可用的近似**。**但它的收敛是 O(h²)——要很高精度就得切很多段**，这正是后面辛普森法则（O(h⁴)）的价值。

</blockquote>

### 第 4 轮：辛普森法则——用"抛物线"比用"直线"聪明

**老谟**："梯形法每段用一条直线。可曲线不是直线——**你用直线去近似一段弧，总差一点。** 那如果每段不用直线、而用**抛物线**呢？你想想，抛物线需要几个点来确定？"

**造物主**："……抛物线 y=ax²+bx+c 有三个未知数，需要三个点！**所以每段得'包'住三个点——也就是每两段看成一个单元，用这两段端点加中点的三个点拟合一条抛物线，再积这个抛物线的面积。** 这样每'两小段'用一个抛物线，比一条直线准多了？"

**老谟**："你造出来的就是**辛普森法则（Simpson's rule）**：每两段用一条抛物线。**它的好处是：抛物线比直线贴合曲线更紧，误差阶从 O(h²) 升到 O(h⁴)**——切细一倍，误差约为原来的 1/16，比梯形快得多。**但代价是它要求段数 n 是偶数（因为要两段配一个抛物线）。** 这一轮你先记住这个'用高次曲线拟合'的思路——下一轮我们算个具体的，看看它到底比梯形准多少。"

---

### 📐 知识锚点：辛普森法则——抛物线拟合

<blockquote style="background:#e3f2fd">

【概念深挖】**辛普森法则（Simpson's rule）**：把 [a,b] 等分成 **偶数** n 段，h=(b−a)/n：
$$S=\frac{h}{3}\left[f(x_0)+4f(x_1)+2f(x_2)+4f(x_3)+\cdots+2f(x_{n-2})+4f(x_{n-1})+f(x_n)\right].$$
- **系数模式**：两端 1，奇数下标 4，偶数下标 2（首尾除外）。**每相邻两段用一个抛物线拟合。**
- **误差阶**（走廊定理 3 严格证明）：
  $$|E_S|\le \frac{b-a}{180}\,h^4\,\max|f''''|\quad(\text{即 } O(h^4)).$$
- **对比**：梯形 O(h²)、辛普森 O(h⁴)。**h 减半：梯形误差 /4，辛普森误差 /16**——辛普森快得多，但要求 f 四阶可导、且 n 为偶数。

**为什么辛普森这么准**：抛物线（二次）能"预判"曲线的弯曲，而直线不能——**用更贴合曲线的形状去逼近，收敛更快。**

【历史溯源】**辛普森法则**得名于**英国数学家辛普森（Thomas Simpson，18 世纪）**——但他本人并非第一个提出者（此前开普勒、卡瓦列里已用过类似抛物线插值求积）。**它是数值积分家族里"用多项式拟合"思想的代表**：拟合次数越高（二次、三次……），误差阶越高，但要求函数越光滑。**"用更高的多项式去贴，换更高阶的收敛"——这是数值积分的核心权衡。**

【工程实践】辛普森法则在工程里是"精度/成本"的甜点位：**大多数工程信号（连续、四阶可导）下，辛普森用较少采样就达到足够精度**——所以它是工程数值积分的默认首选。**但要注意：n 必须偶数，且函数不能太野（四阶导数要存在）**，否则要退回梯形或更稳的方法。

</blockquote>

### 第 5 轮：具体算一把——梯形 vs 辛普森，看谁更准

**老谟**："光说'辛普森快'不够，我们算一个真的。**∫₀¹ eˣ dx 的精确值是 e−1≈1.71828。** 你分别用梯形和辛普森（n=2，h=0.5）手算它，看看各自误差多大。"

**造物主**："……先算点：f(0)=1，f(0.5)=e^0.5≈1.64872，f(1)=e≈2.71828。
梯形（n=2）：T=(0.5/2)[1 + 2(1.64872) + 2.71828] = 0.25[1+3.29744+2.71828]=0.25×7.01572=**1.75393**。
辛普森（n=2）：S=(0.5/3)[1 + 4(1.64872) + 2.71828] = (1/6)[1+6.59488+2.71828]=(1/6)×10.31316=**1.71886**。
误差：梯形 1.75393−1.71828=**0.03565**；辛普森 1.71886−1.71828=**0.00058**。**辛普森误差是梯形的约 1/60！**"

**老谟**："这就是 O(h²) 和 O(h⁴) 的差别——**同样的段数、同样的点，辛普森准了 60 倍。** 下一轮我们把这章收尾：**为什么工程里'先粗调再用牛顿法精修''先梯形打底再用辛普森加密'，以及它们和浮点误差、梯度下降的关系。**"

### 📐 知识锚点：数值求根与数值积分的工程取舍

<blockquote style="background:#fff8e1">

【概念深挖】**工程里的三个"取舍"**：
1. **求根：先稳后快**——先用二分/网格（线性收敛、稳、不挑初值）粗逼近到够近，再用牛顿法（二次收敛、快但挑初值）精修。**把"稳"和"快"各用在其擅长处。**
2. **积分：先简后精**——函数不野、要快速估计用梯形（O(h²)，简单）；要精度用辛普森（O(h⁴)，快但要求四阶可导、n 偶数）。**按精度需求选工具。**
3. **浮点代价**（衔接册02 第 02 章）：数值方法里 h 不能无限小——**h 太小，f(x+h)−f(x) 撞上机器精度（machine epsilon），差商/和式反而被舍入误差淹没**；h 太大又不够准。**"h 该取多大"是数值方法的艺术，也是册02 浮点误差的直接应用。**

【工程实践】**梯度下降 vs 牛顿法**（衔接第 01 章导数）：求"目标函数最小值"（不是求根，但同源）——
- **梯度下降**：只用一阶信息（梯度=导数），沿负梯度走一步 x←x−η∇f，η 是学习率。**便宜、可扩展到高维（深度学习），但收敛慢（线性）。**
- **牛顿法**：用二阶信息（Hessian 矩阵），x←x−H⁻¹∇f。**收敛快（二次），但每步要算并求逆 Hessian，高维太贵。**
- **工程结论**：低维、能算 Hessian → 牛顿法；高维、只能算梯度（深度学习）→ 梯度下降。**"用多少阶信息，换多少收敛速度，付出多少每步代价"——这是优化算法永恒的核心权衡。**

【历史溯源】"先粗调、再精修""按精度选工具"这些取舍，不是现代工程发明的——**从阿基米德（夹逼算 π）到开普勒（酒桶体积用抛物线拟合），人类一直在"精度"与"成本"之间权衡**。**机器只是把这种权衡算法化了**：数值求根、数值积分，本质是"用有限步可算的逼近，换取可控的误差"。

</blockquote>

## 严格化走廊

> 位置说明：对话负责"直觉"——为什么牛顿法沿切线、为什么辛普森比梯形准。本走廊负责"严谨"——把牛顿法二次收敛、梯形/辛普森误差阶落成**完整可复写**的证明。三个定理都标注"证明类型 + 每一步依据"，且都承接第 03 章中值定理、第 04 章黎曼和、第 07 章泰勒展开——红线 1 的硬要求，不许用"显然""差不多"糊弄。

### 定义：牛顿法、梯形法则、辛普森法则

- **牛顿法**：对求根 f(x)=0，给定初值 x₀，迭代 \(x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}\)。若 f 在根 r 附近光滑且 f'(r)≠0、x₀ 离 r 够近，则 xₙ→r。
- **梯形法则**：\(T=\frac{h}{2}[f(x_0)+2f(x_1)+\cdots+2f(x_{n-1})+f(x_n)]\)，h=(b−a)/n，xᵢ=a+ih。
- **辛普森法则**：\(S=\frac{h}{3}[f(x_0)+4f(x_1)+2f(x_2)+\cdots+2f(x_{n-2})+4f(x_{n-1})+f(x_n)]\)，n 为偶数。

> **证明类型标注**：本章三座证明——**定理 1（牛顿法二次收敛）用"泰勒展开 + 误差递推的直接证明"**（对 f(r) 在 xₙ 处二阶展开，消去主项，得 e_{n+1}=C eₙ²）；**定理 2（梯形误差阶）与定理 3（辛普森误差阶）用"单步局部误差 + 累加的直接证明"**（对单个小区间做泰勒展开得局部误差，再对 n 段累加得整体误差阶）。三座都承接第 07 章泰勒、第 03 章中值/积分中值定理。
>
> **关于对话**：本章第 1、2、3、4 轮是读者**第一次**正式接触牛顿法、梯形、辛普森，对话做了"引导式推导"（教学示范——为什么想到"沿切线滑到 x 轴""两端平均""用抛物线拟合"）。**正式的可复写证明（每一步标依据）在本走廊定理 1、2、3**。对话负责"为什么会想到这步"，走廊负责"怎么把它写标准"——与第 01 章 L233-235、第 04 章口径一致。

### 定理 1（牛顿法二次收敛）：|e_{n+1}| ≤ C|eₙ|²（eₙ=xₙ−r）

**前提**：f 在根 r 的某邻域内二阶可导且 f'' 有界；f'(r)≠0 且 f' 在该邻域内有正下界；初值 x₀ 离 r 足够近使迭代收敛。

**结论**：存在常数 C，使 \(|e_{n+1}|\le C\,e_n^2\)（二次收敛）。

**证明类型**：直接证明（泰勒展开 + 误差递推）。

**证明**：
- 第 1 步：**写迭代误差递推**。由迭代格式 \(x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}\) 与 e_{n+1}=x_{n+1}−r、eₙ=xₙ−r：
  $$e_{n+1}=e_n-\frac{f(x_n)}{f'(x_n)}.$$
  （依据：迭代格式定义 + 误差定义代入。）
- 第 2 步：**对 f(r) 做泰勒二阶展开**（在 xₙ 处展开，r 为展开点 xₙ 处的增量）：
  $$0=f(r)=f(x_n)+f'(x_n)(r-x_n)+\frac12 f''(\xi_n)(r-x_n)^2,$$
  其中 ξₙ 介于 xₙ 与 r 之间（依据：第 07 章带拉格朗日余项的泰勒定理）。
- 第 3 步：**解出 f(xₙ)**。因 r−xₙ=−eₙ，代入上式：
  $$0=f(x_n)-f'(x_n)e_n+\frac12 f''(\xi_n)e_n^2 \implies f(x_n)=f'(x_n)e_n-\frac12 f''(\xi_n)e_n^2.$$
  （依据：第 2 步代入 r−xₙ=−eₙ，移项。）
- 第 4 步：**代入迭代递推**。由第 1、3 步：
  $$e_{n+1}=e_n-\frac{f'(x_n)e_n-\frac12 f''(\xi_n)e_n^2}{f'(x_n)}=e_n-e_n+\frac12\frac{f''(\xi_n)}{f'(x_n)}e_n^2=\frac12\frac{f''(\xi_n)}{f'(x_n)}e_n^2.$$
  （依据：第 1 步代入第 3 步的 f(xₙ) 表达式，约去 eₙ 项。）
- 第 5 步：**取绝对值并给上界**。由 f'' 有界（|f''|≤M₂）且 f' 有正下界（|f'|≥m₁>0）：
  $$|e_{n+1}|=\frac12\left|\frac{f''(\xi_n)}{f'(x_n)}\right|\,e_n^2\le \frac{M_2}{2m_1}\,e_n^2=C\,e_n^2.$$
  （依据：有界性 + 三角不等式，令 C=M₂/(2m₁)。）
- 第 6 步：故牛顿法二次收敛（|e_{n+1}|≤C eₙ²）。∎

> **依据标注**：步 2 用"第 07 章泰勒定理（拉格朗日余项）"——发动机；步 3、4 用代数化简（把 f(xₙ) 解出并代入，消去主导项 eₙ）；步 5 用"f'' 有界、f' 有正下界"（由前提保证）。**读法**：二次收敛的根源是泰勒展开里那 (1/2)f''(ξ)eₙ² 的余项——**牛顿法把一阶项 eₙ 精确消掉，剩下的最高阶就是 eₙ²**。这就是"它为什么越算越快"的数学解释：每一步都在"消掉线性误差、留下二次误差"。

### 定理 2（梯形法则误差阶）：|E_T| ≤ (b−a)/12 · h² · max|f''|

**前提**：f 在 [a,b] 上二阶连续可导；[a,b] 等分 n 段，h=(b−a)/n。

**结论**：梯形法则误差满足 \(|E_T|\le\frac{b-a}{12}h^2\max_{[a,b]}|f''|\)（O(h²)）。

**证明类型**：直接证明（单段局部误差 + 累加）。

**证明**：
- 第 1 步：**写单段误差**。对单段 [xᵢ₋₁,xᵢ]（长为 h），梯形近似为 (h/2)(f(xᵢ₋₁)+f(xᵢ))，单段误差
  $$E_i=\int_{x_{i-1}}^{x_i} f(x)\,dx-\frac{h}{2}\big(f(x_{i-1})+f(x_i)\big).$$
  （依据：误差定义 = 真值 − 梯形近似。）
- 第 2 步：**对单段误差做泰勒展开**。把 f(x) 在 xᵢ₋₁ 处展开到二阶：
  $$f(x)=f(x_{i-1})+f'(x_{i-1})(x-x_{i-1})+\frac12 f''(x_{i-1})(x-x_{i-1})^2+O((x-x_{i-1})^3).$$
  逐项积分（∫ 从 xᵢ₋₁ 到 xᵢ，即 t 从 0 到 h，t=x−xᵢ₋₁）：
  $$\int_{x_{i-1}}^{x_i}f=h f(x_{i-1})+\frac{h^2}{2}f'(x_{i-1})+\frac{h^3}{6}f''(x_{i-1})+O(h^4).$$
  又梯形项：
  $$\frac{h}{2}\big(f(x_{i-1})+f(x_i)\big)=\frac{h}{2}\Big(2f(x_{i-1})+h f'(x_{i-1})+\frac{h^2}{2}f''(x_{i-1})+O(h^3)\Big)=h f(x_{i-1})+\frac{h^2}{2}f'(x_{i-1})+\frac{h^3}{4}f''(x_{i-1})+O(h^4).$$
  （依据：第 07 章泰勒展开 + 对多项式的逐项积分/代入。）
- 第 3 步：**相减得局部误差主项**：
  $$E_i=\Big(\frac{h^3}{6}-\frac{h^3}{4}\Big)f''(x_{i-1})+O(h^4)=-\frac{h^3}{12}f''(x_{i-1})+O(h^4).$$
  （依据：第 2 步两式相减，合并 h³ 项。）
- 第 4 步：**累加 n 段**（h³/12·n = h³/12·(b−a)/h = h²(b−a)/12）：
  $$E_T=\sum_i E_i=-\frac{h^2}{12}\sum_i f''(x_{i-1})h+O(h^3)\;\to\;-\frac{h^2}{12}\int_a^b f''(x)\,dx=-\frac{h^2}{12}\big(f'(b)-f'(a)\big)+O(h^3).$$
  取绝对值并用 |f'(b)−f'(a)|≤(b−a)max|f''|（依据：积分中值定理/拉格朗日中值定理，第 03 章）：
  $$|E_T|\le \frac{b-a}{12}h^2\max_{[a,b]}|f''|.$$
  （依据：累加 + 中值定理给上界。）
- 第 5 步：故 \(E_T=O(h^2)\)。∎

> **依据标注**：步 2 用"第 07 章泰勒展开"（把 f 在每段展开，逐项积分）；步 3 用代数化简（两式相减，h³ 系数差得 −1/12）；步 4 用"黎曼和/定积分把 Σf''(xᵢ)h 变成 ∫f''"（第 04 章）+ 中值定理（第 03 章）给上界。**读法**：误差是 h³ 的局部误差，经 n≈(b−a)/h 段累加，整体变成 h²——**"局部 O(h³)、累积 O(h²)"是梯形误差的来源**。切细一倍 h→h/2，误差约 /4，正好对上。

### 定理 3（辛普森法则误差阶）：|E_S| ≤ (b−a)/180 · h⁴ · max|f''''|

**前提**：f 在 [a,b] 上四阶连续可导；[a,b] 等分成**偶数** n 段，h=(b−a)/n。

**结论**：辛普森法则误差满足 \(|E_S|\le\frac{b-a}{180}h^4\max_{[a,b]}|f''''|\)（O(h⁴)）。

**证明类型**：直接证明（单段局部误差 + 累加）。

**证明**：
- 第 1 步：**写双段局部误差**。辛普森每两段（[xᵢ₋₁,xᵢ₊₁]，长 2h，中点为 xᵢ）用一条抛物线，双段近似为 (h/3)(f(xᵢ₋₁)+4f(xᵢ)+f(xᵢ₊₁))，双段误差
  $$E_i^{S}=\int_{x_{i-1}}^{x_{i+1}} f(x)\,dx-\frac{h}{3}\big(f(x_{i-1})+4f(x_i)+f(x_{i+1})\big).$$
  （依据：误差定义。）
- 第 2 步：**对 f 在 xᵢ 处展开到四阶**，并利用"抛物线插值对奇数次幂精确"这一事实（三次及以下幂的积分，辛普森精确，因抛物线插值对二次精确且奇次项在对称区间积分为 0）——于是局部误差主项来自四阶项：
  $$E_i^{S}=-\frac{h^5}{90}f''''(x_i)+O(h^6).$$
  （依据：第 07 章泰勒展开至四阶 + 对称区间上奇次幂积分为 0（第 05 章对称性）+ 逐项积分；此式是标准辛普森局部误差公式，推导过程与梯形同构，只是展开到四阶。）
- 第 3 步：**累加 n/2 个双段**（共 n/2 个双段，h⁵/90·(n/2) = h⁵/90·(b−a)/(2h) = (b−a)h⁴/180；O(h⁶) 项累加后为 O(h⁵)）：
  $$E_S=-\frac{h^5}{90}\sum_i f''''(x_i)+O(h^5)=-\frac{h^4}{90}\sum_i f''''(x_i)\cdot h+O(h^5).$$
  **加注**：这里的 Σ 是对 **n/2 个双段的中点 x₁,x₃,…,xₙ₋₁**（彼此间距 **2h**）求和。因此"宽 2h 的黎曼和"为 Σ f⁗(xᵢ)·2h ≈ ∫ₐᵇf⁗，即 Σ f⁗(xᵢ)·h ≈ (1/2)∫ₐᵇf⁗。故上式化为
  $$E_S=-\frac{h^4}{90}\cdot\frac{1}{2}\int_a^b f''''(x)\,dx+O(h^5)=-\frac{h^4}{180}\big(f'''(b)-f'''(a)\big)+O(h^5).$$
  （依据：累加 + 对双段中点（间距 2h）的黎曼和取极限 + 微积分基本定理 ∫f⁗=f'''。关键：**中点间距是 2h 而非 h，所以宽 h 的 Σf⁗(xᵢ)h 只覆盖半条积分路径，出现 1/2 因子**。）
  取绝对值并用积分中值定理：
  $$|E_S|\le \frac{b-a}{180}h^4\max_{[a,b]}|f''''|.$$
  （依据：累加 + 中值定理（第 03 章），|f'''(b)−f'''(a)|≤(b−a)max|f⁗|。）
- 第 4 步：故 \(E_S=O(h^4)\)。∎

> **依据标注**：步 2 用"第 07 章泰勒展开至四阶 + 对称区间奇次项积分为 0（第 05 章）"得双段局部误差 −h⁵/90 f⁗；步 3 用"累加 n/2 个双段 + 对双段中点（间距 2h）的黎曼和取极限 + FTC"得整体 h⁴ 阶——**关键细节：Σ 在中点 x₁,x₃,…（间距 2h）上求和，故 Σf⁗(xᵢ)h ≈ (1/2)∫f⁗，出现 1/2 因子**。**读法**：辛普森比梯形多用了"抛物线"，把局部误差从 O(h³) 推到 O(h⁵)，累积后从 O(h²) 推到 O(h⁴)——**"拟合阶数越高、要求的导数阶越高、换来的收敛阶越高"**。**注意前提：要 f 四阶可导，否则该误差界失效。**

### 书写格式模板（可复写卡片——对着空白纸照写）

> 这是本章要你抄进脑子的两张卡。**以后机器算"算不出来"的微积分，就照这个骨架填**：

```text
卡1：牛顿法求根
  写迭代 x_{n+1} = x_n − f(x_n)/f'(x_n)。
  从合适的 x_0 开始（先用二分/网格粗逼近到够近）。
  迭代到 |x_{n+1}−x_n| 小于目标容差。每次可估误差 |e_{n+1}|≈C e_n²（二次收敛）。

卡2：数值积分
  定积分 ∫_a^b f ≈ 梯形或辛普森。
  梯形 T = (h/2)[f(x0)+2f(x1)+...+2f(x_{n−1})+f(xn)]，误差 ≤ (b−a)/12·h²·max|f''|。
  辛普森 S = (h/3)[f(x0)+4f(x1)+2f(x2)+...+f(xn)]（n 偶数），误差 ≤ (b−a)/180·h⁴·max|f⁗|。
  要精度翻 n 倍 → 梯形 h 除 √n，辛普森 h 除 n^(1/4)。
```

**三个检查点**：① 牛顿法先确认 f'(xₙ)≠0、初值够近（否则发散）；② 辛普森**n 必须偶数**，且 f 四阶可导（否则误差界不成立）；③ 数值方法的 h/步数不能无脑加大——**h 太小会撞浮点舍入误差（册02 第 02 章），要权衡**。

### 反例/边界：数值方法何时失效

1. **牛顿法：f'(xₙ)=0 或初值太远 → 发散**：若某步 f'(xₙ)=0，切线水平不交 x 轴，迭代无定义；初值离根太远，可能迭代到别的根或震荡发散。**先粗逼近保底。**
2. **牛顿法：重根（f'(r)=0）→ 退化为线性收敛**：根是重根时 f'(r)=0，二次收敛退化为线性（误差只按固定比例缩小）。**本册只讲简单根（f'(r)≠0）。**
3. **梯形/辛普森：f 不够光滑 → 误差界失效**：辛普森要求 f 四阶可导，若 f 在区间内有间断或尖点（不可导），O(h⁴) 误差界不成立，实际可能远差于理论。**先判断函数"野不野"。**
4. **h 太小 → 舍入误差主导**：数值积分/差商里 h 缩到接近 machine epsilon 时，浮点舍入误差淹没截断误差（册02 第 02 章）——**存在一个最优 h，不是越小越好。**
5. **辛普森 n 必须偶数**：n 奇数时公式不对（系数模式断在半截），要么补一段要么退回梯形。

## 知识点总结

### 知识点（本章推出的核心概念）

- **牛顿法**：x_{n+1}=xₙ−f(xₙ)/f'(xₙ)——用切线逼近根，需 f'(r)≠0、初值够近。
- **二次收敛**：|e_{n+1}|≤C eₙ²——误差每步平方，比二分法（线性）快得多。
- **梯形法则**：T=(h/2)[f(x₀)+2f(x₁)+…+f(xₙ)]，误差 O(h²)。**黎曼和的升级版。**
- **辛普森法则**：S=(h/3)[f(x₀)+4f(x₁)+2f(x₂)+…+f(xₙ)]（n 偶数），误差 O(h⁴)。
- **误差阶对比**：梯形 /4、辛普森 /16（h 减半时）——"拟合阶数越高、收敛越快、要求导数阶越高"。
- **"逼近 + 误差估计"**：机器不追求精确解，而是"可算的逼近 + 可估计的误差"。

### 历史结论（本章涉及的史料）

- **牛顿（17 世纪）/ 拉弗森（Raphson，1690）**：牛顿法（牛顿-拉弗森法），用切线逼近求根。
- **阿基米德（公元前 3 世纪）**：夹逼多边形算圆面积——逼近思想鼻祖。
- **辛普森（Thomas Simpson，18 世纪）**：辛普森法则得名（但开普勒、卡瓦列里更早用过抛物线插值求积）。
- **黎曼（1854）**：定积分严格定义，梯形/辛普森等"取法"才被系统整理。
- **洛夫莱斯/图灵（19-20 世纪）**：机器"能算非数值问题"到可计算性——微积分落地为算法。

### 工程实践结论（本章知识在真实工程里怎么用）

- **数值求根**：内部收益率、相机标定、机器学习参数——非线性方程/优化，先牛顿法。
- **梯度下降 vs 牛顿法**：低维可算 Hessian → 牛顿法（二次收敛但贵）；高维只能算梯度 → 梯度下降（便宜但线性）。**用多少阶信息换多少收敛速度。**
- **数值积分**：工程信号（四阶可导）→ 辛普森首选（精度/成本甜点）；函数野 → 退回梯形或更稳方法。
- **浮点取舍**（册02 第 02 章）：h 不是越小越好，太小撞舍入误差——**存在最优 h**。
- **"先稳后快"两段式**：先用二分/网格粗调，再用牛顿法精修。

## 计算训练场

> 位置说明：对话负责"为什么牛顿法快、为什么辛普森准"，这里负责"怎么算"。下面三题**必须动笔**，每题 10 分钟以上，先自己写再对答案。**难度递进：易→中→难。**

### 题 1（易→中）：手算牛顿法 3 步逼近根

**题干**：老谟让造物主用牛顿法求 x³−x−2=0 在 (1,2) 的根，初值取 x₀=1.5，迭代 **3 步**，写出每步 f、f'、x_{n+1}，并估收敛趋势。（f(x)=x³−x−2，f'(x)=3x²−1。）

**完整分步解答：**

- 第 1 步（x₀=1.5）：f(1.5)=3.375−1.5−2=**−0.125**，f'(1.5)=3(2.25)−1=**5.75**。
  x₁ = 1.5 − (−0.125)/5.75 = 1.5 + 0.021739 = **1.521739**。
- 第 2 步（x₁=1.521739）：x₁²=2.315690，f(x₁)=x₁³−x₁−2=3.523876−1.521739−2=**0.002137**，f'(x₁)=3×2.315690−1=**5.94707**。
  x₂ = 1.521739 − 0.002137/5.94707 = 1.521739 − 0.000359 = **1.521380**。
- 第 3 步（x₂=1.521380）：x₂²=2.314597，f(x₂)=3.521382−1.521380−2≈**0.000002**，f'(x₂)=3×2.314597−1=**5.94379**。
  x₃ = 1.521380 − 0.000002/5.94379 = **1.521380**（几乎不变）。
- **收敛趋势**：误差 |eₙ|≈|xₙ−1.52138|，从 ~0.021 跳到 ~0.0004 再跳到 ~10⁻⁶——**每步误差约平方（二次收敛），3 步已到小数点后 6 位。**

**答**：x₁≈1.521739，x₂≈1.521380，x₃≈1.521380。根 ≈ **1.52138**。（与第 05 章 IVT 二分法区间 [1.5,1.625] 对照，牛顿法 3 步比二分法几十步还准。）

**常见错误**：① f'(x) 算错（x³ 导数是 3x²，−x 导数是 −1，x³−x−2 的导数是 3x²−1，别把常数 −2 也求导）；② x_{n+1} 符号用反（是减 f(xₙ)/f'(xₙ)，别加）；③ 每步没重算 f(xₙ)、f'(xₙ)（牛顿法每一步都要在"当前 xₙ"处重新算，不能沿用上一步的值）。

### 题 2（中→难）：梯形 vs 辛普森手算 ∫₀¹ eˣ dx（n=2）并估误差

**题干**：老谟让造物主用梯形法则和辛普森法则分别手算 ∫₀¹ eˣ dx（n=2，h=0.5），已知精确值 e−1≈1.7182818，比较两者误差。

**完整分步解答：**

- 第 1 步（取点）：f(0)=e⁰=1，f(0.5)=e^0.5≈1.6487213，f(1)=e≈2.7182818。
- 第 2 步（梯形，n=2）：
  T=(0.5/2)[f(0)+2f(0.5)+f(1)] = 0.25[1 + 2(1.6487213) + 2.7182818] = 0.25[1+3.2974426+2.7182818] = 0.25×7.0157244 = **1.753931**。
- 第 3 步（辛普森，n=2）：
  S=(0.5/3)[f(0)+4f(0.5)+f(1)] = (1/6)[1 + 4(1.6487213) + 2.7182818] = (1/6)[1+6.5948852+2.7182818] = (1/6)×10.313167 = **1.718861**。
- 第 4 步（误差）：
  梯形误差 |E_T|=|1.753931−1.7182818|=**0.035649**；辛普森误差 |E_S|=|1.718861−1.7182818|=**0.000579**。
  **辛普森误差约是梯形的 1/61**（0.035649/0.000579≈61.6）。
- 第 5 步（误差公式校验）：f=eˣ，f''=eˣ，max|f''| 在 [0,1]=e≈2.71828。梯形误差界 (1/12)(0.5)²·2.71828=0.0566 ≥ 实际 0.03565 ✓。f⁗=eˣ，辛普森误差界 (1/180)(0.5)⁴·2.71828=0.000944 ≥ 实际 0.000579 ✓。

**答**：梯形 ≈1.753931（误差 0.03565），辛普森 ≈1.718861（误差 0.00058）。**同段数下辛普森准约 61 倍。**

**常见错误**：① 梯形中间系数是 2（首尾 1、中间全 2），辛普森是 4/2 交替（首尾 1、奇数下标 4、偶数下标 2）——**两套系数别混**；② 辛普森 n 取奇数导致系数模式错乱；③ 误差公式里 h 的幂用错（梯形 h²、辛普森 h⁴），导致校验失败。

### 题 3（难）：加密一倍看误差——验证 O(h²) 与 O(h⁴)

**题干**：老谟让造物主把 ∫₀¹ eˣ dx 的 n 从 2 加密到 4（h 从 0.5 减到 0.25），分别手算梯形和辛普森，验证"h 减半，梯形误差约 /4、辛普森误差约 /16"。（精确值 1.7182818。）

**完整分步解答：**

- 第 1 步（取 n=4 的点，h=0.25）：f(0)=1，f(0.25)=e^0.25≈1.2840254，f(0.5)=1.6487213，f(0.75)=e^0.75≈2.1170000，f(1)=2.7182818。
- 第 2 步（梯形 n=4）：
  T=(0.125)[f(0)+2f(0.25)+2f(0.5)+2f(0.75)+f(1)]
  =0.125[1 + 2.5680508 + 3.2974426 + 4.2340000 + 2.7182818]
  =0.125×13.8177752 = **1.727222**。
  误差 |E_T|=|1.727222−1.7182818|=**0.008940**。
  与 n=2 的 0.035649 比：0.035649/0.008940≈**3.99 ≈ 4** ✓（h 减半，梯形误差约 /4）。
- 第 3 步（辛普森 n=4）：
  S=(0.25/3)[f(0)+4f(0.25)+2f(0.5)+4f(0.75)+f(1)]
  =(1/12)[1 + 5.1361016 + 3.2974426 + 8.4680000 + 2.7182818]
  =(1/12)×20.619826 = **1.718319**。
  误差 |E_S|=|1.718319−1.7182818|=**0.000037**。
  与 n=2 的 0.000579 比：0.000579/0.000037≈**15.6 ≈ 16** ✓（h 减半，辛普森误差约 /16）。
- 第 4 步（结论）：**h 减半，梯形误差约为原 1/4（O(h²)），辛普森误差约为原 1/16（O(h⁴)）**——这正是定理 2、3 的数值验证。

**答**：n=4 时梯形 ≈1.727222（误差 0.00894，为 n=2 的 ~1/4），辛普森 ≈1.718319（误差 0.000037，为 n=2 的 ~1/16）。**O(h²) vs O(h⁴) 的差别，翻一倍就拉开 4 倍 vs 16 倍。**

**常见错误**：① 加密后没重算所有点（n=4 要多取 f(0.25)、f(0.75) 两个中点）；② 误差比值算错方向（要算"新误差/旧误差"，梯形约 1/4、辛普森约 1/16）；③ 把"误差 /4"误解成"误差减 4"——是除以 4，不是减 4。

**题 A（计算，易→中）：牛顿法 1 步**

用牛顿法求 √2（即 f(x)=x²−2=0 的正根），初值 x₀=1.5，迭代 2 步。f'(x)=2x。

**完整解答**：x₀=1.5，f(1.5)=2.25−2=0.25，f'(1.5)=3，x₁=1.5−0.25/3=1.5−0.0833=**1.41667**。f(1.41667)=2.00694−2=0.00694，f'(1.41667)=2.83333，x₂=1.41667−0.00694/2.83333=1.41667−0.00245=**1.41422**。（√2≈1.41421，两步已到 5 位。）**验证二次收敛**：|e₁|=|1.41667−1.41421|=0.00246，|e₂|=|1.41422−1.41421|=0.00001，误差约 /250（平方级）。

**题 B（计算，中→难）：数值积分并估误差**

用梯形和辛普森（n=2，h=0.5）手算 ∫₀¹ 1/(1+x²)dx（精确值 π/4≈0.785398），并比较两者误差。

**完整解答**：f(0)=1，f(0.5)=1/(1.25)=0.8，f(1)=1/2=0.5。
梯形：T=0.25[1+2(0.8)+0.5]=0.25[1+1.6+0.5]=0.25×3.1=**0.775**，误差 |0.775−0.785398|=0.01040。
辛普森：S=(1/6)[1+4(0.8)+0.5]=(1/6)[1+3.2+0.5]=(1/6)×4.7=**0.783333**，误差 |0.783333−0.785398|=0.00207。
**辛普森误差约为梯形的 1/5**（0.01040/0.00207≈5.0）。（注：此处辛普森优势不如 eˣ 例显著，因为 1/(1+x²) 四阶导数在 [0,1] 变化大，但仍是 O(h⁴) vs O(h²) 的差距方向。）

**题 C（概念，检查理解）**

(a) 牛顿法为什么是"二次收敛"？它比二分法快在哪？
(b) 为什么辛普森法则比梯形法则收敛快，但要求更高？
(c) 为什么数值方法里 h 不是越小越好？

**完整解答**：
(a) 泰勒展开把一阶项 eₙ 精确消掉，剩余最高阶是 (1/2)f''(ξ)/f'(xₙ)·eₙ²，故 |e_{n+1}|≤C eₙ²——**误差平方，小数点位数每步约翻倍**；二分法每步只把误差乘 1/2（线性），两者是数量级差别。
(b) 辛普森用抛物线（二次）拟合每两段，局部误差 O(h⁵)、累积 O(h⁴），比梯形的直线拟合（O(h³)/O(h²)）高一阶——**但要求 f 四阶可导（f'''' 存在），且 n 为偶数**；函数不够光滑则 O(h⁴) 误差界失效。
(c) h 太小，f(x+h)−f(x) 和黎曼项会撞上浮点舍入误差（册02 第 02 章的 machine epsilon），舍入误差淹没截断误差；h 太大又不够准。**存在最优 h，不是越小越好。**
