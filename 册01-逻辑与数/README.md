# 《逻辑与数》· 第 1 册

> **苏格拉底对话体自学教材**，老谟 ⇄ 造物主一问一答，让读者从"只会开和关的比特"一路走到"写出自己的第一个证明"。本册是《数学基础》系列 7 册中的第 **1** 册，也是**推理地基**——后续 6 册（实数极限、微积分、线性代数……）的所有严格化走廊，全靠这一册打底。
>
> **核心立场**：本册在保留样书 Ch1-4（数/逻辑/集合/函数）推导节奏的同时，**新增「证明方法入门」与「证明实战」两章**——因为样书缺失的证明训练，正是读者跨过"看别人证明"到"自己写证明"那道最陡坡的关键。**证明不是魔法，是把"你懂的东西"按规则连起来。**

## 每章标配（继承 skill 升级后的铁律）

- **严格化走廊**：定义 → 定理（带全前提）→ ≥2 个可复写完整证明 → 反例/边界。每步标注"依据"，绝不说"显然"。
- **证明类型标注（本册特色）**：每一章走廊开头都明确标注本章证明的"招式"——直接 / 反证 / 归纳 / 构造 / 对偶。**读证明先问"用的哪一招"，比看懂结论更进一步**；第 05 章系统给出四招的完整分类与适用场景。
- **证明格式模板卡（本册特色）**：第 03 章给「双包含」模板卡，第 05 章给四种证明的书写格式模板——这是后面 6 册严格化走廊的通用脚手架，也是读者"自己写证明"的第一套脚手架。
- **计算训练场**：每章 ≥3 道计算/证明题（动笔 10 分钟+），易→中→难，附完整分步解答 + 常见错误；第 05、06 章以"完整书写证明"为重心。
- **约定意识**：二进制是工程将就、补码是编码约定、"1 不是素数"是规定——**约定的松，推论的硬**，贯穿全册。
- **节奏平衡**：抽象概念（证明四招、反证法）独立成轮、给足篇幅，绝不报菜名。

## 创作流程

本册由 **创世游戏团队** 协作完成，执行「创作 → 三专家评审 → 修改 → 复审 → 定稿」循环：
- **主笔（main）**：统筹、起草样板章、统稿
- **严格性首席（rigor-chief）**：严格化走廊把关（证明类型标注、格式模板卡）
- **习题与工程设计师（exercise-designer）**：计算训练场数值复核
- **跨学科顾问（cross-advisor）**：历史准确、工程实践、节奏平衡
- **统稿员（writer-info）**：答案速查页数值与正文逐章核对、全册统稿
- **作者 ×3（writer-basic/logic/set-func-proof）**：按样板标准并行创作

所有章节经三专家逐章评审通过后定稿，数值经亲手核算、并与正文逐一核对一致。
