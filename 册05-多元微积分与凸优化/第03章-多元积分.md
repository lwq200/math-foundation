# 第 03 章 · 多元积分——高维"面积"怎么加出来

> 本章从哪个问题出发：一元积分把曲线下的面积"切成薄条再累加"，得到的是一条线段上积累的总量。可一旦进入二维，你要算的不再是"一根线段下的面积"，而是"一张曲面底下一整块区域上的体积"——**"切"的方向突然从"一条路"变成"一片地"，你往哪个方向切？不同的切法，加出来的东西还是同一个吗？**
> 推导到哪个结论：答案是**二重积分**——先把区域切成无数小块（小柱），每块的高度乘上小块的底面积，再全部加起来取极限；进而发现**累次积分**（先沿一个方向积、再沿另一个方向积）和"矩形域上的二重积分"是同一件事（**Fubini 定理**）；当区域是圆的、函数带旋转对称性时，**极坐标变换** dA = r·dr·dθ 能把"切"这件事做得又巧又快。
>
> 核心认知：**二重积分 = 把一块区域切成小柱、体积（高×底面积）求和取极限；它有三种"切法"——先 x 后 y、先 y 后 x、极坐标，在"好区域"上它们给出同一个数。** 这一章是你从"点上的导数"走向"整块区域上的累积"的第一块跳板：它直接为册 06 的联合分布概率 P((X,Y)∈D) = ∫∫_D f dxdy 铺好了路。

## 引子

老谟的厨房里横着一大块还没有切的红薯蛋糕，形状歪歪扭扭——不是规整的长方体，也不是圆柱，就是一刀下去随手切出来的、边角不齐的一块。

"我今天不爬山了，"我抄起刀，"我盯上这块蛋糕。老谟，我问你个实在的问题：**这块蛋糕占了多少体积？** 你别跟我说秤——我要的是一个数，而且要用数学算出来。"

老谟靠在灶台边，抱着胳膊看我："行。那我先问你——**你打算怎么切？**"

"切？"我愣了一下神，"我算体积，跟切有什么关系？"

"关系大了去了。你上次算一元积分的'面积'，是不是靠'把曲线下的面积切成无数条细条，一条一条加'？现在这块蛋糕是二维的'面'底下的'体积'，你拿什么当'条'？——**条只有长度，可这片蛋糕底下是一整片地。**"

我盯着那块歪蛋糕沉默了一会儿："……你是说，我这次不能切'条'，得切'块'？"

"你自己说的。"老谟把刀推过来，"来吧，先把'该切什么'想清楚，这一章你就通一半了。"

## 对话引擎

### 第 1 轮：一条线下的面积，怎么长成一片地下的体积

**老谟**："先别碰蛋糕。回到你熟的一元积分：y = f(x)，从 a 到 b 这一段的'面积'，你是靠什么算出来的？"

**造物主**："把 [a, b] 切成 n 段小段，每段宽度 Δx，取一点，高是 f(某点)，做小矩形 f·Δx，然后全部加起来，让 Δx 趋于 0 取极限。"

**老谟**："好。那你现在告诉我：'小段'这条东西，在二维世界里还够用吗？"

**造物主**："……不太够。一元里底下是一条'线段'，切出来的是一维的'段'，所以小片是'宽 × 高'的薄条。可二维里底下是一块'区域'，它有自己的宽度和长度，再切'条'就不对了——得切出一片片有'面积'的小块。"

**老谟**："这就是你刚刚自己立的门槛。**一元积分切'条'，因为底是一维的；二重积分要切'块'，因为底是二维的。** 每块小柱的'体积' = 底下小块的面积 × 这块地方的平均高度。你把这一堆小柱全加起来，让小块面积趋于 0 取极限——这个极限，就是二重积分。你先别急着写式子，跟我说说：这样切出来的一堆小柱，加起来，你觉得和'体积'这件事，对得上吗？"

---

### 📐 知识锚点：二重积分——"切成小柱，求和取极限"

【概念深挖】**二重积分（double integral）** 的直觉：把区域 D 切成许多小矩形（小块），每块面积记为 ΔAᵢ，在每块上取一个代表点，算出该点的高度 f，于是每块对应一个小柱体，体积 ≈ f × ΔAᵢ。把**所有小柱的体积加起来**，再让**每块面积都趋于 0**（也就是切得越来越细），取极限：

```text
∬_D f(x,y) dA = lim  Σᵢ f(xᵢ*, yᵢ*) · ΔAᵢ
```

**读作"二重积分"，dA 表示"一个无穷小的面积元"。** 一元积分里积分项 f·dx 对应"长(宽) × 高"的窄条；二元里 f·dA = f·(长 × 宽) 对应"底面积(长×宽) × 高"的小柱——**注意 dA 本身是二维的面积元，小柱体积是 f·dA，不要再叠第三个维度。** **"切成小块 → 每块近似 → 求和 → 取极限"，这套四步曲和你一元积分见过的完全同构，只是"块"从一维的段长成了二维的小片。**

【工程实践】这套"切块求和取极限"在工程里有个极其直白的名字：**数值积分/蒙特卡洛估计**。你没法解析算某些复杂区域的体积时，就把区域切成网格，每格取个代表值，加总——这就是二重积分的"离散版"。后面讲概率时会看到，**算一个随机点落在某区域的概率，本质就是一个二重积分**：把区域切成小块，每块的概率密度乘小块面积，再加起来。

### 第 2 轮：先切 x 再切 y，还是先切 y 再切 x

**老谟**："二重积分的定义立起来了：切块、求和、取极限。可你手上立刻冒出一个麻烦——**底下这片区域是二维的，你手里只有'对 x 积分'和'对 y 积分'这两把一维的刀。** 你怎么用两把一维的刀，切出一片二维的地？"

**造物主**："……两把刀？那我先沿一个方向切成一条条'薄片'，再把每片薄片沿另一个方向切成'小格'？比如先按 x 切成竖条，每条再按 y 切成小段。"

**老谟**："你这不就是'先 x 后 y'吗。可你凭什么不能'先 y 后 x'——先按 y 切成横条，每条再按 x 切成小格？"

**造物主**："……对啊，为什么不行？横着切、竖着切，最后都是把整片地切成小格，块数也一样多。理论上应该加出同一个数吧？"

**老谟**："你踩到本章最关键的那块石头了。**先横切后竖切、先竖切后横切——这两种切法，得到的小格形状可能不一样（一个长条是横的还是竖的），但当块数趋于无穷时，极限是不是同一个数？** 这个问题，正是 Fubini 定理要回答的。你先别说'应该一样'，先把这两种切法'到底怎么操作'给我想清楚——每一步积分，到底是沿着哪条'边'在扫？"

---

### 📐 知识锚点：累次积分——把二重积分拆成两枚一维积分

【概念深挖】**累次积分（iterated integral）**：当区域 D 是**矩形** [a,b]×[c,d] 时，二重积分可以"一层一层"算：

```text
先 x 后 y：∬_D f dA = ∫_c^d [ ∫_a^b f(x,y) dx ] dy
先 y 后 x：∬_D f dA = ∫_a^b [ ∫_c^d f(x,y) dy ] dx
```

- **内层积分**：把另一个变量当常数，先沿一条直线（一个方向）积——这正好是第 01 章"偏导"反过来做的事：偏导是"按住别的变量求变化率"，累次的内层积分是"按住别的变量求累积"。
- **外层积分**：把内层得到"随外变量变化的函数"，再沿另一个方向积。

**几何直觉**：先 x 后 y 就像"先沿 x 方向扫出一条条长度，再把这些长度沿 y 方向累加"；先 y 后 x 则是反过来。**两者都是"把二维累加拆成两次一维累加"。** 矩形域上，Fubini 定理保证这两种拆法的结果相等（严格证明见严格化走廊定理 1）。

【工程实践】为什么"拆成两次一维积分"对工程是福音？因为**你不需要发明新的"二维积分器"，只要把你已经会的一维积分算法（梯形法、辛普森法、或者查原函数）套用两次**。很多数值库计算高维积分，就是用"一维积分套一维积分"递归下去。**"降维"是工程里最常用的化简手段——把一个难的高维问题，拆成几个好算的低维问题。**

### 第 3 轮：矩形域上，两种切法给出同一个数——但区域一歪，事情就来了

**老谟**："矩形域好办，两条边整整齐齐，先 x 后 y、先 y 后 x 都扫得动。可你抬头看看那块蛋糕——它的底面**不是矩形**，是歪的。这种情况下，'先 x 后 y'的切法还管用吗？"

**造物主**："……管用……吧？还是先沿 x 切成竖条，可每条竖条从 y 的哪里开始、到哪里结束，不再是个固定数了——得看这条竖条在 x 的哪个位置，它的上下边界随 x 变。"

**老谟**："你自己把最麻烦的地方说出来了：**区域歪了，积分限就不再是常数，而会变成'依赖另一个变量的函数'。** 先 x 后 y，竖条的 y 上下限是 y₁(x)、y₂(x)；先 y 后 x，横条的 x 左右限是 x₁(y)、x₂(y)。这两种写法，还是同一个二重积分吗？"

**造物主**："……理论上该是。可我现在有点怕：万一某一种切法特别难算、另一种特别容易呢？"

**老谟**："怕对了。**积分限变成函数之后，'难易'就分化了——有的函数按一种顺序根本积不出来，换个顺序却一马平川。** 这就是为什么'换积分次序'是一门真功夫。先别急，我们先把'矩形域上两种切法为什么一样'这件事，在你脑子里钉死，再去碰歪区域。"

---

### 第 4 轮：凭什么两种切法一样——Fubini 的直觉

**老谟**："矩形域上，先 x 后 y、先 y 后 x 结果一样。你现在打算怎么说服我？别扯'显然'，你给个理由。"

**造物主**："……我可以把矩形切成 n×m 个小格。先 x 后 y，就是先沿 y 方向把每一列的小格加起来，再把所有列加起来；先 y 后 x，就是先沿 x 方向把每一行的小格加起来，再把所有行加起来。**不管是先按行加还是先按列加，最后都是把同一张表里所有格子加一遍——总数当然一样！**"

**老谟**："你抓住了本质：**加法可以换顺序——先按行加还是先按列加，和总是同一个。** 这就是 Fubini 定理的核心直觉：二重积分就是"对一整张数字表求和"，行的和与列的和，最后都一样。**严格证明（走廊定理 1）只是把这个'换加法顺序'的直觉，用黎曼和的分解翻译成严格的极限论证。** 你先把这张'表'想明白——下一轮，我们让这张表变歪。"

---

### 📐 知识锚点：Fubini 定理——"先按行加还是先按列加，结果一样"

【概念深挖】**Fubini 定理（富比尼定理）**，以意大利数学家**圭多·富比尼（Guido Fubini，1879–1943）**命名：若 f 在矩形 R = [a,b]×[c,d] 上可积，则

```text
∬_R f(x,y) dA = ∫_a^b [ ∫_c^d f(x,y) dy ] dx = ∫_c^d [ ∫_a^b f(x,y) dx ] dy
```

**直觉内核**：把矩形切成一张小格表，f 在每格的取值填进表格。**"先按列求和"（内层 x）与"先按行求和"（内层 y）最后都得到整张表的总和。** 这就是"加法交换律"在二维求和上的体现。

> **严格注记**：Fubini 定理要求 f 可积（绝对可积）。若 f 在矩形上不是绝对可积，交换积分次序可能改变结果甚至发散——这是后面反例/边界要处理的。工程上大多数连续函数都满足前提，可放心换序。

【历史溯源】把"多重积分拆成累次积分"的思想，萌芽于**欧拉和拉格朗日**处理曲面面积、转动惯量等物理问题时。**富比尼在 1907 年给出了严格的测度论证明**，把"先按行加还是先按列加"从直觉上升为定理。**值得一提的是：富比尼定理是勒贝格积分框架下的产物——它先把"可积性"这个概念彻底搞清楚，才敢说"换序后仍是同一个数"。这正是"学派中立"的地方：本书走黎曼和的直觉进路来理解它，但它的严格生命在勒贝格理论里。**

【工程实践】**Fubini 是"数值积分库"能安心工作的法律依据**：当你调用一个二维积分函数，底层往往就是"先沿一个方向、再沿另一个方向"套两次一维积分。**正因为 Fubini 保证了两种顺序结果一致，库的实现者才敢随便挑一种好算的顺序去算，而不必担心算出来的是"另一种积分"。** 但你读文档时要知道：这个保证的前提是"可积"——遇到振荡剧烈或带尖点的被积函数，先检查前提。

### 第 5 轮：区域一歪，积分限就"长脚"——换积分次序

**老谟**："现在把矩形拧歪。区域 D 由 x 从 0 到 1、y 从 x 到 1 围出来（一个三角形）。你想算 ∬_D sin(y²) dy dx。我先让你按'先 x 后 y'——不对，'先 y 后 x'——你自己试试，看会不会卡住。"

**造物主**："……先 y 后 x：内层是 ∫_x^1 sin(y²) dy。可 sin(y²) 这玩意儿没有初等原函数啊！我积到天荒地老也积不出一个'好'的式子。这题死路。"

**老谟**："那你换个顺序，'先 x 后 y'。你先告诉我：区域变到'先 x 后 y'，积分限怎么变？"

**造物主**："……原来先 y 后 x，y 从 x 到 1、x 从 0 到 1。反过来，x 就从 0 到 y、y 从 0 到 1。那内层就变成 ∫_0^y sin(y²) dx = x·sin(y²) 从 0 到 y，等于 y·sin(y²)……**这下内层对 x 积，sin(y²) 根本不用管，是常数！** 然后外层 ∫_0^1 y·sin(y²) dy——这个我熟，换元 t = y²，dt = 2y dy，就是能积的了！"

**老谟**："你自己亲手把死路走活了。**同一个二重积分，'先 y 后 x'积不出来，'先 x 后 y'却顺顺当当——因为你把'难积的被积函数'从内层换到了外层，让内层只管一个简单的东西（这里是 1）。** 这就是'换积分次序'的全部意义：不是换了个花样，是**让内层积分负责'好积'的部分**。你把这条记牢——这是本章最实用的一招。"

---

### 📐 知识锚点：换积分次序——"让内层积分负责好积的部分"

【概念深挖】**换积分次序（changing the order of integration）** 的操作步骤：
1. 从原次序读出区域 D 的几何（用不等式画出边界）；
2. 把区域重新描述成另一种次序的不等式；
3. 用新的次序重写累次积分。

经典例子（蓝图指定，也是本章最重要的一题）：

```text
I = ∫_0^1 ∫_x^1 sin(y²) dy dx
```

- 原次序（先 y 后 x）：区域 { (x,y) : 0 ≤ x ≤ 1, x ≤ y ≤ 1 }；
- 换次序（先 x 后 y）：同一区域可写成 { (x,y) : 0 ≤ y ≤ 1, 0 ≤ x ≤ y }；
- 于是 I = ∫_0^1 ∫_0^y sin(y²) dx dy = ∫_0^1 y·sin(y²) dy = [−½cos(y²)]₀¹ = **(1 − cos 1)/2 ≈ 0.2298**。

**关键**：sin(y²) 没有初等原函数，直接先积 y 是死路；但换成先积 x，sin(y²) 当常数，内层立刻可算。**"换序"解决的不是计算复杂度，而是"可不可积"——这比任何技巧都珍贵。**

【工程实践】换序在工程里对应**"交换求和/积分顺序"**：机器学习的期望计算、贝叶斯推理里的边缘化（把联合分布对一个变量积分掉），经常需要"哪个先积"的取舍。**有些积分顺序数值上极不稳定（误差爆炸），换一个顺序就稳定得多——Fubini 给你自由，换序给你灵活，两者合起来是数值工程师调积分的两板斧。**

### 第 6 轮：遇到圆——直角坐标切不动，换个"尺子"量

**老谟**："换序解决'先积哪个'。可还有一类问题，它压根不是'换序'能救的——**区域是圆的，函数还带旋转对称**，比如 ∬_{x²+y²≤4}(x²+y²) dA。你用直角坐标的'先 x 后 y'去切，积分限会变成 ±√(4−x²)，内层和外层都缠着一堆根号，算得你头秃。你说，怎么办？"

**造物主**："……圆的东西，用 x、y 去量就是别扭。能不能……换个坐标系？用半径 r 和角度 θ 去描述每个点？"

**老谟**："你自己把答案说出来了：**极坐标。** 可换坐标系不是白换的——**原来面积元是 dA = dx·dy，换了之后面积元就变成 r·dr·dθ，不是简单的 dr·dθ。** 你为什么觉得该多出一个 r？"

**造物主**："……因为 θ 动一小格，扫过的弧长跟离原点多远有关：离得越远，同样角度扫过的面积越大。所以那块'小扇子'的面积不是 dr×dθ，得是半径 r 乘上角度变化 dθ 再乘 dr——对，r·dr·dθ。"

**老谟**："你把极坐标面积元里最关键的'那个 r'自己逼出来了。**r 是'离原点越远、同样角度裹挟的面积越大'的几何代价。** 有了这个面积元，∬_{x²+y²≤4}(x²+y²)dA 就变成 ∫_0^{2π}∫_0^2 r²·r dr dθ——r² 是 x²+y²，再乘上面积元的 r，一共 r³。这下干净了，你算算？"

---

### 📐 知识锚点：极坐标变换——dA = r·dr·dθ

【概念深挖】**极坐标（polar coordinates）**：点 (x,y) 用 (r, θ) 表示，其中 r = √(x²+y²) 是到原点距离，θ 是辐角。变换关系：

```text
x = r·cos θ，y = r·sin θ
```

**面积元**（这是极坐标积分的核心，也是唯一容易错的地方）：

```text
dA = dx·dy = r·dr·dθ
```

**为什么多一个 r**：从 (r,θ) 到 (x,y) 是一张"放大缩小"的地图——θ 方向的分辨率随 r 变。直观地说，θ 动 dθ 扫过的实际距离是 r·dθ，所以小扇片的面积是 (dr)×(r·dθ) = r·dr·dθ。**r 就是"离原点越远，同样角度对应越大弧长/面积"的代价。**

**典型应用**：圆盘、扇形、环形、以及被积函数含 x²+y² 的情形（旋转对称）。例如：

```text
∬_{x²+y²≤4} (x²+y²) dA = ∫_0^{2π} ∫_0^2 r²·r dr dθ
= ∫_0^{2π} [ r⁴/4 ]_0^2 dθ = ∫_0^{2π} 4 dθ = 8π
```

**（其中 r²·r = r³ 来自"被积函数 x²+y² = r²"乘"面积元里的 r"，这个"多乘一个 r"是最常踩的坑。）**

【工程实践】极坐标在工程里的直白应用：**图像与雷达的距离-方位表示**、**归一化的极坐标损失**、以及**处理旋转对称的物理系统**（电场、引力场、天线方向图）。**"当问题本身有旋转对称性，就用与之匹配的坐标系"——这是工程里'选对坐标系省一半力气'的经典一课。**

## 严格化走廊

> 位置说明：本章对话负责"直觉"——为什么切成小柱、为什么换序、为什么极坐标多个 r。本走廊负责"严谨"——把二重积分写成精确的黎曼和极限，把"先按行加 = 先按列加"用黎曼和的分解思路证明成可复写的定理。**下面每一行，读者都能对着空白纸重写一遍。**

### 关于对话的口径说明

对话里"切成小柱求和""先按行加还是先按列加""多一个 r"这些，都是直觉层面的引导。**本走廊把它们落成严格形式**：二重积分 = 分割 + 黎曼和 + 取极限（定义 1）；Fubini 定理（定理 1）的证明走"黎曼和的换序分解"路线；极坐标面积元 = 坐标变换 + 雅可比行列式（定理 2）。读者应把对话当作"为什么要这样想"，把本走廊当作"为什么这样想是对的"。

### 定义 1：二重积分（黎曼和）

设 f : D ⊆ ℝ² → ℝ 有界，D 是平面有界区域。**对区域 D 作分割**：把 D 分成有限个小矩形（及边界小块）D₁, …, Dₙ，第 i 块的面积为 ΔAᵢ，其直径为 diag(Dᵢ)（该块的最大"跨度"）。在各块内任取代表点 (xᵢ*, yᵢ*)，作**黎曼和**：

```text
S = Σᵢ f(xᵢ*, yᵢ*) · ΔAᵢ
```

若当所有块的直径 maxᵢ diag(Dᵢ) → 0 时，黎曼和 S 趋于同一个极限 I（与分割方式和代表点取法无关），则称 **f 在 D 上可积**，并记：

```text
∬_D f(x,y) dA = I
```

### 定义 2：累次积分（iterated integral）

设 f 在矩形 R = [a,b]×[c,d] 上有界。**先 x 后 y 的累次积分**定义为：

```text
∬_R f dA 的"先 x 后 y"写法 = ∫_c^d [ ∫_a^b f(x,y) dx ] dy
```

其中内层 ∫_a^b f(x,y) dx 把 y 当常数（沿一条水平线积），结果是一个关于 y 的函数，再对 y 积分。**先 y 后 x** 对称定义。

### 定义 3：极坐标下的二重积分

设 D 在极坐标下为 { (r,θ) : θ₁ ≤ θ ≤ θ₂, r₁(θ) ≤ r ≤ r₂(θ) }，且变换 (x,y) = (r cosθ, r sinθ) 是双射，则：

```text
∬_D f(x,y) dx dy = ∫_{θ₁}^{θ₂} ∫_{r₁(θ)}^{r₂(θ)} f(r cosθ, r sinθ) · r dr dθ
```

### 定理 1（Fubini 定理，矩形域）：设 f 在矩形 R = [a,b]×[c,d] 上可积，则

```text
∬_R f(x,y) dA = ∫_a^b [ ∫_c^d f(x,y) dy ] dx = ∫_c^d [ ∫_a^b f(x,y) dx ] dy
```

> **严格注记（前提口径）**：在黎曼积分框架下，"f 可积 ⟹ 两种累次积分相等"并非无条件成立——存在黎曼可积但累次积分不等的病态函数。**本书按经典教学口径使用该定理：f 在 R 上连续（或分片连续、不连续点足够少）时，两种累次积分均存在且相等，无任何例外；** 最一般的成立范围属于勒贝格（Lebesgue）/Tonelli 框架，那里"非负可测 ⟹ 可换序"成为无条件的。**你现在遇到的函数（多项式、指数、三角、分片连续）全部落在"连续/分片连续"安全区内，放心换序；真正的边界留在测度论部分。**

**证明（可复写，走黎曼和的分解思路）**：
- **第 1 步（把矩形切成网格）**：把 [a,b] 等分为 m 段，[c,d] 等分为 n 段，得到 m×n 个小矩形 R_ij，其面积为 Δx·Δy = (b−a)/m · (c−d)/n。取各块代表点，黎曼和 S = Σᵢ Σⱼ f(xᵢ*, yⱼ*)·Δx·Δy。
- **第 2 步（先按列求和）**：固定一个 i（固定一列），先对 j 求和：Σⱼ f(xᵢ*, yⱼ*)·Δy，这正是"先 y 后 x"中内层 ∫_c^d f(xᵢ*, y) dy 的黎曼和近似。把每一列的"列和"再对 i 求和（乘 Δx），即 S = Σᵢ [ Σⱼ f(xᵢ*,yⱼ*)·Δy ]·Δx。
- **第 3 步（先按行求和）**：交换求和顺序（有限和交换次序不改变结果，依据是加法结合律与交换律），S = Σⱼ [ Σᵢ f(xᵢ*,yⱼ*)·Δx ]·Δy，这正是"先 x 后 y"中内层 ∫_a^b f(x,y) dx 的黎曼和近似，再对 j 求和。
- **第 4 步（取极限）**：当 m,n → ∞（网格无限加密）时，S 由可积性趋于 ∬_R f dA。第 2、3 步得到的两个表达式，各自的内层黎曼和趋于对应的一维积分，外层取极限后分别趋于 ∫_a^b [∫_c^d f dy] dx 与 ∫_c^d [∫_a^b f dx] dy。因三者都收敛到同一个 S 的极限（即 ∬_R f dA），故等式成立。∎

**证明要点标注**：第 1 步用**定义 1（分割与黎曼和）**；第 2、3 步用**有限求和的交换次序（加法交换律/结合律）**与**一维黎曼和的定义**；第 4 步用**可积性（极限唯一）**与**极限的四则运算**。

### 定理 2（极坐标面积元）：坐标变换 (x,y) = (r cosθ, r sinθ) 的面积元为 dA = r·dr·dθ。

**证明（可复写，用雅可比行列式）**：
- **第 1 步（写出雅可比矩阵）**：由第 02 章定义 2（雅可比矩阵），变换 T(r,θ) = (r cosθ, r sinθ) 的雅可比矩阵为：

```text
J = [ ∂x/∂r  ∂x/∂θ ] = [ cosθ  −r sinθ ]
    [ ∂y/∂r  ∂y/∂θ ]   [ sinθ   r cosθ ]
```

- **第 2 步（算行列式的绝对值）**：det J = cosθ·(r cosθ) − (−r sinθ)·sinθ = r(cos²θ + sin²θ) = r·1 = r。
- **第 3 步（多重积分换元公式）**：二重积分的换元公式（多元积分换元，与一元 u 换元对应）给出 dA = dx·dy = |det J| dr dθ = r dr dθ。∎

**证明要点标注**：第 1 步用**雅可比矩阵定义（第 02 章）**；第 2 步用**二阶行列式计算**与**毕达哥拉斯恒等式 cos²θ+sin²θ=1**；第 3 步用**二重积分换元公式**（面积元由雅可比行列式的绝对值给出）。

### 反例/边界

- **不绝对可积时 Fubini 失效**：f 在矩形上不可积（不绝对可积）时，交换积分次序可能改变结果。经典例子：f(x,y) = (x²−y²)/(x²+y²)² 在矩形 [0,1]×[0,1] 上，∫∫ f dxdy 与 ∫∫ f dydx 得到不同值（一个为 −π/4，另一个为 +π/4）。**教训：Fubini 的"换序自由"不是免费的，前提是绝对可积。** 工程上遇到振荡/带奇点的被积函数要警惕。
- **积分限函数的边界**：非矩形区域换序时，若区域描述出错（上下限函数配错变量），会算出完全不同的错误值。**换序前先在纸上把区域几何画出来，确认两种不等式描述同一片区域。**
- **极坐标的 r 非负**：极坐标积分中 r ≥ 0（径向坐标约定非负）。若某区域的 r 下限描述错误（比如把半圆写成全圆），会多算或漏算。

## 知识点总结

### 知识点（本章推出的核心概念）

- **二重积分 ∬_D f dA**：把区域切成小柱（底面积 ΔA × 高 f），求和取极限。"切成小块 → 每块近似 → 求和 → 取极限"与一元积分同构，只是块从一维段长成二维小片。
- **累次积分**：把二重积分拆成"内层 + 外层"两次一维积分；内层把另一变量当常数（偏导的逆操作）。
- **Fubini 定理**：矩形域上 ∬_R f dA = ∫∫ f dx dy = ∫∫ f dy dx；直觉是"先按行加还是先按列加，总和一样"；前提是 f 可积（绝对可积）。
- **换积分次序**：区域歪时积分限变成函数；换个次序让"内层负责好积的部分"——经典例 ∫₀¹∫ₓ¹ sin(y²) dy dx = (1−cos1)/2 ≈ 0.2298。
- **极坐标变换**：x = r cosθ，y = r sinθ；**面积元 dA = r dr dθ**（多出的 r 是"离原点越远、同角度扫过的面积越大"的代价）。
- **典型结果**：∬_{x²+y²≤4}(x²+y²) dA = 8π（旋转抛物面下、半径 2 的圆域体积）。

### 历史结论（本章涉及的史料）

- **富比尼（Guido Fubini，1879–1943）**：1907 年在勒贝格测度论框架下严格证明多重积分可拆成累次积分——"先按行加还是先按列加"从直觉升格为定理。
- **思想源头**：欧拉、拉格朗日在处理曲面面积、转动惯量等物理问题时已实践"多重积分拆累次"。
- **二重积分的严格化**：黎曼给出"分割 + 黎曼和 + 极限"的一元积分严格定义，后人推广到多重；而 Fubini 的严格生命在勒贝格积分框架里。

### 工程实践结论（本章知识在真实工程里怎么用）

- **数值积分/蒙特卡洛**：把区域切网格、每格取代表值加总，就是二重积分的离散版。
- **联合分布概率（为册 06 铺路）**：P((X,Y)∈D) = ∬_D f dx dy——二重积分是"联合分布概率"的数学壳子。
- **一维积分套一维积分**：数值库算二维积分常用"一维积分递归套用"，Fubini 保证选哪种顺序都对。
- **选对坐标系**：旋转对称问题用极坐标省一半力气；图像/雷达的距离-方位表示、旋转对称物理系统都用它。

## 计算训练场

> 位置说明：本章对话负责"为什么"，这里负责"怎么算"。**每题请动笔 10 分钟以上，先自己写，再对照完整解答。禁止边算边翻答案。**

### 题 1（易→中）：矩形域累次积分——先 x 后 y、先 y 后 x 各算一遍互证

**题干**：设 f(x,y) = x + y，区域 D = [0,1]×[0,2]。
(a) 用"先 x 后 y"的累次积分计算 ∬_D (x+y) dA。
(b) 用"先 y 后 x"的累次积分重算一遍，验证 Fubini（两结果应一致）。

**完整分步解答：**

**（a）先 x 后 y**：
第 1 步：内层把 y 当常数，对 x 从 0 到 1 积分：∫₀¹(x+y) dx = [x²/2 + y·x]₀¹ = (1/2 + y) − (0 + 0) = **1/2 + y**。（规则：∫(x+y)dx = x²/2 + yx，其中 y 当常数。）
第 2 步：外层对 y 从 0 到 2 积分：∫₀²(1/2 + y) dy = [y/2 + y²/2]₀² = (1 + 2) − 0 = **3**。

**（b）先 y 后 x**：
第 3 步：内层把 x 当常数，对 y 从 0 到 2 积分：∫₀²(x+y) dy = [x·y + y²/2]₀² = (2x + 2) − 0 = **2x + 2**。
第 4 步：外层对 x 从 0 到 1 积分：∫₀¹(2x+2) dx = [x² + 2x]₀¹ = (1 + 2) = **3**。

**答**：两种次序都得到 **3**，Fubini 验证通过 ✓。

**常见错误**：① 内层积分把"另一变量当常数"忘了——比如 ∫₀¹(x+y)dx 里把 y 也当变量一起积成 y²/2；② 外层代入上下限时符号错误，[y/2 + y²/2]₀² 在 y=0 处应为 0 而非负值。

### 题 2（中）：换积分次序——"直接积不出、换序后可算"的经典

**题干**：老谟要造物主算 I = ∫₀¹∫ₓ¹ sin(y²) dy dx。
(a) 画出区域 D = { (x,y) : 0 ≤ x ≤ 1, x ≤ y ≤ 1 }，并用另一种次序重写这个积分。
(b) 用新次序计算 I 的精确值，并给出小数近似（cos 1 ≈ 0.5403）。

**完整分步解答：**

**（a）换次序**：
第 1 步：原区域 x 从 0 到 1，y 从 x 到 1。把 y 当外层变量：y 的范围仍是 0 到 1（三角形底 y=0 顶 y=1）；对固定 y，x 从 0 到 y（因为 x ≤ y 且 x ≥ 0）。故新次序：I = ∫₀¹∫₀^y sin(y²) dx dy。（规则：区域几何重述——不等式 0≤x≤1, x≤y≤1 等价于 0≤y≤1, 0≤x≤y。）

**（b）计算**：
第 2 步：内层把 y 当常数，对 x 从 0 到 y 积分：∫₀^y sin(y²) dx = sin(y²)·x |₀^y = **y·sin(y²)**。（规则：被积函数不含 x，对 x 积分得 sin(y²)·x。）
第 3 步：外层 ∫₀¹ y·sin(y²) dy。换元 t = y²，dt = 2y dy，故 y dy = dt/2。（规则：一元换元法。）
第 4 步：边界 y=0 → t=0，y=1 → t=1。I = ∫₀¹ (1/2) sin t dt = (1/2)[−cos t]₀¹ = (1/2)(−cos1 + cos0) = (1/2)(1 − cos1)。（规则：∫sin t dt = −cos t + C，代入上下限。）
第 5 步：数值：cos1 ≈ 0.5403，I = (1 − 0.5403)/2 = **0.22985 ≈ 0.2298**。

**答**：(a) I = ∫₀¹∫₀^y sin(y²) dx dy；(b) I = (1−cos1)/2 ≈ **0.2298**。（反验算：被积函数非负、区域面积 1/2、函数最大值 sin(y²) ≤ sin1 ≈ 0.8415，故积分应在 0 与 0.5×0.84≈0.42 之间——0.2298 合理 ✓。）

**常见错误**：① 换序时把区域画错，写成 0≤x≤y、y 从 x 到 1 的混乱不等式，导致积分域重复或遗漏；② 换元 t=y² 时忘写 dt=2y dy，直接把 y sin(y²)dy 当 sin(y²)dy 积；③ 代入边界时把 cos1 的符号搞反。

### 题 3（中→难）：极坐标——旋转抛物面下的体积

**题干**：老谟让造物主算旋转抛物面 z = x²+y² 在圆盘 x²+y² ≤ 4（半径 2）下方所围的体积 V = ∬_{x²+y²≤4}(x²+y²) dA。
(a) 用极坐标写出并计算这个积分，得到精确值。
(b) 顺便算圆盘 x²+y²≤4 的面积（即 ∬_{x²+y²≤4} 1 dA），并验证它与 πr² 一致。
(c) 把被积函数换成 1，即 ∬_{x²+y²≤9} 1 dA（半径 3），给出结果并说明它对应什么几何量。

**完整分步解答：**

**（a）极坐标算体积**：
第 1 步：极坐标变换 x = r cosθ，y = r sinθ，x²+y² = r²，dA = r dr dθ。（规则：定理 2 极坐标面积元。）
第 2 步：圆盘 x²+y²≤4 即 r ≤ 2；θ 从 0 到 2π。积分 V = ∫₀^{2π}∫₀² r²·r dr dθ = ∫₀^{2π}∫₀² r³ dr dθ。（规则：被积函数 x²+y²=r² 乘面积元里的 r。）
第 3 步：内层 ∫₀² r³ dr = [r⁴/4]₀² = 16/4 = **4**。（规则：∫r³dr = r⁴/4。）
第 4 步：外层 ∫₀^{2π} 4 dθ = 4·(2π) = **8π**。（规则：常数对 θ 积分 = 常数×区间长度。）
第 5 步：8π ≈ 8×3.1416 = **25.1327**。

**（b）圆盘面积**：
第 6 步：∬ 1 dA = ∫₀^{2π}∫₀² 1·r dr dθ = ∫₀^{2π}[r²/2]₀² dθ = ∫₀^{2π} 2 dθ = **4π**。（规则：被积函数 1，面积元 r dr dθ。）
第 7 步：验证 πr² = π·2² = 4π ✓ 一致。（反验算：半径 2 圆面积 = 4π ✓。）

**（c）半径 3 的圆盘**：
第 8 步：∬_{x²+y²≤9} 1 dA = ∫₀^{2π}∫₀³ r dr dθ = ∫₀^{2π}[r²/2]₀³ dθ = ∫₀^{2π}(9/2) dθ = (9/2)·2π = **9π**。
第 9 步：9π = π·3²，即半径 3 的圆盘面积 ✓。

**答**：(a) V = **8π ≈ 25.133**；(b) 面积 = 4π = π·2² ✓；(c) 9π = π·3²，即半径 3 圆盘面积。

**常见错误**：① 极坐标里忘了"被积函数里已经有一个 r²，面积元里还有一个 r"，把 r²·r 误写成 r²，得到 4π 而非 8π；② 面积元误写成 dr dθ 而非 r dr dθ，圆盘面积会算错；③ 内层 r³ 的积分上限代入错（把 2⁴ 算成 8）。

## 向导便签

> 这一章咱们干了什么：从"一块歪蛋糕的体积怎么算"这个问题出发，把一元积分的"切条"升级成二重积分的"切块"——切成小柱、求和取极限；再用累次积分把它拆成"内层 + 外层"两次一维积分，靠 Fubini 定理保证两种切法结果一样；遇到歪区域就换积分次序，遇到圆就换极坐标。
>
> 钉死一句话：**二重积分 = 一块区域上的总累积；三种切法（先 x 后 y、先 y 后 x、极坐标）在"好区域"上给出同一个数。** 极坐标面积元 **dA = r dr dθ** 里那个 r 最不能忘。
>
> 记住一个边界：**Fubini 的"换序自由"前提是绝对可积**；换序前一定先在纸上把区域画出来，别让积分限配错变量。

## 造物主手记

**我曾踩的坑**：

我最先想用一元那套"切条"去切蛋糕，被老谟一句"条只有长度，可这片蛋糕底下一整片地"噎住。接着我差点说出"先 x 后 y 和先 y 后 x 肯定一样"——这倒没错，但我说不出为什么，被老谟逼着用"按行加还是按列加，总和一样"才讲清楚。最值钱的坑是极坐标：我一开始把 ∬(x²+y²)dA 里的被积函数 x²+y² 换成 r² 就停了，忘了面积元里那个 r，差点算出 4π 而不是 8π。**"被积函数一个 r，面积元又一个 r，两个都要"——这个细节我记死了。**

**顿悟时刻**：

真正开窍是在换序那道题。老谟让我算 ∫₀¹∫ₓ¹ sin(y²)dy dx，我一开始卡死在"sin(y²) 没有初等原函数"上，以为这题完蛋了。可一换序，把 sin(y²) 挪到外层当常数，内层只积一个 1，瞬间就通了。**那一刻我明白：换积分次序不是换个花样，而是"让内层负责好积的部分"——这比任何技巧都珍贵。** 也是这一题，让我第一次尝到"换个角度，死路变活路"的甜头。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：累次积分 + Fubini 验证**

设 f(x,y) = xy，区域 D = [0,2]×[1,3]。
(a) 用"先 x 后 y"算 ∬_D xy dA。
(b) 用"先 y 后 x"重算，验证 Fubini。

**完整解答**：
(a) 内层 ∫₀² xy dx = y·[x²/2]₀² = y·2 = 2y；外层 ∫₁³ 2y dy = [y²]₁³ = 9 − 1 = **8**。
(b) 内层 ∫₁³ xy dy = x·[y²/2]₁³ = x·(9/2 − 1/2) = 4x；外层 ∫₀² 4x dx = [2x²]₀² = **8**。✓ 一致。

**题 B（计算，中→难）：换序 + 极坐标组合**

(a) 计算 ∫₀¹∫_y¹ e^{x²} dx dy（提示：e^{x²} 无初等原函数，先换次序，区域 {0≤y≤1, y≤x≤1}）。
(b) 计算 ∬_{x²+y²≤1} (x²+y²) dA（单位圆盘，旋转抛物面下体积）。

**完整解答**：
(a) 换序：区域 {0≤y≤1, y≤x≤1} = {0≤x≤1, 0≤y≤x}。I = ∫₀¹∫₀^x e^{x²} dy dx = ∫₀¹ e^{x²}·x dx = (1/2)[e^{x²}]₀¹ = **(e−1)/2 ≈ 0.8591**。（换元 t=x²。）
(b) 极坐标：∬ = ∫₀^{2π}∫₀¹ r²·r dr dθ = ∫₀^{2π} r⁴/4|₀¹ dθ = ∫₀^{2π}(1/4) dθ = **(1/4)·2π = π/2**。

**题 C（概念，检查理解）：Fubini 与换序**

老谟给造物主一个矩形域上的积分 ∫∫_R f dA，问：
(1) 先 x 后 y、先 y 后 x 结果一致，这个保证叫什么定理？前提是什么？
(2) 为什么"换积分次序"能救活 sin(y²) 这类"直接积不出"的积分？
(3) 极坐标面积元 dA = r dr dθ 里的 r 是什么几何含义？

**完整解答**：
(1) Fubini 定理；前提是 f 在矩形上可积（绝对可积）。不绝对可积时换序可能改变结果。
(2) 因为换序后把"难积的被积函数"从内层挪到外层当常数，让内层只管"好积"的因子（如 1、x），可积性发生质变——它解决的是"可不可积"而非"复杂度"。
(3) r 是"离原点越远、同样角度扫过的弧长/面积越大"的几何代价：θ 动 dθ 扫过的实际距离是 r·dθ，所以小扇片面积 = dr × r·dθ = r·dr·dθ。

## 预告

你手里现在有"切一块区域"的功夫：二重积分、累次积分、换序、极坐标。

可这一章从头到尾，我们都在假设：**这底下是一片规规矩矩的地，切完加总就行。** 下一章，我们要问一个更刁钻的问题：**如果这片'地面'不是平的，而是一座山的山坡——什么样形状的山，才能保证你从山顶一松手，沿着坡一路滑到谷底，中途绝不会被卡在半山腰的某个"假谷"里出不来？** 那种"敢保证一滑到底"的形状，叫**凸集**；对应的函数，叫**凸函数**。

而在那之前，你先记住本章最后那句话：**二重积分是"联合分布概率"的数学壳子**——这个直觉，册 06 概率统计与信息里，P((X,Y)∈D) = ∬_D f dxdy，会原封不动地回来找你。
