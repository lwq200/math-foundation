# 第 04 章 · 凸集与凸函数——什么形状的"碗"敢保证一滑到底

> 本章从哪个问题出发：上一章我们学会了"切一块区域"的累加。可现实里的优化问题更像这样：你站上一座山坡，把一个小球放在坡顶，松手——**它会不会一路滑到谷底？还是会卡在半山腰某个看似"到底"其实没到底的地方？** 什么形状的山坡能让你"一松手就安心"？什么形状的山坡会偷偷坑你一把？
> 推导到哪个结论：答案是**凸集**（任意两点连成的线段还留在集合里）与**凸函数**（任意两点之间，函数值不超过两端点函数值的"加权平均"）。靠一个不等式 f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)（**Jensen 不等式**），我们能推出凸函数的两个重要"刻画"：**一阶刻画**（可微时，曲线永远躺在切线上方：f(y) ≥ f(x) + ∇f(x)·(y−x)）和**二阶刻画**（二次可微时，海森矩阵半正定）。
>
> 核心认知：**凸函数就是"一滑到底、没有假谷"的函数——任意两点之间，函数值不高于两端值的加权平均；这个性质可以用"定义直接验证"，也可以（可微/二次可微时）用"切线下界"或"海森半正定"来判定。** 这一章是"为什么敢用梯度下降"的第一块地基：只有凸的，局部最优才等于全局最优。

## 引子

老谟的桌上摆着两个漏斗形的透明模型：一个像倒扣的锅，碗口朝上，圆润光滑；另一个像被压皱的波浪板，中间有几道起伏的褶皱，还有几个小凹槽。

"我给你两颗钢珠，"老谟说，"一颗放第一个碗里，从碗沿松手。一颗放第二个'波浪板'上，从一个高点的褶皱松手。你说，这两颗钢珠，谁的'终点'我能打包票？"

我盯着两个模型想了想："第一个碗，钢珠肯定滚到正中央那个最低点，我猜得到。第二个波浪板……它可能滚到某个小凹槽里停住，但那未必是最低的地方——旁边可能还有更深的坑。"

"你自己把整章的题眼说出来了：**有些'坡'，你滚到哪就能信到哪（滚到哪就是全局最低）；有些'坡'，你滚到哪只信到哪（卡在半路的假坑里）。** 那你说，第一种坡和第二种坡，到底差在哪？差在'形状'——差在'凸不凸'。这一章，就是教你把'敢不敢打包票'这件事，翻译成一个能验证的数学条件。"

**老谟**："先别管函数，先管形状。第一种碗——钢珠从碗沿任何位置松手，都能滚到同一个最低点，而且绝不会卡在半路。你观察一下，这种碗的'形状'有什么共同特征？"

**造物主**："……它没有'凹陷'？不对，它明明凹下去的。应该是……它没有'鼓包'和'腰'？从任意一点看，中间不会鼓出来挡路。"

**老谟**："你绕来绕去，其实在说一件很朴素的事：**这种碗里，随便挑两个点，这两点连成的线段，是不是整段都'待在碗里'？** 你想想波浪板：中间那个鼓包，让'左边凹槽的一点'和'右边凹槽的一点'连成的线段，会从鼓包上方'越过去'——线段有一部分跑出碗外了。而光滑的碗，任意两点连线段，整段都在碗里。"

**造物主**："……对！波浪板的两点连线会'悬空'穿过鼓包上方，可光滑碗的两点连线永远贴着碗壁内侧。**区别就是：线段有没有'跑出去'。**"

**老谟**："你刚刚用一句话定义了**凸集**：一个集合，任意两点的连线整段都还在集合里。波浪板的'凹槽'不是凸集（两点连线跑出去了），光滑的'碗'（圆盘）是凸集。先把这个几何直觉抓住——下一轮，我们把它从'形状'翻译成'代数'。"

---

### 📐 知识锚点：凸集——"任意两点连线，整段都留在集合里"

【概念深挖】**凸集（convex set）** 的定义：集合 C ⊆ ℝⁿ 称为凸集，如果对任意两点 x, y ∈ C 及任意 λ ∈ [0,1]，都有

```text
λx + (1−λ)y ∈ C
```

**λx + (1−λ)y 就是 x、y 连线上的点**：λ 从 0 变到 1，这个点从 y（λ=0）滑到 x（λ=1）。**凸集就是"任意两点连线不出去"的集合。**

**常见的凸集**：圆盘 { x²+y² ≤ r² }（光滑碗口）、矩形、半平面、整个 ℝⁿ、单个点、空集、线性方程组的解集（如平面）。**常见的非凸集**：圆环（中间挖空，两点连线会穿过空洞）、两瓣不相连的集合、圆盘挖掉一块。

【工程实践】为什么工程师关心"凸不凸"？**因为约束条件的可行域越凸，优化就越"省心"。** 机器学习里很多约束（参数在某个范数球内、概率向量在单纯形内）都是凸集；而"保证解落在一个无假坑的区域内"，是很多算法的前提。**凸性 = 可预测性 = 可证明的收敛。**

### 第 2 轮：从"碗的形状"到"函数的形状"——凸函数的定义

**老谟**："凸集管的是'区域'。可我们要优化的不是一个区域，而是一个**函数**——损失函数。'碗的形状'对应函数图像的形状。那么问题来了：**什么函数图像，能保证'一滑到底、没有假坑'？** 你先拿一元函数想。"

**造物主**："……开口向上的抛物线？像 x² 那样，中间凹下去，钢珠滚到最低点，不会卡在半路。"

**老谟**："对。可'开口向上'只是对 x² 这种规整函数的直观。你要把它翻译成'任意两个点都满足的条件'——就像凸集是'任意两点连线不出去'一样。你想想，凸集用'两点连线'定义，凸函数的图像是'碗'，那这两者该怎么接上？"

**造物主**："……函数图像是'碗'，碗的内侧是凸集……是不是可以这样：**函数图像上方的区域是凸集**？x² 的图像是条向上弯的抛物线，它上方的整个区域确实是凸的；而 x³ 的图像有 S 形拐弯，它上方有一块凹进去，不是凸集。"

**老谟**："你摸到凸函数的几何定义了。可这个定义用起来要'画图'，不顺手。我们换一个更代数、更好验证的说法：**在任意两点之间，函数值不能超过两端点函数值的'加权平均'。** 也就是说，连线的中点在图像上，要么在图像上，要么在图像上方——**'连线不下垂'。** 你自己用 λ 写出这个条件？"

---

### 📐 知识锚点：凸函数——"任意两点之间，函数值不超过两端值的加权平均"

【概念深挖】**凸函数（convex function）** 的定义：函数 f : C → ℝ（C 为凸集）称为凸函数，如果对任意 x, y ∈ C 及任意 λ ∈ [0,1]，都有

```text
f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y)
```

**几何意义**：把 x、y 连成一条弦，弦上任意一点的"加权平均高度" λf(x)+(1−λ)f(y)，**不低于**图像在该点的高度 f(λx+(1−λ)y)。也就是说：**弦永远在图像上方（或贴着图像），图像"不下垂"。**

**直观**：x² 是凸函数（弦在图像上方）；x³ 不是（有 S 形区段，弦会穿到图像下方）。**"凸"的图像形状像"碗"（U 形），非凸的图像带"S 形""波浪""鼓包"。**

【历史溯源】**凸性**的系统研究要追溯到 20 世纪初：**Jensen（Johan Jensen，1859–1925）** 在 1905–1906 年间给出了凸函数的不等式形式（即本章核心的 **Jensen 不等式**），奠定了凸分析的基础。此后 **Fenchel、Rockafellar** 等人把凸分析发展成系统学科（Rockafellar 的《Convex Analysis》是经典）。**凸性从"几何直觉"到"严格理论"的历程，和你想从"碗的形状"到"不等式定义"的路径完全一致——你正在重走一遍 Jensen 走过的路。**

【工程实践】**几乎所有机器学习损失函数都是凸的**：均方误差（MSE）、交叉熵对参数、线性回归/逻辑回归的目标。**为什么强调凸？因为凸目标意味着"梯度下降一定收敛到全局最优"——没有假坑可卡。** 而神经网络的损失通常**非凸**（多层非线性叠加产生大量局部极值/鞍点），这正是深度学习优化比传统凸优化难的根本原因——第 7 章我们会正面谈这件事。

### 第 3 轮：用定义验证凸性——f(x) = x² 为什么凸、x³ 为什么不凸

**老谟**："定义立起来了：f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)。可这个不等式，你**怎么验证**一个具体的函数？别光说'图像像碗'，拿 x² 来说，你代入试试。"

**造物主**："……代入 x²：左边 f(λx+(1−λ)y) = [λx+(1−λ)y]²。右边 λx²+(1−λ)y²。要证左边 ≤ 右边，那就是……**右边减左边**：[λx²+(1−λ)y²] − [λx+(1−λ)y]²。我算算……展开化简，是不是能因式分解出什么？"

**老谟**："你自己去化简。提示：这是一个关于 λ 的二次式，或者你能凑出 (x−y)² 的样子。你先算，算出来告诉我差是多少。"

**造物主**："……展开 [λx+(1−λ)y]² = λ²x² + 2λ(1−λ)xy + (1−λ)²y²。右边 λx²+(1−λ)y² 减这个：λx² − λ²x² = λ(1−λ)x²；同理 y 那边是 (1−λ) − (1−λ)² = λ(1−λ)y²；中间 −2λ(1−λ)xy。合起来 = λ(1−λ)(x² − 2xy + y²) = **λ(1−λ)(x−y)²**。这玩意儿 ≥ 0（λ∈[0,1] 时 λ(1−λ)≥0，(x−y)²≥0）！所以右边 ≥ 左边，x² 是凸的！"

**老谟**："你自己把 x² 的凸性用代数验证出来了，而且差正好是 λ(1−λ)(x−y)²——一个非负数。**这个方法就是'用定义验证凸性'的标准套路：把不等式两边的差化简，凑出'非负因子 × 平方和'。** 那现在换个角度——x³ 呢？你按这个套路试试，看能不能找到不满足的点。"

---

### 📐 知识锚点：用定义验证凸性——"差化简成非负"

【概念深挖】用定义验证 f 的凸性，标准套路是**算差**：

```text
Δ = [λf(x)+(1−λ)f(y)] − f(λx+(1−λ)y)
```

- 若 **Δ ≥ 0 对所有 x,y,λ 恒成立**，则 f 凸；
- 若**能找到一组 x,y,λ 使 Δ < 0**，则 f 非凸。

对 **f(x) = x²**：Δ = λ(1−λ)(x−y)² ≥ 0，故凸。对 **f(x,y) = x²+y²**：Δ = λ(1−λ)[(x₁−x₂)² + (y₁−y₂)²] ≥ 0，故凸。**非凸的例子**：f(x) = x³（见反例）；f(x,y) = x² − y²（鞍形，后文第 05 章会重点讨论）。

**要点**：这个验证法最适用于**能化简成"平方和/非负因子乘积"**的函数（多项式为主）。它不需要可微，是凸性的**定义级判据**，最"原始"也最可靠。

【工程实践】为什么"定义验证"在工程里反而有用？**因为很多可微判据（海森、切线下界）要求函数二次可微，而真实工程函数经常不可微（ReLU 复合、绝对值损失）。** 此时"定义验证"是唯一硬道理——它不依赖光滑性。**工程代码里判断一个函数凸不凸，往往是'逐段用定义/已知凸函数运算规则拼装'，而不是去算海森。**

### 第 4 轮：从不等式到一个著名推论——Jensen 不等式

**老谟**："凸函数定义里那个不等式，λ 是 [0,1] 里的一个数，作用在'两点'之间。你有没有想过——**如果不止两个点，而是一堆点，各自带不同的'权重'，会怎么样？**"

**造物主**："……不止两点？那是不是把'两点的加权平均'推广成'多个点的加权平均'？比如三个点 x₁、x₂、x₃，权重 λ₁、λ₂、λ₃ 加起来等于 1，那不等式变成 f(λ₁x₁+λ₂x₂+λ₃x₃) ≤ λ₁f(x₁)+λ₂f(x₂)+λ₃f(x₃)？"

**老谟**："你自己把 Jensen 不等式猜出来了。**这个'从两点推广到多点'的版本，就叫 Jensen 不等式**，它是凸函数定义的最重要推论。而且它还能更进一步——**当权重变成'概率'（加起来等于 1 的非负数）时，它就是'函数作用于加权平均 ≤ 加权平均作用后的函数'，这直接指向数学期望。** 你先把这个'多点加权平均'版本记下，我下一轮带你看它能干什么。"

---

### 📐 知识锚点：Jensen 不等式——"凸函数的加权平均不等式"

【概念深挖】**Jensen 不等式（有限形式）**：设 f 为凸函数，x₁,…,xₙ ∈ C，权重 λ₁,…,λₙ ≥ 0 且 Σλᵢ = 1，则

```text
f(Σᵢ λᵢ xᵢ) ≤ Σᵢ λᵢ f(xᵢ)
```

**两点情形**（λ₁=λ, λ₂=1−λ）就是凸函数定义。**加权平均版**是把两点的"λ、(1−λ)"推广到 n 个点的"λ₁,…,λₙ"。**它是凸函数定义的直接推论**：凸定义保证"两点加权平均成立"，对多个点反复应用（数学归纳法）即可。

**与期望的联系**：若把 λᵢ 看成随机变量取 xᵢ 的概率，则 Σλᵢxᵢ = E[X]，Σλᵢf(xᵢ) = E[f(X)]，于是 Jensen 不等式写成：

```text
f(E[X]) ≤ E[f(X)]
```

**这是概率论里最常用的不等式之一**（册 06 会深入）：**"凸函数作用于均值"不超过"函数值的均值"。**

【工程实践】Jensen 不等式在信息论与机器学习里无处不在：**KL 散度非负性**（证明里关键一步）、**EM 算法**（用 Jensen 构造下界然后迭代最大化）、**凸优化对偶理论**。**"E[f(X)] ≥ f(E[X])"这个不等式，是很多'下界 + 迭代逼近'算法的发动机**——先构造一个易算的下界，再不断收紧它逼近真实目标。

### 第 5 轮：凸函数有什么"好性质"——局部最优 = 全局最优

**老谟**："Jensen 不等式是定义的一个推论。现在问你一个更尖锐、也更实用的问题：**凸函数和优化到底什么关系？为什么我们拼命想让损失函数凸？** 你想想'假坑'——波浪板的小凹槽是个局部最低，但不是全局最低。凸函数会不会有这种'假坑'？"

**造物主**："……凸函数图像像'碗'，碗只有一个底，没有假坑。所以凸函数应该……**不会有局部最低但不是全局最低的情况？**"

**老谟**："你把凸优化最核心的定理说出来了：**凸函数的任何局部最优，都是全局最优。** 这一条，就是'为什么敢用梯度下降'的根基——**只要你的目标是凸的，随便从哪起步，朝下降方向走，走到的任何'局部低点'都必然是全局最低。** 你要不要想想，这条定理怎么证明？提示：反证法，假设有个局部最优但不是全局最优，然后用凸定义推出矛盾。"

**造物主**："……假设 x* 是局部最优但不是全局最优，那存在另一个点 y 让 f(y) < f(x*)。x* 是局部最优，意味着在 x* 附近没有更低的点。可凸函数定义说 f(λx*+(1−λ)y) ≤ λf(x*)+(1−λ)f(y)……当 λ 很接近 1 时，λx*+(1−λ)y 就非常接近 x*，而它的函数值 ≤ λf(x*)+(1−λ)f(y) < λf(x*)+(1−λ)f(x*) = f(x*)——**这不就找到 x* 附近一个比 f(x*) 还低的点吗？跟 x* 是局部最优矛盾！**"

**老谟**："反证法用得干净利落。**凸性保证'任何局部最优都是全局最优'——这就是你这一章所有定义的'最终回报'。** 现在我们把它落到'怎么判断一个函数是凸的'这个实操问题上：靠定义直接化简太累，有没有更省力的判据？下一轮看。"

### 📐 知识锚点：凸函数的"好性质"——局部最优 = 全局最优

【概念深挖】**定理（凸函数的关键性质）**：设 f 是凸集 C 上的凸函数。若 x* ∈ C 是 f 在 C 上的**局部极小点**（存在 x* 的邻域使 f(x*) 是最小值），则 x* 也是 f 在 C 上的**全局极小点**（对任意 y ∈ C 有 f(x*) ≤ f(y)）。

**直觉**：凸函数的图像没有"假坑"——它是"单谷"的。任何一个"谷底"，从整个定义域看都是最低点。

**意义**：这是**"为什么敢用梯度下降"的数学根基**。只要目标凸，算法随便从哪初始化、随便怎么下降，只要收敛到一个稳定点，那个点就必然是全局最优。**凸优化 = "找到稳定点就赢了"；非凸优化 = "找到稳定点只是万里长征第一步"。**

【工程实践】这就是为什么经典机器学习（线性回归、逻辑回归、SVM）的损失都要设计成凸的——**保证了训练一定成功**。而深度神经网络的损失非凸，所以深度学习训练依赖大量技巧（初始化、学习率调度、随机性）去"碰运气地逃离假坑"——**凸性，是传统机器学习与深度学习在"可证明性"上的分水岭。**

### 第 6 轮：可微的凸函数——切线永远在图像下方（一阶刻画）

**老谟**："定义验证凸性，要化简代数式，费劲。那如果 f 是**可微**的，有没有更简单的判据？你想想凸函数图像'不下垂'、'像碗'——你从图像上某点作一条**切线**，这条切线和图像是什么关系？"

**造物主**："……切线？x² 在任意点的切线都在图像**下方**吧……因为 x² 是向上弯的，切线只在切点碰到它，其余地方都低于曲线。"

**老谟**："这就是凸函数的一阶刻画：**可微的凸函数，图像永远在任意点的切线（一阶泰勒近似）上方**——f(y) ≥ f(x) + ∇f(x)·(y−x)。这条性质也反过来：**如果一个可微函数处处'站在所有切线上方'，它就是凸的。** 这条刻画的好处是：不用化简代数式，只要看'函数减切线'的符号。严格证明放走廊，你先接受这个直觉：**凸 = 切线是曲线的'下界'**。那再进一步——如果 f 还二次可微呢？能不能用二阶信息判断？"

---

### 📐 知识锚点：一阶刻画——"凸函数永远站在切线上方"

【概念深挖】**凸函数的一阶刻画（first-order characterization）**：设 f 在凸集 C 上可微。则 f 是凸函数，当且仅当对任意 x, y ∈ C：

```text
f(y) ≥ f(x) + ∇f(x)·(y−x)
```

**几何意义**：f 的图像永远在点 x 处的切平面（一阶泰勒近似）**上方**。**"凸 = 切平面是函数的下界"**。

**用途**：这是判断可微函数凸性的一个强判据（比定义省力），也是**证明"局部最优 = 全局最优"**最顺手的工具——如果 ∇f(x*)=0 且 f 凸，则由一阶刻画 f(y) ≥ f(x*) + 0·(y−x*) = f(x*)，立得全局最优。

【工程实践】一阶刻画在**梯度下降收敛性分析**里是主角：要证"梯度下降到稳定点即全局最优"，用的就是这个不等式 f(y) ≥ f(x) + ∇f(x)·(y−x)。**它是"凸优化理论"与"算法设计"之间的接口。** 第 6 章你会反复用它。

---

### 第 7 轮：二次可微的凸函数——海森矩阵半正定（二阶刻画）

**老谟**："一阶刻画要看'函数减切线'，还是要算差值。那如果 f **二次可微**呢？我们用多元泰勒想想：f(y) ≈ f(x) + ∇f(x)·(y−x) + ½(y−x)ᵀH(x)(y−x)。如果 f 要'永远站在切线上方'，那这个二次项得保证什么？"

**造物主**："……站在切线上方 = f(y) − f(x) − ∇f(x)·(y−x) ≥ 0。而泰勒说这个差 ≈ ½(y−x)ᵀH(x)(y−x)。**所以要让差非负，就得让二次型 (y−x)ᵀH(x)(y−x) ≥ 0 对任意方向都成立——也就是海森矩阵 H 半正定！**"

**老谟**："你漂亮地摸到了二阶刻画：**二次可微的 f 是凸函数，当且仅当海森矩阵处处半正定。** '半正定'是个线性代数概念——所有特征值非负，或所有主子式非负。你认出了那个二次型 hᵀHh——第 02 章多元泰勒里它出现过，现在它变成凸性判定的主角。**这一下，判定凸性从'化简代数式'变成了'检查一个矩阵是否半正定'——而这件事，下一章我们要专门系统搞定。** 你先把'海森半正定 ⇔ 凸'这句记牢。"

---

### 📐 知识锚点：二阶刻画——"二次可微 ⇔ 海森矩阵半正定"

【概念深挖】**凸函数的二阶刻画（second-order characterization）**：设 f 在凸集 C 上二次可微。则 f 是凸函数，当且仅当对任意 x ∈ C，**海森矩阵 H(x) 半正定**（对任意方向 h，hᵀH(x)h ≥ 0）。

**来源**：由多元泰勒，f(y) − f(x) − ∇f(x)·(y−x) ≈ ½(y−x)ᵀH(x)(y−x)。**"函数站在切线上方"（一阶刻画）就要求这个二次项非负，即海森半正定。**

**特别地**：
- 若 H(x) **正定**（hᵀHh > 0 对一切 h≠0），f 是**严格凸**（弦严格在图像上方）；
- 若 H(x) 只是**半正定**（允许某些方向 hᵀHh = 0），f 是凸（但不严格）。

【工程实践】**"算海森判断凸性"是工程里判断"这个损失好不好优化"的标准动作**：MSE 的海森是半正定矩阵，所以线性回归是凸问题；逻辑回归的海森半正定，所以也是凸问题；而带非线性激活的多层网络的损失海森不定，所以非凸。**"看海森正不正定"是判断优化难度的一眼快筛。** 下一章，我们专门教你怎么系统地判断一个矩阵正定/半正定/不定。

---

### 第 8 轮：落点——从"碗的形状"到"能验证的条件"

**老谟**："绕了一大圈，你现在把'什么形状的碗敢保证一滑到底'这个问题，用数学语言完整回答一遍。"

**造物主**："敢一滑到底的，是凸函数。判断方法有三种：**定义法**（f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)，把差化简成非负）；**一阶刻画**（可微时 f(y) ≥ f(x)+∇f(x)·(y−x)，切线是下界）；**二阶刻画**（二次可微时海森矩阵半正定）。而它们共同的回报是：**凸函数局部最优 = 全局最优，没有假坑。**"

**老谟**："你手里现在有三把尺子，可三把尺子用起来费力程度不同：定义法要化简，一阶刻画要算差值，二阶刻画要'判断一个矩阵是否半正定'。**下一章，我们把'判断矩阵半正定/正定'这件事彻底工具化——主子式判据、特征值判据，还有一张判定树。** 你先把这个'碗'的形状踩实，明天我们给它装上'量歪坑的尺子'。"

## 严格化走廊

> 位置说明：本章对话负责"直觉"——为什么凸集连线不出去、为什么凸函数没有假坑。本走廊负责"严谨"——把凸集、凸函数、Jensen 不等式、一阶/二阶刻画写成精确的定义与定理，并给出**可复写的证明**。**下面每一行，读者都能对着空白纸重写一遍。**

### 关于对话的口径说明

对话里"碗的形状""切线是下界""海森半正定"都是直觉引导。**本走廊把凸性相关结论落成严格形式**：定义 1（凸集）、定义 2（凸函数）、定义 3（Jensen 不等式）、定理 1（一阶刻画）、定理 2（局部最优 = 全局最优）、定理 3（二阶刻画）。**读者应把对话当"为什么要这样想"，把本走廊当"为什么这样想是对的"。**

### 定义 1：凸集（convex set）

集合 C ⊆ ℝⁿ 称为**凸集**，如果对任意 x, y ∈ C 及任意 λ ∈ [0,1]，有：

```text
λx + (1−λ)y ∈ C
```

**直观**：x、y 连线上的所有点都在 C 内，"任意两点连线不出去"。

### 定义 2：凸函数（convex function）

设 C ⊆ ℝⁿ 为凸集，f : C → ℝ。f 称为**凸函数**，如果对任意 x, y ∈ C 及任意 λ ∈ [0,1]：

```text
f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y)
```

若不等式严格（对 x≠y、0<λ<1 用 <），则称 f **严格凸**。若 −f 凸，则 f **凹**。

### 定义 3：Jensen 不等式（有限形式）

设 f 为凸集 C 上的凸函数，x₁,…,xₙ ∈ C，λ₁,…,λₙ ≥ 0 且 Σᵢλᵢ = 1，则：

```text
f(Σᵢ λᵢ xᵢ) ≤ Σᵢ λᵢ f(xᵢ)
```

### 定理 1（一阶刻画）：设 f 在凸集 C 上可微。则 f 凸，当且仅当对任意 x, y ∈ C：

```text
f(y) ≥ f(x) + ∇f(x)·(y−x)
```

**证明（可复写）**：
- **"凸 ⇒ 不等式"**：
  - 第 1 步：由凸定义，对 λ ∈ (0,1)：f(λy + (1−λ)x) ≤ λf(y) + (1−λ)f(x)。（依据：定义 2。）
  - 第 2 步：移项得 f(λy+(1−λ)x) − f(x) ≤ λ[f(y) − f(x)]。（依据：代数整理。）
  - 第 3 步：左边 = f(x + λ(y−x)) − f(x)。令 λ → 0⁺，左边 → ∇f(x)·(y−x)（依据：可微性/方向导数的定义，第 01 章定理 1：方向导数 = 梯度·方向）。
  - 第 4 步：取极限得 ∇f(x)·(y−x) ≤ f(y) − f(x)，即 f(y) ≥ f(x) + ∇f(x)·(y−x)。∎
- **"不等式 ⇒ 凸"**：
  - 第 5 步：设 z = λx+(1−λ)y，需证 f(z) ≤ λf(x)+(1−λ)f(y)。由假设（对 z 与 x）：f(x) ≥ f(z) + ∇f(z)·(x−z)；对 z 与 y：f(y) ≥ f(z) + ∇f(z)·(y−z)。（依据：假设的不等式。）
  - 第 6 步：λf(x)+(1−λ)f(y) ≥ f(z) + ∇f(z)·[λ(x−z)+(1−λ)(y−z)]。（依据：线性组合不等式。）
  - 第 7 步：计算 λ(x−z)+(1−λ)(y−z) = λx+(1−λ)y − z = z − z = 0（依据：z = λx+(1−λ)y 的定义）。
  - 第 8 步：代入得 λf(x)+(1−λ)f(y) ≥ f(z)，即凸性成立。∎

**证明要点标注**：前四步用**定义 2（凸）**、**可微性与方向导数公式（第 01 章定理 1）**、**极限比较**；后四步用**假设的不等式**、**线性组合**与**z 的定义**。

### 定理 2（局部最优 = 全局最优）：设 f 是凸集 C 上的凸函数，x* ∈ C 是 f 的局部极小点，则 x* 是 f 在 C 上的全局极小点。

**证明（可复写，反证法）**：
- 第 1 步：反设存在 y ∈ C 使 f(y) < f(x*)。（依据：全局极小的否定。）
- 第 2 步：对 λ ∈ (0,1)，由凸性（定义 2）：f(λy + (1−λ)x*) ≤ λf(y) + (1−λ)f(x*)。（依据：定义 2。）
- 第 3 步：因 f(y) < f(x*)，故 λf(y) + (1−λ)f(x*) < λf(x*) + (1−λ)f(x*) = f(x*)。（依据：严格不等式与 f(x*) 相同项合并。）
- 第 4 步：故 f(λy + (1−λ)x*) < f(x*)。当 λ → 0⁺，点 λy + (1−λ)x* 趋近 x*，即 x* 的任意小邻域内存在函数值更低的点。（依据：λy+(1−λ)x* → x* 当 λ→0。）
- 第 5 步：这与"x* 是局部极小点"矛盾。故假设不成立，f(y) < f(x*) 不可能，x* 是全局极小点。∎

**证明要点标注**：第 2 步用**定义 2（凸）**；第 3 步用**严格不等式线性组合**；第 4 步用**凸组合的连续性**（λ→0 时逼近 x*）；第 5 步用**反证法**的归谬。

### 定理 3（二阶刻画）：设 f 在凸集 C 上二次可微。则 f 凸，当且仅当对任意 x ∈ C，海森矩阵 H(x) 半正定（即对一切 h，hᵀH(x)h ≥ 0）。

**证明（可复写，用定理 1 + 多元泰勒）**：
- **"凸 ⇒ H 半正定"**：
  - 第 1 步：由定理 1（凸 ⇒ 一阶不等式），对 x 和 y = x + th（t 足够小使点仍在 C 内）：f(x+th) ≥ f(x) + ∇f(x)·(th)。（依据：定理 1。）
  - 第 2 步：移项 f(x+th) − f(x) − ∇f(x)·(th) ≥ 0。（依据：代数。）
  - 第 3 步：由多元泰勒（第 02 章定理 3）：f(x+th) = f(x) + ∇f(x)·(th) + ½t²hᵀH(x)h + o(t²)。代入第 2 步得 ½t²hᵀH(x)h + o(t²) ≥ 0。（依据：多元泰勒公式。）
  - 第 4 步：除以 t² 并令 t → 0：½hᵀH(x)h ≥ 0，即 H(x) 半正定。（依据：o(t²)/t² → 0。）
- **"H 半正定 ⇒ 凸"**：
  - 第 5 步：由多元泰勒（带拉格朗日余项），存在 ξ 位于 x 与 y 之间使 f(y) = f(x) + ∇f(x)·(y−x) + ½(y−x)ᵀH(ξ)(y−x)。（依据：带余项的多元泰勒。）
  - 第 6 步：因 H 处处半正定，½(y−x)ᵀH(ξ)(y−x) ≥ 0。（依据：半正定定义。）
  - 第 7 步：故 f(y) ≥ f(x) + ∇f(x)·(y−x)，由定理 1（不等式 ⇒ 凸）得 f 凸。∎

**证明要点标注**：前四步用**定理 1**、**多元泰勒（第 02 章定理 3）**与**极限**；后三步用**带余项的多元泰勒**、**半正定定义**与**定理 1 的逆方向**。

### 反例/边界

- **x³ 不是凸函数**：f(x) = x³。取 x = −1，y = 0，λ = 1/2：左边 f((−1+0)/2) = f(−0.5) = −0.125；右边 (1/2)f(−1)+(1/2)f(0) = (1/2)(−1)+0 = −0.5。因 −0.125 > −0.5，不等式 f(中点) ≤ 加权平均 不成立，故 x³ 非凸。**（几何：x³ 有 S 形拐弯，在 x=0 左侧向上凹，弦穿到图像下方。）**
- **海森半正定是"处处"的**：二阶刻画要求 H(x) 在 C 内**每一点**都半正定。若只在局部某点半正定，不能推出全局凸。**（一个函数可能在某个点局部凸，但整体非凸——判定凸性是"整体性质"，要检查所有点。）**
- **不可微函数的凸性**：一阶/二阶刻画都要求可微/二次可微。对不可微的凸函数（如 f(x) = |x|，ReLU），只能用**定义验证**或**次梯度**理论。**可微判据不是万能的，遇到折角函数要退回定义。**
- **严格凸 vs 凸**：x² 严格凸（H=2>0）；而 f(x) = x⁴ 的 H = 12x² 在 x=0 处为 0，只在别处正——f 仍是凸的（H 处处半正定），但不是严格凸（存在 H 半正定但不正定的点）。

## 知识点总结

### 知识点（本章推出的核心概念）

- **凸集**：任意两点连线整段留在集合内（λx+(1−λ)y ∈ C）。圆盘、矩形、半平面是凸集；圆环、两瓣不连的集合非凸。
- **凸函数**：f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)——"弦在图像上方，图像不下垂"。x² 凸、x³ 非凸。
- **用定义验证凸性**：算差 Δ = [λf(x)+(1−λ)f(y)] − f(λx+(1−λ)y)，若能化简成非负（如 λ(1−λ)(x−y)²），则凸。
- **Jensen 不等式**：f(Σλᵢxᵢ) ≤ Σλᵢf(xᵢ)；概率形式 f(E[X]) ≤ E[f(X)]（凸函数作用均值不超过函数值均值）。
- **一阶刻画**：可微时 f(y) ≥ f(x) + ∇f(x)·(y−x)——切线是函数下界。
- **二阶刻画**：二次可微时 f 凸 ⇔ 海森矩阵处处半正定（hᵀHh ≥ 0）。
- **关键性质**：凸函数的局部最优 = 全局最优（没有假坑）——"为什么敢用梯度下降"的根基。

### 历史结论（本章涉及的史料）

- **Jensen（Johan Jensen，1859–1925）**：1905–1906 年给出凸函数的不等式形式（Jensen 不等式），奠定凸分析基础。
- **Fenchel、Rockafellar 等**：20 世纪中叶把凸分析发展为系统学科；Rockafellar 的《Convex Analysis》（1970）是经典教材。
- **凸性的几何直觉（切线/弦）**：早在 19 世纪就有数学家用"弦在图像上方"描述这类函数，但严格的不等式形式由 Jensen 确立。

### 工程实践结论（本章知识在真实工程里怎么用）

- **凸损失 = 训练可证明成功**：MSE、交叉熵、线性回归/逻辑回归/SVM 目标都是凸的，梯度下降保证到全局最优。
- **深度学习损失非凸**：多层非线性产生大量局部极值/鞍点，训练靠技巧"逃离假坑"——凸性是传统 ML 与深度学习的可证明性分水岭。
- **Jensen 不等式是算法发动机**：KL 散度非负性、EM 算法的下界构造、凸优化对偶都靠它。
- **海森半正定 = 优化容易的一眼快筛**：算海森判断正定/半正定，是判断"这损失好不好优化"的标准动作。

> 位置说明：本章对话负责"为什么"，这里负责"怎么算"。**每题请动笔 10 分钟以上，先自己写，再对照完整解答。禁止边算边翻答案。**

### 题 1（易→中）：用定义验证凸性——展开化简

**题干**：用定义 f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y) 验证以下函数凸性：
(a) f(x) = x²。
(b) f(x,y) = x² + y²。
(c) 证明 f(x) = x³ 在实数上**不是**凸函数（构造反例）。

**完整分步解答：**

**（a）f(x) = x²**：
第 1 步：算差 Δ = [λx²+(1−λ)y²] − [λx+(1−λ)y]²。（规则：凸性不等式两边的差。）
第 2 步：展开 [λx+(1−λ)y]² = λ²x² + 2λ(1−λ)xy + (1−λ)²y²。（规则：完全平方展开。）
第 3 步：Δ = λx² − λ²x² + (1−λ)y² − (1−λ)²y² − 2λ(1−λ)xy = λ(1−λ)x² + λ(1−λ)y² − 2λ(1−λ)xy。（规则：合并同类项，λ−λ²=λ(1−λ)。）
第 4 步：Δ = λ(1−λ)(x² − 2xy + y²) = **λ(1−λ)(x−y)²**。（规则：完全平方 a²−2ab+b²=(a−b)²。）
第 5 步：因 λ∈[0,1] 故 λ(1−λ)≥0，且 (x−y)²≥0，故 Δ≥0，即右边 ≥ 左边，**f 凸** ✓。

**（b）f(x,y) = x²+y²**：
第 6 步：Δ = [λ(x₁²+y₁²)+(1−λ)(x₂²+y₂²)] − [λx₁+(1−λ)x₂]² − [λy₁+(1−λ)y₂]²。（规则：凸性差，注意两项都要展开。）
第 7 步：对 x 部分：λx₁²+(1−λ)x₂² − [λx₁+(1−λ)x₂]² = λ(1−λ)(x₁−x₂)²（同 (a)）。（规则：同 (a) 的完全平方。）
第 8 步：对 y 部分同理 = λ(1−λ)(y₁−y₂)²。（规则：对称。）
第 9 步：Δ = **λ(1−λ)[(x₁−x₂)² + (y₁−y₂)²] ≥ 0**，故 f 凸 ✓。

**（c）f(x) = x³ 非凸反例**：
第 10 步：取 x = −1，y = 0，λ = 1/2。左边 f(λx+(1−λ)y) = f(−0.5) = (−0.5)³ = −0.125。（规则：x³ 求值。）
第 11 步：右边 λf(x)+(1−λ)f(y) = (1/2)(−1) + (1/2)(0) = −0.5。（规则：加权平均。）
第 12 步：比较 −0.125 与 −0.5：**−0.125 > −0.5**，即左边 > 右边，凸性不等式 f(中点) ≤ 加权平均 **不成立**，故 x³ 非凸。（规则：凸性要求左边 ≤ 右边，此处违反。）

**答**：(a) Δ = λ(1−λ)(x−y)² ≥ 0，凸；(b) Δ = λ(1−λ)[(x₁−x₂)²+(y₁−y₂)²] ≥ 0，凸；(c) 反例 x=−1,y=0,λ=1/2 使 f(−0.5)=−0.125 > −0.5，非凸。

**常见错误**：① (b) 里漏掉对 y 的那一项展开，只算 x 部分，导致差算不全；② 把 λ−λ² 合并成 λ(1−λ) 时符号写错；③ 判断 (c) 时选了"看起来合理"但不等式不违反的点（如对称点 x=−1,y=1 会让 f(中点)=f(0)=0 与加权平均 0 相等，恰好不违反——要挑非对称点）。

### 题 2（中）：一阶刻画与二阶刻画——判断可微函数凸性

**题干**：对以下函数，判断凸性并说明用了哪种判据：
(a) f(x) = e^x（用二阶刻画）。
(b) f(x) = x⁴（用二阶刻画，注意某点二阶导为 0）。
(c) f(x) = −x²（用二阶刻画）。
(d) f(x,y) = x² + y²（用二阶刻画，算海森）。

**完整分步解答：**

**（a）f(x) = e^x**：
第 1 步：f″(x) = e^x。（规则：e^x 求两次导仍是 e^x。）
第 2 步：因 e^x > 0 对所有 x，故 H = f″ 处处正定，f 严格凸。（规则：二阶刻画——H 半正定 ⇔ 凸。）

**（b）f(x) = x⁴**：
第 3 步：f′(x) = 4x³，f″(x) = 12x²。（规则：幂函数求导。）
第 4 步：f″(x) = 12x² ≥ 0 对所有 x（x=0 处为 0，其余处 > 0）。（规则：二阶刻画。）
第 5 步：故 f 凸；但因 f″(0) = 0，H 在 x=0 处只半正定不正定，f 不是严格凸。（规则：半正定 ≠ 正定。）

**（c）f(x) = −x²**：
第 6 步：f″(x) = −2 < 0。（规则：−x² 求两次导 = −2。）
第 7 步：H = −2 处处负定，不半正定，故 f 不是凸函数（它是凹函数）。（规则：二阶刻画的反向。）

**（d）f(x,y) = x²+y²**：
第 8 步：f_xx = 2，f_xy = 0，f_yy = 2，故 H = [[2,0],[0,2]]。（规则：二阶偏导。）
第 9 步：对任意 h=(h₁,h₂)，hᵀHh = 2h₁² + 2h₂² ≥ 0，且对 h≠0 恒 > 0，H 处处正定。（规则：半正定/正定定义。）
第 10 步：故 f 严格凸 ✓（与题 1(b) 用定义法结论一致，双通道互证）。（规则：二阶刻画。）

**答**：(a) 严格凸（e^x>0）；(b) 凸但不严格（12x²≥0，x=0 处为 0）；(c) 非凸（H=−2 负定）；(d) 严格凸（H=[[2,0],[0,2]] 正定）。

**常见错误**：① 把 (b) 的 x⁴ 当成"只在 x=0 处二阶导为 0 就不凸"——**半正定允许某点等于 0**，x⁴ 仍是凸函数，只是不严格；② (c) 把"凹"和"非凸"混淆，−x² 是凹函数，不是凸函数；③ 算 (d) 的 hᵀHh 时漏项，或把 H 的交叉项（应为 0）当成 2。

### 题 3（中→难）：Jensen 不等式 + 局部最优 = 全局最优

**题干**：
(a) 用 Jensen 不等式（两点形式，即凸定义）证明：对凸函数 f，f(x)+f(y) ≥ 2f((x+y)/2)（中点的函数值不超过两端平均）。
(b) 设 f(x,y) = x² + y²，验证"局部最优 = 全局最优"：求 f 的梯度零点，证明它是全局极小点。
(c) 用一阶刻画 f(y) ≥ f(x) + ∇f(x)·(y−x) 验证：对 (b) 的 f，梯度零点确为全局极小。

**完整分步解答：**

**（a）Jensen 中点不等式**：
第 1 步：在凸定义 f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y) 中取 λ = 1/2。（规则：凸定义。）
第 2 步：左边 f(½x + ½y) = f((x+y)/2)；右边 ½f(x) + ½f(y) = (f(x)+f(y))/2。（规则：代入 λ=1/2。）
第 3 步：故 f((x+y)/2) ≤ (f(x)+f(y))/2，即 **f(x)+f(y) ≥ 2f((x+y)/2)**。（规则：不等式两边同乘 2。）

**（b）梯度零点与全局极小**：
第 4 步：f = x²+y²，∇f = (2x, 2y)。（规则：求偏导。）
第 5 步：令 ∇f = 0，得 2x=0、2y=0，即唯一驻点 **x* = (0,0)**。（规则：解方程组。）
第 6 步：f(0,0) = 0；对任意 (x,y)，f(x,y) = x²+y² ≥ 0 = f(0,0)，故 (0,0) 是全局极小点。（规则：x²≥0、y²≥0。）

**（c）一阶刻画验证**：
第 7 步：一阶刻画说 f 凸时，f(y) ≥ f(x) + ∇f(x)·(y−x) 对一切 x,y 成立。（规则：定理 1。）
第 8 步：在梯度零点 x* = (0,0)，∇f(0,0) = 0，代入一阶刻画（以 x = x* = 0）：f(y) ≥ f(0) + 0·(y−0) = f(0) = 0。（规则：定理 1 取 x=梯度零点。）
第 9 步：故对任意 y，f(y) ≥ f(0)，即 (0,0) 是全局极小点 ✓。（规则：全局极小定义。）

**答**：(a) f(x)+f(y) ≥ 2f((x+y)/2)；(b) 唯一驻点 (0,0)，f(0,0)=0 ≤ f(x,y) 对一切点，故为全局极小；(c) 一阶刻画 + ∇f(0,0)=0 直接给出 f(y)≥f(0)，印证"梯度零点即全局最优"。

**常见错误**：① (a) 里取 λ 忘写 1−λ，或把中点写成 (x+y)/2 但右侧仍保留 λ 形式；② (b) 找到驻点后没说"f 是凸函数所以局部=全局"，只停在"这是驻点"——**要指出因为 f 凸，驻点自动是全局最优**；③ (c) 里忘了"∇f(x*)=0"这一关键代入，导致一阶刻画右边多一项。

## 向导便签

> 这一章咱们干了什么：从"什么形状的坡敢保证钢珠一滑到底"这个问题出发，定义了凸集（任意两点连线不出去）和凸函数（f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)）；推出了 Jensen 不等式；证明了凸函数"局部最优 = 全局最优"；并给出了可微/二次可微时的一阶刻画（切线是下界）和二阶刻画（海森半正定）。
>
> 钉死一句话：**凸函数 = 没有假坑的单谷函数；它的局部最优就是全局最优，所以"敢用梯度下降"。** 判断它有三把尺子：定义法（化简差）、一阶刻画（切线下界）、二阶刻画（海森半正定）。
>
> 记住一个边界：**一阶/二阶刻画要求可微/二次可微**；遇到不可微的折角函数（|x|、ReLU），只能退回定义验证或次梯度理论。还有，**海森"处处"半正定才是凸**，只看某一点不算数。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：定义验证凸性**

用定义验证 f(x) = x² + 2x 是凸函数（提示：算差 Δ，注意它仍是 λ(1−λ)(x−y)²，因为线性项 +2x 的贡献恰好抵消）。

**完整解答**：
Δ = [λf(x)+(1−λ)f(y)] − f(λx+(1−λ)y) = [λ(x²+2x)+(1−λ)(y²+2y)] − [(λx+(1−λ)y)² + 2(λx+(1−λ)y)]。
线性项部分：λ·2x + (1−λ)·2y − 2(λx+(1−λ)y) = 0（恰好抵消）；二次部分同题 1(a)：λ(1−λ)(x−y)²。故 Δ = **λ(1−λ)(x−y)² ≥ 0**，f 凸 ✓。

**题 B（计算，中→难）：二阶刻画 + 局部最优**

设 f(x,y) = x² + y²。
(a) 求海森矩阵 H 并判断正定/半正定。
(b) 求梯度零点，用"凸函数局部=全局"说明它是最优解。
(c) 在 (1,1) 处用一阶刻画验证 f(0,0) ≥ f(1,1) + ∇f(1,1)·(−1,−1)。

**完整解答**：
(a) H = [[2,0],[0,2]]，对 h≠0，hᵀHh = 2h₁²+2h₂² > 0，故 H 处处正定，f 严格凸。（规则：二阶刻画。）
(b) ∇f = (2x,2y)=0 → x*= (0,0)。因 f 严格凸，局部最优 = 全局最优，且 f(0,0)=0 是最小值。（规则：定理 2。）
(c) 一阶刻画：f(y) ≥ f(x)+∇f(x)·(y−x)。取 x=(1,1)、y=(0,0)：∇f(1,1)=(2,2)，y−x=(−1,−1)。f(0,0)=0；右侧 f(1,1)+∇f(1,1)·(−1,−1) = 2 + (2,2)·(−1,−1) = 2 + (−4) = −2。0 ≥ −2 ✓ 成立（注意这里是"y 取 (0,0)"相对 x=(1,1) 确实更低，不等式方向正确：低点的函数值 ≥ 高点的切线外推值）。

**题 C（概念，检查理解）：凸性与判定工具**

老谟给造物主三个函数：x³、x²+y²、−x²−y²。
(1) 哪个是凸函数？哪个是凹函数？哪个既非凸也非凹？
(2) 为什么"局部最优 = 全局最优"只对凸函数成立？
(3) 遇到不可微的凸函数（如 f(x)=|x|），该用哪种判据？

**完整解答**：
(1) x²+y² 凸（H 正定）；−x²−y² 凹（H 负定）；x³ 既非凸也非凹（H=6x 变号，且定义验证出现反例）。（规则：二阶刻画 / 定义验证。）
(2) 因为凸函数没有"假坑"——反证法证明：若局部最优非全局最优，则附近必有更低的凸组合点，与局部最优矛盾。非凸函数（波浪板）有假坑，所以这条只对凸成立。（规则：定理 2。）
(3) |x| 不可微（在 x=0 有棱），一阶/二阶刻画都不适用，只能用**定义验证**（直接检查 f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)）或**次梯度**理论。（规则：可微判据的适用边界。）
