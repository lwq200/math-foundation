# 《线性代数》· 第 4 册

> **苏格拉底对话体自学教材**，老谟 ⇄ 造物主一问一答，让读者从"一个数不够描述世界"出发，一路走到"用 SVD 拆解任意矩阵"——把向量、空间、矩阵、方程组、行列式、特征值、对角化、正交、SVD 全部走通。本册是《数学基础》系列 7 册中的第 **4** 册，是**"多维世界"的完整语言**。
>
> **核心立场**：本册在保留样书 Ch10-12（向量/矩阵/特征值）直觉推导的基础上，系统补足"严格"与"结构"两翼——**向量空间公理化（新增 Ch2）、行列式严格定义（新增 Ch5）、可对角化充要条件（几何重数=代数重数，核心新增 Ch7）、内积空间与正交（新增 Ch8）、SVD 完整推导（Ch9）**。**"代数↔几何翻译"是本册主线：垂直→点积0、相关=有冗余、乘法=变换复合、det=缩放系数、特征值=方向-缩放、SVD=旋转-拉伸-旋转。**

## 每章标配（继承 skill 升级后的铁律）

- **严格化走廊**：定义 → 定理（带全前提）→ ≥1 个完整可复写证明 → 反例/边界。**本册的核心证明**：点积几何意义（余弦定理）、线性相关⟺可表示、秩-零化度（基延拓）、det(AB)=det(A)det(B)（初等归纳）、不同特征值特征向量无关（最短关系反证）、可对角化充要条件（双向）、Gram-Schmidt（构造）、谱定理、SVD 存在性（构造）——**每步标注依据，绝不用"显然"。**
- **证明类型标注**：每一章走廊都标明证明的"招式"——直接/反证/构造/归纳/双向。**读证明先问"用的哪一招"。**
- **"算完必须验证"红线（本册特色）**：求逆验 A⁻¹A=I、特征向量验 Av=λv、对角化验 P⁻¹AP、正交化验 w⊥u、SVD 验 UΣVᵀ=A——**每类题都有专属"回头验证"，这是严谨性的体现。**
- **"代数↔几何翻译"主线（本册特色）**：垂直→点积0、相关=有冗余、乘法=变换复合、det=缩放系数、特征值=方向-缩放、SVD=旋转-拉伸-旋转——**把几何直觉翻译成代数，用代数推广到画不出的高维。**
- **红线口径统一**：对话只推"为什么想到这步"的直觉，**完整可复写证明一律在走廊，对话不演证明**（各章走廊均标注"关于对话"口径）。
- **跨章脊柱（链条式知识）**：向量（01）→空间（02）→矩阵（03）→方程组（04）→行列式（05）→特征值（06）→对角化（07）→正交（08）→SVD（09）。**SVD 是全书集大成**：AᵀA 谱分解用第 08 章谱定理、特征值用第 06-07 章、奇异值判秩用第 04 章、uᵢ=Avᵢ/σᵢ 用第 03 章矩阵。
- **计算训练场**：每章 ≥3 道中大型计算题（动笔 10 分钟+），易→中→难，附完整分步解答 + 常见错误。

- **统稿员（writer-info）**：答案速查页数值与正文逐章核对、全册统稿
- **作者 ×2（writer-stats 负责 Ch2-5、writer-basic 负责 Ch6-7）**：按样板标准创作
