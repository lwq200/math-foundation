# 第 04 章 · 线性方程组与高斯消元——方程组什么时候有解、几个解

> 本章从哪个问题出发：上一章你拿到了"批量变换"的工具——矩阵，以及"撤销变换"的逆矩阵。可矩阵最直接的用武之地是解方程组：**3 个方程 3 个未知数，什么时候有唯一解？什么时候无解？什么时候有无穷多解？** 一个现实问题（线性回归求系数、电路求电流、流量平衡）往往就落成一个线性方程组——**你需要的不是"一个一个试"，而是"一眼看出有几个解、怎么解出来"。**
> 推导到哪个结论：你会学会**高斯消元（行变换化阶梯）**——把方程组用行变换化成阶梯形，然后**根据阶梯形一眼判断解的情况**（主元个数决定秩，秩决定解的情况）。你会严格定义**秩（rank）**与**零化度（nullity）**，并亲手证明本章最重要的一条定理——**秩-零化度定理：rank(A) + nullity(A) = 列数 n**。
>
> 核心认知：**线性方程组的解，由"系数矩阵的秩"决定**——增广矩阵与系数矩阵的秩比较，给出"无解/唯一解/无穷多解"的完整判定；而**秩-零化度定理 rank+nullity=n** 告诉你：列空间有多"大"（秩），零空间就有多"小"（零化度），两者互补。**这一章把矩阵从"工具"变成"解方程组的引擎"，是线性代数从"算"走向"判定"的关键一站。**

### 第 1 轮：解方程组的"机械动作"——行变换不改变解

**老谟**："先看解方程组的'机器'。**解一个方程组，你最常用的动作是什么？** 比如 2x+y=5、x−y=1，你会怎么消元？"

**造物主**："……把一个方程乘个倍数，或者两个方程相加减，消掉一个未知数。**比如第二个方程乘 2 再和第一个相减，消掉 x？**"

**老谟**："**对。这些动作——① 交换两个方程、② 某个方程乘非零倍数、③ 某个方程的倍数加到另一个方程——叫行变换（row operations）。** 关键是：**它们都不改变方程组的解集。** 为什么？因为你做的每一步都是'对等式做合法操作'，解一个都不会丢也不会多。**下一轮，我们把'行变换'用到系数矩阵上，看怎么把它'化阶梯'。**

### 📐 知识锚点：行变换与增广矩阵——把方程组翻译成矩阵
<blockquote style="background:#fff8e1">

【概念深挖】**线性方程组**：\(a_{11}x_1+\cdots+a_{1n}x_n=b_1,\;\dots\)，可写成矩阵形式 \(A\mathbf{x}=\mathbf{b}\)。
- **增广矩阵 [A|b]**：把系数矩阵 A 和右侧向量 b 拼起来，一行对应一个方程。

**三种行变换（row operations，不改变解集）**：
1. **交换**两行（交换两个方程）。
2. **倍乘**某行乘以非零常数（方程两边乘非零数）。
3. **行加减**：某行加上另一行的倍数（方程加减）。

**高斯消元（Gaussian elimination）**：用行变换把增广矩阵化成**行阶梯形（row echelon form）**——每行的主元（首非零元）在下一行主元的右边，主元以下的列全 0。再进一步化成**简化行阶梯形（reduced row echelon form）**（主元为 1、主元上下全 0）。

【工程实践】行变换是**一切数值线性代数求解器的基础**：**线性回归解最小二乘、电路网孔分析、有限元方程组求解，核心都是"高斯消元"**。工程里不用手算，但"消元会不改变解"这个事实，是所有求解算法的正确性根基。
</blockquote>

### 第 2 轮：秩——阶梯形里"主元的个数"

**老谟**："你把增广矩阵化成阶梯形后，**数一数有多少行是'非全零'的（每行有个主元），这个数就叫秩（rank）。** 比如三行阶梯形里有两行有主元，秩就是 2。**你猜，为什么'秩'这么重要？** 它和'解的个数'直接挂钩。下一轮我们看怎么用秩判定解的情况。"

**造物主**："……秩 = 阶梯形里主元的个数？**它好像度量了'方程组里真正独立的信息有几条'**——全零行是多余的，不贡献秩。"

**老谟**："**你抓到秩的灵魂了——秩 = 独立方程（真正有约束力的行）的个数。** 多余的行（可由其他行线性组合出来）在消元时会变成全零行，不贡献秩。**那'真正独立的方程有几条'，就直接决定了'未知数有几个能定下来'。下一轮，我们把这个'秩决定解'的判据写清楚。**"

### 📐 知识锚点：秩——"独立信息的条数"
<blockquote style="background:#e3f2fd">

【概念深挖】**秩（rank）**：矩阵 A 的秩 rank(A) = 行阶梯形中非零行的个数 = 主元的个数。
- 等价定义：**列空间（Col A）的维数**（第 03 章讲过"列=基的像"，秩就是列空间这个子空间的维数）。
- **rank(A) ≤ min(行数, 列数)**。
- 满秩：rank(A)=min(m,n)（行数/列数较小的那个达到）。

**为什么秩=独立信息条数**：消元后全零行 = 可由其他行线性组合出来的"多余行"，不贡献秩。**秩数出"真正独立的方程"有几条。**

**秩与列空间**：rank(A) = dim(Col A) = 列空间中线性无关列的个数（列空间的基）。

【历史溯源】"秩"（rank）概念由**弗罗贝尼乌斯（Frobenius）**等 19 世纪代数家在矩阵论中确立；**秩-零化度定理**（下一章主题）是线性代数的核心结构定理之一。**"用秩判定线性方程组解的情况"是高斯（Gauss）在 19 世纪初系统化消元法的直接应用。**
</blockquote>

### 第 3 轮：用秩判定解——无解/唯一解/无穷多解

**老谟**："现在把'秩决定解'说清楚。**设方程组 Ax=b，系数矩阵秩 rank(A)，增广矩阵秩 rank([A|b])。** 你猜，分几种情况？"

**造物主**："……先想'矛盾'的情况：**如果消元到最后出现'0=非零数'（一行左边全 0、右边非 0），那就无解。** 这种'矛盾行'，就说明 rank([A|b]) > rank(A)（增广矩阵比系数矩阵多出一行独立的"矛盾"）？"

**老谟**："**你摸到判据了。** 完整判据：
- **rank(A) < rank([A|b])** → 无解（出现矛盾行 0=非零）。
- **rank(A) = rank([A|b]) = n**（n=未知数个数，满秩）→ 唯一解。
- **rank(A) = rank([A|b]) = r < n** → 无穷多解（n−r 个自由变量）。
**一句话：系数秩和增广秩相等则有解；相等且等于列数则唯一，小于列数则无穷多。** 下一轮，我们看那个'无穷多解'里的自由度，和秩-零化度定理的关系。"

---

### 📐 知识锚点：解的情况判定——"秩"一锤定音
<blockquote style="background:#fff8e1">

【概念深挖】**线性方程组 Ax=b 的解（由秩判定）**：
- **rank(A) ≠ rank([A|b])** → **无解**（存在矛盾行）。
- **rank(A) = rank([A|b]) = n**（n=列数/未知数）→ **唯一解**。
- **rank(A) = rank([A|b]) = r < n** → **无穷多解**，自由变量个数 = n−r。

**齐次方程组 Ax=0**：恒有解（0 是解）。
- rank(A)=n → 只有零解。
- rank(A)=r<n → 有无穷多解，解空间（零空间 N(A)）维数 = n−r。

**解空间结构**：
- 齐次解 = 零空间 N(A)，是 ℝⁿ 的子空间，dim N(A) = n−r。
- 非齐次解 = 特解 + 零空间（齐次解）。

【工程实践】**"秩判定解"是数值求解的第一步**：**回归/拟合时，如果设计矩阵缺秩（rank 不足），参数解不唯一**——这正是多重共线性的数学本质。**工程师先算 rank，就知道"能不能唯一解出参数、还是需要正则化（加约束挑一个解）"。**
</blockquote>

### 第 4 轮：秩-零化度——"列空间多大 + 零空间多大 = 列数"

**老谟**："你把'无穷多解'里的自由度算出来了——**自由变量个数 = n−r。** 而这个'自由度'，其实就是**零空间（N(A)，所有 Ax=0 的解）的维数，叫零化度 nullity(A)**。**那你发现没有——秩 r 是列空间的维数，零化度 n−r 是零空间的维数，加起来正好是列数 n！**"

**造物主**："……**rank(A) + nullity(A) = n！** 列空间多大 + 零空间多大 = 列数。**这个等式，是不是线性代数最漂亮的一条？**"

**老谟**："**对，这就是秩-零化度定理（rank-nullity theorem）。** 它告诉你：**一个矩阵把输入空间（n 维）拆成两块——'被送到列空间的维数'（秩）+ '被压到零的维数'（零化度）——两块合起来恰好是 n。** 你压扁得越多（零化度大），剩下的像就越小（秩小）；反之亦然。**完整证明在走廊定理 1，翻过去对着空白纸补全。**下一轮收章。"

### 📐 知识锚点：秩-零化度定理——"列空间 + 零空间 = 输入空间"
<blockquote style="background:#e3f2fd">

【概念深挖】**零化度（nullity）**：nullity(A) = dim N(A) = 齐次方程 Ax=0 的解空间维数。
**秩-零化度定理（rank-nullity theorem）**：
$$\text{rank}(A) + \text{nullity}(A) = n,$$
其中 n 是 A 的列数（输入空间维数）。

**直觉**：矩阵 A 把输入空间 ℝⁿ 映射到列空间 Col A（维数=rank）。**被"压到零"的部分（零空间）维数是 nullity；被"保留下来"的像空间维数是 rank——两者加起来恰好补回输入维数 n。** 就像"数到输出端的线数"+"断掉的线数"=总输入线数。

**推论**：
- 满秩方阵（rank=n）⟹ nullity=0 ⟹ 零空间只有零向量 ⟹ 可逆。
- **秩-零化度是判断"信息保不保留"的核心**：nullity 越大，信息被压扁得越多。

【历史溯源】秩-零化度定理是**线性代数核心结构定理**，由**西尔维斯特（Sylvester，1884）**提出"秩不等式"，后经弗罗贝尼乌斯等完善。**它是"解方程组"与"线性映射"结构的统一——"秩决定解的多寡，零化度度量自由度"。**
</blockquote>

**老谟**："把这章收一遍。你最初只会'一个一个解'，现在你手里有什么？"

**造物主**："……**① 行变换**（不改变解集，化阶梯）；**② 秩**（=主元个数=独立方程条数=列空间维数）；**③ 解判定**（rank(A) vs rank([A|b])：不等无解、相等满秩唯一、相等低秩无穷多）；**④ 秩-零化度定理**（rank+nullity=n）。"

**老谟**："**这一章，你把'解方程组'从'苦力活'变成了'看秩一锤定音'。** 而秩-零化度定理，是线性代数'看结构'的眼睛——后面行列式（det≠0 ⟺ 满秩）、特征值（压扁方向）、对角化（能不能掰直），全围着'秩和零空间'转。**下一章，我们看行列式——那个'矩阵缩放空间的程度'的度量，它和'可逆''秩满'紧紧咬合。**"

## 严格化走廊

> 位置说明：对话负责"直觉"——为什么行变换不改变解、为什么秩决定解、为什么 rank+nullity=n。本走廊负责"严谨"——把秩、零化度、解判定落成精确形式，并给出本章的核心**完整可复写**证明：**秩-零化度定理（定理 1，用"构造基并延拓"）**。每个证明都标注"证明类型 + 每一步依据"，红线 1 的硬要求。

### 定义：秩、零空间、零化度、解的情况（精确表述）

- **列空间 Col A**：A 的列张成的子空间（= {Ax : x∈ℝⁿ}）。
- **零空间 N(A)**：{x∈ℝⁿ : Ax=0}。
- **秩 rank(A)**：dim(Col A)（= 行阶梯形主元个数）。
- **零化度 nullity(A)**：dim(N(A))。

**解的情况（对 Ax=b，A 为 m×n）**：
- rank(A) < rank([A|b]) ⟹ 无解。
- rank(A) = rank([A|b]) = n ⟹ 唯一解。
- rank(A) = rank([A|b]) = r < n ⟹ 无穷多解（n−r 个自由变量）。

> **证明类型标注**：本章的核心证明——**定理 1（秩-零化度）用构造性证明（取零空间基，延拓成 ℝⁿ 的基，验证列的像构成列空间基）**，承接 Ch2 的基/维数与 Ch3 的矩阵变换。解的情况判定作为"行阶梯形直接推论"陈述。
>
> **关于对话**：本章第 4 轮是读者**第一次**正式接触"秩-零化度定理"，对话做了"引导式推导"（为什么 rank+nullity 凑成 n、为什么零化度=自由度）。**正式的可复写证明（每一步标依据）在本走廊定理 1**。对话负责"为什么会想到这步"，走廊负责"怎么把它写标准"。

### 定理 1（秩-零化度定理）：对 m×n 矩阵 A，有 rank(A) + nullity(A) = n

**前提**：A 是 m×n 矩阵（n 列），把 ℝⁿ 映射到 ℝᵐ。

**结论**：dim(Col A) + dim(N(A)) = n。

**证明类型**：构造性证明（构造基并延拓）。

**证明**：
- 第 1 步：**取零空间的一组基**：设 nullity(A)=k，取 N(A) 的一组基 {v₁,…,vₖ}。（依据：零空间是子空间，有限维，有基。）
- 第 2 步：**延拓成 ℝⁿ 的基**：把 {v₁,…,vₖ} 延拓为 ℝⁿ 的一组基 {v₁,…,vₖ, w₁,…,w_{n−k}}。（依据：基的延拓定理——任意线性无关组可延拓成整个空间的基。）
- 第 3 步：**验证 {Aw₁,…,Aw_{n−k}} 张成 Col A**：对任意 Ax（x∈ℝⁿ），把 x 用第 2 步的基表示：x = Σcᵢvᵢ + Σdⱼwⱼ。则 Ax = A(Σcᵢvᵢ) + A(Σdⱼwⱼ) = ΣcᵢAvᵢ + ΣdⱼAwⱼ = ΣdⱼAwⱼ（因 vᵢ∈N(A)，Avᵢ=0）。（依据：线性变换性质 + Avᵢ=0。）
- 第 4 步：故 Col A = span{Aw₁,…,Aw_{n−k}}（每个 Awⱼ∈Col A，且任意 Col A 元是其组合）。（依据：第 3 步。）
- 第 5 步：**验证 {Aw₁,…,Aw_{n−k}} 线性无关**：设 ΣdⱼAwⱼ=0，则 A(Σdⱼwⱼ)=0，故 Σdⱼwⱼ∈N(A)。因 {v₁,…,vₖ} 是 N(A) 的基，存在 cᵢ 使 Σdⱼwⱼ=Σcᵢvᵢ，即 Σdⱼwⱼ − Σcᵢvᵢ=0。但 {v₁,…,vₖ,w₁,…,w_{n−k}} 是 ℝⁿ 的基（线性无关），故所有 dⱼ=0、cᵢ=0。（依据：零空间定义 + 基的线性无关性。）
- 第 6 步：故 {Aw₁,…,Aw_{n−k}} 是 Col A 的一组基，rank(A) = dim Col A = n−k。（依据：第 4、5 步——张成 + 线性无关 = 基。）
- 第 7 步：nullity(A)=k，故 rank(A)+nullity(A) = (n−k)+k = n。∎

> **依据标注**：步 1 用零空间有基；步 2 用基的延拓定理；步 3 用线性变换性质与 Avᵢ=0（vᵢ 在零空间）；步 4 用张成；步 5 用零空间定义与基的线性无关（若 Awⱼ 相关，则 wⱼ 的组合落入零空间，与基无关矛盾）；步 6 用"张成+无关=基"（Ch2）；步 7 代数。
> **读法**：秩-零化度证明的钥匙是**"构造基并延拓"**——把零空间基 {vᵢ} 延拓成 ℝⁿ 的基 {vᵢ,wⱼ}，然后"vᵢ 部分被压到 0（Avᵢ=0）、wⱼ 部分被送到列空间成为基"。**于是列空间维数恰好 = wⱼ 的个数 = n−k。** 它把"矩阵把输入空间拆成'保留的像'+'压扁的零'"这件直观，变成了严格证明。

### 解方程组与求秩的书写格式模板（可复写卡片——对着空白纸照写）

> 这是本章要你抄进脑子的卡。**以后解任何线性方程组，就照这个骨架走**：

```text
命题：解 Ax=b（或判断解的情况）。
计算：
  1. 写增广矩阵 [A|b]。
  2. 用行变换化行阶梯形（主元逐步向右下推进），数 rank(A) 和 rank([A|b])。
  3. 判定解：
     - rank(A) < rank([A|b]) → 无解（有矛盾行 0=非零）。
     - rank(A)=rank([A|b])=n → 唯一解（继续回代）。
     - rank(A)=rank([A|b])=r<n → 无穷多解（选 n−r 个自由变量，用特解+齐次解表示）。
  4. 求 rank 与 nullity：rank=主元个数；nullity=n−rank（秩-零化度）。
  5. 收束：写出解集。∎
```

**填写时的三个检查点**：① **行变换化阶梯要规范**（主元逐个向右推进，别跳步）；② **比较 rank(A) 与 rank([A|b])**（无解的判据）；③ **无穷多解要写出"自由变量"**，别只说"无穷多"。

### 反例/边界：线性方程组的适用边界

1. **"唯一解"要满秩**：rank(A)=n 才有唯一解；rank<n 时有无穷多或零解。**别把"方程个数=未知数个数"当成"必有唯一解"**（方程可能线性相关）。
2. **无解 vs 无穷解的区分**：看 rank(A) 是否 < rank([A|b])。**"矛盾行"=无解；"缺秩但一致"=无穷解，别混。**
3. **零空间 {0} 的维数是 0**：满秩时 nullity=0（只有零解）。**别把 nullity=0 当成"没有零空间"。**
4. **齐次方程 Ax=0 恒有解（零解）**：秩-零化度对齐次尤其有用（解空间维数=n−r）。**非齐次的解 = 特解 + 齐次解。**
5. **秩-零化度对"非方阵"也成立**：m×n 矩阵，rank+nullity=n（列数）。**别只想到方阵。**

## 知识点总结

### 知识点（本章推出的核心概念）

- **行变换**（交换/倍乘/行加减）：不改变解集；把增广矩阵化阶梯。
- **增广矩阵 [A|b]**：方程组 Ax=b 的矩阵形式。
- **秩 rank(A)**：阶梯形主元个数 = 列空间维数 = 独立方程条数。
- **零空间 N(A)**：Ax=0 的解空间；**零化度 nullity(A)=dim N(A)**。
- **解判定**：rank(A)<rank([A|b]) 无解；相等且=列数唯一解；相等且<列数无穷多解（自由变量 n−r）。
- **秩-零化度定理**：rank(A)+nullity(A)=n。

### 历史结论（本章涉及的史料）

- **高斯（Gauss，19 世纪初）**：系统化消元法（高斯消元），用于最小二乘。
- **弗罗贝尼乌斯（Frobenius）、西尔维斯特（Sylvester，1884）**：确立"秩"概念与秩不等式、秩-零化度结构定理。
- **凯莱（Cayley，1858）**：矩阵论使方程组/消元能统一在矩阵语言下。

### 工程实践结论（本章知识在真实工程里怎么用）

- **解方程组 = 线性回归最小二乘**：设计矩阵满秩才唯一解参数；缺秩=多重共线性，需正则化。
- **"秩判定" = 求解前先查可解性**：电路网孔、流量平衡、有限元都先算 rank。
- **零化度 = 自由度**：nullity 度量"有几个方向被压扁"，在欠定系统、PCA 里都相关。
- **可逆 = 满秩**：rank=n ⟺ 可逆（连接下一章行列式）。

## 计算训练场

> 位置说明：对话负责"为什么秩决定解、为什么 rank+nullity=n"，这里负责"怎么算"。下面三题**必须动笔**，每题 10 分钟以上，先自己写再对答案。**难度递进：易→中→难。**

### 题 1（易→中）：高斯消元解具体方程组

**题干**：老谟给了方程组，让造物主用高斯消元解出唯一解：
x + y + z = 6；2x − y + z = 3；x − 2y + 3z = 4。

**完整分步解答：**

- 第 1 步：**写增广矩阵**：
  ```text
  [1  1  1 | 6]
  [2 −1  1 | 3]
  [1 −2  3 | 4]
  ```
- 第 2 步：**化阶梯**：R₂←R₂−2R₁：[0 −3 −1 | −9]；R₃←R₃−R₁：[0 −3 2 | −2]。
- 第 3 步：**R₂←(−1/3)R₂**：[0 1 1/3 | 3]。
- 第 4 步：**R₃←R₃+3·R₂**：[0 0 3 | 7]。
- 第 5 步：**回代**：由 R₃：3z=7 ⟹ z=7/3。由 R₂：y+z/3=3 ⟹ y+7/9=3 ⟹ y=20/9。由 R₁：x+y+z=6 ⟹ x=6−20/9−21/9=13/9。
- 第 6 步：**验证**：x+y+z=13/9+20/9+21/9=54/9=6 ✓；2x−y+z=26/9−20/9+21/9=27/9=3 ✓；x−2y+3z=13/9−40/9+63/9=36/9=4 ✓。
- **答**：唯一解 (x,y,z)=(13/9, 20/9, 7/3)。

**常见错误**：① 行变换算错（R₃+3R₂ 时把常数项也算错）；② 回代顺序错（应从最后一行往上）；③ 忘了验证（解完必须代回检验）。

### 题 2（中）：含参方程组——讨论解的情况

**题干**：老谟给了三组含参方程组，让造物主逐个讨论 a 取何值时是唯一解/无解/无穷多解：
(a) x+2y=1；2x+ay=3。(b) x+y+z=1；x+2y+z=2；x+3y+az=3。(c) x+y+z=1；2x+2y+2z=a。

**完整分步解答：**

**(a)** 增广 [1 2 | 1; 2 a | 3]，R₂←R₂−2R₁：[0 a−4 | 1]。
- **a≠4**：y=1/(a−4)，x=1−2/(a−4)，**唯一解**。
- **a=4**：0·y=1，矛盾，**无解**。

**(b)** 增广 [1 1 1 | 1; 1 2 1 | 2; 1 3 a | 3]，R₂←R₂−R₁：[0 1 0 | 1]；R₃←R₃−R₁：[0 2 a−1 | 2]。R₃←R₃−2·R₂：[0 0 a−1 | 0]。
- **a≠1**：z=0（(a−1)z=0 ⟹ z=0），y=1，x=0，**唯一解** (0,1,0)。
- **a=1**：0·z=0，z 自由，y=1，x=1−1−z=−z，**无穷多解**（自由变量 z）。

**(c)** 增广 [1 1 1 | 1; 2 2 2 | a]，R₂←R₂−2R₁：[0 0 0 | a−2]。
- **a≠2**：0=a−2 矛盾，**无解**。
- **a=2**：冗余，x+y+z=1，两个自由变量，**无穷多解**。

**答**：(a) a≠4 唯一、a=4 无解；(b) a≠1 唯一 (0,1,0)、a=1 无穷多；(c) a≠2 无解、a=2 无穷多。

**常见错误**：① 消元时把参数 a 当普通数参与行变换出错；② 讨论"a−4=0"时忘了分"等于/不等于"两类；③ 无穷多解只说"有自由变量"没说清哪几个自由、解怎么表示。

### 题 3（难）：求秩与零化度——验证秩-零化度

**题干**：老谟给了矩阵 A=[[1,2,3],[2,4,6],[0,1,1]]，让造物主：
(a) 求 rank(A)；(b) 求 nullity(A)；(c) 验证 rank+nullity=n；(d) 求零空间的一组基。

**完整分步解答：**

- 第 1 步：**化阶梯求秩**：
  ```text
  [1 2 3]
  [2 4 6]
  [0 1 1]
  ```
  R₂←R₂−2R₁：[0 0 0]；R₃ 保持 [0 1 1]。阶梯形：[1 2 3; 0 0 0; 0 1 1]（行交换得 [1 2 3; 0 1 1; 0 0 0]）。主元两行。
- 第 2 步：**rank(A) = 2**（两行有主元）。
- 第 3 步：**nullity(A)**：n=3（列数），rank+nullity=3 ⟹ **nullity(A)=3−2=1**。
- 第 4 步：**求零空间基**：解 Ax=0：x+2y+3z=0，y+z=0。
  - 由 y+z=0：y=−z。
  - 由 x+2y+3z=0：x−2z+3z=x+z=0 ⟹ x=−z。
  - 解向量 (x,y,z)=(−z,−z,z)=z(−1,−1,1)。**零空间基 = {(−1,−1,1)}**，dim 1。
- 第 5 步：**验证**：rank(2)+nullity(1)=3=n ✓。
- **答**：(a) rank=2；(b) nullity=1；(c) 2+1=3=n ✓；(d) 零空间基 {(−1,−1,1)}。

**常见错误**：① 化阶梯时把全零行也算进秩（rank 只数主元行）；② 忘了"nullity=n−rank"直接用秩-零化度；③ 求零空间时漏了自由变量（z 自由，x、y 都写成 z 的倍数）。

## 向导便签

> 这一章咱们干了什么：把"解方程组"从"一个一个消元"升级成了"看秩一锤定音"——**行变换化阶梯、秩（主元个数/列空间维数）、解判定（rank(A) vs rank([A|b])）、秩-零化度定理（rank+nullity=n）**。你亲手证明了本章核心定理——秩-零化度定理（构造基并延拓）。
>
> 钉死一句话：**方程组的解由秩决定——rank(A)<rank([A|b]) 无解、相等满秩唯一、相等低秩无穷多；而秩-零化度 rank+nullity=n 告诉你"列空间多大 + 零空间多大 = 列数"。**
>
> 记住：**"rank 数出独立方程"、"矛盾行=无解"、"自由变量数=n−r"**，这三条是你解任何线性方程组的钥匙。下一章，我们看行列式——那个"矩阵缩放空间的程度"的度量，它和"可逆""满秩"紧紧咬合，**det≠0 ⟺ 满秩 ⟺ 可逆**。

我一开始以为"3 个方程 3 个未知数就必有唯一解"，被反例堵住——方程可能线性相关（像 2x+2y=4 是第一式的倍数），实际少一个独立方程。判解的时候，我一度只看了 rank(A)，忘了比 rank([A|b])，把"无解"（矛盾行）和"无穷解"（缺秩一致）搞混。最险的是秩-零化度：我求完 rank=2 就以为完事，忘了还要用"nullity=n−rank"算零化度，更忘了"零空间要真的解出基"。还有一次含参方程组，我讨论"a−4=0"时漏了"等于/不等于"的分类。

**顿悟时刻**：

真正开窍是"rank+nullity=n"被证出来那一刻——**矩阵把一个 n 维输入空间，拆成"被保留下来的像"（列空间，维数 rank）和"被压到零的方向"（零空间，维数 nullity），两块恰好凑回 n。** 这让我第一次"看见"了矩阵的内在结构：**它不是一张死表，是一台'把空间拆成两半'的机器——压扁多少，保留多少，此消彼长。** 而"矛盾行=无解"让我豁然开朗：**解方程组的全部玄机，就在"增广矩阵比系数矩阵多出几行独立的矛盾"这一件事上。** 秩，是线性代数第一把"看结构的尺子"。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：高斯消元解方程组**

解：x+2y+z=1；2x+5y+z=2；x−y+z=3。

**完整解答**：增广 [1 2 1|1; 2 5 1|2; 1 −1 1|3]。R₂−2R₁：[0 1 −1|0]；R₃−R₁：[0 −3 0|2]。R₃+3R₂：[0 0 −3|2]。阶梯形：[1 2 1|1; 0 1 −1|0; 0 0 −3|2]。回代：−3z=2⟹z=−2/3；y−z=0⟹y=−2/3；x+2y+z=1⟹x+2(−2/3)+(−2/3)=1⟹x−4/3−2/3=1⟹x=1+2=3。**解 (3, −2/3, −2/3)**。（验证：x+2y+z=3−4/3−2/3=1 ✓。）

**题 B（计算，中→难）：含参 + 求秩零化度**

(a) 讨论 x+y=1；2x+2y=a 的解。(b) 求 A=[[1,1,1],[1,2,3],[2,3,4]] 的 rank 与 nullity。

**完整解答**：
(a) 增广 [1 1|1; 2 2|a]，R₂−2R₁：[0 0|a−2]。**a≠2 无解；a=2 无穷多解**（x+y=1，y 自由，x=1−y）。
(b) 化阶梯：R₂−R₁：[0 1 2]；R₃−2R₁：[0 1 2]；R₃−R₂：[0 0 0]。阶梯形两行有主元 ⟹ **rank=2**；n=3，**nullity=3−2=1**。零空间解 Ax=0：x+y+z=0、y+2z=0⟹y=−2z、x−2z+z=x−z=0⟹x=z，解 (z,−2z,z)=z(1,−2,1)，基 {(1,−2,1)}。

**题 C（概念，检查理解）**

(a) 为什么行变换不改变方程组的解集？
(b) "无解"和"无穷多解"的本质区别是什么？怎么用秩区分？
(c) 秩-零化度定理为什么说"rank 和 nullity 互补"？

**完整解答**：
(a) 因为每种行变换都是对"等式"做合法操作（交换/乘非零/加倍数），不改变解集——解一个都不会丢也不会多。
(b) 无解是"有矛盾"（增广秩比系数秩大，出现 0=非零行）；无穷多解是"一致但缺秩"（两秩相等但小于列数，有自由变量）。用秩区分：rank(A)<rank([A|b]) 无解；rank(A)=rank([A|b])<n 无穷多。
(c) 因为矩阵把 n 维输入空间拆成"像空间"（列空间，维数 rank）+"零空间"（维数 nullity），两块互斥且补回整个输入空间，所以 rank+nullity=n——压扁越多（nullity 大），保留越少（rank 小）。

## 预告

你终于把"解方程组"从"苦力活"变成了"看秩一锤定音"——**行变换、秩、解判定、秩-零化度定理**。你手里有了"看结构"的尺子：rank 数出独立方程，nullity 量出自由度，而 rank+nullity=n 补回了整个空间。

可你马上会问一个"度量"的问题：**矩阵变换空间，会"放大"或"缩小"——那放大/缩小的程度，有没有一个数能量出来？** 比如 [[2,0],[0,3]] 把面积放大 6 倍，[[1,0],[0,0]] 把面积压成 0——**这个"缩放系数"，就是行列式。** 它会和"可逆"（det≠0 ⟺ 满秩 ⟺ 可逆）、"缩放方向"（特征值）紧紧咬合。**把秩和零空间练熟，下一章，我们看行列式——那个"矩阵缩放空间的程度"的度量。**
