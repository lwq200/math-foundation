# 第 06 章 · 无约束优化与梯度下降——闭着眼睛下山，凭什么能到谷底

> 本章从哪个问题出发：前五章你攒下了梯度、链式法则、多元泰勒、凸函数和凸性判定——可你手里一直缺一样东西：**怎么真的"走"到谷底？** 一个函数，有无数个点，你不一定知道它长什么样，只能在当前位置摸一摸"脚下往哪边斜"。沿负梯度走，听起来有道理——可**凭什么**这样走就能到谷底？走多快？步子该迈多大？迈大了会不会摔进另一座山？
> 推导到哪个结论：答案是把"下山"翻译成一个可以反复执行的**迭代格式** x_{k+1} = x_k − η∇f(x_k)——每一步都沿着"最陡下降"方向迈出学习率 η 的一步。本章会证明：**当函数是凸函数、且梯度是 Lipschitz 光滑的（∇f 不会陡得离谱）时，只要学习率选得够小（η ≤ 1/L），函数值就单调下降，而且收敛速度是 O(1/k)**——这就是"凭什么敢用梯度下降"的数学保证。
>
> 核心认知：**梯度下降不是魔法，它是一条"保证下降 + 保证收敛"的可靠循环：凸性给出方向不迷路，Lipschitz 梯度给出步子别太大，学习率是那个决定"你会不会跳过谷底"的旋钮。** 这一章补上了样书（旧第 17 章）最缺的一块地基——"不解释凸性就敢用梯度下降"的逻辑空当，就在这里填平。

## 引子

夜里十一点，老谟的工作室里只剩一盏台灯。他扔给造物主一个小沙盘——不是沙盘，是一块微微倾斜的木板，上面挖了个坑，坑底埋了一颗滚珠。

"我把灯全关了。"老谟真的去关了灯，屋里黑得伸手不见五指，"现在你手里只有一根细杆，杆头能测出你脚下'往哪个方向是下坡、坡有多陡'。你被放在木板上某个位置，看不见整块板子的样子——**你唯一的任务：让滚珠滚到坑底。** 你怎么办？"

黑暗中，造物主握着细杆想了半天："我……我拿杆子测一圈，哪个方向最往下，就朝那个方向挪一小步？然后再测、再挪？"

"好啊。"老谟的声音带着笑意，"那我再问你两个刁钻的：**你朝'最陡下坡'挪一小步，凭什么这一小步就比乱走更接近坑底？** 还有——**你这一小步该迈多大？** 迈大了，会不会一步跨过坑底，滑到对面的坡上，然后来回晃悠永远到不了？"

造物主愣住了。白天他刚学完梯度——"朝负梯度走就是下坡最陡"——可那只是回答了"方向"。**方向对了，剩下的问题才刚开始：步子多大、凭什么收敛、多久能到。** 这一章，老谟要他把"闭着眼摸黑下山"这件事，从"感觉对"变成"算得准"。

## 对话引擎

### 第 1 轮：把"找谷底"写成一个干净的问题——优化问题的三件套

**老谟**："摸黑下山前，先把你到底要找什么说清楚。你要找的那个点，叫**最优点**。你凭什么说一个点是'最好'的？给我个能写下来的标准。"

**造物主**："……不就是函数值最小吗？f(x) 取最小值那个点 x*。"

**老谟**："对了一半。可你漏了关键的一层：**你在哪儿找？** 是在整个空间随便找，还是被限制在某块区域里找？别小看这一句——它会决定后面所有的算法。"

**造物主**："我们这一章……应该是随便找吧？没有绳子拴着我，整块木板我都走得。"

**老谟**："对，你这次是**无约束**的——想走哪儿走哪儿。这就是'无约束优化'（unconstrained optimization）这个词的来历。现在你把三件套说全：**要最小化的目标函数 f、变量 x 所在的空间、以及'无约束'这个前提。** 写下来，这就是优化问题的'户口本'。以后每遇到一个优化问题，先问自己这三件事齐不齐。"

**造物主**："明白了。可我还是没抓住核心——**知道要最小化 f，跟我'一步一步挪'有什么关系？**"

### 📐 知识锚点：无约束优化问题——"找谷底"的正式表述

【概念深挖】**无约束优化问题（unconstrained optimization problem）**的标准形式：
minimize f(x)，x ∈ ℝⁿ。

- **目标函数 f**：你要最小化的量（如损失函数、成本函数）；
- **变量 x**：可调的自由参数（如模型权重 w₁, …, wₙ）；
- **无约束**：x 可以在整个 ℝⁿ 中取值，没有任何等式或不等式限制（"有没有绳子拴你"）。

我们的目标：找到最优点 **x\* = argmin f(x)**（让 f 取到最小的那个点），以及最小值 f(x\*)。

【工程实践】**几乎所有"调参/训练"都是无约束优化的实例**：训练神经网络时，你在最小化损失函数 L(w₁,…,wₙ)，权重 w 没有任何硬性约束（你可以把每个权重设成任何实数），这就是一个高维无约束优化问题。**"最小化 f(x)"这句话，是机器学习里出现频率最高的半句话。** 本章往后学的一切，都是回答"这个 min 到底怎么算出来"。

【历史溯源】"沿最陡方向下降"的直觉可追溯到**柯西（Cauchy，1847）**——他在一篇研究里第一次明确提出"沿着负梯度方向迭代寻找极小点"的想法，后世称之为最速下降法（steepest descent）。**有意思的是，它虽然是最古老的优化算法之一，却直到今天都是深度学习最常用优化的雏形**——因为它只要"局部梯度"就能跑，对看不见全局的函数最友好。

### 第 2 轮：方向是梯度的反面——为什么是"负"梯度

**老谟**："回到摸黑下山。你说你拿杆子测一圈，找'最陡的下坡方向'。上一章你学过梯度——**梯度指着什么方向？**"

**造物主**："梯度指着**上坡最陡**的方向，长度就是最陡的坡度。"

**老谟**："那'最陡下坡方向'是哪个？"

**造物主**："……梯度反着来！朝 **−∇f** 走，就是下坡最陡的方向。"

**老谟**："那我现在问你一个你可能没想过的问题：**这一步迈下去，'下坡最陡'就等于'最接近谷底'吗？** 你想清楚再答。"

**造物主**："……我盯着这个问号想了一会儿。不一定吧？最陡下坡只是'这一步降得最快'，可它未必带你直奔谷底——也许它先带你斜着滑到一条沟里。就像我学过的：**'局部最快'和'全局最优'是两码事。**"

**老谟**："抓住要害了。**最速下降方向只保证'这一步'最陡，不保证'全局'最优。** 这正是梯度下降的第一个性格：它是**贪心**的——每一步只管眼前最陡，从不抬头看全局。所以接下来我们必须回答：**一个贪心的、只看脚下的算法，凭什么最后还能收敛到谷底？** 这才是本章真正的难处。"

---

### 📐 知识锚点：最速下降方向——贪心的"眼前最优"

【概念深挖】设 f 在 x_k 处可微且 ∇f(x_k) ≠ 0。在所有"迈出单位步长"的方向 d（‖d‖ = 1）中，让 **f 下降最多**（即方向导数 D_d f(x_k) 最负）的方向，由第 01 章定理 2（最陡方向）知是

```text
d = −∇f(x_k) / ‖∇f(x_k)‖
```

因为 D_d f = ∇f·d = ‖∇f‖·cos θ，在 θ = 180°（d 与 ∇f 反向）时取到最小值 −‖∇f‖。**这就是"最速下降（steepest descent）"方向——只看脚下最陡，不看全局。**

【概念深挖】**梯度下降（gradient descent）迭代格式**：不严格归一化步长，而是直接按
x_{k+1} = x_k − η∇f(x_k) 更新，其中 **η > 0 叫学习率（learning rate）或步长（step size）**。
- 方向项 −∇f(x_k)：下坡最陡；
- 幅度项 η：决定这一步迈多大。

**这个格式是全章的"总引擎"：重复同一个动作——算梯度、朝负梯度迈 η 步。** 深度学习里最常见的 SGD（随机梯度下降）只是把"用全部数据算的梯度"换成"用一小批数据估的梯度"，框架不变。

【概念深挖】为什么写成"减去梯度"而不是别的？因为泰勒一阶近似 f(x_k + h) ≈ f(x_k) + ∇f·h。想让它下降（小于 f(x_k)），就要 ∇f·h < 0——**而 h = −η∇f 恰好让 ∇f·h = −η‖∇f‖² < 0**（η > 0）。所以"负梯度"不是约定俗成的漂亮名字，它是"让泰勒一阶近似下降"的最省事选择。

### 第 3 轮：步子太大摔过谷底，步子太小到不了——学习率是个旋钮

**老谟**："格式到手了：x_{k+1} = x_k − η∇f(x_k)。现在盯着那个 η 看。**你拍拍脑袋，η 该取多大？**"

**造物主**："……取个小的？1？0.1？反正是正的就行？"

**老谟**："'正的就行'？我给你两个极端，你体会一下。**η 很大，比如比 1 还大——会发生什么？**"

**造物主**："……大步一跨，可能直接越过谷底，冲到对面坡上，甚至越冲越高？那就不是下山了，是'跳山'了。"

**老谟**："这就是**发散（diverge）**——步子太大，误差 o(η²) 失控，函数值不降反升，越跳越高。**那 η 很小很小呢？**"

**造物主**："小步挪，肯定不跳山……但也很慢？就像老牛拉车，半天挪不到谷底，浪费人生。"

**老谟**："这就是**龟速（too slow）**——收敛是有，可慢到你等不起。所以你被夹在两难中间：**η 大了发散，η 小了磨蹭。** 数学家不让你拍脑袋——他们给了你一个'安全上限'：当 ∇f 是 L-Lipschitz 的（梯度不会太陡），**取 η ≤ 1/L 就能保证不发散、函数值单调下降。** 那个 L 从哪儿来、为什么 1/L 是关键，我们放到走廊里用证明说话。你先记住一个直觉：**学习率不是'随便正的'，它是整个算法里最需要小心拧的旋钮。**"

---

### 📐 知识锚点：学习率的两难——发散 vs 龟速

【概念深挖】学习率 η（步长）是梯度下降里**最敏感的超参数**：
- **η 过大 → 发散**：从泰勒误差 o(η²) 角度，步长一大，二阶以上项不再可忽略，近似失效，函数值可能上升，迭代震荡甚至跑远（发散）。
- **η 过小 → 龟速**：每步下降太少，需要天文数字的迭代才收敛。
- **安全区**：当 ∇f 满足 L-Lipschitz 条件（后面定义），**η ≤ 1/L 保证函数值单调下降且收敛**（严格证明见走廊定理）。

【工程实践】**学习率是训练深度学习时第一个要调的旋钮**：框架（PyTorch、TensorFlow）里 `learning_rate` 参数默认值往往基于经验（如 0.01 附近），因为真实损失函数通常不是"标准凸函数"，1/L 的安全界没法精确算，只能靠试。**训练日志里"损失炸了"（loss 变 NaN 或飙升）十有八九是学习率太大**；"损失死活降不下去"则常是学习率太小。调参的第一课，就是先把这个旋钮拧到能"稳着降"的量级。

【实现思考】如果让你自己实现梯度下降，你会怎么写？核心就三步循环：**① 算梯度 ∇f(x_k)；② 乘学习率 η；③ 从当前位置减掉它。** 伪代码就一句话：
```text
x = 初始点
for k in range(步数):
    g = 梯度(x)      # 算脚下多陡、往哪边陡
    x = x - η * g    # 朝负梯度迈 η 步
```
代价是：每步都要算梯度，维度高时梯度本身计算昂贵（这正是后来"随机梯度下降"登场的原因——用一小批样本估梯度，省算力）。换条路：如果不用梯度、改用二阶信息（Hessian），能一次跳到抛物线顶点（牛顿法），但算 Hessian 在高维更贵。**"贵"和"快"的权衡，贯穿整个优化领域。**

### 第 4 轮：怎么保证不迷路？——凸性是"一滑到底"的通行证

**老谟**："你把方向（负梯度）和步子（η）都定了。可还有个最要命的问题悬着：**我闭着眼瞎走，万一下到一半，发现脚下有个'小坑'，它不是最深的谷底，可我滑进去就出不来了——怎么办？**"

**造物主**："……那不就卡在局部最优了吗？不是谷底的最小值，是个假谷底。"

**老谟**："对。**这就是优化里最阴险的敌人——局部极小点（local minimum）**：一个点，周围都比它高，但它不是全局最矮的那个坑。你闭着眼下山，很容易掉进这种'假谷底'就以为到头了。那你说，**有没有一种函数，天然没有这种假谷底？**"

**造物主**："……除非这个函数只有一个坑，没有别的小坑？那种'碗'？就是第 4 章学的——**凸函数**！凸函数只有一个谷底，任何局部极小都是全局极小。"

**老谟**："你把这个函数库翻出来了。**凸函数（convex function）就是'没有假谷底'的函数**：它的任何局部极小点都是全局极小点。所以对凸函数，梯度下降不会'误入歧途'——你滑到的谷底就是真谷底。**这就是'为什么敢用梯度下降'的第一块通行证：凸性。** 第二块通行证，就是上一轮说的 L-Lipschitz 梯度（保证步子别太大）。两证齐全，收敛才说得准。"

**造物主**："可深度学习要优化的损失函数，根本不是凸的呀？"

**老谟**："问得好，先记下这个矛盾。**深度学习确实不凸——这也是为什么深度学习优化比'凸优化'难得多。** 但你要先听懂'凸的情形下梯度下降为什么可靠'，才能理解'不凸时问题出在哪'。凸性是'理想教科书'，第 7 章那个'高维景观'才是'残酷现实'。一步一步来，先把教科书吃透。"

---

### 📐 知识锚点：凸性与局部/全局——为什么凸函数敢"一滑到底"

【概念深挖】**凸函数的"无假谷底"性质**：若 f 是凸函数，则 f 的**任何局部极小点都是全局极小点**（严格证明见走廊定理）。直观：凸函数的图像像一口"碗"，没有第二个坑；站在碗里任意处，顺着下降方向走，最终只能滑向唯一的碗底。**这是"局部 = 全局"在凸情形下成立的数学事实。**

【概念深挖】为什么这个性质对"敢不敢用梯度下降"至关重要：梯度下降是贪心的（只看脚下），它天然只能保证找到"局部极小"。**如果函数不凸，贪心可能停在假谷底；如果函数凸，局部极小 = 全局极小，贪心就不怕停错。** 所以"凸"这个条件，直接把"算法能保证的结果"从"某个局部坑"升级成"全局最矮坑"。

【工程实践】**为什么深度学习的损失通常不是凸的**：损失函数对权重的高阶依赖（多层非线性复合）让损失面凹凸不平，存在大量局部极小与鞍点。**但工程上发现：高维损失面的'假谷底'其实比想象中少，真正的麻烦是'鞍点'（第 7 章）**——这纠正了一个过时的二维直觉。现在你只需记住：**凸性给了你'局部=全局'的理想保证，而深度学习在'没有这个保证'的野外求生。**

### 第 5 轮：收敛快不快？——O(1/k) 是一张"账本"

**老谟**："假设函数凸、η 也选对了，函数值确实单调下降。可它降得**多快**？你说 100 步之后能离谷底多近？这不能靠感觉，得给个'账本'。"

**造物主**："……你是说收敛速度？我猜……每一步都缩一点，越到后面越慢？但总得有个具体说法吧。"

**老谟**："给你一句能刻在墙上的话：**凸函数 + L-Lipschitz 梯度 + η = 1/L，梯度下降的函数值差距满足 f(x_k) − f(x*) ≤ O(1/k)。** 翻译成人话：**走了 k 步之后，你离最优值的'残余'大致按 1/k 的速度缩小——想让误差减半，步数要翻倍。** 这是'慢但稳'的收敛：它不保证指数级加速（那是强凸才有的待遇），但它给你一个**确定性承诺**：只要凸、只要 η 在安全区，就一定能慢慢逼近，误差有明确上界。"

**造物主**："1/k……也就是说想压误差到 1/1000，得走大约 1000 步？这也太慢了。"

**老谟**："慢，但**可靠**。而且这正是'为什么凸优化是地基'的原因——它的行为是**可预期的**，你知道最坏要多少步。相比之下，非凸优化连'最坏多少步'都说不清。**先把'可靠但慢'吃透，再看'快但不保'（动量、牛顿）怎么加速。** 下一轮我们聊聊'怎么让步子更聪明'。"

---

### 📐 知识锚点：收敛率 O(1/k)——"慢但稳"的确定性账本

【概念深挖】**收敛率（convergence rate）**：衡量"迭代 k 步后离最优解有多近"的递减速度。对凸函数梯度下降（η=1/L、∇f L-Lipschitz），标准结论是
```text
f(x_k) − f(x*) ≤ L·‖x_0 − x*‖² / (2k)
```
即误差按 **O(1/k)** 收敛（"残余 ≤ 常数/步数"）。含义：误差减半，步数需翻倍。

【概念深挖】**L 是什么**：L 是梯度 ∇f 的 **Lipschitz 常数**——梯度变化的最坏速率（下面走廊定义）。直观：**L 越大，说明曲面"弯"得越厉害，能容忍的学习率 η=1/L 就越小。** 对二次函数 f = xᵀAx（A 对称正定），L 正好等于 A 的最大特征值。

【工程实践】真实优化不会真等 O(1/k) 磨到 1/1000——因为现实函数非凸、且计算昂贵。工程上会用**加速手段**：动量（momentum）把历史梯度的"惯性"存下来，减少之字形震荡、加快中后期收敛；Adam 则进一步给每个参数自适应的学习率。**但所有加速器都建立在本章这条'基础循环'之上——先懂 O(1/k) 的可靠循环，再谈加速。**

【历史溯源】梯度下降收敛性的严格分析始于 20 世纪中后期，**B. T. Polyak（波利亚克，1960s）**对凸情形下最速下降的收敛性做了系统研究；**Nesterov（1983）**则给出凸情形下加速的 O(1/k²) 收敛率（动量型加速的数学根基），后来演化成深度学习里动量方法的思想源头。

### 第 6 轮：一步迈多大最划算？——线搜索的"试步"思想

**老谟**："我们一路都在说'η 要选小'，可你有没有想过：**每一小步的 η，能不能现场动态地调？** 比如我这一脚先迈个试试，不行就收回一半，直到迈出一步真的在下降。"

**造物主**："……试一步，不行减半？这不就是'边试边改'吗？那跟固定 η 有什么区别？"

**老谟**："区别在于：**固定 η 是盲人摸象，线搜索是'每步都用脚下的反馈校准一次'。** 两种主流做法，你先听个名：**① 精确线搜索（exact line search）**——把 η 当变量，一步走到'沿这个方向 f 最低'的点；**② 回溯线搜索（backtracking line search）**——从一个大步长开始，若这一步没让 f 降得够多（比如没满足'下降充分'），就把步长减半重试，直到满意。**这俩都比你'拍一个固定 η'更聪明，因为它们让每一步都'自适应'。**"

**造物主**："那为什么不全都用回溯线搜索？"

**老谟**："因为**贵**。每试一次步长都要多算一次 f 和梯度，多一轮前向/反向传播。深度学习里每一步本来就算得慢，再内嵌线搜索，训练时间翻倍都不止。**所以工程上的折中是：先用经验固定一个 η（如 0.01），发现爆了再手动调小；只有在算力不敏感的小问题上，才用线搜索自动找步长。** 你先把'步长可以自适应'这个思想记住，具体公式我们点到为止。"

### 📐 知识锚点：线搜索——让步长"现场自适应"

【概念深挖】**线搜索（line search）**的两条路线（点到为止，细节不作要求）：
- **精确线搜索（exact line search）**：固定方向 d = −∇f(x_k)，把 f(x_k + η·d) 看成 η 的一元函数，求使它的最小的 η\*。代价：每步要解一个一元极小化，贵。
- **回溯线搜索（backtracking line search）**：从较大步长 η₀ 开始，反复把 η 减半（η ← η/2），直到满足"Armijo 条件"（下降量充分：f(x_k + η·d) ≤ f(x_k) + c·η·∇f·d，c∈(0,1)，通常 c=1e−4）。每步只多算几次 f，性价比高。

【工程实践】**深度学习的标准做法其实不是线搜索**，而是"调度（schedule）"：用一个固定学习率，按固定节奏衰减（如每 30 轮乘以 0.1）。为什么不用回溯线搜索？因为**深度学习每步的算力极贵**，线搜索多试几次步长 = 多算几次整个网络，成本不可接受。**"便宜但经验式"胜过"昂贵但自适应"**——这是工程与理论的一个典型分岔。

## 严格化走廊

> 位置说明：本章对话负责"直觉"——为什么负梯度、为什么凸、为什么 η 不能太大。本走廊负责"严谨"——把优化问题、Lipschitz 条件、凸性保证、收敛率全部写成精确的定义与可复写的证明。**下面每一行，读者都能对着空白纸重写一遍。**

### 定义 1：无约束优化问题（unconstrained optimization problem）

设 f : ℝⁿ → ℝ。**无约束优化问题**是
```text
minimize f(x)，x ∈ ℝⁿ
```
称 x\* 为**全局极小点**，若对一切 x ∈ ℝⁿ 有 f(x\*) ≤ f(x)；称 x₀ 为**局部极小点**，若存在 r > 0，使对满足 ‖x − x₀‖ < r 的一切 x 有 f(x₀) ≤ f(x)。

> **严格注记**：全局极小对"所有点"成立，局部极小只对"邻域内"成立。凸函数下二者重合（见定理 1）。

### 定义 2：L-Lipschitz 梯度（L-Lipschitz gradient / 梯度 L-光滑）

设 f 可微。称 **∇f 是 L-Lipschitz 的**（L ≥ 0），若对一切 x, y ∈ ℝⁿ：
```text
‖∇f(x) − ∇f(y)‖ ≤ L·‖x − y‖
```
**L 称为 Lipschitz 常数**。直观：梯度函数本身不会"陡得离谱"，最坏情况每移动单位距离，梯度变化不超过 L。

### 定义 3：梯度下降迭代（gradient descent iteration）

给定初始点 x₀ ∈ ℝⁿ 与学习率 η > 0，梯度下降生成序列
```text
x_{k+1} = x_k − η·∇f(x_k)，k = 0, 1, 2, …
```

### 定义 4：凸函数（convex function，复习第 4 章）

设 f 的定义域是凸集。称 f 为**凸函数**，若对一切 x, y ∈ 定义域、一切 λ ∈ [0,1]：
```text
f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y)
```

### 定理 1（凸函数的局部极小 = 全局极小）：设 f 是凸函数，x₀ 是 f 的局部极小点，则 x₀ 也是全局极小点。

**证明（可复写）**：
- 反设 x₀ 不是全局极小：则存在 y ∈ 定义域使 f(y) < f(x₀)。记 d = y − x₀ ≠ 0。
- 考虑点 x(λ) = x₀ + λ·d = λy + (1−λ)x₀，λ ∈ (0,1]。由**定义 4（凸函数不等式）**：
  f(x(λ)) ≤ λf(y) + (1−λ)f(x₀) = f(x₀) + λ[f(y) − f(x₀)] < f(x₀)（因为 f(y) < f(x₀)，λ > 0）。
- 因此对任意小的 λ > 0，都有 f(x₀ + λd) < f(x₀)——即**在 x₀ 的任意小邻域内，都存在函数值比 f(x₀) 更小的点**，与"x₀ 是局部极小点"（定义 1）矛盾。
- 故反设不成立，x₀ 必是全局极小点。∎

**证明要点标注**：第 1 步是**反证法**（假设结论相反）；第 2 步用**定义 4（凸函数的弦不等式）**把中间点 x(λ) 的函数值夹到 f(x₀) 之下；第 3 步用**定义 1（局部极小的邻域性质）**制造矛盾；第 4 步是**反证法收尾**。

### 定理 2（下降引理）：设 f 可微且 ∇f 是 L-Lipschitz 的（定义 2），则对一切 x, y ∈ ℝⁿ：
```text
f(y) ≤ f(x) + ∇f(x)·(y − x) + (L/2)·‖y − x‖²
```

**证明（可复写）**：
- 由微积分基本定理，把 f 沿从 x 到 y 的线段积分：
  f(y) − f(x) = ∫₀¹ ∇f(x + t(y−x))·(y−x) dt。
- 变形：f(y) − f(x) − ∇f(x)·(y−x) = ∫₀¹ [∇f(x + t(y−x)) − ∇f(x)]·(y−x) dt。
- 对被积函数用**柯西-施瓦茨不等式**与**定义 2（Lipschitz）**：
  [∇f(x+t(y−x)) − ∇f(x)]·(y−x) ≤ ‖∇f(x+t(y−x)) − ∇f(x)‖·‖y−x‖ ≤ L·‖t(y−x)‖·‖y−x‖ = L·t·‖y−x‖²。
- 代入积分并求值：
  f(y) − f(x) − ∇f(x)·(y−x) ≤ ∫₀¹ L·t·‖y−x‖² dt = (L/2)‖y−x‖²。
- 移项即得 f(y) ≤ f(x) + ∇f(x)·(y−x) + (L/2)‖y−x‖²。∎

**证明要点标注**：第 1 步是**微积分基本定理的积分形式（把函数差写成梯度线积分）**；第 2 步是**代数整理**；第 3 步用**柯西-施瓦茨不等式**与**定义 2（L-Lipschitz 梯度）**；第 4 步是**定积分 ∫₀¹ t dt = 1/2**；第 5 步移项。

### 定理 3（单调下降）：设 f 凸、可微，∇f 是 L-Lipschitz 的，取学习率 0 < η ≤ 1/L，则由定义 3 生成的序列满足：
```text
f(x_{k+1}) ≤ f(x_k) − (η/2)·‖∇f(x_k)‖² ≤ f(x_k)
```
从而**函数值单调下降**；且当且仅当 ∇f(x_k) = 0（驻点，即极值的必要条件）时下降量为 0。

**证明（可复写）**：
- 在**定理 2（下降引理）**中取 x = x_k、y = x_{k+1} = x_k − η∇f(x_k)，得
  f(x_{k+1}) ≤ f(x_k) + ∇f(x_k)·(−η∇f(x_k)) + (L/2)‖−η∇f(x_k)‖²
  = f(x_k) − η‖∇f(x_k)‖² + (Lη²/2)‖∇f(x_k)‖²。
- 合并：f(x_{k+1}) ≤ f(x_k) − η(1 − Lη/2)·‖∇f(x_k)‖²。
- 因 0 < η ≤ 1/L，有 1 − Lη/2 ≥ 1/2，故
  f(x_{k+1}) ≤ f(x_k) − (η/2)·‖∇f(x_k)‖² ≤ f(x_k)（因 ‖∇f(x_k)‖² ≥ 0）。
- 结论：只要 ∇f(x_k) ≠ 0，函数值严格下降；下降到某处 ∇f(x*) = 0（驻点）时不再下降。结合**定理 1**（凸，局部=全局），驻点即全局极小。∎

**证明要点标注**：第 1 步用**定理 2（下降引理）**并代入迭代格式（定义 3）；第 2 步是**代数合并同类项**；第 3 步用**学习率条件 η ≤ 1/L** 与 **范数非负性**；第 4 步结合**定理 1（凸性）**与驻点条件。

### 定理 4（收敛率 O(1/k)）：设 f 凸、可微，∇f 是 L-Lipschitz 的，x\* 是全局极小点，取 η = 1/L，则由定义 3 生成的序列满足：
```text
f(x_k) − f(x\*) ≤ L·‖x_0 − x\*‖² / (2k)，k = 1, 2, …
```
即**函数值差距按 O(1/k) 收敛**。

**证明（可复写）**：
- 记 p_k = ‖x_k − x\*‖²，δ_k = f(x_k) − f(x\*) ≥ 0。
- 由**定义 3（迭代格式，η=1/L）**与范数性质：
  p_{k+1} = ‖x_{k+1} − x\*‖² = ‖x_k − x\* − (1/L)∇f(x_k)‖²
  = p_k − (2/L)∇f(x_k)·(x_k − x\*) + (1/L²)‖∇f(x_k)‖²。
- 由**凸函数的一阶刻画（第 4 章）**：f(x\*) ≥ f(x_k) + ∇f(x_k)·(x\* − x_k)，即 ∇f(x_k)·(x_k − x\*) ≥ f(x_k) − f(x\*) = δ_k。
  代入得：p_{k+1} ≤ p_k − (2/L)δ_k + (1/L²)‖∇f(x_k)‖²。
- 由**定理 3（单调下降）**：δ_{k+1} ≤ δ_k − (1/(2L))‖∇f(x_k)‖²，即 ‖∇f(x_k)‖² ≤ 2L(δ_k − δ_{k+1})。
  代入：p_{k+1} ≤ p_k − (2/L)δ_k + (1/L²)·2L(δ_k − δ_{k+1}) = p_k − (2/L)δ_k + (2/L)δ_k − (2/L)δ_{k+1} = p_k − (2/L)δ_{k+1}。
- 移项：(2/L)δ_{k+1} ≤ p_k − p_{k+1}，即 δ_{k+1} ≤ (L/2)(p_k − p_{k+1})。
- 对 k = 0, 1, …, N−1 求和（望远镜求和）：
  Σ_{k=0}^{N−1} δ_{k+1} ≤ (L/2)(p_0 − p_N) ≤ (L/2)p_0。
- 因 δ_k 单调不增（定理 3），N 项中每一项 ≥ δ_N，故 N·δ_N ≤ Σ_{k=0}^{N−1} δ_{k+1} ≤ (L/2)p_0，
  即 δ_N ≤ (L/(2N))·p_0 = L·‖x_0 − x\*‖² / (2N)。∎

**证明要点标注**：第 1 步是**平方范数展开**；第 2 步用**凸函数一阶刻画（第 4 章定理）**；第 3 步用**定理 3（单调下降）**回代梯度范数；第 4 步是**代数整理得相邻步距离的收缩**；第 5 步是**望远镜求和**；第 6 步用**δ 单调不增**把"每项 ≥ δ_N"代入求和得到 O(1/k)。

### 反例/边界

- **凸性缺失 → 局部≠全局**：f(x) = x³ 不是凸函数，x = 0 处 f′(0) = 0（驻点）但既非局部极小也非全局极小（它是鞍点/拐点）；f(x) = x⁴ − x² 有局部极小 x = ±1/√2 和局部极大，梯度下降从不同起点会落到不同坑——**不凸时"贪心"可能停错**。
- **Lipschitz 缺失 → 单调下降失效**：f(x) = −x⁴（在 ℝ 上梯度不是 L-Lipschitz，因为 f′(x) = −4x³ 的增长超过线性）。梯度下降朝 −f′ 走其实在远离，且函数无下界，无所谓"收敛"——**"L-Lipschitz"不是装饰，去掉它定理 2、3、4 全部失效。**
- **η 超出安全区 → 发散**：对 f(x) = x²（L = 2），若取 η = 2 > 1/L = 0.5，则 x_{k+1} = x_k − 2·2x_k = −3x_k，|x_k| 每次 ×3，函数值 f = x² 每次 ×9 爆炸——**这就是"学习率太大"的数学微观机制**（计算训练场题 2 会手算这一条）。

## 知识点总结

### 知识点（本章推出的核心概念）

- **无约束优化问题**：min f(x)，x ∈ ℝⁿ——目标函数 f、变量 x、无约束前提三件套。
- **梯度下降迭代格式**：x_{k+1} = x_k − η∇f(x_k)；方向 = 负梯度（最陡下降、贪心），幅度 = 学习率 η。
- **学习率（步长）**：最敏感的超参数；过大 → 发散，过小 → 龟速；安全区 η ≤ 1/L（L 为梯度 Lipschitz 常数）。
- **L-Lipschitz 梯度**：‖∇f(x) − ∇f(y)‖ ≤ L‖x−y‖——梯度不会"陡得离谱"；L 越小，曲面越平缓，可容忍步长越大。
- **凸性是"局部=全局"的通行证**：凸函数任何局部极小都是全局极小（定理 1）——这是"敢用贪心梯度下降"的第一块地基。
- **单调下降**：凸 + L-Lipschitz + η ≤ 1/L ⇒ f(x_{k+1}) ≤ f(x_k)（定理 3）。
- **收敛率 O(1/k)**：f(x_k) − f(x*) ≤ L‖x₀−x*‖²/(2k)——慢但确定性可靠（定理 4）。
- **线搜索思想**：精确线搜索（一步到该方向最低点）与回溯线搜索（步长过大则减半重试），让步长自适应；深度学习因每步昂贵而常用固定学习率 + 调度。

### 历史结论（本章涉及的史料）

- **柯西（1847）**：最早提出沿负梯度方向迭代求极小（最速下降法的雏形）——最古老也最持久。
- **Polyak（1960s）**：系统研究凸情形下最速下降的收敛性。
- **Nesterov（1983）**：给出凸情形下加速的 O(1/k²) 收敛率，是动量加速方法的数学根源。
- **一个共性**：优化算法的严格收敛分析晚于算法的朴素使用上百年——"先有工程直觉，后有数学保证"，与梯度这个概念的诞生路径一致。

### 工程实践结论（本章知识在真实工程里怎么用）

- **调参/训练 = 无约束优化**：损失最小化就是 min L(w)，权重无硬约束。
- **"损失炸了"多半是学习率太大**：训练日志出现 NaN/飙升，先拧小 η。
- **"损失降不下去"常是学习率太小**：收敛太慢，需调大或加速。
- **深度学习每步太贵，用固定学习率 + 衰减调度**，而非线搜索——"便宜但经验式"胜过"昂贵但自适应"。
- **所有加速器（动量、Adam）都建立在基础循环上**：先懂 O(1/k) 的可靠循环，再谈加速。
- **非凸的野外求生**：深度学习损失不凸，局部极小与鞍点并存——凸性保证只是"教科书"，真实挑战在第 7 章。

### 题 1（易→中）：梯度下降走 3 步——验证单调下降

**题干**：设 f(x, y) = x² + y²，初始点 (x₀, y₀) = (1, 1)，学习率 η = 0.1。
(a) 写出梯度 ∇f 的表达式。
(b) 用梯度下降迭代格式手算走 3 步，列出每一步的 (x_k, y_k) 与 f(x_k, y_k)。
(c) 验证函数值单调下降，并指出极限点（最小点）是什么。
(d) 用收敛率界 L‖x₀−x*‖²/(2k) 估算第 3 步的误差上界，与实际误差对比。

**完整分步解答：**

**(a) 梯度**：
第 1 步：f(x,y) = x² + y²。对 x 求偏导：f_x = 2x；对 y 求偏导：f_y = 2y（把另一个变量当常数）。
第 2 步：∇f(x, y) = **(2x, 2y)**。

**(b) 迭代 3 步**：
第 3 步（第 0→1 步）：在 (1,1)，∇f(1,1) = (2, 2)。
第 4 步：x₁ = (1,1) − 0.1·(2,2) = (1 − 0.2, 1 − 0.2) = **(0.8, 0.8)**。
第 5 步：f(0.8, 0.8) = 0.64 + 0.64 = **1.28**（初始 f(1,1) = 1 + 1 = 2，已下降）。

第 6 步（第 1→2 步）：∇f(0.8,0.8) = (1.6, 1.6)。
第 7 步：x₂ = (0.8,0.8) − 0.1·(1.6,1.6) = (0.8 − 0.16, 0.8 − 0.16) = **(0.64, 0.64)**。
第 8 步：f(0.64, 0.64) = 0.4096 + 0.4096 = **0.8192**。

第 9 步（第 2→3 步）：∇f(0.64,0.64) = (1.28, 1.28)。
第 10 步：x₃ = (0.64,0.64) − 0.1·(1.28,1.28) = (0.64 − 0.128, 0.64 − 0.128) = **(0.512, 0.512)**。
第 11 步：f(0.512, 0.512) = 0.262144 + 0.262144 = **0.524288**。

**(c) 单调下降验证**：
第 12 步：f 值序列为 2 → 1.28 → 0.8192 → 0.524288，**严格递减 ✓**。
第 13 步：∇f = (2x, 2y) = 0 当且仅当 x = y = 0，故最小点 x\* = **(0, 0)**，f(x\*) = 0。序列 (0.512, 0.512) 正朝 (0,0) 收缩。

**(d) 收敛率界对比**：
第 14 步：L = Hessian 最大特征值。H = [[2,0],[0,2]]，特征值均为 2，故 L = **2**。
第 15 步：‖x₀ − x*‖² = ‖(1,1) − (0,0)‖² = 1² + 1² = **2**。
第 16 步：k = 3 时上界 = L·‖x₀−x*‖²/(2k) = 2·2/(2·3) = **4/6 ≈ 0.6667**。
第 17 步：实际误差 δ₃ = f(x₃) − f(x*) = 0.524288 − 0 = **0.524288 ≤ 0.6667 ✓**，上界成立。

**答**：(a) ∇f = (2x, 2y)；(b) x₁ = (0.8, 0.8), f = 1.28；x₂ = (0.64, 0.64), f = 0.8192；x₃ = (0.512, 0.512), f = 0.524288；(c) 单调递减，极限点 (0,0)，f* = 0；(d) 上界 0.6667，实际 0.5243，成立 ✓。

**常见错误**：① 求偏导时把 x² 对 x 求导算成 x 而不是 2x；② 更新时把"减"写成"加"（x_{k+1} = x_k − η∇f，不是加）；③ 迭代时忘了每次用"最新点"算梯度，而是沿用第一次的梯度 (2,2)——**每步梯度都要重新算**。

### 题 2（中）：学习率对照——发散 vs 龟速 vs 精确线搜索

**题干**：仍用 f(x, y) = x² + y²，初始点 (1, 1)。
(a) 取 η = 1.1（比安全值 1/L = 0.5 大），走 3 步，证明函数值上升（发散）。
(b) 取 η = 0.01，走 3 步，说明"龟速"（下降极少）。
(c) 用精确线搜索思想求该方向的最优步长 η\*，说明一步即可到位。

**完整分步解答：**

**(a) η = 1.1 发散**：
第 1 步：∇f(1,1) = (2,2)。x₁ = (1,1) − 1.1·(2,2) = (1 − 2.2, 1 − 2.2) = **(−1.2, −1.2)**。
第 2 步：f(−1.2, −1.2) = 1.44 + 1.44 = **2.88 > 2**（初始值）。函数值**上升了**！
第 3 步：∇f(−1.2,−1.2) = (−2.4, −2.4)。x₂ = (−1.2,−1.2) − 1.1·(−2.4,−2.4) = (−1.2 + 2.64, −1.2 + 2.64) = **(1.44, 1.44)**。
第 4 步：f(1.44, 1.44) = 2·2.0736 = **4.1472**，继续上升。
第 5 步：∇f(1.44,1.44) = (2.88, 2.88)。x₃ = (1.44,1.44) − 1.1·(2.88,2.88) = (1.44 − 3.168, …) = **(−1.728, −1.728)**。
第 6 步：f(−1.728, −1.728) = 2·2.985984 = **5.971968**。函数值 2 → 2.88 → 4.1472 → 5.972，**一路上升，发散 ✓**。

**(b) η = 0.01 龟速**：
第 7 步：x₁ = (1,1) − 0.01·(2,2) = **(0.98, 0.98)**；f = 2·0.9604 = **1.9208**。
第 8 步：∇f(0.98,0.98) = (1.96, 1.96)。x₂ = (0.98,0.98) − 0.01·(1.96,1.96) = (0.98 − 0.0196, …) = **(0.9604, 0.9604)**；f = 2·0.92236816 = **1.844736**。
第 9 步：∇f(0.9604,0.9604) = (1.9208, 1.9208)。x₃ = (0.9604 − 0.019208, …) = **(0.941192, 0.941192)**；f = 2·0.885842… = **1.771685**。
第 10 步：走 3 步，f 从 2 只降到 1.7717，**下降约 0.23**——比 η=0.1 的 0.52 慢太多，堪称龟速。

**(c) 精确线搜索**：
第 11 步：方向 d = −∇f(1,1) = (−2, −2)。沿此方向点 (1,1) + η·(−2,−2) = (1−2η, 1−2η)。
第 12 步：f(1−2η, 1−2η) = (1−2η)² + (1−2η)² = 2(1−2η)²。
第 13 步：对 η 求极小。令 g(η) = 2(1−2η)²，g′(η) = 2·2(1−2η)·(−2) = −8(1−2η) = 0 ⇒ 1 − 2η = 0 ⇒ **η\* = 0.5**。
第 14 步：η\* = 0.5 = 1/L，恰好是安全上限。一步：x = (1,1) − 0.5·(2,2) = (0,0)，f = 0，**一步到位**。

**答**：(a) η=1.1：f 值 2→2.88→4.1472→5.972 上升发散；(b) η=0.01：f 值 2→1.9208→1.8447→1.7717 龟速；(c) η\* = 0.5，一步到 (0,0)。

**常见错误**：① 发散时误以为"负梯度一定下降"——η 大于安全值后，泰勒二阶项 o(η²) 失控，下降方向被"跳过头"反噬；② 算 f(−1.2,−1.2) 时平方写成 −1.2² = −1.44 而非 +1.44（**负数的平方是正的**）；③ 精确线搜索求导时漏掉链式法则的内层 (−2)。

### 题 3（中→难）：带交叉项的非标准二次函数——凸性判定 + 梯度下降 + 单调验证

**题干**：设 f(x, y) = x² + y² + xy，初始点 (1, 0)，学习率 η = 0.2。
(a) 写出 ∇f 表达式，判断 f 是否凸函数（用 Hessian 特征值，复习第 5 章主子式/特征值判据）。
(b) 用梯度下降走 3 步，列出每步 (x_k, y_k) 与 f(x_k, y_k)。
(c) 验证函数值单调下降，并说明为何"敢"用梯度下降（联系凸性保证）。
(d) 求真正的最小点 x\*（令梯度 = 0 解方程组）。

**完整分步解答：**

**(a) 梯度与凸性**：
第 1 步：f = x² + y² + xy。f_x = 2x + y（x² 对 x 求导 2x，xy 对 x 求导 y，y² 当常数）；f_y = 2y + x（y² 对 y 求导 2y，xy 对 y 求导 x）。
第 2 步：∇f(x,y) = **(2x + y, 2y + x)**。
第 3 步：Hessian：f_xx = 2，f_yy = 2，f_xy = 1。H = [[2, 1], [1, 2]]。
第 4 步：特征值：det(H − λI) = (2−λ)² − 1 = 0 ⇒ (2−λ)² = 1 ⇒ 2−λ = ±1 ⇒ **λ = 1 或 3**。
第 5 步：两个特征值都 > 0，H 正定 ⇒ f **凸**（严格凸）。故梯度下降"局部=全局"，敢用 ✓。

**(b) 迭代 3 步**：
第 6 步（第 0→1 步）：∇f(1,0) = (2·1 + 0, 2·0 + 1) = (2, 1)。
第 7 步：x₁ = (1,0) − 0.2·(2,1) = (1 − 0.4, 0 − 0.2) = **(0.6, −0.2)**。
第 8 步：f(0.6, −0.2) = 0.36 + 0.04 + (0.6)(−0.2) = 0.36 + 0.04 − 0.12 = **0.28**（初始 f(1,0) = 1，已下降）。

第 9 步（第 1→2 步）：∇f(0.6, −0.2) = (2·0.6 + (−0.2), 2·(−0.2) + 0.6) = (1.2 − 0.2, −0.4 + 0.6) = **(1.0, 0.2)**。
第 10 步：x₂ = (0.6, −0.2) − 0.2·(1.0, 0.2) = (0.6 − 0.2, −0.2 − 0.04) = **(0.4, −0.24)**。
第 11 步：f(0.4, −0.24) = 0.16 + 0.0576 + (0.4)(−0.24) = 0.16 + 0.0576 − 0.096 = **0.1216**。

第 12 步（第 2→3 步）：∇f(0.4, −0.24) = (0.8 − 0.24, −0.48 + 0.4) = **(0.56, −0.08)**。
第 13 步：x₃ = (0.4, −0.24) − 0.2·(0.56, −0.08) = (0.4 − 0.112, −0.24 + 0.016) = **(0.288, −0.224)**。
第 14 步：f(0.288, −0.224) = 0.082944 + 0.050176 + (0.288)(−0.224) = 0.082944 + 0.050176 − 0.064512 = **0.068608**。

**(c) 单调下降验证**：
第 15 步：f 值序列 1 → 0.28 → 0.1216 → 0.068608，**严格递减 ✓**。
第 16 步：因 f 凸（(a)），由定理 1 局部=全局，梯度下降不会停错假谷底——**这是"敢用"的数学依据**；又 η = 0.2，安全值 1/L = 1/3 ≈ 0.333（L = 最大特征值 3），η = 0.2 < 0.333，落在安全区，故单调下降有保证 ✓。

**(d) 最小点**：
第 17 步：令 ∇f = 0：2x + y = 0，2y + x = 0。
第 18 步：由第一式 y = −2x，代入第二式：2(−2x) + x = 0 ⇒ −4x + x = 0 ⇒ −3x = 0 ⇒ **x = 0**。
第 19 步：y = −2·0 = 0。故 x\* = **(0, 0)**，f(0,0) = 0。
第 20 步：验证序列 (0.288, −0.224) 确实在朝 (0,0) 收缩（各分量绝对值在变小）✓。

**答**：(a) ∇f = (2x+y, 2y+x)，H 特征值 1 与 3 均正，f 凸；(b) x₁ = (0.6,−0.2), f = 0.28；x₂ = (0.4,−0.24), f = 0.1216；x₃ = (0.288,−0.224), f = 0.068608；(c) 单调递减，η=0.2 在安全区，凸性保证局部=全局；(d) x\* = (0,0)。

**常见错误**：① 求 f_x 时把 xy 对 x 求导写成 x（正确是 y）；② Hessian 特征值解错——det(H−λI) 展开忘了减掉交叉项平方（1²），导致 (2−λ)² 误当成特征值 2、2；③ 更新时 y 分量漏掉"负号变化"（x₁ 的 y 从 0 变 −0.2，符号要看梯度方向）。

**题 C（概念，检查理解）：凸性与"敢用"**

老谟问造物主：一个函数 f 不凸，梯度下降从某点出发最终停在一个"小坑"（局部极小）。
(1) 这说明 f 的梯度下降违反了本章哪条定理？为什么？
(2) 如果 f 是凸的，还会发生这种事吗？为什么？

**完整解答**：
(1) 不违反任何定理本身——本章定理 1（凸 ⇒ 局部=全局）的**前提（凸）不满足**。梯度下降仍然单调下降（只要 η 够小、梯度够光滑），但它**没有保证停在全局最优**；定理 1 正是"保证停在全局"的那条，前提缺失它就失效。**这是"前提不满足导致结论失效"，不是"算法出错"。**
(2) 不会。凸函数（定理 1）任何局部极小都是全局极小，所以梯度下降停的任何"坑"都等于全局最优。**这正是"凸性敢用梯度下降"的全部含义。**
