# 《概率统计与信息》· 第 6 册

> **苏格拉底对话体自学教材**，老谟 ⇄ 造物主一问一答，让读者从零亲手推导概率、统计、信息论。本册是《数学基础》系列 7 册中的第 6 册，承接第 05 册（多元微积分与凸优化），并为第 07 册（图论与可计算性）提供概率视角。
>
> **核心立场**：本册**双轨并述**频率派与贝叶斯派——置信区间是"工序长期覆盖率"（频率）vs"μ 的后验概率"（贝叶斯可信区间），两套并存、不判胜负。这是对样书"贝叶斯立场偏移"的正面修复。

## 每章标配（继承 skill 升级后的铁律）

- **严格化走廊**：定义 → 定理（带全前提）→ ≥2 个可复写完整证明 → 反例/边界。全册 20+ 个证明逐步标依据。
- **计算训练场**：每章 ≥3 道中大型计算题（动笔 10 分钟+），易→中→难，附完整分步解答 + 常见错误 + Python 工程案例（数值全部实测）。
- **学派中立**：频率/贝叶斯双轨显式区分，随机性安在谁身上谁就是那一派的主语。
- **对话/证明分离**：对话只推"为什么想到这步"，公式与证明全部交给走廊，不演定理。
- **节奏平衡**：熵/互信息/KL 等抽象概念独立成轮、给足篇幅，绝不报菜名。

## 创作流程

本册由 **创世游戏团队** 协作完成，执行「创作 → 三专家评审 → 修改 → 复审 → 定稿」循环：
- **主笔（main）**：统筹、起草样板章、统稿
- **严格性首席（rigor-chief）**：严格化走廊把关
- **习题与工程设计师（exercise-designer）**：计算训练场数值复核
- **跨学科顾问（cross-advisor）**：学派中立、历史准确、节奏平衡
- **作者 ×3（writer-basic/stats/info）**：按样板标准并行创作

所有章节经三专家逐章评审通过后定稿，数值经亲手核算。
