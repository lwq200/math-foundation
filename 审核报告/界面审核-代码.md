## 二、问题清单

### P1-1　顶部导航「册次目录」下拉漏册 07

- **问题**：`config.mts` 的 `nav` 下拉 `items` 仅列出册 01~06，**册 07 缺失**。
- **触发路径**：页面顶栏 →「册次目录」→ 下拉无「册07 · 图论与可计算性」。
- **根因**：`.vitepress/config.mts:193-206`，`items` 数组到 `册06`（第203行）即止。
- **影响**：导航入口不完整。注意左侧 `sidebar`（第26-124行）完整包含册07 全部 8 章 + 答案速查页，仅顶栏下拉遗漏。
- **修复建议**：在第203行后补 `{ text: '册07 · 图论与可计算性', link: '/册07-图论与可计算性/第01章-图的基础' }`。

### P1-2　KaTeX 数学模式中出现中文字符（缺字形）

- **问题**：`npm run build` stderr 反复出现 KaTeX 警告 `unicode text in math mode`，涉及中文「已/用/数/首/末」等字符。
- **根因**：正文某些 `$...$` 数学块内混入了中文词（KaTeX 会渲染为默认 serif 缺字形样式，观感突兀）。
- **影响**：个别公式块中文以衬线体直排，破坏公式一致性；属内容级缺陷。
- **修复建议**：将数学块内的中文移出 `$...$` 或改用 `\text{中文}` 包裹。

### P1-3　公式中出现不可识别字符 `␣`（U+2423）

- **问题**：构建日志约 80 处 `␣`（U+2423 OPEN BOX）未被 KaTeX 识别。
- **根因**：正文以「␣」字符代表空格/占位，KaTeX 无该字形，浏览器会渲染为缺字形方框（豆腐块）。
- **影响**：数学表达中出现 `□` 状乱码，可读性受损。
- **修复建议**：全局替换为 `\,`（细空格）或 `\;`，或改写字面 `\text{ }`。

### P2-1　`GraphCanvas.vue` 命名导入 `JXG` 在 jsxgraph 1.13.1 下为 undefined（死代码）

- **问题**：`.vitepress/theme/components/GraphCanvas.vue:22` 使用 `(await import('jsxgraph')).JXG`。
- **根因**：安装的 jsxgraph 为 **1.13.1**（`package-lock` 锁定），其 ESM 导出为 `default`（含 `JSXGraph` 命名空间），**无命名导出 `JXG`** → `JXG` 为 `undefined`，第24行 `JXG.JSXGraph.initBoard(...)` 会抛 `TypeError`。
- **影响**：**当前无实际影响**——`VizFigure`/`GraphCanvas` 未被任何 `.md` 使用（md 中仅 `TangentExplorer`/`RiemannSum`/`LimitEpsilonDelta`），属死代码。一旦有人按注释启用 `<VizFigure />` 即崩溃。
- **修复建议**：改为 `const jsxg = await import('jsxgraph'); const JXG = jsxg.default ?? jsxg;`（与 `TangentCanvas.vue` 等在用组件一致），或删除这套死代码。

### P2-2　审计脚本 JSXGraph 时序假阳性（非站点 bug）

- **问题**：`scripts/diag-all.mjs` 在 `.vp-doc` 出现后**立即**检查 `svgShapeCount`，未等待 JSXGraph 懒加载 + 绘制完成，导致 11 个交互页误报 `board-svg-empty`、readout 全零。
- **根因**：JSXGraph 经 `defineClientComponent` 懒加载（独立 chunk + `await import('jsxgraph')`），首帧 `.vp-doc` 出现时画布尚未初始化。
- **实测证据**：同一页面等待 8s + `networkidle` 后，`TangentCanvas` chunk 与 jsxgraph chunk（`chunks/index.GuNCb1gd.js`）均 `200`，`.tan-board` 内生成 `svg` 且 `shapeCount=46`，读数 `切点 a=1.00，差商=3，f'(a)=2` 完全正确。**功能无异常。**
- **影响**：仅影响自动审计结果可靠性，误导修复方向（曾误判为 P0）。**非生产代码缺陷。**
- **修复建议**：审计脚本对画布断言前增加显式等待（`waitForSelector('.xxx-board svg')` 或等待 6~8s + `networkidle`），勿用固定短延时。
