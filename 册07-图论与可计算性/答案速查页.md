## 第 01 章 · 图的基础

**计算训练场**
- 题 1（Σd=10 的 3 顶点图）：**不存在**（3 顶点简单图最多 3 条边，Σd≤6<10）✓；改用 6 顶点画 5 条边可实现 Σd=10 ✓
- 题 2（度序列 1,1,2,2,3,3）：**可实现**，Σ=12=2×6 ✓；一个构造：$a$ 连 $c,d,e$、$b$ 连 $c,d,f$（度 3,3,2,2,1,1 逐一核对）✓
- 题 3（七桥图）：(a) 4 个奇度顶点，无一笔画 ✓；(b) Σd=14=2×7 反向核算 ✓；(c) 在两个原奇度顶点间加一条桥，奇度 4→2，可一笔画 ✓

**自测题**
- 题 A：8 顶点 12 条边，Σd=**24**、奇度顶点个数必为**偶数** ✓
- 题 B：度序列 2,2,2,4,4，奇度 0 个，存在**欧拉回路** ✓（构造 $a,b,c$ 各连 $d,e$，走法 $a\to d\to b\to e\to c\to d\to e\to a$）
- 题 C：统计 0,1,1,2,2,5 之和 = **11**（奇数），违反握手引理，**不可信** ✓
- 题 D：概念

## 第 02 章 · 树与图的遍历

**计算训练场**
- 题 1（9 顶点树）：(a) 边数 = **8** = n−1 ✓；(b) Σd = **16** = 2×8 ✓，由握手引理逼出"至少两片叶子" ✓
- 题 2（BFS，顶点 a–f，边 ab,ac,bd,be,ce,cf,df，从 a）：访问顺序 **a,b,c,d,e,f**（逐层 a→b,c→d,e,f）✓；队列轨迹 [a]→[b,c]→[c,d,e]→[d,e,f]→[e,f]→[f]→[] ✓；BFS 树边 **{ab,ac,bd,be,cf}** 共 5 条 = 6−1 ✓
- 题 3（DFS，顶点 a–e，边 ab,ac,bd,ce，f 孤立）：访问顺序 **a,c,e,b,d** ✓；连通分量个数 = **2**（五个点一块 + f 孤立）✓

**自测题**
- 题 A：7 顶点树边数 = **6**；由 Σd=12 逼出至少 **两片叶子** ✓
- 题 B（BFS p–s）：访问顺序 **p,q,r,s**；树边 **{pq,pr,qs}** 共 3 条 = 4−1 ✓
- 题 C（DFS a–f）：访问顺序 **a,c,e,b,d**；连通分量 = **2** ✓
- 题 D：概念

## 第 03 章 · 最短路径与 Dijkstra

**正文贯穿例题（对话第 4 轮）**：$s\to a(4), s\to b(2), b\to a(1), a\to t(3), b\to t(5)$ → **dist[t]=6**，路径 **s→b→a→t**（2+1+3=6）✓

**计算训练场**
- 题 1（同贯穿例题）：dist 逐轮 定s→{a=4,b=2}→定b→{a=3,t=7}→定a→{t=6}→定t；**最短 6，路径 s→b→a→t** ✓（其他 s→a→t=7、s→b→t=7 均 >6）
- 题 2（s,u,v,x,y,t，7 边）：逐轮 dist 更新后**最短 19**，路径 **s→v→y→t**（9+2+8=19）✓（s→u→v→y→t=27、s→v→x→t=26 均 >19；注意 t 前驱是 y 非 x）
- 题 3（负权反例）：真实最短 **0**（s→b→a→t = 4−5+1=0），Dijkstra 错误输出 **4** ✓（过早定死 a，负权破坏贪心前提）

**自测题**
- 题 A：最短 **6**，路径 **s→b→a→t** ✓
- 题 B：最短 **6**，路径 **s→v→u→t**（2+1+3=6）✓
- 题 C / 题 D：概念

## 第 04 章 · 图着色

**计算训练场**
- 题 1（a,b,c,d，边 ab,ac,ad,bc，顺序 a,b,c,d）：贪心用色 1,2,3,2 共 **3 色** ✓；Δ=3，3≤Δ+1=4 ✓；χ=**3**（含三角形 a,b,c）✓
- 题 2（五边形 C5，BFS 交替染色）：c,d 相邻却同为 1 → **非二部图** ✓；χ=**3**（奇环）✓
- 题 3（正方形+对角线 ac）：Δ=3、Δ+1=4；两个顺序贪心都 **3 色** ✓；χ=**3** ✓（贪心任何顺序恒 3 色，不翻车——见走廊定理 2）

**自测题**
- 题 A（三角形 C3）：贪心 1,2,3 共 3 色；Δ=2、3≤3 ✓；χ=3 ✓
- 题 B（路径 a–b–c–d）：BFS 交替无冲突，**二部图**，χ=**2** ✓
- 题 C（正方形 C4）：两顺序都 2 色；χ=**2**（偶环）✓
- 题 D：概念

**计算训练场**

- 题 2（a,b,c,d，边 ab,bc,ca,ad,dc）：奇度 a(3),c(3) 共 **2 个**，无回路、有欧拉迹 **a→b→c→a→d→c**（5 条边各一次）✓

- 题 C：(a) 正方形 C4 有哈密顿回路 **a→b→c→d→a** ✓；(b) TSP n=5→**12** = 4!/2 ✓

## 第 07 章 · 可判定性与停机问题

**计算训练场**
- 题 1（填空）：A=**死循环**、B=**停机**、C=**M 在 ⟨M⟩ 上不停机**、D=**D(⟨D⟩) 不停机**、E=**存在判定机 H** ✓
- 题 2（完整反证法）：自指 = **第 4 步（M=D）**；反例击穿 = **H 对输入 (⟨D⟩,⟨D⟩) 的回答必错**；排中律 = **第 5 步（两分支穷尽所有可能）** ✓
- 题 3（辨析）：(a)**对**（可判定⊂可识别）；(b)**错**（HALT 可识别却不可判定，反例）；(c)**错**（不可判定 = 已被数学证明不存在算法，非"还没想出"）✓

**自测题**
- 题 A：可判定 ⊂ 可识别，**真包含**（HALT 为样板）✓
- 题 B：两分支都矛盾——分支一"停机"反被 D 反转成不停机、分支二"不停机"反被 D 反转成停机，故 **H 不存在** ✓
- 题 C / 题 D：概念（D 结论：可判定是真子集）

## 第 08 章 · P 与 NP

**走廊亲算（步数核算）**
- 奇数机（输入 `1011`，n=4）：扫描 n 步 + 读空白 1 步 + 看个位 1 步 = **n+2 = 6 步**，O(n) ✓
- 全 0 判定机（最坏全 0）：扫描 n 步 + 读空白 1 步 = **n+1 步**，O(n) ✓（n=3 输入 `000` 为 4 步核算一致）

**计算训练场**
- 题 1：(a) 全 0 判定最坏 **n+1 步** = **O(n)**（线性）✓；(b) 枚举子串 **O(2ⁿ)**（指数）✓
- 题 2：(a)奇数、(b)质数（AKS 2002）**在 P** ✓；(c)哈密顿回路、(d)SAT **在 NP**（是否在 P = P vs NP，未解）✓
- 题 3（归约方向）：(a) 两者 NP-complete，**互相可归约**；(b) 若 3-SAT∈P，则哈密顿回路∈P，进而 **P=NP** ✓；(c) 归约箭头指向"更难"的那边 ✓

**自测题**
- 题 A：首字符判断机最坏/最好都 **1 步**，**O(1)**（常数）✓
- 题 B：(a) 偶数个 1 判定**在 P**（O(n)）；(b) 欧拉回路**在 P**（第 5 章充要条件多项式可查）；(c) 哈密顿回路**在 NP**（是否在 P 未解）✓
- 题 C / 题 D：概念（D：算的边界三重 = 可计算性 / 可判定性 / 复杂度）

## 使用说明

1. **难度标尺**：每题分（易/中/难）见各章计算训练场题干；本页只给终值，不重复解答过程。
2. **链式互证**：① Dijkstra（第 03 章）每轮 dist 更新表，建议算完用"沿前驱树还原路径 + 反向验证该路径权值 = dist[t]"核对；② 欧拉回路（第 05 章）充要条件"连通 + 全偶度"双向验证——必要性沿迹数度、充分性回路拼合，构造出迹后再数一遍边数是否 = |E| 且每条恰一次；③ TSP 候选数（第 05 章）用 (n−1)!/2 核对，n=6→60、n=10→181440 应能互验。
3. **双轨提醒**：第 03 章负权反例中 Dijkstra 输出 **4** 是"算法错误输出"，真实最短是 **0**——对答案时勿把算法输出当真实值；第 04 章贪心着色恒 ≤ Δ+1（上界）但可能 ≠ χ（最优），对答案时区分"够用"与"最少"两个概念。
4. 如发现本页某值与章节解答不一致，先回看章节——全册经评审复核，本页为权威终值。
