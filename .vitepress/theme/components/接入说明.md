# 交互组件接入说明

> 用途：在任意章节 `.md` 中引入 `TangentExplorer`（切线/割线/差商原型，对应 P0-3「导数=切线斜率」）。组件已在主题 `enhanceApp` 中**全局注册**，无需逐文件 import。

## 一、最小接入（推荐）

在章节正文任意位置直接写：

```md
<TangentExplorer />
```

> 说明：VitePress 会把 `.md` 里的 HTML 标签识别为 Vue 组件。因组件已在 `theme/index.ts` 中 `app.component('TangentExplorer', …)` 注册，直接使用即可。

## 二、带标题 / 提示框的规范接入

建议配合标题与教学提示使用，方便学生定位：

```md
### 交互实验：导数 = 切线斜率

拖动绿色点 a 改变切点，拖动 h 滑杆让割线贴合切线，观察差商趋近 f'(a)。
切到 |x| 并把 a 拖到 0，能看到左右斜率冲突 → 不可导。

<TangentExplorer />
```

若想包在 VitePress 提示框里（可折叠，适合放在「计算训练场」末尾）：

````md
::: tip 交互原型 · 割线→切线
拖动 a 与 h，观察差商趋近导数；切到 |x| 检验 a=0 处的不可导。

<TangentExplorer />
:::
````

## 三、组件当前能力（P0-3）

- 函数切换：`x²` / `x³` / `|x|`
- 拖动点 `a` 移动切点，实时显示 `f(a)` 与切线斜率 `f'(a)`
- 拖动 `h` 滑杆（0.1→3），割线逐步**贴合**切线，实时显示差商 `[f(a+h)−f(a)]/h`
- 教学点：
  - `x³` 在 `a=0` 处切线水平（斜率 0）→ 直观区分「切线水平 ≠ 极值点」
  - `|x|` 在 `a=0` 处左右差商互为相反数 → 斜率冲突 → 不可导，呼应「可导 ⇒ 连续，连续 ⇏ 可导」

## 四、SSR / 构建安全

采用「`defineClientComponent` 懒加载 + 实现组件 `onMounted` 内动态 `import('jsxgraph')`」的体系（与部署集成师的 `VizFigure`/`GraphCanvas` 同模式）：

- `TangentExplorer.vue` 是薄包装层，用 `defineClientComponent(() => import('./TangentCanvas.vue'))` 声明「仅客户端」组件 → SSR 阶段渲染占位、不执行 jsxgraph。
- `TangentCanvas.vue` 在 `onMounted` 内 `await import('jsxgraph')` 后再 `initBoard`，setup/SSR 阶段不访问 `document` → `npm run build` 不会因 `window is not defined` 报错。
- 好处：jsxgraph 被打成**独立 chunk，懒加载，不进首屏主包**。
- 首次在 md 中引入后请运行 `npm run build` 验证一次。

## 五、依赖声明

`jsxgraph` 已在 `package.json` devDependencies 声明（`^1.7.1`），CI 会安装。本地如需开发预览请先 `npm install`。无需改动 `config.mts`。

## 六、深色模式

- **init 时判断**：`initBoard` 传入 `dark` 布尔值，从 `document.documentElement.classList.contains('dark')` 探测 VitePress 主题。
- **CSS 变量取色**：坐标轴/网格/文字用 `var(--vp-c-text-*)`、`var(--vp-c-divider)` 等，深浅色自动适配，与 KaTeX 视觉一致。
- **运行时跟随**：实现组件监听 `<html>` 的 `class` 变化（`MutationObserver`），主题切换时调用 `board.setAttribute({ dark })` 实时同步，无需刷新。

## 七、扩展规范（重要：每个交互组件 = 包装器 + 画布两文件）

统一采用部署集成师确立的「包装器 + 画布」拆分：

- 目录：`.vitepress/theme/components/`
- 命名 `<Domain><Interaction>Xxx.vue`（包装器，薄壳，仅 `defineClientComponent(() => import('./XxxCanvas.vue'))`）
- 命名 `<Domain><Interaction>Canvas.vue`（实现，`onMounted` 内动态 `import('jsxgraph')` + 全部绘图/交互逻辑）
- 已有范例：
  - `TangentExplorer.vue`（包装器）+ `TangentCanvas.vue`（画布）—— 本次交付
  - `VizFigure.vue`（通用包装器）+ `GraphCanvas.vue`（通用画布骨架）—— 部署集成师
- 未来组件同样两文件：`LimitEpsilonDelta(+Canvas).vue`、`RiemannSum(+Canvas).vue`、`MatrixTransform(+Canvas).vue`、`GradientDescent(+Canvas).vue`、`NormalDistSlider(+Canvas).vue` 等。
- 注册：仅在 `theme/index.ts` 中注册**包装器**（`TangentExplorer`、`VizFigure` 等），画布由 `defineClientComponent` 懒加载、无需注册。
- 静态图：`withBase('/assets/viz/xxx.svg')`（base=`/math-foundation/`）。

## 八、注意事项

- 画布用 `ref` 容器而非固定 `id`，保证一页多个交互实例不冲突。
- 组件样式用了 `scoped` + VitePress 变量（`--vp-c-bg-soft`、`--vp-c-divider`、`--vp-c-brand-*`），与站点主题一致，无需额外 CSS。
- 若在某章节首次构建报「组件未定义」，多半是 `theme/index.ts` 的 `app.component` 注册被遗漏；此文件由部署集成师统一管理，改动已并入，无需你再改 `config.mts`。
