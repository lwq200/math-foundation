# 第 07 章 · 高维景观鞍点与局部最优——深度学习为什么怕"马鞍"不怕"小坑"

> 本章从哪个问题出发：上一章你证明了——只要函数凸、梯度够光滑、学习率够小，梯度下降就能保证到谷底。可你也亲眼承认了：**深度学习的损失函数根本不凸。** 那真实的高维地形到底什么样？当你训练模型、损失卡在一个平台死活不动时，你以为你掉进了"深谷里的小坑"——**这个直觉，可能是错的。**
> 推导到哪个结论：答案是，在梯度为零的"驻点"，光看梯度分不清它是什么。要用**海森矩阵（Hessian）的二阶信息**给稳定点分类：正定 = 局部极小、负定 = 局部极大、**不定 = 鞍点**。关键结论：**在几百上千维的空间里，鞍点（某些方向是谷、另一些方向是脊）的数量压倒性多于"小坑"，深度学习损失面的真正常态是"鞍点海"，而非二维想象里的"浅坑深谷"。**
>
> 核心认知：**优化的难，不是难在"掉进小坑爬不出来"，而是难在"站在鞍点上，往所有轴方向看都是上坡、可斜着的方向明明有下坡"。** 梯度下降对鞍点的麻烦在于：它在鞍点附近"梯度很小、看起来像收敛"，于是卡住。这一章补上样书最过时的一环——用"高维鞍点海"取代"浅坑深谷"的二维可视化。

## 引子

凌晨两点，老谟的屋里只剩屏幕的蓝光。造物主对着一行训练日志发呆，loss 停在 0.7 已经整整二十轮没动。

"老谟，我模型卡死了。"他指着那条笔直的水平线，"你看，损失降到 0.7 就再也不降了。我猜……我是不是掉进了一个'深谷里的小坑'？就像一块凹地，四周都高，我滑进去就爬不出来了。"

老谟没接话。他从抽屉里翻出一张折过的硬纸板，递到造物主面前——那是一张被折成"马鞍"形状的纸：前后是高高翘起的两个檐，左右却向下弯成两个低垂的翅膀。

"你先别急着给结论。看这张纸。"老谟把它放在桌上，"你站在中间那个'鞍顶'上。往前是上坡，往后是上坡——**可往左往右，都是下坡。** 现在你告诉我：你站的这个地方，算'坑'吗？"

造物主盯着那个马鞍形愣住："……不算坑。往前后是上坡，可左右明明能溜下去。这……这既不是谷底，也不是山顶啊。"

"可你的训练日志告诉你什么？"老谟敲了敲屏幕，"loss 不动了，梯度小得像停了——你的优化器也以为'到头了'。**你信的是'掉进小坑'，可高维世界里，让你卡住的最常见凶手，恰恰是这张纸的形状——鞍点（saddle point）。** 这一章，我们就把'你站在什么地形上'这件事，用数学钉死。"

## 对话引擎

### 第 1 轮：先分清"停下来"的数学含义——驻点

**老谟**："你说损失卡住了。'卡住'在优化里意味着什么？——梯度变成什么样了？"

**造物主**："……梯度变成 0 了吧？梯度下降每步是 x_{k+1} = x_k − η∇f，如果 ∇f 是 0，就走不动了，原地停住。"

**老谟**："对。梯度为零的点，数学家叫**驻点（stationary point）**——'停驻'的点，梯度不再推你走。这是'停下来'的必要条件。**可问题来了：梯度为零，能告诉你是哪种地形吗？** 你猜猜——光看 ∇f = 0，你能分得清是谷底、山顶、还是你眼前这个马鞍吗？"

**造物主**："……分不清吧？这三处梯度都是 0，但地形差远了。谷底是四周都高，山顶是四周都低，马鞍是前高后低、左右再低。"

**老谟**："好，那你现在亲手发现了一个重要事实：**驻点是'停下来'的必要条件，但不是'到谷底'的充分条件。** 梯度为零只告诉你'脚下不斜了'，可没告诉你'往四周看是坑还是脊'。要看清楚地形，光有梯度（一阶信息）不够了——你需要的是……什么？"

---

### 📐 知识锚点：驻点——"停下来"的必要条件

【概念深挖】**驻点（stationary point）**：设 f 在 x₀ 可微。若 **∇f(x₀) = 0**，则称 x₀ 为 f 的**驻点**（也叫稳定点）。它是"梯度下降走不动"的数学表述，也是"极值的必要条件"——**f 在 x₀ 取到局部极值 ⇒ ∇f(x₀) = 0**（一元情形的"费马引理"推广到多元）。

【概念深挖】**驻点不等于极值点**：驻点可能是局部极小、局部极大、鞍点中的任意一种。一阶信息（梯度）在驻点处全部归零，**区分这三种地形需要二阶信息（Hessian）**——这正是本章要做的分类。

【工程实践】训练日志里"loss 卡平"的数学含义，大概率是**梯度已经小到优化器判定'接近驻点'**。但要注意：**梯度小不等于到了谷底**——它可能只是到了鞍点附近（梯度在鞍顶恰好为零）。所以工程上"loss 不动"需要警惕，它未必是好消息。

---

### 第 2 轮：一阶归零之后，靠什么区分地形——海森矩阵登场

**老谟**："驻点处梯度全归零了。要区分谷底、山顶、马鞍，你手里还剩下什么工具？——想想第 2 章你学过的多元泰勒。"

**造物主**："多元泰勒！f(a+h) ≈ f(a) + ∇f·h + ½hᵀHh。在驻点 ∇f = 0，那一阶项就没了，**剩下决定'往四周看是升是降'的，就是那个海森二次型 ½hᵀHh！**"

**老谟**："抓住关键了。**驻点附近，地形完全由 Hessian 决定**：你朝某个方向 h 挪一小步，函数是升是降，取决于 hᵀHh 是正是负。**如果朝所有方向都是升（hᵀHh > 0 对所有 h）——那是什么地形？**"

**造物主**："……四周都升，那我站在谷底！局部极小！"

**老谟**："那如果朝所有方向都是降呢？"

**造物主**："四周都降，山顶——局部极大！"

**老谟**："那如果**有的方向升、有的方向降**呢？——你先别急着说'马鞍'，你就描述这个地形。"

**造物主**："……那就有方向能下去，有方向得上去。既不是坑也不是山顶，是个'骑跨'的地形——就是你给我看的那张马鞍纸！"

**老谟**："你自己把三种地形都摸出来了。**它们的区别全在 Hessian 的'符号分布'上：正定（全正）= 极小，负定（全负）= 极大，不定（有正有负）= 鞍点。** 现在问题变成：**怎么用 Hessian 判断'全正/全负/有正有负'？** 你学过的特征值，正好派上用场。"

---

### 📐 知识锚点：稳定点的二阶分类——Hessian 决定地形

【概念深挖】**驻点的二阶分类**（设 x₀ 为驻点，H = H_f(x₀) 为海森矩阵，用特征值或主子式判断）：

| Hessian H 的类型 | 特征值 | 地形 | 例子 f |
|---|---|---|---|
| **正定** | 全 > 0 | 局部极小 | x² + y² |
| **负定** | 全 < 0 | 局部极大 | −x² − y² |
| **不定** | 有正有负 | **鞍点** | x² − y² |
| **半正定（含 0）** | ≥ 0 且有 0 | 需更高阶判定 | x⁴ 在 x=0 |

【概念深挖】**特征值视角的直觉**：H 的特征值 λ 和对应特征向量 v 告诉你：**沿方向 v，二阶方向导数是 λ·‖v‖²。** 所以：
- 正特征值 = "这个方向是条谷"（往上弯，会聚）；
- 负特征值 = "这个方向是条脊"（往下弯，会散）；
- **鞍点 = 同时拥有正特征值和负特征值 = 某些方向是谷、另一些方向是脊**——这正是一张马鞍的几何本质。

【工程实践】**二阶方法（牛顿法）正是靠 Hessian 的信息避开鞍点**：梯度下降只认一阶梯度，在鞍点附近梯度小、容易误判为收敛；而二阶方法看到"有负特征值方向"就知道那边能下降。**深度学习中较少直接用牛顿法（Hessian 太大算不起），但这个"识别负方向"的思想很重要**——随机梯度与噪声，本质上也是在帮你"晃出"那些负方向。

---

### 第 3 轮：什么是鞍点——用二阶泰勒钉死它

**老谟**："'鞍点'这个词你用了好几轮了，但一直停在'马鞍纸'的直觉上。现在我给你定义，你帮我确认它准不准：**鞍点 = 一个驻点，它的 Hessian 是不定的。** 你觉得这个定义抓住了马鞍的本质吗？"

**造物主**："……抓住了吧？不定 = 有正有负特征值 = 有的方向是谷、有的方向是脊，正好是那张马鞍纸：前后翘（脊）左右垂（谷）。"

**老谟**："那我要再问你一个更硬核的：**凭什么 Hessian 不定，这个点就一定'既不是局部极小、也不是局部极大'？** 你光凭直觉说'它不像'可不够——这要能写下来、能证。你打算怎么证？"

**造物主**："……用二阶泰勒？在驻点 f(x₀+h) ≈ f(x₀) + ½hᵀHh。如果 H 有负特征值，那我沿着那个方向走，f 就比 f(x₀) 小，所以它不是局部极小；如果 H 有正特征值，沿着它走 f 更大……啊，但局部极小只要求'周围不比它小'，我得证明'存在一个方向让它更小'——对，负特征值那个方向就行！"

**老谟**："你自己把证明思路摸出来了：**Hessian 不定 ⇒ 存在下降方向（负特征值方向）⇒ 不是局部极小；同理存在上升方向（正特征值方向）⇒ 不是局部极大。** 所以它既不是极小也不是极大——配得上'鞍'这个字。完整可复写的证明放走廊，你先把'负特征值方向能下降'这个直觉钉牢。"

---

### 📐 知识锚点：鞍点的精确定义与"方向性"

【概念深挖】**鞍点（saddle point）**：设 x₀ 是 f 的驻点（∇f(x₀) = 0）。若海森矩阵 **H_f(x₀) 是不定矩阵**（既有正特征值又有负特征值），则称 x₀ 为**鞍点**。此时 x₀ **既不是局部极小点，也不是局部极大点**（严格证明见走廊定理）。

【概念深挖】**鞍点的"方向性"直觉**：鞍点的本质是"同时包含谷与脊"。站在鞍顶，沿负特征值方向是下坡（能离开），沿正特征值方向是上坡。**它之所以危险，是因为它既有'看起来像极值'的一面（梯度为零、各轴方向都上坡），又有'其实能离开'的一面（斜方向藏着下坡）。** 梯度下降按"梯度反方向"走，在鞍顶梯度为零，就容易被骗得停住。

【历史溯源】"鞍点"这个称呼借自**骑马的鞍**——那种前后翘起、左右下凹的形状。在优化理论里，**局部极小/极大/鞍点的严格分类在 19 世纪极值理论中逐步成型**（黑塞、西尔维斯特等人奠基）；而"鞍点在高维优化里是常态而非例外"这个认知，要等到**20 世纪末机器学习与高维优化兴起**之后才被充分认识——它是深度学习时代才被推到台前的概念。

---

### 第 4 轮：高维直觉——为什么高维空间里鞍点"满地都是"

**老谟**："鞍点定义清楚了。现在我要问一个让二维直觉崩掉的问题：**高维空间里，鞍点多还是小坑多？** 你先凭直觉猜。"

**造物主**："……那我猜小坑多吧？毕竟要找谷底嘛，坑多才合理。"

**老谟**："你被你脑补的二维地形骗了。让我换个说法问你：**在一个点，它是局部极小，要求什么？**"

**造物主**："要求 Hessian 正定，所有特征值都是正的……"

**老谟**："那如果特征值有正有负呢？——它是什么？"

**造物主**："……鞍点。"

**老谟**："好。现在假设这 n 个特征值'正负随机、各有约一半'。你算算：**所有 n 个特征值同时为正，这个概率有多大？**"

**造物主**："……如果每个独立、一半概率为正，那全部为正就是 (1/2)ⁿ……**n 一大，这个概率指数级缩小！** 几百维就是 (1/2)^几百，小到可以忽略——所以几乎不可能所有方向都是谷！"

**老谟**："你自己把'高维鞍点压倒性多数'算出来了。**在几百上千维里，一个随机驻点几乎必然是不定的——既有正也有负特征值，也就是鞍点。** 真正'所有方向都是谷'的局部极小，在高维里稀有得像中彩票。这就是为什么高维优化那么难——**你要找的'坑'太少了，而'马鞍'满地都是，梯度下降动不动就撞上一张鞍被卡住。**"

---

### 📐 知识锚点：高维直觉——鞍点的"压倒性多数"

【概念深挖】**为什么高维里鞍点占压倒性多数**：局部极小要求 Hessian 的所有 n 个特征值都为正。若把特征值符号看成"近似随机"，全部为正的概率约为 (1/2)ⁿ——**随维度 n 增大指数级趋近于 0**。反过来，只要有一个特征值为负（概率极高），该驻点就是鞍点。**结论：高维空间的驻点，绝大多数是不定的鞍点；真正的局部极小是极端稀有事件。**

【概念深挖】这个直觉怎么修正你的二维地图：**低维（一二维）里"浅坑深谷"的图景，是因为低维时'所有方向都正'的概率不算太小**。一旦升到高维，"坑"变得极其罕见，常态变成了"有谷有脊交错"的鞍点海。**二维直觉里'山谷里有小坑'的图，在高维里基本不成立。**

【工程实践】这条认知直接改变工程师的心态：**遇到 loss 卡住，先怀疑'撞上鞍点'而不是'掉进深坑'**。因为高维里深坑太稀有，鞍点才是常态。这也解释了为什么**训练要加随机性（mini-batch 采样、Dropout、学习率调度）**——噪声能帮你"晃出"鞍点附近那个"梯度为零"的假平衡，顺着负特征值方向溜走。

### 第 5 轮：深度学习损失面是"鞍点海"而非"浅坑"——修正过时的图景

**老谟**："我们费这么大劲，是为了纠正一个**过时的二维可视化**。你说说，你以前脑子里的深度学习损失面长什么样？"

**造物主**："……我以为是一张起伏的山地，有很多'小坑'，我担心掉进某个浅坑里出不来。"

**老谟**："**这就是那个过时图景。** 它是把一维、二维的'山谷深坑'直觉直接搬到高维。真实情况我们已经论证了：**高维损失面的常态是'鞍点海'——大片的鞍点连成片，真正的'深坑（好极小）'反而是少数。** 你更该担心的，不是'掉进浅坑'，而是'卡在鞍点'。你觉得，这俩的应对方式一样吗？"

**造物主**："……不一样吧？掉进坑，得想办法'爬出去'；卡在鞍点，其实周围明明有下坡方向（负特征值方向），只是梯度为零骗了优化器，需要'晃动一下'让它找到那个方向。"

**老谟**："完全正确。**这个区别是理解深度学习优化的钥匙**：对鞍点，你要的是'扰动/噪声'把它晃出来；对深坑，你要的才是'改变损失面本身'（更多数据、更强正则）。**先分清风向再开药，这是本章最重要的工程观。**"

---

### 📐 知识锚点：鞍点海 vs 浅坑深谷——一次认知升级

【概念深挖】**深度学习损失面的现代认知（高维）**：近年来理论和实验都支持，深层网络的损失面在**高维空间里以鞍点为主**——真正的局部极小通常与全局极小的值相近（好的坑），但大量驻点是鞍点。**过时的"浅坑深谷"二维图景会误导人以为"掉进坑爬不出来"；真实的麻烦是"卡在鞍点梯度为零"。**

【工程实践】**应对之策完全不同**：
- 针对**鞍点**（常态）：用**随机性**——随机梯度下降（用 mini-batch 估梯度，天然带噪声）、Dropout、重启（多起点）、学习率热身——让优化器"晃出"鞍顶，找到负特征值方向的出口。
- 针对**坏极小点**（少见）：才需要用**改变损失面**的手段（换损失函数、加正则项、更多数据）把那个深坑填平或绕开。

【实现思考】如果让你设计一个"能逃出鞍点"的优化器，你会加什么？最容易想到的是**给梯度加一点随机噪声**：在梯度下降更新里混入零均值噪声，让它在鞍顶那个"梯度为零"的点上不断被扰动，一旦顺着负特征值方向积累足够位移，就能"滑下马鞍"。**这正是随机梯度下降（SGD）比全批量梯度下降更擅长逃出鞍点的直观原因——它的梯度是带噪声的估计。** 代价：噪声也会让收敛到"谷底"时抖动（所以后期要衰减学习率/噪声）。换条路：用二阶信息（检测负特征值方向）能精准找到出口，但 Hessian 太大算不起——**"便宜但靠运气"（噪声）vs"精确但太贵"（Hessian）**，工程里通常选前者。

### 第 6 轮：落点——"怕马鞍"不是怕"小坑"

**老谟**："把马鞍纸收起来。回到你凌晨那句'我是不是掉进小坑了'。你现在能回答自己了吗？"

**造物主**："我先不说坑不坑——我先得看**梯度是不是零（驻点）**，再看 **Hessian 的特征值符号**：全正是极小、全负是极大、有正有负是鞍点。高维里鞍点占压倒性多数，所以我更可能撞上的**不是'小坑'，是'马鞍'——梯度为零把我卡住，可斜方向明明有下坡。**"

**老谟**："那对付它，你打算怎么办？"

**造物主**："如果是鞍点，**靠随机性晃出去**——SGD 的噪声、Dropout、多起点重启，让我顺着负特征值方向溜下马鞍。这跟'掉进深坑要改变损失面'完全是两套药。"

**老谟**："这一章你从'怕小坑'升级到'认马鞍'，已经比很多从业者清醒了。**可还有最后一层你没碰：万一这个高维地形里，连'往哪边走是允许的'都被限制了呢？** 比如你的解必须满足某些等式/不等式约束——只能在一条'路'上走，不能想怎么走就怎么走。**那时候'负梯度方向'都未必是你能走的。** 这种'带着锁链找谷底'的问题，是下一章的地盘。"

## 严格化走廊

> 位置说明：本章对话负责"直觉"——为什么鞍点危险、为什么高维鞍点占多数。本走廊负责"严谨"——把驻点、二阶分类、鞍点定义写成精确形式，并证明"Hessian 不定 ⇒ 鞍点"（用二阶泰勒 + 反证）。**下面每一行，读者都能对着空白纸重写一遍。**

### 定义 1：驻点（stationary point）

设 f 可微，点 x₀ 在 f 的定义域内。若 **∇f(x₀) = 0**，则称 x₀ 为 f 的**驻点**。

### 定义 2：局部极小/极大（local minimum / maximum）

称 x₀ 为 f 的**局部极小点**，若存在 r > 0，使对一切满足 ‖x − x₀‖ < r 的 x 有 f(x₀) ≤ f(x)。**局部极大点**定义对称（f(x₀) ≥ f(x)）。

### 定义 3：鞍点（saddle point）

设 x₀ 是 f 的驻点（定义 1）。若海森矩阵 **H_f(x₀) 是不定矩阵**（存在正特征值、也存在负特征值），则称 x₀ 为**鞍点**。

### 定义 4（复习，第 5 章）：正定 / 负定 / 半正定 / 不定矩阵

实对称矩阵 H 称为：
- **正定**：对一切 h ≠ 0，hᵀHh > 0（等价：所有特征值 > 0）；
- **负定**：对一切 h ≠ 0，hᵀHh < 0（所有特征值 < 0）；
- **半正定**：对一切 h，hᵀHh ≥ 0 且存在 h ≠ 0 使等号成立（所有特征值 ≥ 0 且有 0）；
- **不定**：存在 h₁ 使 h₁ᵀHh₁ > 0，也存在 h₂ 使 h₂ᵀHh₂ < 0（有正有负特征值）。

### 定理 1（驻点的二阶最优性条件——分类）：设 f 在 x₀ 附近有二阶连续偏导，x₀ 为驻点（∇f(x₀) = 0），H = H_f(x₀)。

- (a) 若 H 正定，则 x₀ 是局部极小点；
- (b) 若 H 负定，则 x₀ 是局部极大点；
- (c) 若 H 不定，则 x₀ **既不是局部极小点，也不是局部极大点**（即鞍点，见定义 3）。

**证明（可复写，证 (c) 的"不是局部极小"部分；"(a)(b)(c)的其余部分"思路同构）**：
- 由第 02 章**定理 3（多元泰勒，二阶）**，对驻点 x₀（∇f(x₀) = 0）：
  f(x₀ + h) = f(x₀) + ½·hᵀH·h + o(‖h‖²)，当 h → 0。
- **(c) 方向一：证明 x₀ 不是局部极小点。** 因 H 不定（定义 4），存在负特征值 μ < 0 及其单位特征向量 w（Hw = μw，‖w‖ = 1）。取 h = t·w（t > 0）：
  f(x₀ + tw) = f(x₀) + ½·(tw)ᵀH(tw) + o(t²) = f(x₀) + ½·t²·μ·‖w‖² + o(t²) = f(x₀) + ½μt² + o(t²)。
- 因 μ < 0，当 t → 0 时 ½μt² 是负的主部；而余项 o(t²)/t² → 0，故取 t 足够小可使 |o(t²)| < |½μt²|，于是 f(x₀ + tw) < f(x₀)。
- 这意味着：**在 x₀ 的任意小邻域内，都存在点 x₀ + tw 使 f 更小**——与定义 2（局部极小要求邻域内 f(x₀) ≤ f(x)）矛盾。故 x₀ **不是局部极小点**。
- **(c) 方向二：证明 x₀ 不是局部极大点。** 因 H 不定，存在正特征值 λ > 0 及其单位特征向量 v。取 h = t·v：
  f(x₀ + tv) = f(x₀) + ½λt² + o(t²)。取 t 足够小，f(x₀ + tv) > f(x₀)——邻域内存在更高点，与"局部极大"矛盾。故 x₀ **不是局部极大点**。
- 综合：H 不定 ⇒ x₀ 既非局部极小亦非局部极大，即鞍点（定义 3）。∎

**证明要点标注**：第 1 步用**第 02 章定理 3（多元二阶泰勒）**，并代入驻点条件 ∇f(x₀) = 0 消去一阶项；第 2 步用**定义 4（不定矩阵存在负特征值方向）**与**特征向量性质 Hw = μw、‖w‖=1**；第 3 步是**代数化简（二次型 = μt²‖w‖² = μt²）**；第 4 步用**余项 o(t²) 相对 t² 的高阶无穷小性质**（t 足够小时主部 ½μt² 占主导）；第 5 步用**定义 2（局部极小的邻域性质）**制造矛盾；第 6 步对称地对正特征值方向重复，证"非局部极大"。

### 定理 2（半定情形需要高阶信息）：设 x₀ 为驻点，H = H_f(x₀) 半正定（有特征值 0），则无法仅凭二阶信息判定 x₀ 的类型。

**说明（思路）**：当 H 有零特征值时，沿对应方向的二阶项为 0，地形由**更高阶偏导**决定。例：f(x) = x⁴ 与 f(x) = −x⁴ 在 x = 0 处，H = f″(0) = 0（半正定且半负定），但前者是局部极小（f ≥ 0）、后者是局部极大（f ≤ 0）——**单看 H 判不出来**，需看四阶项。

### 反例/边界

- **驻点但不是极值**：f(x, y) = x² − y² 在原点，∇f = (2x, −2y) = (0,0)，是驻点；H = [[2,0],[0,−2]] 不定，故原点**不是局部极小也不是局部极大**（是鞍点）——这正是本章反例与鞍点活标本（计算训练场题 1 会算）。
- **Hessian 半定的边界**：f(x, y) = x⁴ + y⁴ 在原点，H = [[0,0],[0,0]]（半正定），但它其实是局部极小（四阶项 > 0）。**所以"H 正定 ⇒ 极小"是充分条件，不是必要条件**——H 半正定时不能下结论，要看高阶项。
- **非光滑边界**：f(x,y) = |x| + y² 在原点梯度不存在（不可微），谈不上"驻点"和 Hessian——**二阶分类的前提是 f 二阶可微**。遇到折角（如带 ReLU 的损失面），这套分析要打折扣。

## 知识点总结

### 知识点（本章推出的核心概念）

- **驻点（stationary point）**：∇f(x₀) = 0 的点；"梯度下降走不动"的必要条件，但不是"到谷底"的充分条件。
- **二阶分类**：驻点处，地形由 Hessian 决定——**正定（全正特征值）= 局部极小、负定（全负）= 局部极大、不定（有正有负）= 鞍点、半定（含 0）= 需高阶判定**。
- **鞍点（saddle point）**：驻点且 Hessian 不定——某些方向是谷、另一些方向是脊；**既不是局部极小也不是局部极大**（定理 1）。
- **特征值的方向含义**：H 的每个特征值 λ 与特征向量 v 表示"沿 v 方向的二阶方向导数 = λ‖v‖²"——正特征值是谷，负特征值是脊。
- **高维鞍点压倒性多数**：局部极小要求 n 个特征值全正，概率约 (1/2)ⁿ，随维度指数级趋近 0——**高维驻点绝大多数是鞍点**。
- **鞍点海 vs 浅坑深谷**：深度学习损失面以鞍点为常态，而非二维想象里的"小坑"；应对方式截然不同（随机性晃出 vs 改变损失面）。

### 历史结论（本章涉及的史料）

- **鞍点称呼**：借自骑马的鞍（前后翘、左右垂）的形状。
- **极值分类奠基**：局部极小/极大/鞍点的二阶分类在 19 世纪极值理论中成型（黑塞、西尔维斯特等）。
- **高维认知**："鞍点在高维优化中占压倒性多数"是 20 世纪末机器学习与高维优化兴起后才被充分认识的——它是深度学习时代才被推到台前的概念，样书（用"浅坑深谷"二维可视化）在这个点上已经过时。

### 工程实践结论（本章知识在真实工程里怎么用）

- **loss 卡平，先怀疑鞍点**：高维里深坑稀有、鞍点常态，训练卡住更可能是卡在"梯度为零的马鞍"而非"掉进深坑"。
- **随机性帮你逃出鞍点**：SGD 的 mini-batch 噪声、Dropout、多起点重启、学习率热身，本质是"晃出"鞍顶，找到负特征值方向的出口。
- **对坏极小才需要改变损失面**：换损失函数、加正则、加数据——那是针对"深坑"的药，不是针对"鞍点"的药。
- **二阶方法能识别负方向**：牛顿类方法看到负特征值方向就知道能下降，但 Hessian 太大算不起，所以深度学习更多依赖噪声而非精确二阶信息。

## 计算训练场

> 位置说明：本章对话负责"为什么"，这里负责"怎么算"。**下面每题请动笔 10 分钟以上，先自己写，再对照完整解答。所有数值我都亲手验算过。**

### 题 1（易→中）：求驻点并用 Hessian 分类——三种地形的活标本

**题干**：对以下三个函数，求所有驻点（∇f = 0），用 Hessian 判定每个驻点是局部极小、局部极大还是鞍点。
(a) f₁(x, y) = x² + y²
(b) f₂(x, y) = −x² − y²
(c) f₃(x, y) = x² − y²

**完整分步解答：**

**(a) f₁ = x² + y²**：
第 1 步：∇f₁ = (2x, 2y) = 0 ⇒ 唯一驻点 **(0, 0)**。
第 2 步：二阶偏导：f_xx = 2，f_yy = 2，f_xy = 0。H = **[[2, 0], [0, 2]]**。
第 3 步：特征值：diag 矩阵特征值即对角线元素 = **2, 2**（均 > 0，正定）。
第 4 步：结论：**局部极小点**。验证 f(0,0) = 0 ≤ 任何点的 x²+y² ≥ 0。✓

**(b) f₂ = −x² − y²**：
第 5 步：∇f₂ = (−2x, −2y) = 0 ⇒ 驻点 **(0, 0)**。
第 6 步：H = **[[−2, 0], [0, −2]]**（特征值 −2, −2，均 < 0，负定）。
第 7 步：结论：**局部极大点**。验证 f(0,0) = 0 ≥ −x²−y²。✓

**(c) f₃ = x² − y²**：
第 8 步：∇f₃ = (2x, −2y) = 0 ⇒ 驻点 **(0, 0)**。
第 9 步：H = **[[2, 0], [0, −2]]**（特征值 2, −2，一正一负，不定）。
第 10 步：结论：**鞍点**——沿 x 方向（特征值 2）是谷（上弯），沿 y 方向（特征值 −2）是脊（下弯）。

**答**：(a) (0,0) 局部极小（H 特征值 2,2）；(b) (0,0) 局部极大（H 特征值 −2,−2）；(c) (0,0) 鞍点（H 特征值 2,−2 不定）。

**常见错误**：① 求 f₃ 的 f_y 时忘了"对 y 求偏导 x² 是常数、−y² 是 −2y"，把 H 的 (2,2) 项写成 +2；② 把"特征值有正有负"误判成"极小"——**鞍点不是极值**；③ 判定时忘了先确认是驻点（梯度为零），直接对非驻点套 Hessian 会出错。

### 题 2（中→难）：含两个驻点的函数——鞍点与局部极小并存

**题干**：设 f(x, y) = x³ + y³ − 3xy。
(a) 求所有驻点（解 ∇f = 0 的方程组）。
(b) 对每个驻点计算 Hessian，并判定类型。
(c) 求 f 在这两个驻点的函数值，指出哪个是全局极小（若有）。

**完整分步解答：**

**(a) 求驻点**：
第 1 步：f_x = 3x² − 3y，f_y = 3y² − 3x。令 ∇f = 0：
第 2 步：方程组 { 3x² − 3y = 0；3y² − 3x = 0 } ⇒ 化简为 { y = x²；x = y² }（除以 3）。
第 3 步：把 y = x² 代入 x = y²：x = (x²)² = x⁴ ⇒ x − x⁴ = 0 ⇒ x(1 − x³) = 0 ⇒ **x = 0 或 x = 1**。
第 4 步：x = 0 ⇒ y = 0² = 0，得驻点 **(0, 0)**；x = 1 ⇒ y = 1² = 1，得驻点 **(1, 1)**。

**(b) Hessian 与分类**：
第 5 步：二阶偏导：f_xx = 6x，f_yy = 6y，f_xy = −3。故 H(x,y) = **[[6x, −3], [−3, 6y]]**。
第 6 步：在 (0,0)：H = [[0, −3], [−3, 0]]。
第 7 步：特征值：det(H − λI) = (0−λ)(0−λ) − (−3)(−3) = λ² − 9 = 0 ⇒ **λ = ±3**（一正一负，不定）。
第 8 步：结论：**(0,0) 是鞍点**。
第 9 步：在 (1,1)：H = [[6, −3], [−3, 6]]。
第 10 步：特征值：det(H − λI) = (6−λ)² − 9 = 0 ⇒ (6−λ)² = 9 ⇒ 6−λ = ±3 ⇒ **λ = 3 或 λ = 9**（均 > 0，正定）。
第 11 步：结论：**(1,1) 是局部极小点**。

**(c) 函数值**：
第 12 步：f(0,0) = 0³ + 0³ − 3·0·0 = **0**。
第 13 步：f(1,1) = 1 + 1 − 3·1·1 = **−1**。
第 14 步：因 f(1,1) = −1 < f(0,0) = 0，且 f 是整体往下降的函数（当 |x|,|y| 大时 f 趋于 ±∞ 方向不单调，但局部极小 (1,1) 是已知最小的驻点值），**本题两个驻点中，(1,1) 的局部极小值 −1 是更低的值**。（注：f 无全局最小，因 x³、y³ 可趋于 −∞；本题只是比较两个驻点谁更低。）

**答**：(a) 驻点 (0,0) 与 (1,1)；(b) (0,0) 为鞍点（λ=±3），(1,1) 为局部极小（λ=3,9）；(c) f(0,0)=0、f(1,1)=−1，(1,1) 是更低的驻点。

**常见错误**：① 解方程组时只想到 x=0，漏掉 x=1（**要解出所有根**，x⁴−x=0 有 x=0 和 x=1 两个）；② 把 H(0,0) 的 det 算成 λ²−9=0 却写成"特征值都是 0"（漏了交叉项 (−3)²）；③ 忘了"不定 ⇒ 鞍点"，把 (0,0) 错判成极大或极小。

### 题 3（中→难）：构造高维鞍点——验证"某些方向谷、某些方向脊"

**题干**：设 f(x, y, z) = x² − y² + z²。
(a) 求驻点并写出 Hessian。
(b) 用特征值判定类型，指出它为什么是鞍点。
(c) 分别沿着坐标轴 x、y、z 方向走一小步，说明每个方向的升降（验证"谷"与"脊"交错）。
(d) 解释：为什么这样的高维鞍点在深度学习里更可能是"常态"而非"例外"（结合概率直觉）。

**完整分步解答：**

**(a) 驻点与 Hessian**：
第 1 步：∇f = (2x, −2y, 2z) = 0 ⇒ 唯一驻点 **(0, 0, 0)**。
第 2 步：二阶偏导：f_xx = 2，f_yy = −2，f_zz = 2，交叉偏导均为 0。H = **diag(2, −2, 2)**（对角矩阵）。

**(b) 类型判定**：
第 3 步：特征值即对角线元素 = **2, −2, 2**。
第 4 步：有正（2）也有负（−2），H **不定** ⇒ **(0,0,0) 是鞍点**。

**(c) 各方向升降**：
第 5 步：沿 +x 方向走 ε（即 (ε, 0, 0)）：f = ε² > 0，**上升**（x 方向是谷，特征值 2）。
第 6 步：沿 +y 方向走 ε（即 (0, ε, 0)）：f = −ε² < 0，**下降**（y 方向是脊，特征值 −2）。
第 7 步：沿 +z 方向走 ε（即 (0, 0, ε)）：f = ε² > 0，**上升**（z 方向是谷，特征值 2）。
第 8 步：验证结果：3 个坐标方向里，2 个是谷（升）、1 个是脊（降）——**"既有谷又有脊"，正是鞍点的标志**。

**(d) 高维常态解释**：
第 9 步：本例 3 维中，局部极小要求 3 个特征值全为正（概率约 (1/2)³ = 1/8）。而本例只有 1/3 的方向是脊，就已经不是极值了。
第 10 步：推广到 n 维：全部为正概率约 (1/2)ⁿ，指数级趋近 0；**只要有一个负特征值（概率极高）就是鞍点**。
第 11 步：故在几百维的深度学习损失面里，绝大多数驻点是鞍点——**"高维鞍点海"才是常态，"深坑"是稀有事件**。

**答**：(a) 驻点 (0,0,0)，H = diag(2,−2,2)；(b) 特征值 2,−2,2 不定 ⇒ 鞍点；(c) 沿 ±x 升、沿 ±y 降、沿 ±z 升（谷/脊交错）；(d) 局部极小要求 n 特征值全正，概率 (1/2)ⁿ 指数级趋 0，故高维鞍点占压倒性多数。

**常见错误**：① 把对角矩阵的特征值当成"其他值"——**对角矩阵的特征值就是对角线元素**；② 误以为"有几个方向是谷"就接近极值——**只要有一个脊（负特征值），就不可能是局部极小**；③ 概率直觉用错：是 (1/2)ⁿ 不是 (1/2)n（指数 vs 线性，区别巨大）。

## 向导便签

> 这一章咱们干了什么：从"loss 卡住是不是掉进小坑"这个问题出发，先分清'停下来'的数学含义——驻点（梯度为零）；再发现一阶信息不够，要用 Hessian 做二阶分类（正定=极小、负定=极大、不定=鞍点、半定=需高阶）；用二阶泰勒 + 反证证明"Hessian 不定 ⇒ 既非极小也非极大（鞍点）"；最后用"特征值全正概率 (1/2)ⁿ"论证**高维鞍点占压倒性多数**，并据此修正"浅坑深谷"的过时二维图景为"鞍点海"。
>
> 钉死一句话：**驻点 ≠ 极值；分类看 Hessian 特征值——全正是极小、全负是极大、有正有负是鞍点。高维里局部极小要 n 个特征值全正（概率 (1/2)ⁿ，几乎不可能），所以深度学习损失的常态是鞍点海，不是浅坑深谷。**
>
> 记住一个边界：**Hessian 半定（有零特征值）时，二阶信息不够，要看高阶项**（如 x⁴ 在 0 处是极小但 H=0）。还有，这套分类的前提是 f 二阶可微——遇到折角（ReLU）要打折。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：求驻点并分类**

设 f(x, y) = x² − y² + 4xy。
(a) 求驻点。
(b) 写出 Hessian 并判定类型（是极小、极大还是鞍点）。
(c) 指出沿哪个"主方向"是谷、哪个是脊。

**完整解答**：
(a) f_x = 2x + 4y，f_y = −2y + 4x。令 ∇f = 0：{2x + 4y = 0；4x − 2y = 0}。由第一式 x = −2y；代入第二式：4(−2y) − 2y = −10y = 0 ⇒ y = 0，x = 0。驻点 **(0, 0)**。
(b) f_xx = 2，f_yy = −2，f_xy = 4。H = **[[2, 4], [4, −2]]**。特征值：det(H−λI) = (2−λ)(−2−λ) − 16 = 0 ⇒ (2−λ)(−2−λ) = 16 ⇒ −4 −2λ +2λ + λ² = 16 ⇒ λ² − 4 = 16 ⇒ λ² = 20 ⇒ **λ = ±√20 ≈ ±4.472**。一正一负，**不定 ⇒ 鞍点**。
(c) 特征向量方向：正特征值 √20 方向是"谷"（沿它走 f 升），负特征值 −√20 方向是"脊"（沿它走 f 降）。具体：对 λ = √20，解 (H−λI)v = 0 得谷方向；对 λ = −√20 得脊方向。（方向不唯一，正交即可，本题只需说明"存在谷方向与脊方向"。）

**题 B（计算，中→难）：构造并验证高维鞍点**

设 f(x, y, z) = −x² + y² + z² − 2yz。
(a) 求驻点。
(b) 写 Hessian，用特征值判定类型。
(c) 说明这个点为什么是鞍点（既不是极小也不是极大），并指出哪个方向能下降。

**完整解答**：
(a) f_x = −2x，f_y = 2y − 2z，f_z = 2z − 2y。令 ∇f = 0：−2x = 0 ⇒ x = 0；2y − 2z = 0 ⇒ y = z；2z − 2y = 0 ⇒ z = y（与上同式）。故驻点为 **(0, t, t)**（t 为任意实数，一整条线）。取代表性驻点 (0, 0, 0)。
(b) f_xx = −2，f_yy = 2，f_zz = 2，f_yz = −2（因 −2yz 对 y 求导 −2z，再对 z 求导 −2），其余交叉为 0。H = **[[−2, 0, 0], [0, 2, −2], [0, −2, 2]]**。
特征值：对角元 −2 已是一个特征值（对应 x 方向）。剩下 2×2 块 [[2,−2],[−2,2]]：det = 2·2 − 4 = 0，trace = 4，特征值满足 λ² − 4λ + 0 = 0 ⇒ λ = 0 或 λ = 4。故**全部特征值为 −2, 0, 4**。
(c) 特征值有正（4）有负（−2），还有 0（沿 y=z 方向的"脊-谷平衡"）。含负特征值 −2 ⇒ **不是局部极小**；含正特征值 4 ⇒ **不是局部极大**。故 **(0,0,0) 是鞍点**（即便含零特征值，有正有负已定鞍点）。下降方向：沿负特征值 −2 对应的 x 方向（±x）走，f 下降（−x² 项）。

**题 C（概念，检查理解）：为什么深度学习怕马鞍不怕小坑**

(1) 从"特征值全正概率 (1/2)ⁿ"出发，解释为什么高维里鞍点占压倒性多数。
(2) 针对"卡在鞍点"与"掉进坏极小"，分别给出一种应对策略，并说明为什么策略不同。
(3) 为什么说"浅坑深谷"的二维图景在高维优化里会误导人？

**完整解答**：
(1) 局部极小要求 Hessian 所有 n 个特征值全正。若特征值符号近似独立随机，全正概率约 (1/2)ⁿ，随维度指数级趋 0。只要有一个负特征值（概率极高），该驻点就是鞍点。故高维驻点绝大多数是不定的鞍点。
(2) 卡在鞍点：用随机性（SGD 的 mini-batch 噪声、Dropout、多起点重启、学习率热身）"晃出"鞍顶，顺着负特征值方向滑下。掉进坏极小：才需要改变损失面本身（换损失函数、加正则、加数据）。**因为鞍点的"出路"（负特征值方向）本就在，只需扰动；坏极小的出路不在，只能改地形。**
(3) 二维里"所有方向都是谷"的概率（(1/2)² = 1/4）还算可观，所以"山谷里有小坑"的图景在低维勉强成立；但高维里极小概率趋 0，"坑"几乎绝迹，常态是"有谷有脊交错"的鞍点海。**用二维"深坑"图景去想象高维优化，会把"卡在鞍点"误诊成"掉进深坑"，开错药。**

## 预告

你这一章终于看清了高维地形的真相：驻点不全是坑，绝大多数是鞍点——而对付鞍点，你要靠随机性"晃"出去。

可你还留着一块没啃的硬骨头：**这一整章，你都在"无拘无束"地优化——想往哪走就往哪走。** 现实里真有这么自由吗？比如一个投资项目，钱的总量是固定的；一个资源分配问题，各资源之和有上限；一个物理系统，解必须满足守恒律——**你的变量被"锁链"拴住了，只能在某些等式或不等式划定的"路"上走。**

这时，"负梯度方向"都可能指向你不被允许的地方。**在锁链约束下找最优点，该往哪走？** 那个"锁链"的松紧，甚至能用钱和价格来理解……
