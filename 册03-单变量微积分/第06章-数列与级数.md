# 第 06 章 · 数列与级数——无穷多项相加，什么时候"有个结果"

> 本章从哪个问题出发：你在第 01-02 章学会了"变化"（导数），第 03 章拿到"平均变化率的落点"（中值定理），第 04-05 章学会了"累积"（积分）与"怎么算积分"（换元/分部）。可还有一类更"野"的求和没解决：**1 + 1/2 + 1/4 + 1/8 + … 加到无穷多项，会是什么？** 无穷多项相加，什么时候"有个结果"？什么时候"爆掉"？
> 推导到哪个结论：你会先把"无穷项相加"钉成一个严格对象——**级数 = 部分和的极限**。然后拿到一套判断"有没有结果"的判别法：**比较判别、比值判别（达朗贝尔）、根值判别（柯西）、交错级数判别（莱布尼茨）**，并分清"绝对收敛"与"条件收敛"。你会亲手证明**比值判别法与莱布尼茨交错判别**——它们是你判断千千万万个级数"敛不敛"的判官。
>
> 核心认知：**级数收敛 ⟺ 部分和数列收敛**（这是册02 的 ε-N 在"求和"上的直接套用）。而判断收敛，比值判别说"看相邻项之比能否压在 1 之下"，交错判别说"交替变号、绝对值递减到 0 就收敛"。**"无穷多项相加有没有结果"这件事，从此从"直觉"变成了"套判别法"——这是你走向幂级数与泰勒展开（下一章）的必经之路。**

## 引子

老谟在桌上排了一列硬币，第一枚下面写"1"，第二枚下面写"1/2"，第三枚"1/4"，第四枚"1/8"……一直排下去，越排越小。

"你猜，"老谟指着这一列，"**把这些硬币全部加起来，是多少？**"

"……1 + 1/2 + 1/4 + 1/8 + …，"我试着加，"1.5、1.75、1.875……**好像越来越靠近 2，但永远差那么一点？**"

"**靠近 2，但没到 2。**"老谟顿了顿，"可问题来了——**'加到无穷多项'是什么意思？你总不能真加无穷多枚硬币吧？** 而且，不是所有这样的和都有结果——**1 + 1/2 + 1/3 + 1/4 + … 你猜它会怎样？**"

我想了想："……它好像越来越大？1.5、1.833、2.083……**它好像越加越大，没有'靠近'某个数！**"

"**对。**"老谟把两列硬币并排，"一个'靠近 2'，一个'越加越大'——**同样都是无穷多项相加，为什么一个有结果、一个没有？这一章，我们就来回答：无穷多项相加，什么时候'有个结果'。**"

## 对话引擎

### 第 1 轮：无穷多项相加，凭什么"有结果"——先把"求和"钉死

**老谟**："你刚才说'1+1/2+1/4+… 靠近 2'。**那'无穷多项相加'到底是什么意思？** 你总不能把无穷多枚硬币一枚枚全加完吧？我们得把它变成'能定义'的东西。你先想想——**你实际能算的是什么？**"

**造物主**："……我能算的，是'有限多项'的和。**比如前 n 项加起来，1 + 1/2 + … + 1/2ⁿ，这是有限和，我能算。** 那'无穷多项'，是不是'有限和'随着 n 增大逼近的那个数？"

**老谟**："**你又用上了册02 的极限思想——而且是数列极限！** '有限和'随着 n 增大，本身就是一个数列（第 n 个部分和）。**'无穷多项相加的和'，就是这个'部分和数列'的极限。** 这个'部分和的极限'，数学里就叫**级数的和**。**你发现没有——'无穷项求和'这个吓人的东西，被你拆成了'部分和数列的极限'，而数列极限你在册02 已经会用 ε-N 写死了。**"

**造物主**："……所以'级数收敛'，就是'部分和数列收敛'，即**存在一个有限的极限 S，让部分和数列 Sₙ → S**。收敛不了，就是发散。**我没在'加无穷多项'，我在'看部分和数列逼近谁'！**"

### 📐 知识锚点：级数的严格定义——"部分和的极限"
<blockquote style="background:#fff8e1">

【概念深挖】**级数（series）**：给定数列 {aₙ}，称 **Σₙ₌₁^∞ aₙ** 为级数。定义其**部分和（partial sum）**：
$$S_n = a_1 + a_2 + \cdots + a_n = \sum_{k=1}^{n} a_k.$$
- **级数收敛（converge）**：若部分和数列 {Sₙ} 收敛于某个有限数 S（即 limₙ→∞ Sₙ = S），则称级数收敛于 S，记 Σₙ₌₁^∞ aₙ = S。
- **级数发散（diverge）**：若 {Sₙ} 发散（极限不存在或为无穷），则称级数发散。
- **核心**：**"无穷项相加" = "部分和数列的极限"**——你在册02 用 ε-N 写的"数列收敛"，原样搬到"部分和数列"上。

**关键例子**（本章的"基准"）：
- **几何级数** Σₙ₌₀^∞ rⁿ：收敛当且仅当 |r|<1，和为 1/(1−r)。（1+1/2+1/4+…=2 ✓。）
- **调和级数** Σₙ₌₁^∞ 1/n：**发散**（部分和 Sₙ≈ln n →∞）。这"看似项趋 0 却发散"是初学最大的反直觉。
- **p-级数** Σₙ₌₁^∞ 1/nᵖ：收敛当且仅当 p>1。

【工程实践】"无穷项相加"在工程里处处是"逼近"：**数值积分把连续区域切无数片相加、滤波器的卷积是级数/积分、机器学习里期望是分布下的求和/积分**。**工程里没有真正的"无穷"，只有"加到误差可接受的那一项"**——这和你册02 的"浮点逼近"是同一种味道：真身在极限，工程拿够近的替身。
</blockquote>

### 第 2 轮：项趋 0 够吗——调和级数的"反直觉陷阱"

**老谟**："先说一个几乎人人都会踩的坑。**你看调和级数 1 + 1/2 + 1/3 + …，它的每一项 1/n → 0。** 直觉上"项都趋 0 了，和应该有结果吧"？可你刚才自己算过——**它越加越大，没有结果。** 所以：**'项趋 0'能保证级数收敛吗？**"

**造物主**："……不能？**调和级数项趋 0 但发散了。** 那'项趋 0'到底够不够？"

**老谟**："**项趋 0 是收敛的'必要条件'，不是'充分条件'。** 也就是说：如果级数收敛，那项一定趋 0（因为部分和有极限，相邻项之差 aₙ=Sₙ−Sₙ₋₁→0）；**但项趋 0 不代表级数收敛**——调和级数就是反例。**那调和级数到底为什么发散？** 我提示你一个'分桶'的想法：把它按 2 的幂分组，1 + (1/2) + (1/3+1/4) + (1/5+…+1/8) + …，**每一桶里有多少项、每项多大，你能估出来吗？**"

**造物主**："……第 k 桶是从 1/(2ᵏ⁻¹+1) 到 1/2ᵏ，共 2ᵏ⁻¹ 项，每一项 ≥ 1/2ᵏ（因为分母 ≤2ᵏ）。**所以第 k 桶的和 ≥ 2ᵏ⁻¹ × 1/2ᵏ = 1/2。** 每一桶都至少 1/2，无限多桶，那总和就……爆了！"

**老谟**："**你抓住调和级数发散的本质了——'分桶'每组至少贡献固定量（1/2），无限多组就无限大。** 这个'分桶下界'思路，正是后面'积分判别'和'比较判别'的雏形。完整证明放走廊。下一轮，我们把'判别收敛'系统化成几条好用的准则。"

### 📐 知识锚点：项趋 0 的必要性与调和级数发散
<blockquote style="background:#e3f2fd">

【概念深挖】**项测试（term test，必要条件）**：若级数 Σaₙ 收敛，则 limₙ→∞ aₙ = 0。
- 证明：aₙ = Sₙ − Sₙ₋₁，若 Sₙ→S，则 aₙ→S−S=0。
- **注意方向**：项趋 0 是**必要**条件。**项不趋 0 ⟹ 级数一定发散**（很好用）；但项趋 0 **不保证**收敛（调和级数反例）。
- **调和级数发散（分桶证明，奥雷姆约 1350）**：
  1 + (1/2) + (1/3+1/4) + (1/5+…+1/8) + …，第 k 桶（2ᵏ⁻¹+1 到 2ᵏ）有 2ᵏ⁻¹ 项、每项 ≥1/2ᵏ，故每桶和 ≥ 1/2。无限桶 ⟹ 部分和→∞，发散。

**p-级数** Σ1/nᵖ：p>1 收敛、p≤1 发散（p=1 即调和，p<1 项比调和还大）。**这是'比较判别'的第一个基准。**

【历史溯源】调和级数发散，**早在奥雷姆（Nicholas Oresme，约 1350）**就用"分桶"证出来了——比微积分早了三百多年。**而'项趋 0 却不收敛'的反直觉，让一代代学生栽跟头**：它提醒你，"无穷和"不是"有限和的自然延伸"，必须回到"部分和的极限"。
</blockquote>

### 第 3 轮：怎么判断收敛——从"和已知的级数比大小"入手

**老谟**："项趋 0 不够用。那我们怎么判断一个级数收敛不收敛？**最朴素的想法：拿它和'已知收敛/发散'的级数比。** 比如 Σ1/n² 收敛（p=2>1），那如果有个级数每一项都 ≤ 1/n²，它是不是也收敛？反过来，如果一个级数每一项都 ≥ 调和级数的项，它是不是也发散？"

**造物主**："……**如果 0 ≤ aₙ ≤ bₙ，且 Σbₙ 收敛，那 Σaₙ 也收敛**（部分和 a 的 ≤ 部分和 b 的，b 的部分和有界 ⟹ a 的也有界）；**如果 aₙ ≥ bₙ ≥ 0 且 Σbₙ 发散，那 Σaₙ 也发散**。这个'跟已知的比'，就是比较判别？"

**老谟**："**对，这就是比较判别法（comparison test）——拿未知级数跟已知的'基准'（几何级数、p-级数）比大小。** 它是所有判别法里最'直觉'的一个，也是后面比值/根值判别的'地基'。下一轮，我们看一个更'机械'的判别——比值判别：不看项本身，看'相邻两项之比'。"

### 📐 知识锚点：比较判别法——"跟已知的比大小"
<blockquote style="background:#fff8e1">

【概念深挖】**比较判别法（comparison test）**：设 0 ≤ aₙ ≤ bₙ（对充分大的 n）。
- **收敛方向**：若 Σbₙ 收敛，则 Σaₙ 收敛。
- **发散方向**：若 Σaₙ 发散，则 Σbₙ 发散。
- **依据**：部分和数列单调有界（a 的部分和 ≤ b 的部分和，b 的有界 ⟹ a 的有界；册02 的"单调有界必收敛"由完备性保证）。

**常用"基准"**（判断时先想到它们）：
- 几何级数 Σrⁿ（|r|<1 收敛）；
- p-级数 Σ1/nᵖ（p>1 收敛、p≤1 发散）；
- 调和级数 Σ1/n（发散）。

**极限形式的比较**：若 lim aₙ/bₙ = c（0<c<∞），则 Σaₙ 与 Σbₙ 同敛散。**这让你可以"用主导项比较"**——比如 Σ(n²+1)/(n⁴+2) 与 Σ1/n² 同敛散（极限比 1）。

> **跨章衔接（积分判别）**：这套"部分和单调 + 有界 ⟹ 收敛"的思路，正是**后面积分判别与 Ch4 定积分的接缝**——把"通项求和"想成"面积累积"，就是**积分判别（integral test）的雏形**：Σaₙ 与 ∫f(x)dx 同敛散（当 aₙ=f(n) 且 f 单调递减非负）。**你在 Ch4 把"累积"讲成黎曼和的极限，这里把"求和"讲成部分和的极限——两者在"把离散求和看成连续面积累积"这一点上接上了头。**

【工程实践】"跟已知的比"是工程里估界的通用思维：**算法复杂度估界（大 O）、误差累积估界，都是"拿未知量跟已知可控制上界的量比"**。比较判别把这种"比大小估界"落成了严格的收敛判据。
</blockquote>

### 第 4 轮：比值判别——看"相邻项之比"能不能压住 1

**老谟**："比较判别要'找到合适的基准'，有时候不容易。**有没有一种更'机械'的判别？** 你想想——几何级数 Σrⁿ 什么时候收敛？"

**造物主**："……|r|<1 时收敛。**几何级数的相邻项之比，就是 r，恒定不变。** 那如果某个级数'相邻项之比'越来越小、最终 <1，它是不是就像几何级数一样收敛？"

**老谟**："**你摸到比值判别的核心了：把一般级数'和几何级数比'——看相邻项之比 |aₙ₊₁/aₙ| 的极限 L。** 如果 L<1，说明项最终按几何级数的速度衰减（比 r<1 的几何级数还快），收敛；如果 L>1，说明项最终按几何级数增长，发散。**这个比值判别的完整证明，要靠'把项夹成几何级数'——用比较判别收尾。** 完整证明放走廊定理 1。下一轮，我们看根值判别和'交错'这种特殊的级数。"

### 📐 知识锚点：比值判别法（达朗贝尔）与根值判别法（柯西）
<blockquote style="background:#e3f2fd">

【概念深挖】**比值判别法（ratio test，达朗贝尔）**：设 aₙ≠0，令 L = limₙ→∞ |aₙ₊₁/aₙ|。
- **L<1**：级数绝对收敛（项最终被夹在几何级数之下）。
- **L>1**：级数发散（项最终按几何级数增长，项不趋 0）。
- **L=1**：**无法判断**（需换别的方法）。

**根值判别法（root test，柯西）**：令 L = limₙ→∞ ⁿ√|aₙ|。
- **L<1**：收敛；**L>1**：发散；**L=1**：无法判断。

**两者同源**：都是"跟几何级数比"——看项能否最终被 r<1 的几何级数夹住。**比值用相邻项比，根值用 n 次根**；对含 n! 或含 nⁿ 的级数，比值更顺手；对含 n 次幂的级数，根值更顺手。

【历史溯源】**让·勒朗·达朗贝尔（Jean le Rond d'Alembert，1768）**提出比值判别；**柯西（Cauchy，1821）**提出根值判别并把它们建立在极限严格定义上。**它们把"判断级数收敛"从"逐项猜"变成"看一个极限"**——比值/根值，是级数判别的两大主力。
</blockquote>

### 第 5 轮：交错级数——"正负交替"反而更好判断

**老谟**："以上都是'非负项'的级数。**可现实中常有'正负交替'的级数**，比如 1 − 1/2 + 1/3 − 1/4 + …（这就是 Σ(−1)ⁿ⁺¹/n）。**它每一项的绝对值 1/n → 0，但它是'交替变号'的。** 你猜它收敛吗？"

**造物主**："……它好像是在 0.5 附近上下摆？1、0.5、0.833、0.583……**越来越收敛到一个数？** 可它绝对值加起来的 Σ1/n 是发散的（调和）。**它收敛但不绝对收敛？**"

**老谟**："**对——这就是'条件收敛'：级数本身收敛，但它的绝对值级数发散。** 而判断'正负交替'这种级数，有一条很美的准则——**莱布尼茨交错判别：如果各项绝对值 aₙ 递减且趋 0，则交错级数 Σ(−1)ⁿ⁺¹aₙ 收敛。** 它靠的是'部分和上下摆、摆幅越来越小、最终夹出一个极限'。**完整证明在走廊定理 2。** 下一轮，我们把'绝对收敛 vs 条件收敛'这个重要区别钉死。"

### 📐 知识锚点：绝对收敛 vs 条件收敛
<blockquote style="background:#fff8e1">

【概念深挖】**绝对收敛（absolutely convergent）**：若 Σ|aₙ| 收敛，则称 Σaₙ 绝对收敛。
- **关键定理**：若 Σaₙ 绝对收敛，则 Σaₙ 收敛。**（绝对收敛 ⟹ 收敛。）**

**条件收敛（conditionally convergent）**：若 Σaₙ 收敛但 Σ|aₙ| 发散，则称 Σaₙ 条件收敛。
- 例：Σ(−1)ⁿ⁺¹/n 条件收敛（收敛但 Σ1/n 发散）。

**为什么要分清**：
- 绝对收敛的级数，可以任意重排而不改变和（"无条件收敛"）。
- 条件收敛的级数，**重排可能改变和，甚至发散**（黎曼重排定理）——"和"依赖项的顺序，非常脆弱。
- **收敛性分三档**：绝对收敛 ⊂ 收敛 ⊂ （发散之外）；条件收敛是"收敛但脆弱"的那档。

【历史溯源】**"绝对收敛 ⟹ 收敛"**由柯西等严格确立；**黎曼（Riemann）**进一步发现条件收敛级数可重排成任意值甚至发散（黎曼重排定理），揭示"条件收敛"的脆弱性。**分清绝对/条件收敛，是判断级数性质的第一步。**
</blockquote>

### 第 6 轮：落点——"无穷项相加"从此有了一套判官

**老谟**："把这章收一遍。你最初只会'直觉'地说'1+1/2+1/4+… 靠近 2'，现在你会怎么严格说？"

**造物主**："……我会说：**级数收敛 = 部分和数列收敛**（册02 的 ε-N 套在 Sₙ 上）。然后判断敛散有几条准则：**比较**（跟几何/p-级数比）、**比值**（看相邻项之比极限 L）、**根值**（看 ⁿ√|aₙ|）、**交错**（Leibniz：绝对值递减趋 0）。还要分清**绝对收敛**（Σ|aₙ| 收敛）与**条件收敛**（收敛但 Σ|aₙ| 发散）。"

**老谟**："**这一章，你从'直觉求和'走到了'套判别法'——无穷多项相加有没有结果，从'感觉'变成了'可验证的准则'。** 而这套判别法，是下一章的入场券：**幂级数与泰勒展开**——把函数写成'无穷多项的和'，那个'和'什么时候有意义（收敛半径），就要靠你这一章的判别法来钉死。**你准备好把这套判官用到'函数级数'上了吗？**"

**造物主**："……准备好了。无穷多项相加，我有判官了。"

## 严格化走廊

> 位置说明：对话负责"直觉"——为什么级数=部分和的极限、为什么项趋 0 不够、为什么比值/交错判别成立。本走廊负责"严谨"——把级数收敛、绝对/条件收敛、判别法落成精确形式，并给出本册最核心的两个**完整可复写**证明：**比值判别法（定理 1，用几何级数比较 + 项测试）**、**莱布尼茨交错级数判别（定理 2，用部分和上下摆 + 单调有界）**。每个证明都标注"证明类型 + 每一步依据"，这是红线 1 的硬要求。

### 定义：级数收敛、绝对收敛、条件收敛（精确表述）

设 {aₙ} 为数列，部分和 Sₙ = a₁+⋯+aₙ。
- **级数收敛于 S**：limₙ→∞ Sₙ = S（S 有限）。此时记 Σₙ₌₁^∞ aₙ = S。
- **绝对收敛**：Σ|aₙ| 收敛。
- **条件收敛**：Σaₙ 收敛，但 Σ|aₙ| 发散。
- **级数收敛（ε-N 表述，衔接册02）**：级数 Σaₙ 收敛于 S ⟺ 对任意 ε>0，存在 N，当 n>N 时 |Sₙ − S|<ε。**这是册02 数列极限定义在"部分和数列"上的直接套用。**

> **证明类型标注**：本章的核心证明——**定理 1（比值判别法）用直接证明（几何级数比较 + 项测试）**；**定理 2（莱布尼茨交错判别）用直接证明（部分和上下摆 + 单调有界收敛准则，册02 完备性）**。调和级数发散（引理 1）用"分桶"直接证明（奥雷姆）。都承接册02 的 ε-N 语言与"单调有界必收敛"。
>
> **关于对话**：本章第 4、5 轮是读者**第一次**正式接触"比值判别""交错判别"的证明，对话做了"引导式推导"（为什么想到"跟几何级数比"、为什么交错级数"上下摆能夹出极限"）。**正式的可复写证明（每一步标依据）在本走廊定理 1、2**。对话负责"为什么会想到这步"，走廊负责"怎么把它写标准"——与册03 前五章口径一致。

### 引理 1（调和级数发散）：Σₙ₌₁^∞ 1/n 发散

**前提**：无（直接由定义）。

**证明类型**：直接证明（分桶下界，奥雷姆）。

**证明**：
- 第 1 步：把部分和按 2 的幂分桶：
  $$S_{2^m} = 1 + \frac12 + \left(\frac13+\frac14\right) + \left(\frac15+\cdots+\frac18\right) + \cdots + \left(\frac{1}{2^{m-1}+1}+\cdots+\frac{1}{2^m}\right).$$
  （依据：把部分和分成 m+1 组，第 0 桶 {1}、第 1 桶 {1/2}、第 2 桶 {1/3,1/4}、…、第 k 桶 {1/(2ᵏ⁻¹+1),…,1/2ᵏ}。）
- 第 2 步：**每桶下界**：第 k 桶有 2ᵏ⁻¹ 项，每项 ≥ 1/2ᵏ（因分母 ≤2ᵏ），故第 k 桶和 ≥ 2ᵏ⁻¹·(1/2ᵏ) = 1/2。（依据：项数 × 每项最小值的代数。）
- 第 3 步：于是 S_{2^m} ≥ 1 + (1/2)·m（第 1 桶起，m 个桶各 ≥1/2）。当 m→∞，S_{2^m}→∞。（依据：累加下界。）
- 第 4 步：部分和 {Sₙ} 无上界（取 n=2ᵐ 就超过任意大），故 {Sₙ} 发散。**Σ1/n 发散。**∎

> **依据标注**：步 1 用分桶（奥雷姆构造）；步 2 用"每桶项数 × 每项下界"；步 3 用累加（m 桶各 ≥1/2）；步 4 用"部分和无上界 ⟹ 发散"（若收敛则部分和有界，逆否）。
> **读法**：调和级数发散的钥匙是"分桶"——**把项按 2 的幂分组，每组至少贡献固定的 1/2**。这个"分桶下界"是后面积分判别的雏形。

### 定理 1（比值判别法）：设 aₙ≠0，L = limₙ→∞ |aₙ₊₁/aₙ|。若 L<1 则 Σaₙ 绝对收敛；若 L>1 则 Σaₙ 发散；若 L=1 则无法判断。

**前提**：aₙ≠0（比值有意义）；极限 L = lim |aₙ₊₁/aₙ| 存在（允许 =+∞，此时视为发散）。

**证明类型**：直接证明（几何级数比较 + 项测试）。

**证明（L<1 情形，绝对收敛）**：
- 第 1 步：**选 r 满足 L<r<1**（因为 L<1，可找到这样的 r）。（依据：L<1。）
- 第 2 步：由极限定义，对 r−L>0，存在 N，当 n≥N 时 |aₙ₊₁/aₙ| < r。（依据：比值极限 = L < r，故最终比值 < r。）
- 第 3 步：**用几何级数夹住**：对 n≥N，
  $$|a_n| < r|a_{n-1}| < r^2|a_{n-2}| < \cdots < r^{n-N}|a_N|.$$
  （依据：反复用第 2 步的不等式递推。由第 2 步 |aₙ₊₁/aₙ|<r ⟹ |aₙ₊₁|<r|aₙ|，一路乘下来。）
- 第 4 步：于是对 n≥N，|aₙ| < |a_N|·r^{n−N}。而几何级数 Σ r^{n−N}（公比 r<1）收敛。（依据：几何级数收敛 ⟺ |r|<1。）
- 第 5 步：由比较判别法（0≤|aₙ|≤|a_N|r^{n−N} 且 Σr^{n−N} 收敛），Σ|aₙ| 收敛，即 **Σaₙ 绝对收敛**。（依据：比较判别，收敛方向。）
- 第 6 步：**L>1 情形**：选 r 满足 1<r<L，由极限定义存在 N，当 n≥N 时 |aₙ₊₁/aₙ|>r>1，故 |aₙ| ≥ |a_N|·r^{n−N}→∞，项不趋 0。由项测试，**Σaₙ 发散**。（依据：项测试——项不趋 0 ⟹ 发散。）
- 第 7 步：**L=1 情形**：无法判断（见反例/边界——调和 Σ1/n 发散、Σ1/n² 收敛，两者比值极限都=1）。∎

> **依据标注**：步 1 用 L<1 取 r；步 2 用比值极限定义（最终比值<r）；步 3 用递推不等式；步 4 用几何级数收敛准则；步 5 用比较判别（收敛方向）；步 6 用项测试；步 7 用反例说明 L=1 无法判断。
> **读法**：比值判别的灵魂是第 3 步——**"把 |aₙ| 反复放大，夹进一个公比 r<1 的几何级数"**，然后交给比较判别收尾。**它把"级数收敛"归结为"看相邻项之比能否最终压到 1 之下"**。L=1 无法判断，是因为调和（发散）和 Σ1/n²（收敛）的比值极限都是 1——**L=1 时信息不够，要换方法。**

### 定理 2（莱布尼茨交错级数判别）：若 aₙ>0、{aₙ} 单调递减、且 lim aₙ=0，则 Σₙ₌₁^∞ (−1)ⁿ⁺¹ aₙ 收敛

**前提**：aₙ>0，{aₙ} 单调递减（aₙ≥aₙ₊₁），lim aₙ=0。

**证明类型**：直接证明（部分和上下摆 + 单调有界收敛准则，册02 完备性）。

**证明**：
- 第 1 步：**写部分和**：Sₙ = a₁ − a₂ + a₃ − a₄ + … + (−1)ⁿ⁺¹ aₙ。（依据：交错级数定义。）
- 第 2 步：**看偶数部分和**：S₂ₙ = (a₁−a₂) + (a₃−a₄) + … + (a₂ₙ₋₁−a₂ₙ)。因 aₙ 递减，每个括号 a₂ₖ₋₁−a₂ₖ ≥0，故 S₂ₙ **单调递增**。（依据：递减性 ⟹ 括号非负。）
- 第 3 步：**偶数部分和上有界**：S₂ₙ = a₁ − (a₂−a₃) − (a₄−a₅) − … − (a₂ₙ₋₂−a₂ₙ₋₁) − a₂ₙ ≤ a₁（各括号 ≥0）。故 {S₂ₙ} 递增且有上界 a₁。（依据：改写 + 递减性。）
- 第 4 步：由**单调有界收敛准则**（册02 完备性），{S₂ₙ} 收敛，记 lim S₂ₙ = L。（依据：单调有界必收敛。）
- 第 5 步：**看奇数部分和**：S₂ₙ₋₁ = S₂ₙ + a₂ₙ。因 a₂ₙ→0（前提），lim S₂ₙ₋₁ = lim(S₂ₙ + a₂ₙ) = L + 0 = L。（依据：极限加法 + lim a₂ₙ=0。）
- 第 6 步：偶数部分和 S₂ₙ→L、奇数部分和 S₂ₙ₋₁→L，故整个部分和数列 {Sₙ} 收敛于 L。（依据：偶数/奇数子列同极限 ⟹ 整列收敛。）
- 第 7 步：由级数收敛定义，**Σ(−1)ⁿ⁺¹ aₙ 收敛**。∎

> **依据标注**：步 1 用交错级数定义；步 2 用递减性（括号非负 ⟹ 单调）；步 3 用改写与递减性（有上界）；步 4 用单调有界收敛准则（册02 完备性）；步 5 用极限加法 + 前提 lim aₙ=0；步 6 用"偶/奇子列同极限 ⟹ 整列收敛"；步 7 用级数收敛定义。
> **读法**：莱布尼茨判别的灵魂是"**部分和上下摆、摆幅越来越小**"——偶数部分和单调递增被 a₁ 卡住（收敛到 L），奇数部分和比偶数部分和多个 a₂ₙ（也趋 L）。**它用册02 的"单调有界必收敛"抓住了一头，再用"摆动尾巴 a₂ₙ→0"接上另一头**。注意它只判"收敛"，不判"绝对收敛"——交错级数常常只是条件收敛。

### 级数判别的书写格式模板（可复写卡片——对着空白纸照写）

> 这是本章要你抄进脑子的卡。**以后你判断任意级数 Σaₙ 敛散，就照这个决策树走**：

```text
命题：判断 Σaₙ 的敛散。
判别决策树：
  0. 先看 lim aₙ 是否 = 0？不趋 0 → 项测试，直接判发散。
  1. 是否非负项（或取绝对值看）？
     - 是：先试 比较判别（跟几何级数 Σrⁿ / p-级数 Σ1/nᵖ 比）。
           再试 比值判别（L=lim|aₙ₊₁/aₙ|：L<1 收敛、L>1 发散、L=1 再试别的）。
           或 根值判别（L=lim ⁿ√|aₙ|：同样判法）。
     - 否（交替变号）：用 莱布尼茨交错判别（|aₙ|递减且→0 ⟹ 收敛）。
  2. 判断是否绝对收敛：Σ|aₙ| 收敛吗？收敛=绝对收敛；仅 Σaₙ 收敛而 Σ|aₙ|发散=条件收敛。
  3. 收束：写出"收敛/绝对收敛/条件收敛/发散"及依据。∎
```

**填写时的三个检查点**：① **先看项是否趋 0**（项不趋 0 直接发散，别浪费时间）；② **比值/根值 L=1 时换方法**（调和发散、Σ1/n² 收敛都 L=1，不能下结论）；③ **交错级数用莱布尼茨，别硬套比值**。

### 反例/边界：级数判别的适用边界

1. **项趋 0 不保证收敛**：调和级数 Σ1/n 项趋 0 但发散。**"项趋 0"只是必要条件。**
2. **比值/根值 L=1 无法判断**：Σ1/n（发散）和 Σ1/n²（收敛）比值极限都=1。**L=1 时信息不够，换比较/积分判别。**
3. **比较判别要求非负项**：对含负项的级数不能直接比大小，要先取绝对值或转成交错级数判断。
4. **条件收敛级数"脆弱"**：Σ(−1)ⁿ⁺¹/n 收敛但重排可改变和（黎曼重排定理）。**别对条件收敛级数随意重排。**
5. **交错判别只判"收敛"不判"绝对值"**：莱布尼茨给的是收敛（可能只是条件收敛），不能误认为绝对收敛。

## 知识点总结

### 知识点（本章推出的核心概念）

- **级数 = 部分和的极限**：Σaₙ = S ⟺ Sₙ=a₁+⋯+aₙ → S。**"无穷项相加"拆成"部分和数列的极限"（册02 ε-N 套用）。**
- **项测试（必要条件）**：级数收敛 ⟹ 项趋 0；但项趋 0 不保证收敛（调和级数反例）。
- **调和级数发散（分桶）**：每桶至少 1/2，无限桶 ⟹ 发散（奥雷姆）。
- **几何级数** Σrⁿ：|r|<1 收敛，和=1/(1−r)；**p-级数** Σ1/nᵖ：p>1 收敛。
- **比较判别**：0≤aₙ≤bₙ，Σbₙ 收敛 ⟹ Σaₙ 收敛；aₙ≥bₙ 且 Σbₙ 发散 ⟹ Σaₙ 发散。
- **比值判别（达朗贝尔）**：L=lim|aₙ₊₁/aₙ|<1 收敛、>1 发散、=1 无法判断。
- **根值判别（柯西）**：L=lim ⁿ√|aₙ|<1 收敛、>1 发散、=1 无法判断。
- **交错级数判别（莱布尼茨）**：|aₙ|递减且→0 ⟹ Σ(−1)ⁿ⁺¹aₙ 收敛。
- **绝对 vs 条件收敛**：绝对收敛（Σ|aₙ|收敛）⟹ 收敛；条件收敛=收敛但 Σ|aₙ|发散（脆弱，重排可变和）。

### 历史结论（本章涉及的史料）

- **奥雷姆（约 1350）**：分桶证明调和级数发散，比微积分早三百多年。
- **达朗贝尔（1768）**：提出比值判别。
- **柯西（1821）**：提出根值判别，并用极限严格定义建立级数理论。
- **莱布尼茨（Leibniz）**：给出交错级数判别（莱布尼茨判别）。
- **黎曼（Riemann）**：重排定理揭示条件收敛级数的脆弱性（重排可变和甚至发散）。

### 工程实践结论（本章知识在真实工程里怎么用）

- **"无穷相加=部分和的极限"= 数值逼近**：数值积分、卷积、期望计算都是"加到误差可接受"，与"部分和的极限"同构。
- **比值/根值判别 = 收敛速度判断**：算法/迭代收敛速度常由相邻项之比（比值）或 n 次根（根值）决定——比值<1 说明几何收敛。
- **条件收敛的脆弱性 = 数值稳定性警示**：依赖项顺序的和（条件收敛）在数值计算里不稳定，可能因舍入/重排改变结果。
- **判别决策树 = 调试/分析流程**：先看项趋 0、再选判别法，与工程"先排除 trivial 情况、再选工具"的分析流程同构。

## 计算训练场

> 位置说明：对话负责"为什么级数=部分和的极限、为什么判别法成立"，这里负责"怎么判"。下面三题**必须动笔**，每题 10 分钟以上，先自己写再对答案。**难度递进：易→中→难。** 重点是"判断 6 个级数敛散（逐题写判别依据）+ 含参级数条件收敛区间"。

### 题 1（易→中）：判断 4 个级数敛散——几何/调和/p-级数/比较

**题干**：老谟给了四个级数，让造物主逐个判断敛散并写出判别依据：
(a) Σₙ₌₀^∞ (1/2)ⁿ；(b) Σₙ₌₁^∞ 1/n；(c) Σₙ₌₁^∞ 1/n²；(d) Σₙ₌₁^∞ 1/√n。

**完整分步解答：**

**(a) Σ (1/2)ⁿ**：几何级数，公比 r=1/2，|r|<1 ⟹ **收敛**。和为 1/(1−1/2)=**2**。
**(b) Σ 1/n**：调和级数，**发散**（分桶：每桶 ≥1/2，无限桶 ⟹ 部分和→∞）。
**(c) Σ 1/n²**：p-级数，p=2>1 ⟹ **收敛**。
**(d) Σ 1/√n**：p-级数，p=1/2<1 ⟹ **发散**（项比调和级数还大）。

**答**：(a) 收敛(=2)；(b) 发散；(c) 收敛；(d) 发散。

**常见错误**：① 把 (c) Σ1/n² 当成"调和"——p=2>1 收敛，别和 p=1 的调和混；② 把 (d) Σ1/√n 当成收敛（以为分母带根号就小）——p=1/2<1 发散；③ (a) 几何级数忘条件 |r|<1（r=1/2 满足才收敛）。

### 题 2（中）：用比值/根值判别 3 个级数

**题干**：老谟给了三个级数，让造物主用比值或根值判别判断敛散：
(a) Σₙ₌₁^∞ n²/2ⁿ；(b) Σₙ₌₁^∞ 2ⁿ/n!；(c) Σₙ₌₁^∞ (n/(2n+1))ⁿ。

**完整分步解答：**

**(a) Σ n²/2ⁿ（比值）**：
- 第 1 步：|aₙ₊₁/aₙ| = [(n+1)²/2ⁿ⁺¹] ÷ [n²/2ⁿ] = ((n+1)²/n²)·(1/2) = ((n+1)/n)²·(1/2)。
- 第 2 步：lim = (1)²·(1/2) = **1/2 < 1**。
- 第 3 步：比值 L=1/2<1 ⟹ **收敛**（绝对收敛）。

**(b) Σ 2ⁿ/n!（比值）**：
- 第 1 步：|aₙ₊₁/aₙ| = [2ⁿ⁺¹/(n+1)!] ÷ [2ⁿ/n!] = 2·n!/(n+1)! = 2/(n+1)。
- 第 2 步：lim 2/(n+1) = **0 < 1**。
- 第 3 步：比值 L=0<1 ⟹ **收敛**（绝对收敛）。

**(c) Σ (n/(2n+1))ⁿ（根值）**：
- 第 1 步：ⁿ√|aₙ| = n/(2n+1)。
- 第 2 步：lim n/(2n+1) = lim 1/(2+1/n) = **1/2 < 1**。
- 第 3 步：根值 L=1/2<1 ⟹ **收敛**（绝对收敛）。

**答**：(a)(b)(c) 都收敛（比值/根值 L 均 <1）。

**常见错误**：① (a) 比值化简错——((n+1)/n)²·(1/2) 的极限是 1/2，别算成 2 或漏除 2；② (b) 把 n!/(n+1)! 化简错——=1/(n+1)，不是 1/n；③ (c) 用比值硬算可能麻烦——含 (…)^n 用根值更顺。

### 题 3（难）：含参级数条件收敛区间 + 交错级数

**题干**：老谟让造物主完成两个任务：
(a) 讨论幂级数 Σₙ₌₁^∞ xⁿ/n 的收敛区间（哪些 x 收敛、绝对收敛、条件收敛）。
(b) 判断 Σₙ₌₁^∞ (−1)ⁿ⁺¹/n 的敛散，并说明它是绝对收敛还是条件收敛。

**完整分步解答：**

**(a) Σ xⁿ/n 的收敛区间**：
- 第 1 步：**用比值判别（对固定 x）**：|aₙ₊₁/aₙ| = |x|ⁿ⁺¹/(n+1) · n/|x|ⁿ = |x|·n/(n+1) → |x|·1 = **|x|**。
- 第 2 步：比值 L=|x|。由比值判别：**|x|<1 时绝对收敛；|x|>1 时发散**。
- 第 3 步：**讨论端点 x=±1**：
  - x=1：Σ1/n 是调和级数，**发散**。
  - x=−1：Σ(−1)ⁿ/n，交错级数，|1/n|递减且→0，由莱布尼茨判别**收敛**（但 Σ|−1|ⁿ/n=Σ1/n 发散，故**条件收敛**）。
- 第 4 步：**收敛区间**：(−1,1) 内绝对收敛；x=−1 处条件收敛；x=1 处发散。
- **答 (a)**：收敛区间为 [−1,1)（x∈(−1,1) 绝对收敛，x=−1 条件收敛，x=1 发散）。**收敛半径 R=1。**

**(b) Σ(−1)ⁿ⁺¹/n**：
- 第 1 步：aₙ=1/n，aₙ>0、单调递减（1/n ≥ 1/(n+1)）、lim 1/n=0。（依据：单调性 + 极限。）
- 第 2 步：由莱布尼茨交错判别，**Σ(−1)ⁿ⁺¹/n 收敛**。
- 第 3 步：绝对值级数 Σ1/n 是调和级数，**发散**。故原级数收敛但不绝对收敛。
- **答 (b)**：收敛，且是**条件收敛**（收敛但 Σ|·|=Σ1/n 发散）。

**常见错误**：① (a) 只算比值得出 |x|<1 就收手，忘了讨论端点 x=±1（端点常需单独用交错/调和判断）；② (a) x=1 时误判收敛（Σ1/n 是发散调和，不是收敛）；③ (b) 说"绝对收敛"——Σ1/n 发散，只能是条件收敛。

**顿悟时刻**：

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：判断敛散**

判断下列级数敛散并写依据：
(a) Σₙ₌₁^∞ 1/3ⁿ；(b) Σₙ₌₁^∞ (−1)ⁿ⁺¹/√n；(c) Σₙ₌₁^∞ n/(n²+1)。

**完整解答**：
(a) 几何级数 r=1/3<1，**收敛**，和=1/(1−1/3)=**3/2**。
(b) 交错级数，|1/√n|递减且→0，由莱布尼茨**收敛**；但 Σ1/√n（p=1/2<1）发散，故**条件收敛**。
(c) 比较：n/(n²+1) ≤ n/n²=1/n，但 Σ1/n 发散，**上界不够**。改用极限比较：n/(n²+1) ÷ (1/n) = n²/(n²+1)→1，故与调和 Σ1/n **同敛散**，**发散**。

**题 B（计算，中→难）：比值/根值 + 收敛区间**

(a) 用比值判别判断 Σₙ₌₁^∞ nⁿ/n! 的敛散；(b) 讨论 Σₙ₌₁^∞ xⁿ/n² 的收敛区间（含端点）。

**完整解答**：
(a) |aₙ₊₁/aₙ| = (n+1)ⁿ⁺¹/(n+1)! · n!/nⁿ = ((n+1)/n)ⁿ = (1+1/n)ⁿ → e>1。比值 L=e>1 ⟹ **发散**。（注：这里用到已知常数极限 limₙ→∞(1+1/n)ⁿ = e，本书视为已知基准——它是自然常数 e 的经典定义之一。）
(b) 比值：|aₙ₊₁/aₙ|=|x|·n²/(n+1)² → |x|。|x|<1 绝对收敛、|x|>1 发散。端点：x=1 时 Σ1/n²（p=2>1）收敛；x=−1 时 Σ(−1)ⁿ/n² 绝对收敛（Σ1/n² 收敛）。故**收敛区间 [−1,1]（闭）**，且处处绝对收敛。

**题 C（概念，检查理解）**

(a) "项趋 0"为什么不是收敛的充分条件？举反例。
(b) 比值判别 L=1 时为什么无法判断？举两个 L=1 但敛散不同的例子。
(c) 绝对收敛与条件收敛的本质区别是什么？为什么条件收敛"脆弱"？

**完整解答**：
(a) 因为收敛还要求"部分和有界且稳定"，项趋 0 只说明"尾巴在变小"，不保证"累积不爆"。反例：调和级数 Σ1/n 项趋 0 但发散（分桶每桶≥1/2）。
(b) 因为 L=1 时信息不够——Σ1/n（发散）和 Σ1/n²（收敛）的比值极限都=1，故无法仅凭 L=1 下结论，需换比较/积分判别。
(c) 绝对收敛（Σ|aₙ|收敛）的级数可任意重排而不变和；条件收敛（收敛但 Σ|aₙ|发散）的级数重排可变和甚至发散（黎曼重排定理）——**"和"依赖项的顺序，非常脆弱**，数值计算里要小心。

## 预告

你终于把"无穷多项相加有没有结果"这个直觉，钉成了一套完整的判别系统——**级数=部分和的极限**，加上比较/比值/根值/交错判别和绝对/条件收敛的分野。你手上的这套"判官"，已经能判断千千万万个"无穷和"敛不敛。

可你马上会问一个更进一步的问题：**不只是"数的无穷和"，能不能把"函数"本身也展开成无穷和？** 比如 sin x、eˣ、ln(1+x)——能不能写成"1 + x + x²/2! + …"这种无穷多项式？**这就是幂级数与泰勒展开**。而那个展开"到哪一步还有意义"（收敛半径）、"误差有多大"（余项），正好要你这一章练的判别法，加上第 03 章的中值定理来钉死。**把级数这套判官和导数工具带上，下一章，我们把函数"展开成无穷和"。**
