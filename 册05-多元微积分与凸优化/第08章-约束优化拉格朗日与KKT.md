# 第 08 章 · 约束优化——拉格朗日乘子与 KKT：戴上锁链找谷底

> 本章从哪个问题出发：第 06 章你学会了"无约束"下山——想往哪走就往哪走，朝负梯度走就行。可现实里你常常**被锁链拴住**：总投资固定、总预算有限、资源之和有上限、物理系统的解必须满足守恒律。**你的变量只能在某些等式或不等式划定的"路"上走，负梯度方向可能根本不指向你被允许的地方。** 这怎么办？
> 推导到哪个结论：答案是**拉格朗日乘子法**：把"带约束的优化"变成一个无约束问题，用一个（或一组）乘子 λ 把约束"买"进目标函数。核心结论是**在最优点，目标函数的梯度 ∇f 与约束的梯度 ∇g 平行（∇f = λ∇g）**。更进一步，当约束是不等式时，要用 **KKT 条件**（驻点 + 互补松弛 + 对偶可行性 + 原始可行性）；当目标函数与可行域都凸时，**KKT 是全局最优的充分条件**——这给"戴锁链也能放心找谷底"提供了保证。
>
> 核心认知：**约束优化 = 在"被允许的曲面/区域"上找 f 的极值；最优点处，目标与约束的梯度"顶牛"到共线。** λ 不只是个数学参数——对资源约束，它是**影子价格**：约束放松一单位，最优值改善多少。这一章是第 06、07 章"无约束"的收口，也是系列转向"概率与信息"（册 06）前的最后一块优化拼图。

## 引子

老谟的沙盘又换了一张——这回，木板中央刻了一条**弯曲的沟**，滚珠只能沿着这条沟滚，沟以外全是凸起的障碍，滚珠过不去。

"上一章你下山，是想怎么走怎么走。"老谟指着那条沟，"可你看这张板：**你的滚珠只能在沟里滚，不能翻到沟外的平地。** 现在我问你：滚珠停在沟里的哪个位置，它所在的高度最低？"

造物主盯着那条弯弯的沟，又看了看沟外那片显然更低的平地："……可沟外明明更低啊？我不能翻出去吗？"

"不能。**这条沟就是你的锁链——一个约束。** 你在沟上某点，心里想往'最低处'冲，可脚下只有沿着沟这一条路。**你现在要解决的，是在'一条路'上找最低点，而不是在整块平地上找。** 你觉得，这跟你第 06 章学的'随便下山'，差别在哪儿？"

造物主沉默了片刻："差别在于……我不能随便选方向了。哪怕我知道沟外的方向更低，我也不能走。我只能在'被允许的方向'里挑最降的那个。"

"你自己点破了约束优化的核心：**不是'哪个方向最降'，而是'在被允许的方向里，哪个最降'。** 那怎么把这条'锁链'数学化？又怎么在这条锁链上算出最低点？这一章，我们就把锁链写进方程。"

## 对话引擎

### 第 1 轮：把"锁链"写下来——等式约束优化问题

**老谟**："先把你这条沟的'锁链'写成数学。沟是木板上的一条线，对应到一个等式。你说，这条沟能用什么等式表示？"

**造物主**："……一条线的方程？比如 g(x, y) = 0？就是说，沟上的点都满足 g(x, y) = 0，沟外的点不满足。"

**老谟**："对。**等式约束（equality constraint）**：你要最小化 f(x)，但 x 必须落在 g(x) = 0 这张'曲面'（对两个变量就是一条曲线）上。把整个问题写全，就是：
min f(x)，s.t. g(x) = 0。
这就是**带等式约束的优化问题**。你说，它和无约束 min f(x) 差在哪？"

**造物主**："无约束时我在整个空间找；有约束时我只能在那张 g=0 的曲面上找。"

**老谟**："那第一个问题就来了：**既然只能在这条曲面上走，你站在曲面上某点，哪些方向是'被允许'的？** ——你沿沟走，方向必须贴着沟。你想想，这个'贴着沟的方向'，数学上怎么描述？"

**造物主**："……沿沟走，g 的值不变（一直等于 0），所以我要找的'被允许方向'，是那种让我 **g 保持不变**的方向？"

**老谟**："顺着这个想下去。g 保持不变的方向，跟你学过的'等高线'有什么关系？回想第 01 章——沿等高线走，函数值不变，那个方向的切线垂直于谁？"

---

### 📐 知识锚点：等式约束与"被允许的方向"

【概念深挖】**等式约束优化问题（equality-constrained optimization）**：
```text
minimize f(x)，subject to g(x) = 0，x ∈ ℝⁿ
```
约束 g(x) = 0 在 ℝⁿ 里定义了一张 **n−1 维曲面**（n=2 时是一条曲线，n=3 时是一张面）。最优解必须落在这张曲面上。

【概念深挖】**"被允许的方向" = 沿约束曲面走的方向**：在点 x，沿某个方向 d 走一小步，若仍保持在曲面上（g 值不变），则这个方向是"被允许的"。由第 01 章结论——**沿等高线（g 不变的方向）的切线方向垂直于梯度 ∇g**——得到：**被允许的方向 d 满足 ∇g(x)·d = 0，即 d 与约束的梯度 ∇g 垂直。** 这是后面"梯度共线"论证的几何地基。

【概念深挖】为什么"朝负梯度走"在约束下失灵：无约束时你朝 −∇f 走，保证下降；但 −∇f 很可能**不贴着你这条沟**（不垂直于 ∇g），你走出一步就掉出曲面、违反约束。**所以约束下不能只盯 ∇f，必须同时盯 ∇g——目标想拉你往这、约束只许你往那，两股力最后会"顶牛"。**

【工程实践】约束优化在工程里无处不在：**投资组合优化**（资金总和 = 预算约束）、**资源分配**（各资源用量 ≤ 上限）、**控制问题**（状态满足动力学方程）、**机器学习里的约束**（如权重约束、L1/L2 正则的约束形式）。"只能在某个约束曲面/区域里找最优"是常态，不是特例。

### 第 2 轮：最优点处，两股力怎么"顶牛"——梯度共线

**老谟**："你站在约束曲面上，被允许的方向 d 都垂直于 ∇g。现在，什么条件下，你站的这个点 x\* 才是曲面上 f 的最低点？"

**造物主**："……在曲面上往任何被允许的方向走，f 都不该再降了？也就是说，**f 在曲面上这点取得'相对最低'**——沿任何被允许方向 d，f 的变化率都是 0？"

**老谟**："对，这就是极值的必要条件：**在最优点 x\*，沿任何被允许方向 d（∇g·d = 0），都有 f 的变化率 ∇f·d = 0。** 现在你把这个条件翻译一下：∇f 在 x\* 处，跟那些被允许方向 d 是什么关系？"

**造物主**："∇f·d = 0 对所有被允许 d 成立——**那 ∇f 也垂直于所有被允许方向！** 而所有被允许方向又都垂直于 ∇g……两个都垂直于同一批方向，那 ∇f 和 ∇g 只能是……**互相平行（共线）！**"

**老谟**："你自己把'梯度共线'推出来了。**在最优点，∇f 与 ∇g 平行——存在某个数 λ，使 ∇f(x\*) = λ∇g(x\*)。** 这个 λ，就是**拉格朗日乘子（Lagrange multiplier）**。它扮演的正是那个'锁链的松紧'：λ 的大小告诉我们，目标与约束这两股力，在平衡点处怎么分高低。"

**造物主**："可光有 ∇f = λ∇g 这个方程，我还是算不出具体位置啊？它只是说'方向平行'，没说在哪。"

**老谟**："所以要把方程组写全。这就是拉格朗日的聪明之处——**把'约束优化'变成一个'无约束优化'**，乘子 λ 自己会冒出来。具体怎么构造那个新函数，你下一轮自己推。"

---

### 📐 知识锚点：拉格朗日乘子——梯度共线的"翻译官"

【概念深挖】**核心几何结论**：设 x\* 是约束优化 min f s.t. g=0 的最优点，且 ∇g(x\*) ≠ 0（约束曲面在 x\* 处"光滑"，没有退化）。则存在实数 λ（拉格朗日乘子）使
```text
∇f(x\*) = λ·∇g(x\*)
```
即**目标梯度与约束梯度在最优点共线**。直觉：两股力——目标想往某个方向降、约束只许在曲面上走——在最优处正好"顶牛"到平行。

【概念深挖】**拉格朗日函数（Lagrangian）**：
```text
L(x, λ) = f(x) + λ·g(x)
```
它把约束"加钱"进目标。对 L 求无条件驻点：
∂L/∂x = ∇f + λ∇g = 0，∂L/∂λ = g = 0。
**第一个方程正是梯度共线，第二个方程正是约束本身。** 所以"解 L 的无约束驻点"就自动同时满足"梯度共线 + 约束成立"——**这就是把约束优化变成无约束优化的核心魔法。**

【历史溯源】**拉格朗日（Joseph-Louis Lagrange）在 1788 年的《分析力学》**里系统引入了乘子法，用于处理带约束的力学极值问题（如带绳子的摆、约束轨道上的运动）。**他给这种方法留下了'拉格朗日乘子'这个名字**。值得注意的是，它是被"物理约束"（力学系统必须满足的运动方程）逼出来的工具——与梯度一样，又是工程/物理先行，数学随后钉牢。KKT 条件则是近两百年后，由**Karush（1939）与 Kuhn、Tucker（1951）**分别提出的不等式约束推广。

### 第 3 轮：乘子 λ 是什么——"锁链的松紧"与影子价格

**老谟**："你把拉格朗日函数构造出来了：L = f + λg，解它的驻点就搞定。可我还要追问一个'哲学'问题：**λ 到底是个什么量？** 它不只是个'凑数用的系数'吧？"

**造物主**："……从方程看，λ = ∇f/∇g？它表示目标梯度和约束梯度的比值，也就是'锁链把目标拽住多少'……"

**老谟**："接近了。给你一个更实在的场景：假设 g(x) = b 是个'资源上限'——比如你的总预算刚好等于 b，改写成 g(x) − b = 0。**你把预算 b 调大一丁点（放一点点水），最优值 f\* 会改善多少？** 数学上可以证明，这个'每放开一单位约束，最优值改善多少'，**恰好就是 λ**。"

**造物主**："……哦！λ 是'这个约束值多少钱'？它衡量的是'这条锁链到底捆住我多少'——锁链越紧（λ 绝对值越大），放开它带来的好处越大！"

**老谟**："你自己摸到了**影子价格（shadow price）**的思想：**λ 是约束的'边际价值'——资源多给一单位，目标能优化多少。** 经济学里算资源该不该多买、该不该换，靠的就是这个 λ。我们点到为止——你只要记住：**λ 不是个没意义的系数，它给'约束的松紧'标了个价。**"

---

### 📐 知识锚点：拉格朗日乘子的经济解释——影子价格

【概念深挖】**影子价格（shadow price）**：对约束写成形如 g(x) = b 的资源约束，拉格朗日乘子 λ 度量"**约束资源 b 每增加一单位，最优目标值 f\* 变化多少**"。即
```text
λ ≈ ∂f\*/∂b   （最优值对资源量的偏导）
```
直觉：λ 是这条约束的"边际价值"——**它告诉你'多放开一单位约束'值多少，从而判断资源该不该增加、往哪个约束上加。** 注意：符号与约定有关（f 是 min 还是 max），"改善/恶化"方向要结合具体问题看。

【工程实践】影子价格在**线性规划与资源配置**里是标准工具：工厂要决定每种产品生产多少（约束是原材料、工时、资金有限），影子价格告诉你"哪种资源最稀缺、多买一单位最划算"。**在机器学习的约束优化里（如带正则的拉格朗日形式），λ 的角色常被重新诠释为'正则化强度'**——控制模型复杂度与拟合的权衡。同一个 λ，在数学里是乘子，在经济学里是价格，在 ML 里是正则系数，本质都是"这个约束有多重要"。

【工程实践】**KKT 的工程意义**：真实优化（尤其带不等式约束，如资源 ≤ 上限）几乎都是 KKT 条件判断"是否最优"。凸优化求解器（如 CVX、SDPT3）内部就在解 KKT 方程组。**理解 KKT，你就读得懂优化求解器的'心电图'。**

### 第 4 轮：约束不只是等式——不等式约束与"要不要锁住"

**老谟**："到目前为止，你的锁链都是'必须满足 g = 0'——只能在这条线上。可现实里更常见的锁链是**不等式**：'至少花这么多''不超过这个上限'。比如你要求 x + y ≥ 1——这时候约束可能是'松'的（你已经满足，不用锁），也可能是'紧'的（刚好卡在边界）。你说，这两种情况的处理一样吗？"

**造物主**："……不一样？如果约束是松的，它根本不影响我，我该往哪走往哪走；如果约束是紧的（刚好在 x+y=1 边界上），那它跟等式约束一样，把我锁住了。"

**老谟**："很敏锐！**这就是不等式约束的关键：约束要么'起作用（active）'——刚好在边界，像等式约束一样锁住你；要么'不起作用（inactive）'——你离边界还远，它管不着你。** 数学家把这个'要不要锁'的判断，写成了 KKT 条件里的'互补松弛'（complementary slackness）。我们先把不等式优化的问题立起来：min f(x)，s.t. g(x) ≥ 0。你说说，处理它，除了'梯度共线'，还得多出什么约束？"

**造物主**："……得告诉我'这个锁是紧的还是松的'？松的锁乘子该是 0（没作用），紧的锁乘子才可能非零？"

**老谟**："你一句话把互补松弛的直觉说出来了：**乘子 μ ≥ 0（对偶可行性），且 μ·g = 0（互补松弛）——要么约束起作用（g=0），要么乘子为 0（μ=0），二者至少一个成立。** 那'松锁没作用'对应的就是 μ = 0、g > 0。这个结构，就是 KKT 条件的核心。完整的四条，我们下一轮收齐。"

---

### 📐 知识锚点：KKT 条件——不等式约束的四件套

【概念深挖】**KKT 条件（Karush–Kuhn–Tucker conditions）**，对问题 min f(x)，s.t. gᵢ(x) ≥ 0（i = 1,…,m），设 x\* 为最优，且约束满足一定的正则性条件，则存在乘子 μᵢ ≥ 0 使以下四条同时成立：
1. **驻点（stationarity）**：∇f(x\*) = Σᵢ μᵢ·∇gᵢ(x\*)（目标梯度 = 约束梯度的非负线性组合）；
2. **原始可行性（primal feasibility）**：gᵢ(x\*) ≥ 0（解必须落在可行区域内）；
3. **对偶可行性（dual feasibility）**：μᵢ ≥ 0（乘子非负）；
4. **互补松弛（complementary slackness）**：μᵢ·gᵢ(x\*) = 0（每个约束：要么起作用 gᵢ=0，要么乘子 μᵢ=0）。

【概念深挖】**KKT 的直觉**：等式约束的"梯度共线"被推广成"梯度是约束梯度的非负线性组合"（因为不等式约束只允许朝'可行侧'拉，方向有约束，故系数非负）；"要不要锁"由互补松弛判定（紧的锁 μᵢ>0 且 gᵢ=0，松的锁 μᵢ=0）；对偶可行性保证乘子方向正确（不会出现"越优化越违反约束"的荒谬）。

【历史溯源】**KKT 条件**由**William Karush（1939，硕士论文）**、以及**Harold W. Kuhn 与 Albert W. Tucker（1951）**独立提出，将拉格朗日乘子法从等式约束推广到不等式约束。**它是"约束优化的终极检查清单"**——判断一个候选点是否最优，逐条核对这四件事即可。

### 第 5 轮：什么时候 KKT 够用？——凸优化里它是"充分"的

**老谟**："KKT 四条都摆出来了。可我必须给你泼盆冷水：**KKT 通常只是'必要条件'**——就是说，最优点一定满足它，但满足它未必是最优点（还可能是个驻点/鞍点）。你说说，在什么条件下，它能从'必要'升格成'充分'？"

**造物主**："……又是凸性？第 6 章在无约束时，就是靠凸性把'局部'升成'全局'。约束这里，应该也是凸吧？目标函数凸，可行域……也得凸？"

**老谟**："你猜对了。**当 f 是凸函数、且每个约束 gᵢ(x) ≥ 0 定义的可行域是凸集（通常 gᵢ 是凹函数即可）时，KKT 条件就是全局最优的充分条件**——满足 KKT 的候选点，一定是全局最优点。** 这跟第 6 章'凸 ⇒ 局部=全局'是同一脉：**凸性给'满足必要条件的点'上了'它就是最优'的保险。** 这一条，是'戴锁链也能放心找谷底'的数学保证。"

**造物主**："那如果不凸呢？"

**老谟**："不凸时，KKT 只能帮你'筛掉'一些点，不能保证'挑出'全局最优——你还得在多个 KKT 点里比较，甚至依赖启发式。**所以工程上凡是能写成凸问题，都尽量写成凸的，图的就是这个'充分'的确定性。** 你先记住这个结论，完整证明在走廊。"

---

### 📐 知识锚点：凸优化的 KKT 充分性

【概念深挖】**KKT 充分性定理**：设 f 是凸函数，可行域 K = {x : gᵢ(x) ≥ 0} 是凸集（若每个 gᵢ 是凹函数，则可行域凸）。若 (x\*, μ\*) 满足 KKT 条件，则 **x\* 是全局最优点**。证明见走廊定理（用凸函数一阶刻画 + 互补松弛）。

【概念深挖】**为什么凸性带来充分性**：KKT 的驻点条件 ∇f = Σμᵢ∇gᵢ，配合凸函数的一阶刻画 f(y) ≥ f(x) + ∇f(x)·(y−x)，能把"任意可行点 y"的函数值压到 ≥ f(x\*)——一旦这一步成立，"x\* 是全局最优"就水到渠成（详见走廊）。

【工程实践】**凸优化的"金字招牌"**：凸优化问题（目标凸 + 可行域凸）的局部最优 = 全局最优，且 KKT 给出可验证的充分条件——这就是为什么**线性规划、二次规划、以及大量机器学习问题（SVM、Lasso、逻辑回归等）都被设计成凸问题**：能写凸，就能保证解的质量，还能用高效求解器。**"能不能写成凸"常常是问题建模的第一个战略决策。**

## 严格化走廊

> 位置说明：本章对话负责"直觉"——为什么梯度共线、什么是互补松弛、凸性为何带来充分性。本走廊负责"严谨"——把拉格朗日乘子法、KKT 条件写成精确形式，并给出可复写的证明。**下面每一行，读者都能对着空白纸重写一遍。**

### 定义 1：等式约束优化问题（equality-constrained problem）

设 f, g : ℝⁿ → ℝ 可微。**等式约束优化问题**为
```text
minimize f(x)，subject to g(x) = 0
```
若 x\* 在约束曲面 g = 0 上且对曲面上邻近的一切 x 有 f(x\*) ≤ f(x)，则称 x\* 为**约束局部最优解**。

### 定义 2：拉格朗日函数（Lagrangian）

对上述问题，定义 **拉格朗日函数**
```text
L(x, λ) = f(x) + λ·g(x)，λ ∈ ℝ
```
λ 称为**拉格朗日乘子（Lagrange multiplier）**。

### 定义 3：不等式约束优化问题与 KKT 条件

设 f, g₁, …, gₘ : ℝⁿ → ℝ 可微。问题 **min f(x)，s.t. gᵢ(x) ≥ 0**（i = 1,…,m）。设 x\* 为最优且约束满足正则性条件，则存在乘子 μ = (μ₁,…,μₘ) 使以下**KKT 条件**成立：
- **(S) 驻点**：∇f(x\*) = Σᵢ μᵢ·∇gᵢ(x\*)；
- **(P) 原始可行性**：gᵢ(x\*) ≥ 0，∀i；
- **(D) 对偶可行性**：μᵢ ≥ 0，∀i；
- **(C) 互补松弛**：μᵢ·gᵢ(x\*) = 0，∀i。

### 定理 1（等式约束的拉格朗日乘子法 / 梯度共线）：设 x\* 是问题 min f s.t. g = 0 的约束局部最优解，f、g 在 x\* 附近**连续可微（C¹，隐函数定理所需）**，且 ∇g(x\*) ≠ 0。则存在 λ ∈ ℝ 使
```text
∇f(x\*) = λ·∇g(x\*)
```

**证明（可复写，几何/隐函数论证）**：
- 由**隐函数定理**（∇g(x\*) ≠ 0），约束 g = 0 在 x\* 附近是一条光滑曲线/曲面 S，且存在一组**切向量**张成的切空间。取 S 上任意过 x\* 的光滑曲线 x(t)（x(0) = x\*，且 g(x(t)) = 0）。
- 因沿曲线恒有 g(x(t)) = 0，对 t 求导（**链式法则，第 02 章定理 2**）：
  d/dt g(x(t))|_{t=0} = ∇g(x\*)·x′(0) = 0。故 **S 在 x\* 的切向量 x′(0) 都垂直于 ∇g(x\*)**。
- 因 x\* 是 f 在 S 上的极值点（定义 1），函数 t ↦ f(x(t)) 在 t = 0 处取极值，故其导数（**费马引理 / 一元极值必要条件**）为 0：
  d/dt f(x(t))|_{t=0} = ∇f(x\*)·x′(0) = 0。故 **∇f(x\*) 也垂直于一切切向量 x′(0)**。
- 于是 ∇f(x\*) 与 ∇g(x\*) 都垂直于 S 的同一个切空间（由所有 x′(0) 张成，维数 n−1）。垂直于同一 (n−1) 维子空间的向量必互相平行（都在一维法向），故存在 λ ∈ ℝ 使 ∇f(x\*) = λ·∇g(x\*)。∎

**证明要点标注**：第 1 步用**隐函数定理**保证约束曲面光滑、切空间存在；第 2 步用**第 02 章定理 2（多元链式法则）**对约束求导得"切向量 ⊥ ∇g"；第 3 步用**一元极值必要条件（费马引理）**对"沿曲线的 f"求导得"切向量 ⊥ ∇f"；第 4 步用**线性代数事实**（垂直于同一超平面的两向量共线）。

### 定理 2（KKT 是凸优化的充分条件）：设 f 是凸函数，可行域 K = {x : gᵢ(x) ≥ 0} 是凸集（例如每个 gᵢ 是凹函数）。若 (x\*, μ\*) 满足 KKT 条件（定义 3），则 **x\* 是全局最优点**：对一切 x ∈ K，f(x) ≥ f(x\*)。

**证明（可复写）**：
- 任取可行点 x ∈ K（gᵢ(x) ≥ 0）。由**凸函数的一阶刻画（第 04 章定理）**：
  f(x) ≥ f(x\*) + ∇f(x\*)·(x − x\*)。
- 代入**KKT 驻点条件 (S)** ∇f(x\*) = Σᵢ μᵢ∇gᵢ(x\*)：
  f(x) ≥ f(x\*) + Σᵢ μᵢ·∇gᵢ(x\*)·(x − x\*)。
- 因每个 gᵢ 是凹函数，其满足**凹函数的一阶刻画**（方向与凸相反）：gᵢ(x) ≤ gᵢ(x\*) + ∇gᵢ(x\*)·(x − x\*)，即
  ∇gᵢ(x\*)·(x − x\*) ≥ gᵢ(x) − gᵢ(x\*)。
  由**KKT 对偶可行性 (D)** μᵢ ≥ 0，乘上 μᵢ 保持不等式方向：
  Σᵢ μᵢ∇gᵢ(x\*)·(x − x\*) ≥ Σᵢ μᵢ[gᵢ(x) − gᵢ(x\*)]。
- 展开右端 = Σᵢ μᵢgᵢ(x) − Σᵢ μᵢgᵢ(x\*)。由**互补松弛 (C)** μᵢgᵢ(x\*) = 0，第二项为 0；又 x 可行（gᵢ(x) ≥ 0）且 μᵢ ≥ 0，故第一项 Σᵢ μᵢgᵢ(x) ≥ 0。
- 综合：f(x) ≥ f(x\*) + 0 = f(x\*)。由 x ∈ K 任意，**x\* 是全局最优点**。∎

**证明要点标注**：第 1 步用**第 04 章凸函数一阶刻画**；第 2 步用**KKT 驻点条件 (S)**；第 3 步用**凹函数的一阶刻画**与**KKT 对偶可行性 (D)**（μᵢ ≥ 0 保持不等式方向）；第 4 步用**互补松弛 (C)** 与**原始可行性 (P)**（gᵢ(x) ≥ 0）；第 5 步是**不等式传递**。

### 反例/边界

- **∇g(x\*) = 0 的退化约束**：若约束在最优点处梯度为零（约束曲面在该点退化/折叠），梯度共线定理 1 不成立（法向不存在）。例：min x² + y²，s.t. g(x,y) = x² + y² − 1 = 0，在点 (0,0) 处 ∇g = (0,0)，但 (0,0) 不在约束上（x²+y²=0≠1）——退化约束要特殊处理。
- **KKT 只是必要（不凸时）**：min f(x,y) = x³ − 3xy + y³（非凸），约束 g(x,y) = x + y ≥ 0。KKT 点未必是全局最优，可能只是局部/鞍点——**非凸时 KKT 不能保证全局**。
- **不等式约束"松"的情形**：min x² + y²，s.t. x + y ≥ 10。可行域是半平面，内部最优点（0,0）不在可行域，故最优在边界 x+y=10 上（约束起作用），λ/μ ≠ 0。反之若可行域包含 (0,0)（如 x+y ≥ −5），约束松，μ=0，最优退回无约束解 (0,0)——**互补松弛在此分辨"紧/松"。**

## 知识点总结

### 知识点（本章推出的核心概念）

- **等式约束优化**：min f(x)，s.t. g(x) = 0——只能在 g=0 这张曲面上找极值。
- **被允许的方向**：满足 ∇g·d = 0 的方向（沿约束曲面走，垂直于约束梯度）。
- **拉格朗日函数**：L(x, λ) = f(x) + λ·g(x)；解 ∂L/∂x=0（梯度共线）+ ∂L/∂λ=0（约束）的无约束驻点，等价于约束优化。
- **梯度共线**：最优点处 ∇f(x\*) = λ∇g(x\*)——目标与约束两股力"顶牛"到平行。
- **拉格朗日乘子 λ 与影子价格**：λ ≈ ∂f\*/∂b，度量"约束资源每放一单位，最优值改善多少"——锁链的"边际价值"。
- **不等式约束优化**：min f，s.t. gᵢ(x) ≥ 0；约束分"起作用（紧，gᵢ=0）"与"不起作用（松，μᵢ=0）"。
- **KKT 条件四件套**：驻点 (S) + 原始可行性 (P) + 对偶可行性 (D) + 互补松弛 (C)。
- **凸优化的 KKT 充分性**：目标凸 + 可行域凸 ⇒ 满足 KKT 的点是全局最优（定理 2）。

### 历史结论（本章涉及的史料）

- **拉格朗日（1788）**：《分析力学》系统引入乘子法处理带约束的力学极值（如摆、约束轨道），命名"拉格朗日乘子"——又是物理约束逼出数学工具。
- **Karush（1939）**：在硕士论文中提出不等式约束的最优性条件。
- **Kuhn & Tucker（1951）**：独立重新提出并推广，后世合称 **KKT 条件**——把拉格朗日乘子法从等式推广到不等式约束。
- **一个共性**：约束优化同样"物理/经济先行"——先有带锁链的实际问题（力学、资源），后有拉格朗日与 KKT 的理论钉牢。

### 工程实践结论（本章知识在真实工程里怎么用）

- **约束无处不在**：投资组合（预算约束）、资源分配（上限）、控制（动力学方程）、ML 约束（权重/正则约束）。
- **影子价格用于资源配置**：线性规划里判断"哪种资源最稀缺、多买一单位最划算"。
- **λ 的多种诠释**：数学上是乘子，经济学上是价格，机器学习里常是正则化强度（L1/L2 的正则系数）。
- **KKT 是凸优化求解器的内核**：CVX、SDPT3 等求解器内部就在解 KKT 方程组。
- **"能不能写成凸"是建模的第一个战略决策**：凸问题能保证全局最优（KKT 充分），非凸只能比较多个 KKT 点——所以 SVM、Lasso、逻辑回归都被设计成凸问题。

> 位置说明：本章对话负责"为什么"，这里负责"怎么算"。**下面每题请动笔 10 分钟以上，先自己写，再对照完整解答。所有数值我都亲手验算过。**

### 题 1（易→中）：拉格朗日乘子法解等式约束优化

**题干**：求 min f(x, y) = x² + y²，subject to x + y = 1。
(a) 写出拉格朗日函数 L(x, y, λ)。
(b) 求 ∂L/∂x、∂L/∂y、∂L/∂λ 并令它们为零，解出 x、y、λ。
(c) 给出最优值 f\* 与最优解，并验证梯度共线 ∇f = λ∇g。

**完整分步解答：**

**(a) 拉格朗日函数**：
第 1 步：目标 f = x² + y²，约束写成 g(x,y) = x + y − 1 = 0。
第 2 步：L(x, y, λ) = f + λ·g = **x² + y² + λ(x + y − 1)**。

**(b) 求驻点方程组**：
第 3 步：∂L/∂x = 2x + λ（对 x 求导，x²→2x，λx→λ）。令 = 0：**2x + λ = 0**。
第 4 步：∂L/∂y = 2y + λ（对 y 求导）。令 = 0：**2y + λ = 0**。
第 5 步：∂L/∂λ = x + y − 1。令 = 0：**x + y = 1**。
第 6 步：由 2x + λ = 0 与 2y + λ = 0 相减：2(x − y) = 0 ⇒ **x = y**。
第 7 步：代入 x + y = 1：2x = 1 ⇒ **x = 1/2，y = 1/2**。
第 8 步：代入 2x + λ = 0：λ = −2x = −1 ⇒ **λ = −1**。

**(c) 最优值与验证**：
第 9 步：f\* = f(1/2, 1/2) = (1/4) + (1/4) = **1/2**。
第 10 步：梯度共线验证：∇f = (2x, 2y) = (1, 1)；∇g = (1, 1)。λ∇g = −1·(1,1) = (−1,−1) ≠ ∇f？——注意 ∇f = (1,1)，而 λ∇g = (−1,−1)，两者**反向**。这是因为本问题 ∂L/∂x = 0 给出 2x + λ = 0，即 ∇f + λ∇g = 0 ⇒ ∇f = −λ∇g。取 λ′ = −λ = 1，则 ∇f = 1·∇g ✓ 共线（λ′ = 1 是"标准乘子"，满足 ∇f = λ′∇g）。**共线成立，只是 λ 符号约定不同。**

**答**：(a) L = x²+y²+λ(x+y−1)；(b) x = y = 1/2，λ = −1；(c) f\* = 1/2，梯度共线 ∇f = (1,1) = 1·∇g ✓（λ′ = 1）。

**常见错误**：① 对 λ 求导时忘了"约束要写成 g = 0 再乘 λ"，直接对 x+y=1 的 1 处理错；② 解 2x+λ=0 与 2y+λ=0 时漏掉"相减得 x=y"这步，直接硬凑；③ 忘了验证梯度共线，或对"λ 取负号"疑惑——**只要 ∇f 与 ∇g 平行即可，乘子符号取决于 L 的约定，不改变几何结论**。

### 题 2（中→难）：两个等式约束——完整方程组求解

**题干**：求 min f(x, y, z) = x² + y² + z²，subject to x + y + z = 1 **且** x − y = 0。
(a) 写拉格朗日函数（两个乘子 λ₁、λ₂）。
(b) 求所有偏导并令为零，解出 x、y、z、λ₁、λ₂。
(c) 给出最优值 f\*，验证约束成立。

**完整分步解答：**

**(a) 拉格朗日函数**：
第 1 步：约束 g₁ = x + y + z − 1 = 0，g₂ = x − y = 0。
第 2 步：L = f + λ₁g₁ + λ₂g₂ = **x² + y² + z² + λ₁(x + y + z − 1) + λ₂(x − y)**。

**(b) 求驻点方程组**：
第 3 步：∂L/∂x = 2x + λ₁ + λ₂ = 0。
第 4 步：∂L/∂y = 2y + λ₁ − λ₂ = 0。
第 5 步：∂L/∂z = 2z + λ₁ = 0。
第 6 步：∂L/∂λ₁ = x + y + z − 1 = 0。
第 7 步：∂L/∂λ₂ = x − y = 0。
第 8 步：由 ∂L/∂x − ∂L/∂y = (2x + λ₁ + λ₂) − (2y + λ₁ − λ₂) = 2(x − y) + 2λ₂ = 0。由第 7 步 x − y = 0，得 **λ₂ = 0**。
第 9 步：由 ∂L/∂x（λ₂=0）：2x + λ₁ = 0 ⇒ λ₁ = −2x。由 ∂L/∂z：2z − 2x = 0 ⇒ **z = x**。
第 10 步：由第 7 步 x − y = 0 ⇒ **x = y**。结合 z = x，得 x = y = z。
第 11 步：代入 x + y + z = 1：3x = 1 ⇒ **x = y = z = 1/3**。
第 12 步：λ₁ = −2·(1/3) = **−2/3**，λ₂ = 0。

**(c) 最优值**：
第 13 步：f\* = f(1/3,1/3,1/3) = 3·(1/9) = **1/3**。
第 14 步：验证约束：1/3 + 1/3 + 1/3 = 1 ✓；1/3 − 1/3 = 0 ✓。

**答**：(a) L = x²+y²+z²+λ₁(x+y+z−1)+λ₂(x−y)；(b) x=y=z=1/3，λ₁=−2/3，λ₂=0；(c) f\* = 1/3，约束均满足 ✓。

**常见错误**：① 写 L 时把两个约束乘同一个 λ，或漏写第二个约束的乘子 λ₂；② 解方程组时不会用"两式相减"消去 λ，而是硬代数死算；③ 忘了"x−y=0 ⇒ x=y"这一约束其实约束了对称性，结果应满足 x=y=z（两个约束叠加导致的强对称）。

### 题 3（中→难）：不等式约束——验证 KKT 条件（含边界情形）

**题干**：求 min f(x, y) = x² + y²，subject to x + y ≥ 1。
(a) 说明为什么最优点会落在边界 x + y = 1 上（而不是可行域内部）。
(b) 在边界情形（约束起作用）用拉格朗日解出候选点，并写出 KKT 四条逐一验证。
(c) 验证这是全局最优（用凸性充分性），并给出影子价格的直观意义。

**完整分步解答：**

**(a) 最优在边界**：
第 1 步：若无约束，全局最小在 (0,0)，f = 0，但 (0,0) 处 x + y = 0 < 1，**不在可行域**（违反 x+y≥1）。
第 2 步：可行域是半平面 x + y ≥ 1。f = x²+y² 是"离原点越远越大"，在可行域内离原点最近的点在**边界直线 x + y = 1 上**（半平面内离原点最近的点是原点到该直线的垂足）。
第 3 步：故最优点在边界（约束起作用），可当等式约束处理。

**(b) KKT 验证**：
第 4 步：边界上求 min x²+y²，s.t. x+y=1。拉格朗日 L = x²+y²+λ(x+y−1)。
第 5 步：∂L/∂x = 2x+λ=0，∂L/∂y = 2y+λ=0 ⇒ x=y；∂L/∂λ = x+y−1=0 ⇒ x=y=1/2。
第 6 步：候选点 x\* = (1/2, 1/2)。用 KKT 四件套验证（约束写 g = x+y−1 ≥ 0，μ ≥ 0，驻点 ∇f − μ∇g = 0）：
- 第 7 步 **(S) 驻点**：∇f = (2x, 2y) = (1, 1)，∇g = (1, 1)。取 μ = 1：∇f − μ∇g = (1,1) − 1·(1,1) = (0,0) ✓。
- 第 8 步 **(P) 原始可行**：g(x\*) = 1/2 + 1/2 − 1 = 0 ≥ 0 ✓。
- 第 9 步 **(D) 对偶可行**：μ = 1 ≥ 0 ✓。
- 第 10 步 **(C) 互补松弛**：μ·g(x\*) = 1·0 = 0 ✓。
第 11 步：四条全满足，x\* = (1/2, 1/2) 是 KKT 点。

**(c) 全局最优与影子价格**：
第 12 步：f 是凸函数（Hessian = [[2,0],[0,2]] 正定）；可行域 {x+y≥1} 是半平面，凸集。由**定理 2（KKT 充分性）**，KKT 点 x\* 是**全局最优**。
第 13 步：f\* = f(1/2,1/2) = 1/4 + 1/4 = **1/2**。
第 14 步：影子价格直观：μ = 1 表示"约束右端 1 每增加一单位（x+y ≥ 1 变成 ≥ 2），最优值改善量"——具体验证：若约束改为 x+y ≥ 2，最优点在直线 x+y=2 上离原点最近，即 (1,1)，f = 2。从 1/2 增到 2，约束从 1 增到 2（增 1 单位），f\* 从 0.5 增到 2，增量约 1.5——**μ = 1 度量了这一"边际价格"的方向与量级（min 问题中"更严约束"会提高 f\*，μ 反映其敏感度）**。（影子价格的精确数值受凸性/二次结构影响，这里重在直观。）

**答**：(a) (0,0) 不在可行域，半平面内离原点最近点在边界 x+y=1 上；(b) x\* = (1/2,1/2)，μ=1，KKT 四条全满足；(c) f\* = 1/2，凸 + 凸可行域 ⇒ KKT 充分 ⇒ 全局最优；μ=1 给出约束"边际价格"直观。

**常见错误**：① 忘记"无约束最优 (0,0) 不在可行域"，直接报 f=0；② 互补松弛理解错——**约束起作用（g=0）时 μ 可非零，约束不起作用（g>0）时 μ 必为 0**；③ 验证 (S) 时方向搞错（不等式约束是 ∇f − Σμ∇g = 0，不是 ∇f + λ∇g = 0），导致符号错。

## 向导便签

> 这一章咱们干了什么：从"滚珠只能沿一条沟滚，不能翻出去"这个问题出发，把"锁链"写成等式约束 min f s.t. g=0；发现"被允许的方向"垂直于约束梯度，从而推出最优点处**梯度共线 ∇f = λ∇g**；用拉格朗日函数 L = f + λg 把约束优化变成无约束；再推广到不等式约束，得到 **KKT 四件套**（驻点 + 原始可行 + 对偶可行 + 互补松弛），并理解 λ 是"影子价格"；最后，当目标凸、可行域凸时，KKT 是全局最优的充分条件。
>
> 钉死一句话：**等式约束看 ∇f = λ∇g（梯度共线），不等式约束看 KKT 四条；λ 是约束的边际价值（影子价格）；目标凸 + 可行域凸 ⇒ 满足 KKT 就是全局最优。**
>
> 记住一个边界：**KKT 在不凸时只是必要条件**——满足它未必全局最优；还有约束正则性（∇g ≠ 0）是梯度共线证明的前提，退化约束要特殊处理。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：拉格朗日乘子法**

求 min f(x, y) = x² + 2y²，subject to x + y = 3。
(a) 写拉格朗日函数。
(b) 解驻点方程组，求 x、y、λ。
(c) 求 f\*，验证梯度共线。

**完整解答**：
(a) L = x² + 2y² + λ(x + y − 3)。
(b) ∂L/∂x = 2x + λ = 0；∂L/∂y = 4y + λ = 0；∂L/∂λ = x + y − 3 = 0。
由前两式：2x = 4y ⇒ x = 2y。代入 x + y = 3：2y + y = 3 ⇒ 3y = 3 ⇒ **y = 1，x = 2**。
λ = −2x = −4 ⇒ **λ = −4**。
(c) f\* = f(2,1) = 4 + 2 = **6**。梯度共线：∇f = (2x, 4y) = (4, 4)；∇g = (1, 1)；4·(1,1) = (4,4) = ∇f ✓（λ′ = 4）。验证约束 x+y = 3 ✓。

**题 B（计算，中→难）：两个等式约束**

求 min f(x, y, z) = x² + y² + z²，subject to x + y + z = 2 且 x − y − z = 0。
(a) 写拉格朗日函数（λ₁、λ₂）。
(b) 解方程组求 x、y、z、λ₁、λ₂。
(c) 求 f\*。

**完整解答**：
(a) L = x² + y² + z² + λ₁(x + y + z − 2) + λ₂(x − y − z)。
(b) ∂L/∂x = 2x + λ₁ + λ₂ = 0；∂L/∂y = 2y + λ₁ − λ₂ = 0；∂L/∂z = 2z + λ₁ − λ₂ = 0。
由 ∂L/∂y 与 ∂L/∂z：2y + λ₁ − λ₂ = 2z + λ₁ − λ₂ ⇒ **y = z**。
由 ∂L/∂x − ∂L/∂y = 2(x − y) + 2λ₂ = 0 ⇒ λ₂ = −(x − y)。
由 ∂L/∂x：2x + λ₁ + λ₂ = 0；∂L/∂y：2y + λ₁ − λ₂ = 0。相加：2(x+y) + 2λ₁ = 0 ⇒ λ₁ = −(x+y)。
又约束 x − y − z = 0 且 y = z ⇒ x − 2y = 0 ⇒ x = 2y。
约束 x + y + z = 2 且 y = z、x = 2y ⇒ 2y + y + y = 4y = 2 ⇒ **y = 1/2，z = 1/2，x = 1**。
λ₁ = −(1 + 1/2) = **−3/2**；λ₂ = −(x − y) = −(1 − 1/2) = **−1/2**。
(c) f\* = f(1, 1/2, 1/2) = 1 + 1/4 + 1/4 = **3/2**。验证约束：x+y+z = 1+0.5+0.5 = 2 ✓；x−y−z = 1−0.5−0.5 = 0 ✓。

**题 C（概念，检查理解）：KKT 与凸性充分性**

老谟问造物主：
(1) 为什么"凸目标 + 凸可行域"能让 KKT 从必要条件升格为充分条件？
(2) 不凸时，满足 KKT 的点可能是全局最优吗？可能不是吗？分别给一个例子。
(3) 互补松弛的工程意义是什么（"这条锁是紧是松"）？

**完整解答**：
(1) 凸函数满足一阶刻画 f(y) ≥ f(x) + ∇f(x)·(y−x)，用它 + KKT 驻点条件 + 互补松弛，可对任意可行点 y 推出 f(y) ≥ f(x\*)——从而 x\* 是全局最优（走廊定理 2）。**凸性保证了"KKT 点的下界性"，让"满足必要条件"等于"达到最优"。**
(2) 可能：若某个全局最优恰好也满足 KKT（任何最优都满足 KKT 必要），它当然既是 KKT 点又是全局最优。可能不是：非凸问题里，KKT 点可能是局部极小或鞍点，不是全局最优——如 f = x³ − 3xy + y³ 的某些驻点满足 KKT 却只是鞍点/局部解。**不凸时，KKT 只能筛出"候选"，不能保证"最优"。**
(3) 互补松弛 μ·g = 0 告诉你每条约束"有没有真正锁住你"：约束起作用（g=0）且乘子 μ>0，说明它在限制最优解（紧锁）；约束不起作用（g>0）则 μ=0，说明它没在限制（松锁，可以忽略）。**工程里靠它判断"哪个约束真正稀缺、该优先加资源"。**
