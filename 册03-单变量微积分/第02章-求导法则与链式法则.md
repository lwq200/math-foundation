# 第 02 章 · 求导法则与链式法则——把"算导数"变成拼积木

> 本章从哪个问题出发：上一章你终于把"瞬时变化率"钉成了定义——f'(a) = lim_{h→0} (f(a+h)−f(a))/h。可你手里只有"回定义"这一把刀：算 x³、1/x 还行，遇到 **sin(x²)·eˣ** 这种复合函数，每一步都回定义会算到怀疑人生。**有没有办法，把复杂函数的导数，拆成简单函数导数的"组合"？**
> 推导到哪个结论：你会拿到一套"拼积木"的法则——**四则运算的求导法则**（和/积/商）和微积分里最著名也最反直觉的**链式法则**（复合函数：(f∘g)' = f'(g)·g'）。你会亲手证明链式法则——用上一章"差商×h"那招的升级版"差分比相乘"，看清楚"外层导数×内层导数"凭什么这样拼。
>
> 核心认知：**求导法则 = 把"复杂函数"拆成"简单函数的运算"，再按规则拼导数。** 链式法则的灵魂是"差分比相乘"：(f(g(x)))' = f'(g(x))·g'(x)——外层看整体、内层换回 x。它不仅是算题工具，更是现代 AI 的引擎：**神经网络的反向传播（backpropagation），算的就是链式法则在千层网络里的逐层回传。**

"……sin 套在 x² 外面？外层是 sin，内层是 x²。"

## 对话引擎

### 第 1 轮：为什么要"法则"——回定义会算到天荒地老

**老谟**："先算一笔账。**上一章你用定义求 x³ 在 2 的导数，展开 (2+h)³ 花了几步？** 那要让你用定义求 sin(x²)·eˣ 的导数，你觉得会怎样？"

**造物主**："……展开 (2+h)³ 都要三步。**sin(x²)·eˣ 的差商，分子是 sin((x+h)²)·e^{x+h} − sin(x²)·eˣ，再除以 h——这化简……我光写着就想逃。**"

**老谟**："**所以'每次都回定义'不是办法。** 但你注意——**sin(x²)·eˣ 不是'凭空'那么复杂，它是'简单函数拼出来的'：x² 是个简单函数，sin 是个简单函数，eˣ 是个简单函数，它们靠'复合（sin 套 x²）'和'乘法（×eˣ）'拼在一起。** 那问题就变成：**如果我会算简单函数的导数，能不能靠'它们是怎么拼的'，把复杂函数的导数也拼出来？**"

**造物主**："……就像乐高？我会拼每一块小积木（简单函数的导数），现在要知道'几块积木按某种方式接起来'，整体怎么拼。**加法、乘法、复合……每种'接法'都该对应一条'怎么拼导数'的规则。**"

**老谟**："你摸到本章的骨架了。**求导法则就是'每种组合方式对应一条拼导数的规则'。** 这一章，我们一条一条把它们钉出来。先来最简单的——**两个函数相加，导数怎么拼？**"

### 📐 知识锚点：从"回定义"到"法则"——一张算题的"世界观转变"
<blockquote style="background:#fff8e1">

【概念深挖】**为什么需要求导法则**：导数定义 f'(a)=lim (f(a+h)−f(a))/h 是"终极判据"，但直接用它算复杂函数是灾难。**求导法则把"复杂函数"分解成"简单函数的组合"，并给出"每种组合的导数规则"**——你只需要：①认识基础函数（xⁿ、sin、eˣ…）的导数（一张小表）；②掌握组合规则（和/积/商/复合）。**从此"算导数"从"每次展开差商"变成"套规则"，快几个量级。**

**本章要拼的"积木组合"**（对应求导法则）：
- **和差**：(f±g)' = f'±g'（极限的线性）
- **数乘**：(cf)' = c·f'（常数因子提出）
- **乘积**：(fg)' = f'g + fg'（两条积木各导一次，交叉相加）
- **商**：(f/g)' = (f'g − fg')/g²
- **复合（链式）**：(f∘g)' = f'(g)·g'（外层导 × 内层导）

【工程实践】"拼积木"正是工程师的日常：**任何复杂系统都能拆成简单模块的组合，系统的"响应"由模块的组合规则决定**。数值微分软件（自动微分 autodiff）不是"回定义算极限"，而是**把函数表达式建成一张计算图，节点是运算，边是导数，反向传播沿边逐层回传**——这就是下一章落点的工程版。**"法则"让"算导数"从"手算极限"变成"沿计算图传播"，这直接就是现代深度学习训练的核心。**
</blockquote>

### 第 2 轮：和与积——先看"加法"和"乘法"怎么拼

**老谟**："先看最朴素的组合——**加法**。两个函数相加，f(x)+g(x) 的导数，你想怎么拼？"

**造物主**："……直觉是各导各的再相加？(f+g)' = f' + g'？因为极限是线性的——差的极限等于极限的差，所以差商里 f 和 g 可以拆开。**f(x+h)+g(x+h) 的差商，分子拆成 [f(x+h)−f(x)] + [g(x+h)−g(x)]，除以 h，就是两个差商相加。**"

**老谟**："**对，和法则就是这么直接——差商的极限是线性的，所以加法能拆。** 那'乘法'呢？(fg)' 会不会也是'各导各的再相乘'，即 (fg)' = f'·g'？"

**造物主**："……直觉上像是 f'·g'？可我又觉得没这么简单……让我用定义试一个：**f=x，g=x，那 fg=x²，应该导数是 2x。** 如果 (fg)'=f'g'，那就是 1×1=1，不等于 2x——**错了！所以乘法不是各导各的再相乘。**"

**老谟**："**你用反例把自己堵住了——(fg)'≠f'g'。** 那正确的长什么样？我们用定义推一推。你把 (fg) 的差商写出来：分子是 f(x+h)g(x+h) − f(x)g(x)。**怎么拆？提示你：在中间插一项 f(x+h)g(x) 和 f(x)g(x+h)，看能不能配出'两个差商'。**"

**造物主**："……插中间项？f(x+h)g(x+h) − f(x)g(x) = **f(x+h)g(x+h) − f(x+h)g(x) + f(x+h)g(x) − f(x)g(x)** = f(x+h)[g(x+h)−g(x)] + g(x)[f(x+h)−f(x)]。除以 h：**f(x+h)·[g 的差商] + g(x)·[f 的差商]**。那取极限，f(x+h)→f(x)，就得到 **(fg)' = f(x)g'(x) + g(x)f'(x)**！"

**老谟**："**漂亮，你把积法则亲手推出来了：'左导右不导 + 右导左不导'（f'g + fg'）。** 注意那个'中间插一项'的招——它是分析里最常用的'凑'的技巧。下一轮，我们看最难的'复合'——链式法则。"

### 📐 知识锚点：和、积法则——"线性"与"插项"
<blockquote style="background:#e3f2fd">

【概念深挖】**和差法则（sum/difference rule）**：(f±g)' = f'±g'。**依据**：差商的极限是线性的（册02 极限四则运算），分子拆开即可。
- 数乘法则：(cf)' = c·f'（常数提出，依据同样来自极限线性）。

**积法则（product rule）**：(fg)' = f'g + fg'。
- **证明思路（关键插项）**：在分子 f(x+h)g(x+h)−f(x)g(x) 中间插入 **f(x+h)g(x)**（和 **f(x)g(x+h)** 等价地）：
  f(x+h)g(x+h)−f(x)g(x) = f(x+h)[g(x+h)−g(x)] + g(x)[f(x+h)−f(x)]。
  除以 h 取极限：f(x+h)→f(x)（f 可导⟹连续），得 f(x)g'(x)+g(x)f'(x)。
- **为什么不是 f'g'**：f=x、g=x 时 f'g'=1 而 (x²)'=2x——用反例排除。**乘法必须"交叉"：一块积木导，另一块不动，两块轮流。**

**口诀**：积法则 = "前导后不导 + 前不导后导"（f'g + fg'）。

【历史溯源】**牛顿与莱布尼茨（17 世纪）**各自建立微积分时，求导法则（和/积/商/链式）已基本成型——它们是"算法"，随定义一起给出。**但"为什么积法则不是 f'g'"这个坑，初学几乎必踩**：直到用极限定义严格推导，才看清"插项"这个本质。**法则的"怎么用"（算法）在 17 世纪就有了，"凭什么"（证明）要到柯西的极限定义（19 世纪）才彻底钉死。**
</blockquote>

### 第 3 轮：复合函数——"外层导 × 内层导"凭什么

**老谟**："现在上最难的——**复合函数**。设 y = g(x)，z = f(y) = f(g(x))，即 z 是 x 的复合函数。**我们想知道 z 对 x 的变化率。** 你说，'z 随 x 变'，中间隔了谁？"

**造物主**："……中间隔了 y。**x 变了，y=g(x) 先变；y 变了，z=f(y) 再变。** 所以 z 对 x 的变化率，应该是'z 对 y 的变化率'乘上'y 对 x 的变化率'？**就像连锁齿轮：外圈转速 = 中间齿比 × 内圈转速。**"

**老谟**："**你这个'连锁齿轮'的直觉，就是链式法则的核心：dz/dx = (dz/dy)·(dy/dx)。** 用导数符号写：(f∘g)'(x) = f'(g(x))·g'(x)——**外层导（在外层里对内层整体求导）× 内层导（对 x）**。但你光有直觉不算数——**'凭什么可以乘'？上一章你学了一个'差商×h'的招，这一章我们要用它的升级版——'差分比相乘'——把它证死。** 完整证明放走廊定理 1，你翻过去对着空白纸补全。现在你先抓住这个'齿轮'图景。"

**造物主**："……那'外层导×内层导'里，**外层求导时，是不是要把内层当成一个整体？** 比如 sin(x²)，外层是 sin，求导得 cos(内层整体)=cos(x²)，再乘内层导 (x²)'=2x？"

**老谟**："**你已经在用链式法则了，而且用法对了——cos(x²)·2x。** 这个'把内层当整体、求完外层导再乘内层导'的动作，就是链式法则的全部操作。**下一轮，我们看它怎么在'多层复合'里一层一层套。**

### 📐 知识锚点：链式法则——"齿轮"图景与操作
<blockquote style="background:#fff8e1">

【概念深挖】**链式法则（chain rule）**：若 g 在 x 可导，f 在 g(x) 可导，则复合函数 f∘g 在 x 可导，且
$$(f\circ g)'(x) = f'(g(x))\cdot g'(x).$$
- **用符号看**：外层导数 f'(·) 在"内层整体"g(x) 处取值，再乘内层导数 g'(x)。
- **"齿轮"直觉**：dz/dx = (dz/dy)·(dy/dx)——z 对 x 的变化率 = "z 对中间量 y 的变率" × "中间量 y 对 x 的变率"。**中间层是'传动'。**
- **操作口诀**："外层导（内层不变）× 内层导"。**sin(x²)' = cos(x²)·(x²)' = cos(x²)·2x。**

**为什么叫"链"**：多层复合 y=g(x), z=f(y), w=h(z) 时，dw/dx = dw/dz·dz/dy·dy/dx——**一条传动链，逐层相乘**（这正是"多层链式逐层展开"的由来）。

【工程实践】**链式法则 = 反向传播（backpropagation）的心脏**：神经网络把输入逐层通过激活函数（复合函数），要算损失对每个权重的梯度，靠的正是"链式法则从输出层往回逐层回传"。**你在这里学的一个"乘法"规则，就是所有深度学习训练引擎（PyTorch/TensorFlow 的自动微分）在算梯度时的数学本质。**
</blockquote>

### 第 4 轮：多层链式——"一层套一层"怎么剥

**老谟**："你会在 sin(x²) 这种'两层'上用了链式。**那遇到'三层、四层'呢？** 比如 sin((2x+1)³)——外层 sin，中层 (·)³，内层 (2x+1)。**它的导数，你想怎么一层层剥？**"

**造物主**："……从外往里剥？**先当它只有'外层 sin 套着一个整体'：导数 = cos((2x+1)³) × (整体 (2x+1)³ 的导数)。** 然后 (2x+1)³ 本身又是复合：它的导数是 3(2x+1)² × (2x+1)' = 3(2x+1)²·2 = 6(2x+1)²。**所以整个 = cos((2x+1)³)·6(2x+1)²。**"

**老谟**："**剥洋葱，从外到里一层层剥，每层'外层导×内层导'。** 你注意到没有——**每剥一层，外层导数里那个'整体'要保持不变，只动当前这一层，然后乘上往里一层。** 这套'逐层展开'，就是链式法则在多层复合里的标准操作。具体怎么一步步写，计算训练场里练。"

**造物主**："……那万一复合里还夹着乘法、商呢？比如 sin(x²)·eˣ 这种'复合×复合'？"

**老谟**："**那就要'法则套法则'——先用积法则把 sin(x²)·eˣ 拆成两个因子，每个因子再用链式法则。** 这就是拼积木的'组合'：一条规则处理一个'接点'。**你这一章练的，就是熟练地认出'每个接点该用哪条法则'，再逐层/逐项套。**"

### 📐 知识锚点：求导法则的"决策"——先看组合方式
<blockquote style="background:#e3f2fd">

【概念深挖】**求导时"先看什么"的决策清单**（碰到一个函数，先问它"怎么拼的"）：
- **是两数相加/相减** → 和差法则，各导各。
- **是常数×函数** → 数乘，提出常数。
- **是两函数相乘** → 积法则，f'g+fg'。
- **是两函数相除** → 商法则，(f'g−fg')/g²。
- **是复合（A 套 B）** → 链式法则，外层导×内层导，逐层剥。
- **混合** → 每个"接点"各用一条，法则可以嵌套（先用积法则拆，再用链式逐项）。

**多层链式的"剥洋葱"写法**（逐层展开）：
```text
设 h(x) = sin((2x+1)³)。
1. 最外层 sin 套整体：h'(x) = cos((2x+1)³) · d/dx[(2x+1)³]
2. 中层 (·)³ 套整体：     = cos((2x+1)³) · 3(2x+1)² · d/dx[(2x+1)]
3. 内层线性：              = cos((2x+1)³) · 3(2x+1)² · 2
4. 合并：                  = 6(2x+1)² · cos((2x+1)³)
```
**每层"外层导"里的整体保持不变**，这是链式法则最易错也最关键的地方。

【工程实践】"先看怎么拼、再选法则"= 工程师拆解复杂系统的思维：**把大问题分解成子模块，每个子模块用对应的求解器，再按模块间的耦合（乘法/复合/加法）组合结果**。自动微分正是把"逐层剥洋葱"机械化为计算图上的反向传播——**你手工逐层求导的动作，机器只是更快地重复它。**
</blockquote>

### 第 5 轮：商法则与隐函数——"除"和"绕弯"的导数

**老谟**："复合你会了。再补两个'拼法'——**商**和**隐函数**。先看商：f/g 的导数，你能不能从'积法则 + 倒数'推出来？提示：f/g = f × (1/g)。**

**造物主**："……1/g 的导数？(1/g)' = −g'/g²（用商定义或积法则配）。然后 f×(1/g) 用积法则：f'·(1/g) + f·(−g'/g²) = **(f'g − fg')/g²**。这就是商法则！"

**老谟**："**对，商法则 (f/g)'=(f'g−fg')/g²，可以从积法则+倒数法则推，不必另证。** 那再看一个更'绕弯'的——**隐函数**。比如 x² + y² = 25 定义了一个圆，y 是 x 的隐函数（没显式解出 y）。**你想求 dy/dx，可 y 没解出来，怎么办？** 提示：两边同时关于 x 求导，把 y 当成 x 的复合函数。"

**造物主**："……两边对 x 求导：**d/dx[x²] + d/dx[y²] = d/dx[25]**。第一项 2x；第二项 y² 是'外层平方套 y'，用链式：2y·y'；右边常数导数是 0。所以 **2x + 2y·y' = 0 ⟹ y' = −x/y**。在圆上点 (3,4)：y' = −3/4——斜率为 −3/4，对，圆的切线方向！"

**老谟**："**你把'隐函数求导'也拿下了——两边对 x 求导，把 y 当 x 的复合（用链式），再解出 y'。** 你这一章已经把四则 + 复合 + 隐函数全打通了。下一轮，我们把链式法则的'为什么能乘'收个尾——那个'差分比相乘'的证明直觉。"

### 📐 知识锚点：商法则与隐函数求导
<blockquote style="background:#fff8e1">

【概念深挖】**商法则（quotient rule）**：(f/g)' = (f'g − fg')/g²。
- **推导**：f/g = f·(1/g)，用积法则 + (1/g)'=−g'/g²。（(1/g)' 可用积法则配：令 h·(1/g)=1，两边求导 0=h'(1/g)+h(1/g)' ⟹ (1/g)'=−h'/h²=−g'/g²。）
- **口诀**："上导下不导 − 上不导下导，除以分母平方"。

**隐函数求导（implicit differentiation）**：若 F(x,y)=0 隐式定义 y=y(x)，对两边关于 x 求导，把 y 当作 x 的函数（**凡遇 y 用链式乘 y'**），再解出 y'。
- 例：x²+y²=25 ⟹ 2x+2y·y'=0 ⟹ y'=−x/y。
- **要点**：① 遇到含 y 的项，用链式乘 y'（y 是 x 的复合）；② 解出 y' 时把含 y' 的项并到一边。

**参数方程求导（parametric differentiation）**（蓝图计算训练场要求）：若 x=x(t)、y=y(t)，则 **dy/dx = (dy/dt)/(dx/dt)**（链式法则 dz/dx=(dz/dt)/(dx/dt) 的直接推论）。
- 例：x=t−sin t，y=1−cos t ⟹ dy/dx = (sin t)/(1−cos t)。

【工程实践】隐函数与参数方程在工程里对应"关系由约束隐式给出"的场景：**隐式曲面（F(x,y,z)=0）、约束优化、轨迹用参数方程描述（导弹/机器人路径）**——要求"沿着约束的变化率"，正是隐函数/参数方程求导。**在机器学习里，损失对参数的梯度常需解隐式关系，自动微分对这类'约束梯度'的处理，本质就是隐函数求导的规模化。**
</blockquote>

<blockquote style="background:#e3f2fd">

【概念深挖】**"差分比相乘"（链式法则证明的核心改写）**：设 y=g(x)，考察 x→a 时复合差商：
$$\frac{f(g(x))-f(g(a))}{x-a} = \frac{f(g(x))-f(g(a))}{g(x)-g(a)} \cdot \frac{g(x)-g(a)}{x-a}.$$

- **第二个因子**：g 对 x 的差商 → g'(a)（g 在 a 可导）。

## 严格化走廊

> 位置说明：对话负责"直觉"——为什么复杂函数要拆成简单函数的组合、为什么链式是"外层导×内层导"。本走廊负责"严谨"——把求导法则落成精确形式，并给出本册第一个**完整可复写**的关键证明：**链式法则（定理 1，用"差分比相乘"标准证明）**，以及**积法则（定理 2）**。每个证明都标注"证明类型 + 每一步依据"，这是红线 1 的硬要求。

### 定义：求导法则（精确表述）

设 f、g 在 x 处可导，c 为常数。则（在 x 处）：
1. **和差法则**：(f±g)' = f'±g'；
2. **数乘法则**：(cf)' = c·f'；
3. **积法则**：(fg)' = f'g + fg'；
4. **商法则**：(f/g)' = (f'g − fg')/g²（g(x)≠0）；
5. **链式法则**：若 g 在 x 可导、f 在 g(x) 可导，则 (f∘g)'(x) = f'(g(x))·g'(x)。

> **证明类型标注**：本章的核心证明——**定理 1（链式法则）用直接证明（差分比相乘 + 连续性 + 乘积极限）**，承接册02 的极限语言与 Ch1 的"差商×h"改写；**定理 2（积法则）用直接证明（中间插项 + 连续性 + 极限线性）**。**商法则**作为积法则+倒数法则的推论（直接推导，不必独立成定理）。
>
> **关于对话**：本章第 3、6 轮是读者**第一次**正式接触"链式法则"及其证明，对话做了"引导式推导"（为什么想到"齿轮/连锁"、为什么想到"差分比相乘"）。**正式的可复写证明（每一步标依据）在本走廊定理 1**。对话负责"为什么会想到这步"，走廊负责"怎么把它写标准"——与册02 第 03/04 章及册03 第 01 章口径一致。

### 定理 1（链式法则）：若 g 在 a 可导、f 在 g(a) 可导，则 (f∘g)'(a) = f'(g(a))·g'(a)

**前提**：g 在 a 的某邻域有定义且可导；f 在 g(a) 的某邻域有定义且可导。

**结论**：(f∘g)'(a) 存在，且等于 f'(g(a))·g'(a)。

**证明类型**：直接证明（差分比相乘 + g 连续 + 乘积极限）。

**证明**：
- 第 1 步：**改写目标**：由导数定义，要证
  $$\lim_{x\to a}\frac{f(g(x))-f(g(a))}{x-a} = f'(g(a))\cdot g'(a).$$
  （依据：导数的极限定义（Ch1）。）
- 第 2 步：**定义辅助差商（动机铺垫）**：对满足 g(x)≠g(a) 且 x≠a 的 x，可定义
  $$Q(x) = \frac{f(g(x))-f(g(a))}{g(x)-g(a)}.$$
  （依据：这是 f 对"中间量 g"的差商，体现"差分比相乘"的直觉。**注意：Q 只在 g(x)≠g(a) 时有意义，故正式证明不直接用它**——下面第 3 步改用更稳的"误差刻画"，它对 g(x)=g(a) 也成立，绕开了分母为零的坑。Q 的意义在"看懂思路"，正式推演走误差刻画。）
- 第 3 步：**建立"误差刻画"**：因 f 在 g(a) 可导，由导数定义，当 g(x)→g(a) 时
  $$f(g(x))-f(g(a)) = f'(g(a))\cdot(g(x)-g(a)) + \varepsilon_1(x)\cdot(g(x)-g(a)),$$
  其中 ε₁(x)→0（g(x)→g(a) 时）。**此式对 g(x)=g(a) 也成立（两边都等于 0）**，故不必区分 g(x) 是否等于 g(a)。（依据：可导 ⟹ 差商可写成"导数值 + 无穷小误差"形式，等价于导数定义。这一步正是红线要求的严谨处理：绕开"差分比分母为零"的坑。）
- 第 4 步：**写 g 的差商**：因 g 在 a 可导，
  $$g(x)-g(a) = g'(a)\cdot(x-a) + \varepsilon_2(x)\cdot(x-a),$$
  其中 ε₂(x)→0（x→a 时）。（依据：g 在 a 可导，同样的误差刻画。）
- 第 5 步：**合并（差分比相乘的核心）**：把第 4 步代入第 3 步，再除以 x−a：
  $$\frac{f(g(x))-f(g(a))}{x-a} = f'(g(a))\cdot g'(a) + f'(g(a))\cdot\varepsilon_2(x) + \varepsilon_1(x)\cdot g'(a) + \varepsilon_1(x)\varepsilon_2(x).$$
  （依据：把 f(g(x))−f(g(a)) 展开，代入 g(x)−g(a)=g'(a)(x−a)+ε₂(x)(x−a)，再除以 x−a。这是"差分比相乘"的严谨展开版：两块差商的乘积 + 交叉误差项。）
- 第 6 步：**取极限**：因 ε₁(x)→0、ε₂(x)→0（x→a 时），上式右端除 f'(g(a))·g'(a) 外各项都趋于 0（f'(g(a)) 是常数）：
  $$\lim_{x\to a}\frac{f(g(x))-f(g(a))}{x-a} = f'(g(a))\cdot g'(a).$$
  （依据：乘积/和的极限法则 + 无穷小收敛到 0。）
- 第 7 步：由导数定义，(f∘g)'(a) = f'(g(a))·g'(a)。∎

> **依据标注**：步 1 用导数定义改写目标；步 2 用"差商"定义（f 对中间量）；步 3 用"可导 ⟹ 差商=导数值+无穷小误差"（等价于导数定义，且**绕开了 g(x)=g(a) 时分母为零的坑**——这是严谨性的关键）；步 4 用 g 可导的误差刻画；步 5 用代入与代数展开（差分比相乘的思想：外层差商×内层差商 + 交叉误差）；步 6 用"无穷小×有界/常数 → 0"与极限四则运算；步 7 用导数定义收束。
> **读法**：这个证明的发动机是第 3、4 步的"误差刻画"——把"差分比相乘"这个直觉写成严格形式，同时绕开"g(x)=g(a) 时分母为 0"的坑（那是"差分比直接相乘"写法不成立的隐蔽漏洞）。**它与 Ch1"可导⇒连续"的证明同一精神：把复合差商拆成"两块都有极限的差商之积 + 可忽略的交叉误差"。** 如果你只用"差分比相乘"而不管 g(x)=g(a)，会在极端情况（g 在 a 附近取常值）出错——这正是红线"不许无限接近/显然糊弄"要防的。

### 定理 2（积法则）：若 f、g 在 x 可导，则 (fg)'(x) = f'(x)g(x) + f(x)g'(x)

**前提**：f、g 在 x 的某邻域有定义且可导。

**结论**：(fg)'(x) = f'(x)g(x) + f(x)g'(x)。

**证明类型**：直接证明（中间插项 + 连续性 + 极限线性）。

**证明**：
- 第 1 步：**改写目标**：要证 lim_{h→0} [f(x+h)g(x+h) − f(x)g(x)]/h = f'(x)g(x) + f(x)g'(x)。（依据：导数定义。）
- 第 2 步：**中间插项（关键改写）**：在分子中间插入 f(x+h)g(x)（保持等式不变，一加一减）：
  $$f(x{+}h)g(x{+}h) - f(x)g(x) = \big[f(x{+}h)g(x{+}h) - f(x{+}h)g(x)\big] + \big[f(x{+}h)g(x) - f(x)g(x)\big].$$
  （依据：代数恒等式——插入 f(x+h)g(x)，一加一减抵消。）
- 第 3 步：**分解成两个差商**：提取公因式：
  $$= f(x{+}h)\big[g(x{+}h)-g(x)\big] + g(x)\big[f(x{+}h)-f(x)\big].$$
  （依据：提出 f(x+h) 与 g(x)。）
- 第 4 步：**除以 h 取极限**：
  $$\lim_{h\to0}\frac{f(x{+}h)g(x{+}h)-f(x)g(x)}{h} = \lim_{h\to0} f(x{+}h)\cdot\frac{g(x{+}h)-g(x)}{h} + g(x)\cdot\lim_{h\to0}\frac{f(x{+}h)-f(x)}{h}.$$
  （依据：极限的线性——和的极限=极限的和；常因子 f(x+h)、g(x) 提出。注意 f(x+h)→f(x) 用了 f 可导⟹连续。）
- 第 5 步：**代入已知极限**：lim f(x+h)=f(x)（f 连续）；lim [g(x+h)−g(x)]/h = g'(x)（g 可导）；lim [f(x+h)−f(x)]/h = f'(x)（f 可导）。故上式 = f(x)·g'(x) + g(x)·f'(x)。（依据：连续性 + 导数定义。）
- 第 6 步：由导数定义，(fg)'(x) = f'(x)g(x) + f(x)g'(x)。∎

> **依据标注**：步 1 用导数定义；步 2 用"中间插项"（把乘积的差商拆成两块——这是积法则的核心技巧）；步 3 用提取公因式；步 4 用极限的线性（和可拆、常数因子可提）+ f 连续（f(x+h)→f(x)）；步 5 用导数定义；步 6 用导数定义收束。
> **读法**：积法则证明的钥匙是第 2 步"中间插项"——**在 f(x+h)g(x+h)−f(x)g(x) 中间插入 f(x+h)g(x)**，把它拆成"第一项 g 变、f 固定"和"第二项 f 变、g 固定"两块，正好对应公式里的 f(x)g'(x) 和 g(x)f'(x)。**这个"插项"招，和链式法则的"差分比相乘"一样，都是"把一个差商拆成你能控制的两块"。**
> **推论（商法则，直接推导）**：(1/g)' = −g'/g²（由积法则：(g·(1/g))'=0 ⟹ g'(1/g)+g(1/g)'=0 ⟹ (1/g)'=−g'/g²）；再由积法则：(f/g)' = (f·(1/g))' = f'(1/g)+f(−g'/g²) = (f'g−fg')/g²。∎

### 求导法则的书写格式模板（可复写卡片——对着空白纸照写）

> 这是本章要你抄进脑子的卡。**以后你碰到任何"求导"题，就照这个骨架走**：

```text
命题：求 h'(x)（h 由 f、g 等组合而成）。
计算（套法则）：
  1. 认"怎么拼"：h 是 和/差/积/商/复合 中的哪种（每个接点各一种）？
  2. 按对应法则套：
     - 和/差：各导各再加减。
     - 积：f'g + fg'（前导后不导 + 前不导后导）。
     - 商：(f'g − fg')/g²。
     - 复合（链式）：外层导（内层整体不变）× 内层导，逐层剥。
  3. 若嵌套：先外后内逐层套，每层"外层导里的整体保持原样"。
  4. 化简合并。∎
```

**填写时的三个检查点**：① **先认"怎么拼"再套法则**，别对着整个式子盲目套；② **链式时"外层导里的整体要保持原样"**——sin(x²) 的外层导是 cos(x²)，不是 cos(x)；③ **隐函数/参数方程要"两边求导乘 y' / 除 dt"**，别漏了 y' 或 dy/dt。

### 反例/边界：求导法则的适用边界

1. **积法则 ≠ f'g'**：f=x、g=x 时 f'g'=1 但 (x²)'=2x。**乘法必须"交叉"（f'g+fg'），不能各导各。**
2. **商法则要求 g(x)≠0**：f/g 在 g(x)=0 处无定义，谈不上求导。**别对分母为零的点套商法则。**
3. **链式法则要求 f 在 g(a) 可导、g 在 a 可导**：若内层 g 在 a 不可导（如 |x|），或外层 f 在 g(a) 不可导，链式不保证成立。**例：f(u)=|u|、g(x)=x²，复合 f(g(x))=x² 在 0 可导，但"硬套"f'(g(0))g'(0) 需 f 在 0 可导——f 在 0 不可导，链式不能直接套（此处复合函数本身可导是另一回事）。** 判断时先看两个前提是否满足。
4. **"法则套法则"的嵌套顺序**：多层复合先剥外层，再逐层往里；混合（积×复合）先用积法则拆，再对每个因子用链式。**别把外层导和内层导的位置搞反。**
5. **隐函数求导易漏 y'**：凡遇含 y 的项，用链式时一定要乘 y'（y 是 x 的函数）。**漏乘 y' 是最常见的算错点。**

## 知识点总结

### 知识点（本章推出的核心概念）

- **求导法则 = 拼积木**：复杂函数 = 简单函数的组合；每种组合（和/积/商/复合）对应一条求导规则。
- **和差/数乘法则**：(f±g)'=f'±g'；(cf)'=c·f'。**依据极限线性。**
- **积法则**：(fg)'=f'g+fg'。**中间插项 + 连续性；≠ f'g'。**
- **商法则**：(f/g)'=(f'g−fg')/g²。**积法则+倒数法则的推论。**
- **链式法则**：(f∘g)'=f'(g)·g'。**外层导（内层整体不变）×内层导；"齿轮"传动；证明用"差分比相乘"。**
- **多层链式**：逐层剥洋葱，每层"外层导×内层导"。
- **隐函数求导**：两边对 x 求导，含 y 项用链式乘 y'，再解 y'。
- **参数方程求导**：dy/dx=(dy/dt)/(dx/dt)。

### 历史结论（本章涉及的史料）

- **牛顿（流数法）/莱布尼茨（无穷小）**（17 世纪）：各自建立微积分，求导法则（和/积/商/链式）作为"算法"基本成型。
- **链式法则的严格证明**：依赖 19 世纪柯西/魏尔斯特拉斯用 ε-δ 极限把导数钉死，"无穷小"悖论消失后，链式法则的"差分比相乘"才能严谨成立。
- **"积法则≠f'g'"的坑**：初学几乎必踩，直到极限定义下的"插项"才看清本质。

### 工程实践结论（本章知识在真实工程里怎么用）

- **链式法则 = 反向传播（backpropagation）**：神经网络算梯度靠链式从输出逐层回传，是所有深度学习训练引擎（自动微分）的数学本质。
- **自动微分（autodiff）**：把函数建成计算图，节点是运算、边是导数，沿图反向传播——就是"逐层套法则"的机械化。
- **隐函数/参数方程 = 约束/轨迹的导数**：隐式曲面、约束优化、机器人路径（参数方程）求变化率都靠它们。
- **"先认怎么拼、再选法则" = 系统拆解思维**：工程师把复杂系统拆成模块、按模块耦合组合结果。

## 计算训练场

> 位置说明：对话负责"为什么要求导法则"，这里负责"怎么算"。下面三题**必须动笔**，每题 10 分钟以上，先自己写再对答案。**难度递进：易→中→难。** 重点是亲手"认拼法→套法则→逐层/逐项展开"。

### 题 1（易→中）：多层链式逐层展开——sin(cos(x²))

**题干**：老谟让造物主求 h(x)=sin(cos(x²)) 的导数 h'(x)，并**逐层写出**（三层复合：sin 套 cos 套 x²）。

**完整分步解答：**

- 第 1 步：**认拼法**：sin(cos(x²)) 是三层复合——外层 sin、中层 cos、内层 x²。用链式逐层剥（从外到里）。
- 第 2 步：**最外层**（sin 套"整体"）：
  h'(x) = cos(cos(x²)) · d/dx[cos(x²)]。
  （外层 sin 导 = cos(内层整体)。）
- 第 3 步：**中层**（cos 套 x²）：
  d/dx[cos(x²)] = −sin(x²) · d/dx[x²]。
  （外层 cos 导 = −sin(内层整体)。）
- 第 4 步：**内层**：d/dx[x²] = 2x。
- 第 5 步：**合并**：
  h'(x) = cos(cos(x²)) · [−sin(x²) · 2x] = **−2x·sin(x²)·cos(cos(x²))**。

**答**：h'(x) = **−2x·sin(x²)·cos(cos(x²))**。

**常见错误**：① 中层求导时忘了"外层 cos 导 = −sin(x²)"里的负号；② 把外层导写成 cos(cos(x²))·(−sin(x))——**内层整体是 x² 不是 x，必须保持整体**；③ 三层复合只剥了两层就收手。

### 题 2（中）：隐函数求导——sin(xy) = x + y

**题干**：老谟给了一个由方程 sin(xy) = x + y 隐式定义的关系，让造物主求 dy/dx，并在点 (0,0) 处求导数值（先验证该点在曲线上）。

**完整分步解答：**

- 第 1 步：**验证点**：x=0、y=0 时，左 sin(0·0)=sin0=0，右 0+0=0，相等。(0,0) 在曲线上 ✓。
- 第 2 步：**两边对 x 求导**（把 y 当作 x 的函数，凡遇 y 用链式乘 y'）：
  d/dx[sin(xy)] = d/dx[x + y]。
- 第 3 步：**左边用链式**：sin(xy) 外层 sin、内层 xy。d/dx[sin(xy)] = cos(xy)·d/dx[xy]。
  d/dx[xy] 用积法则（x 导 ×y + x×y'）= 1·y + x·y' = y + x·y'。
  所以左边 = **cos(xy)·(y + x·y')**。
- 第 4 步：**右边**：d/dx[x+y] = 1 + y'。
- 第 5 步：**列方程并解 y'**：
  cos(xy)(y + xy') = 1 + y'
  ⟹ y·cos(xy) + x·cos(xy)·y' = 1 + y'
  ⟹ y'·(x·cos(xy) − 1) = 1 − y·cos(xy)
  ⟹ **y' = (1 − y·cos(xy)) / (x·cos(xy) − 1)**。
- 第 6 步：**代入 (0,0)**：x=0、y=0 时，cos(0·0)=cos0=1。
  y' = (1 − 0·1) / (0·1 − 1) = 1/(−1) = **−1**。
- **答**：dy/dx = (1 − y·cos(xy))/(x·cos(xy) − 1)；在 (0,0) 处，**dy/dx = −1**。

**常见错误**：① 求 d/dx[sin(xy)] 时漏了内层 xy 的导数（用积法则，得 y+xy'，不是 y）；② 解 y' 时没把含 y' 的项并到一边；③ 代入 (0,0) 时把 cos(xy) 算错（cos0=1，不是 0）。

### 题 3（难）：参数方程求导——x = t − sin t，y = 1 − cos t

**题干**：老谟给参数方程 x(t) = t − sin t，y(t) = 1 − cos t，让造物主求 dy/dx（作为 t 的函数），并在 t=π/2 处求值。

**完整分步解答：**

- 第 1 步：**求 dx/dt 和 dy/dt**：
  dx/dt = d/dt[t − sin t] = 1 − cos t。
  dy/dt = d/dt[1 − cos t] = sin t。
- 第 2 步：**用参数方程求导公式**：dy/dx = (dy/dt)/(dx/dt) = **sin t / (1 − cos t)**。
- 第 3 步：**在 t=π/2 求值**：sin(π/2)=1，cos(π/2)=0。
  dy/dx = 1 / (1 − 0) = **1**。
- **答**：dy/dx = sin t/(1 − cos t)；在 t=π/2 处，**dy/dx = 1**。

**常见错误**：① 把 dx/dt 和 dy/dt 求反（dx/dt 是分母，dy/dt 是分子）；② 求 dy/dt 时 cos 的导数符号（d/dt[1−cos t]=sin t，不是 −sin t）；③ 在 t=π/2 代入时忘了 cos(π/2)=0、sin(π/2)=1。

## 造物主手记

**我曾踩的坑**：

我一开始以为积法则就是"各导各再相乘"（(fg)'=f'g'），被 f=x、g=x 的例子堵死——(x²)'=2x 不是 1。被点破才明白**乘法必须"交叉"：前导后不导 + 前不导后导**。链式法则我第一次写 sin(x²) 的导数，差点写成 cos(x)（把内层整体丢了）——**外层导里的整体必须保持原样**，是 cos(x²) 不是 cos(x)。最险的是隐函数求导：d/dx[sin(xy)] 我漏了内层 xy 的导数，只写了 cos(xy)，被提醒"xy 是 x 的函数，要用积法则得 y+xy'，还要乘 y'"。参数方程我一度把 dx/dt 和 dy/dt 的次序搞反。

**顿悟时刻**：

真正开窍是"差分比相乘"那一幕——我把 (f(g(x))−f(g(a)))/(x−a) 中间插一个 g(x)−g(a)，突然就看出链式法则"外层导×内层导"不是规定，是**两块差商相乘的极限自然给出的**。这和上一章"差商×h"是同一个灵魂：**把一个控制不了的差商，拆成两块能控制的差商。** 而"先认怎么拼、再选法则"这套动作，让我意识到求导不再是苦力活，是像搭乐高一样"看接点、选积木"。原来**复杂，不过是简单的正确组合**。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：复合函数求导**

求 h(x) = (sin(3x) + 1)⁵ 的导数 h'(x)。

**完整解答**：外层 (·)⁵ 套整体，h'(x) = 5(sin(3x)+1)⁴ · d/dx[sin(3x)+1] = 5(sin(3x)+1)⁴ · (3cos(3x)) = **15cos(3x)(sin(3x)+1)⁴**。（内层和法则：d/dx[sin(3x)+1]=3cos(3x)+0。）

**题 B（计算，中→难）：隐函数求导**

求由 x² + y² = 25 定义的 y 在点 (3,4) 处的导数 dy/dx。

**完整解答**：两边对 x 求导：2x + 2y·y' = 0 ⟹ y' = −x/y。代入 (3,4)：y' = −3/4。**答：dy/dx = −3/4**。（几何意义：圆 x²+y²=25 在 (3,4) 的切线斜率 −3/4，垂直于半径斜率 4/3 ✓。）

**题 C（概念，检查理解）**

(a) 为什么 (fg)' ≠ f'g'？给出反例。
(b) 链式法则 (f∘g)'=f'(g)·g' 里，"f'(g)"表示什么？为什么外层导里的"整体"要保持不变？
(c) 隐函数求导时，遇到含 y 的项为什么要"乘 y'"？

**完整解答**：
(a) f=x、g=x 时 fg=x²，左边 (x²)'=2x，右边 f'g'=1×1=1，不等。积法则必须"交叉"：f'g+fg'。
(b) f'(g) 表示 f 的导数在外层函数值 g(x) 处取值——即"把内层 g(x) 当整体，求外层 f 的导数"。因为链式求导时，当前这一层是"f 随 g 变"，g 是一个整体（就像齿轮的中间轴），所以 f' 里要保持 g(x) 原样，再乘内层导 g'。
(c) 因为 y 是 x 的函数（隐式），d/dx[y] = y'（链式：y 对 x 求导就是 y'）。遇到 y²、sin(y) 等含 y 的项，外层对 y 求导后还要乘 dy/dx=y'——否则漏了"y 随 x 变"的贡献。

## 预告

你终于把"算导数"从"回定义"升级成了"拼积木"——**和/积/商/复合法则 + 隐函数 + 参数方程**，还亲手证明了链式法则（差分比相乘）。你手上的算力，已经能算几乎所有"拼得出来"的函数的导数了。

可"会算导数"只是第一步。下一章，我们要问一个更深刻的问题：**算出来的导数，能告诉我们函数长什么样？** 有个看似平凡的观察：你开车从 A 到 B，平均速度 60 km/h，那途中**某个时刻**，你的瞬时速度一定恰好是 60 km/h 吗？——**这就是"中值定理"要回答的：平均变化率，途中某点真的会"达到"吗？** 这一章，我们要从"费马引理"一路走到"拉格朗日中值定理"，它是下一章积分（FTC）和后面泰勒展开的地基。**把链式法则和求导法则练熟，下一章要用它们来"反推函数行为"。**
