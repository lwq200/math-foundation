# 《图论与可计算性》· 第 7 册

> **苏格拉底对话体自学教材**，老谟 ⇄ 造物主一问一答，让读者从零亲手推导图论与可计算性。本册是《数学基础》系列 7 册中的**最后一册**，承接第 06 册（概率统计与信息），把"数学能做什么"推到最根本的问题——**算的边界在哪里**。
>
> **核心立场**：本册是"节奏平衡"红线的**样板册**——原样书 Ch16 把图论、NP-难、停机问题三大板块"报菜名"式压缩在一章里，本册拆为 **8 章**、每章 ≥6 轮对话，把"报菜名"变成"逐道硬菜"。从图论的具体算法出发，走到图灵机（什么能算）、停机问题（什么注定算不出来）、P vs NP（算得出来的里面，难度怎么分级）。**七册筑成《数学基础》全系列**，本册为其收官。

## 本册 8 章

| 章 | 主题 | 关键推导 |
|----|------|----------|
| 01 图的基础 | 一堆点和线，凭什么是"数学"？ | 握手引理（∑度=2\|E\|）→ 奇度顶点数为偶数 → 一笔画必要条件（3 个可复写证明） |
| 02 树与图的遍历 | 怎么保证走遍一座"图城"不迷路？ | n 顶点树恰有 n−1 边 → 连通图必有生成树 → BFS 不漏且给最短距离 |
| 03 最短路径（Dijkstra） | 导航凭什么知道"最短"？ | 松弛/最优子结构 → Dijkstra 贪心选择正确性（归纳） |
| 04 图着色 | 地图染色，最少几种颜色？ | 贪心着色 Δ+1 上界 → 贪心着色顺序敏感（存在用色>χ 的图） |
| 05 欧拉与哈密顿 | 一笔画的问题，和找旅行线路的问题一样吗？ | 欧拉回路 ⟺ 连通且全偶度（双向证明）→ TSP 候选回路 (n−1)!/2 |
| 06 计算模型（图灵机） | "能算"到底是什么意思？ | 图灵机七元组/格局 → 确定性=每步转移唯一 → 图灵机可模拟有限自动机（构造） |
| 07 可判定性与停机问题 | 有没有算不出来的问题？ | **停机问题不可判定——完整反证法（全册皇冠）** → 可判定 ⇒ 可识别 |
| 08 复杂度理论（P/NP） | 算得出来 vs 算得快，是两回事吗？ | 时间复杂度/大 O → P、NP 定义 → P ⊆ NP（直接法）→ 归约单调性 → NP-完全直觉 |

## 每章标配（继承 skill 升级后的铁律）

- **严格化走廊**：定义 → 定理（带全前提）→ 可复写完整证明（每步标"证明类型 + 依据"，禁"显然"）→ 反例/边界。全册共 **17 个可复写证明**，跨章递进铺垫证明方法：第 1 章就埋下**反证法**（一笔画必要条件）、第 7 章把反证法推到**完整停机问题反证法**（构造 D 吃自己）。
- **计算训练场**：每章 ≥3 道中大型计算题（动笔 10 分钟+），易→中→难，附完整分步解答 + 常见错误 + 反向核算。图算法（Dijkstra 逐轮更新表、BFS/DFS 访问序、贪心着色）全部**完整手算**。
- **对话/证明分离**：对话只推"为什么想到这步"（引导式推导），公式与证明全部交给走廊，不演定理；每章走廊均含"关于对话"注明口径。
- **节奏平衡**：三大板块（图论/NP-难/停机问题）各成多章、给足篇幅，绝不报菜名；停机问题反证法从第 1 章起逐步铺垫证明方法。
- **跨册/跨章衔接**：本册内部形成"图论算法 → 图灵机 → 停机问题 → P vs NP"的主线（第 6 章埋"非确定=转移关系"伏笔，第 7 章兑现，第 8 章承接"可判定但难算 vs 不可判定"）；并承接册 06（概率）与册 01（逻辑与数、反证法地基）。
