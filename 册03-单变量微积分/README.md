# 《单变量微积分》· 第 3 册

> **苏格拉底对话体自学教材**，老谟 ⇄ 造物主一问一答，让读者从"瞬时速度到底是谁的速度"（第 01 章）出发，一路走到"机器怎么算'算不出来'的微积分"（第 08 章）——把导数、积分、级数、泰勒、数值方法全部走通。本册是《数学基础》系列 7 册中的第 **3** 册，是**微积分的计算与证明并重的核心卷**。
>
> **核心立场**：本册在保留样书 Ch6-8（导数/积分/级数）推导节奏的基础上，系统补足"严格"与"工程"两翼——**每一条求导/积分法则都给出可复写证明（MVT、泰勒、误差阶），每一个数值方法都给出误差可估计的落地（牛顿法、梯形、辛普森）**。**"证明 + 计算并重"：该证的绝不省（中值定理、泰勒定理、级数判别、误差阶），该算的绝不糊（导数、积分、级数终值、数值方法）。**

## 每章标配（继承 skill 升级后的铁律）

- **严格化走廊**：定义 → 定理（带全前提）→ ≥2 个完整可复写证明 → 反例/边界。**本册的证明要"算得出 + 证得清"：求导/积分公式给完整推导，MVT/泰勒/误差阶给完整证明，每步标注依据，绝不用"显然"。**
- **证明类型标注**：每一章走廊都标明证明的"招式"——MVT 证不等式（直接构造 c）、换元/分部（链式/乘积倒过来）、级数判别（几何级数比较/单调有界）、泰勒定理（构造性+反复柯西 MVT）、误差阶（单段局部误差+累加）。**读证明先问"用的哪一招"。**
- **书写格式模板卡（本册特色）**：第 05 章给「换元/分部决策卡」，第 06 章给「级数判别决策树」，第 07 章给「展开+收敛半径+余项估误差卡」，第 08 章给「牛顿法/数值积分卡」——这是后续多元微积分、数值计算所有逼近类问题的通用脚手架。
- **红线口径统一**：对话只推"为什么想到这步"的直觉（引导式推导），**完整可复写证明一律在走廊，对话不演证明**（第 05-08 章走廊均明确标注"关于对话"口径）。
- **跨章脊柱（链条式知识）**：FTC（Ch4）依赖 Ch3 中值定理；泰勒定理（Ch7）反复用 Ch3 柯西中值定理；牛顿法/误差阶（Ch8）用 Ch7 泰勒 + Ch3 中值；数值积分衔接 Ch4 黎曼和。**断一截漏一截，环环踩实。**
- **计算训练场**：每章 ≥3 道中大型计算/证明题（动笔 10 分钟+），易→中→难，附完整分步解答 + 常见错误 + 反解 N/δ/c/误差阶实操。
