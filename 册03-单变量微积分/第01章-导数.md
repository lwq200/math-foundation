# 第 01 章 · 导数——极限定义下的瞬时变化率

> 本章从哪个问题出发：你在册02 用 ε-δ 钉死了"函数极限"，又用"极限值=函数值"钉死了连续。可你心里一直压着一个从中学就缠着你的问题：**"瞬时速度"到底是谁的速度？** 汽车仪表盘显示"此刻 60 km/h"——可"此刻"没有时长，没有时长就没有路程，没有路程哪来的速度？"瞬间的变化率"这种说法，数学上站得住脚吗？
> 推导到哪个结论：你会看到，"瞬时速度"不是"某一段的速度"，而是**平均速度在时间间隔趋于 0 时的极限**。把它写下来，就是**导数**的定义：f'(a) = lim_{h→0} (f(a+h)−f(a))/h。你会亲手证明第一个微积分定理——**可导必连续**（从极限定义推出，绝不用"显然"），还会看到"连续却不可导"的反面样板。
>
> 核心认知：**导数 = 差商的极限。** "瞬时变化率"不是玄学，是"把平均变化率的间隔压到 0，看它逼近谁"。这一章是全册微积分的门口：导数（变化率）与积分（累积量）是互逆的两面，而**可导 ⇒ 连续**这条链，是你在册02 打下的"完备性→极限→连续"脊柱在微积分里的第一次延伸。

## 引子

我趴在老谟书房的桌上，面前摊着一张高速公路的照片——一辆车，车头正对着一块"120"的限速牌。

"老谟，"我指着照片问，"测速摄像头拍下这辆车的'瞬间'，说它此刻 120 km/h。可'此刻'没有长度——没有长度就没有路程，没有路程，哪来的速度？这 120 到底是怎么算出来的？"

老谟放下手里的茶杯，在照片上画了一条曲线："你说得对，'此刻'没有长度。那我问你——**测速摄像头是只拍一张照片，还是拍两张？**"

"……两张？隔一小段时间拍两张，用两张照片里的位置差除以时间差，得到一段'平均速度'。"

"那如果这段'一小段时间'越来越短呢？短到接近 0，这个平均速度会怎样？"

我盯着那两张照片，隐约觉得答案就在那个"越来越短"里，却说不出它到底"逼近"什么。

## 对话引擎

### 第 1 轮：瞬时速度为什么说不清——"此刻"没有时长

**老谟**："你先把'瞬时速度'这个说法，逼到墙角。**'瞬时'是多久？** 一秒钟？一毫秒？一微秒？你越说越短，可永远有一个'长度'——只要有个长度，那就是'一段'速度，不是'瞬时'速度。"

**造物主**："……所以'瞬时速度'这个词本身是矛盾的？没有时长的速度，就像没有长度的路程，都是空话？"

**老谟**："别急着判死刑。你想想——**你说'这辆车此刻是 120'，靠的是摄像头拍的两张照片。** 那你为什么信这个数？"

**造物主**："因为……两张照片隔得越近，算出来的平均速度就越像'那一刻'的速度？隔 1 秒算的是这 1 秒的平均，隔 0.1 秒就更接近'此刻'……"

**老谟**："你摸到关键了。**'瞬时速度'不是'某一段'的速度，是'平均速度'这个数，在时间间隔越缩越短时，逼近的那个极限。** 我们把'间隔长度'叫 h，你算的就是 (f(t+h)−f(t))/h——然后问：h 缩到 0，这个式子逼向谁？"

**造物主**："……所以'瞬时速度'不是一个独立的东西，它是'平均速度'这个家族，在 h→0 时的极限。**'此刻 120'的意思是：你把间隔缩到任意小，平均速度都越来越靠近 120。**"

### 📐 知识锚点：平均速度 vs 瞬时速度——差商与它的极限

<blockquote style="background:#fff8e1">

【概念深挖】设 s(t) 是 t 时刻的位置（路程函数）。
- **平均速度**（区间 [t, t+h] 上）：\(\frac{s(t+h)-s(t)}{h}\)——"h 这段时间里，平均每单位时间走了多少"。
- **瞬时速度**（时刻 t）：平均速度在 **h → 0** 时的极限（若存在）：\(\lim_{h\to 0} \frac{s(t+h)-s(t)}{h}\)。
- **关键**：瞬时速度不是"h=0 时那个式子"（h=0 时差商 0/0 无意义），而是"h 趋近 0 时差商逼近的值"。**这正是不用"无限接近"糊弄、而用极限语言钉死的地方——你在册02 已经会写这种句子了。**

【工程实践】测速摄像头、GPS 的瞬时速度，全是"隔一小段时间算平均、再把时间间隔当 h 缩到接近 0"——**工程里没有真正的 h=0，只有"h 足够小、小到误差可接受"**。这和你册02 学的"浮点机的逼近"是同一种味道：真身在极限，工程拿够近的替身。

</blockquote>

### 第 2 轮：差商是什么——把"变化率"拆成"变化量 ÷ 间隔"

**老谟**："现在把'瞬时速度'这个物理词放一边，看数学本身。**我给你一个函数 f 和一点 a，我要问'f 在 a 附近变化得多快'。你打算怎么量？**"

**造物主**："……从 a 挪开一点点，看 f 变了多少？挪开 h，f 从 f(a) 变成 f(a+h)，变化量是 f(a+h)−f(a)，除以间隔 h，就是'每单位间隔的平均变化量'——(f(a+h)−f(a))/h。"

**老谟**："这个式子叫**差商**。它是'平均变化率'。那'a 这一点'的变化率，就是把这个 h 越缩越小，看差商逼向谁。**你说说，这个思路和册02 的哪个定义长得一模一样？**"

**造物主**："……和数列极限、函数极限一模一样！'h 缩到 0'就是'h→0'，'差商逼向谁'就是'求极限'。**我只缺一个名字：把这个极限叫'导数'。**"

**老谟**："名字不重要，重要的是你认出来了——**导数就是差商的极限，是你已经会写的 ε-δ/ε-N 语言的又一次应用。** 至于这个极限具体怎么算、什么时候存在，我们下一轮把它写成标准形式。"

---

### 📐 知识锚点：导数的极限定义——标准形式与两种写法

<blockquote style="background:#e3f2fd">

【概念深挖】**导数（derivative）的极限定义**：
> 设 f 在 a 的某邻域内有定义。若极限 \(\lim_{h\to 0} \frac{f(a+h)-f(a)}{h}\) 存在，则称 **f 在 a 处可导**，记该极限为 **f'(a)**（读作 "f prime of a"）。

**两种等价写法**（同一个极限，不同记法）：
1. **差商形式**：\(f'(a) = \lim_{h\to 0} \frac{f(a+h)-f(a)}{h}\)（h 是"挪开的间隔"）；
2. **变量形式**：\(f'(a) = \lim_{x\to a} \frac{f(x)-f(a)}{x-a}\)（令 x=a+h，x→a 等价于 h→0）。

> **约定观元说明**：这两种写法是**等价的约定选择**——同一个极限换了个记法，选哪个全看计算方便（差商形式适合"挪一小格"的直观，变量形式适合和函数极限定义直接对照）。**正如册02 的 ε-N/ε-δ 语言，"用极限定义导数"本身也是我们选定的形式化约定**——"瞬时变化率"的直觉是真的，但"怎么写下来"是数学界的约定，它把直觉钉成了可以验证的句子。这延续了全书"约定是地基"的主线：先有约定，后有可证明的定理。

**三个必须注意的点**：
- **h≠0**：差商的分母 h 不为 0（h→0 是"趋近"，不是"等于"）——这对应册02 函数极限里的"0<|x−a|"。
- **导数存在 ⟺ 这个极限存在**：极限不存在，就说"f 在 a 不可导"，不说"导数无穷大"之类的含糊话。
- **几何意义**：f'(a) 是曲线 y=f(x) 在点 (a, f(a)) 处**切线的斜率**——"变化率"的几何化身。

【历史溯源】**导数的诞生是一场 200 年的乱账**：**费马（Fermat，17 世纪）**已用"取极小间隔"求切线极值；**牛顿（Newton）**用"流数法"、**莱布尼茨（Leibniz）**用"无穷小量"各自发明了微积分——但"无穷小"到底是 0 还是不是 0，成了著名悖论（贝克莱主教讥讽它是"已死量的幽灵"）。**直到 19 世纪，柯西（Cauchy）与魏尔斯特拉斯（Weierstrass）用 ε-δ 极限把导数钉死**，"无穷小"的悖论才彻底消失。**你在册02 学的那套 ε-δ 语言，正是人类从"无穷小的幽灵"走向"可验证的极限"的钥匙——这一章你亲手用它定义导数。**

【工程实践】"变化率"在工程里无处不在：**速度、加速度、电流变化率、温度梯度、学习曲线**——都是"差商在间隔趋于 0 时的极限"。**数值计算里你没法真正取 h→0（浮点精度有限），只能取很小的 h 算近似差商**——这和册02 的 machine epsilon 直接挂钩：h 太小会撞上舍入误差，h 太大又不够"瞬时"，这个"h 该取多大"的取舍，正是数值微分的艺术。

</blockquote>

### 第 3 轮：可导必连续——为什么"有斜率"就"没断"

**老谟**："你有了导数的定义。现在我抛给你一个命题：**如果 f 在 a 可导，那么 f 在 a 必连续。** 你先凭直觉说——这个方向对吗？"

**造物主**："……对？曲线在那一点有切线（有斜率），那它当然没断——**断了的地方怎么会有切线呢？** 可'直觉对'不算数，我得用定义推。可导数定义里是 f(a+h)−f(a)，连续定义里要的是'h→0 时 f(a+h)→f(a)'——**这两件事怎么连起来？**"

**老谟**："你卡在'怎么把差商变成 f(a+h)−f(a)'上。提示你一句：**差商乘上 h，就等于 f(a+h)−f(a)。** 剩下的，就是把'差商趋于 f'(a)'和'h 趋于 0'这两个已知，乘起来。完整推演在走廊定理 1，你翻过去对着空白纸补全。"

**造物主**："……差商乘 h？如果差商趋于一个有限的数 f'(a)，而 h 趋于 0，那乘积就趋于 f'(a)·0 = 0？**那 f(a+h)−f(a) → 0，也就是 f(a+h)→f(a)——这不就是连续吗！** 我摸到'为什么可导就连续'了。"

### 📐 知识锚点：可导 ⇒ 连续的直觉与"逆命题不成立"的预告

<blockquote style="background:#fff8e1">

【概念深挖】**可导 ⇒ 连续**（严格证明在走廊定理 1）：
- 直觉：f(a+h)−f(a) = [差商] × h。差商趋于 f'(a)（有限），h 趋于 0，乘积趋于 0，故 f(a+h)→f(a)。
- 意义：**"有斜率"比"没断"更强**——可导是连续的一个"加粗"版本。

**但逆命题不成立**（连续不一定可导，预告）：
- f(x)=|x| 在 0 处**连续**（lim=f(0)=0），但**不可导**（左右差商分别是 −1 和 +1，极限不存在）。
- 更野的：f(x)=x·sin(1/x)（x≠0，f(0)=0）在 0 处**连续但不可导**——差商 sin(1/h) 在 h→0 时疯狂震荡，根本没有极限。**这个例子是册02 第 04 章 sin(1/x) 无极限的直接翻版。**
- 结论链（本册第 1 章的核心链）：**可导 ⇒ 连续；连续 ⇏ 可导。** "可导"是比"连续"更硬的条件。

【历史溯源】"连续但不可导"在 19 世纪前被视为不可能——直觉上"连续曲线总有切线"。**魏尔斯特拉斯（1872）构造了一个处处连续、处处不可导的函数**，震惊整个数学界：原来"连续"和"可导"差得这么远。**这个反例的意义是：直觉在分析里必须让位于定义**——这正是你在册02 反复看到的主题。

【工程实践】"可导 ⇒ 连续"在工程里的对应：**如果某个量'变化率'是定义良好的（可导），那么它本身一定'平滑连续'；反之，一个量连续不保证变化率有意义**。例如：位置曲线连续但可能有"折点"（如碰撞反弹瞬间），折点处速度（导数）不存在——**工程里遇到"速度突变"（不可导点），往往意味着模型在该点失效，要单独处理。**

</blockquote>

### 第 4 轮：不可导长什么样——|x| 与 x·sin(1/x)

**老谟**："光说'连续不一定可导'不够。你给我造一个——**一个在 0 处连续、但不可导的函数，而且要用导数定义说清楚它为什么不可导。**"

**造物主**："……先来 f(x)=|x|。它在 0 处连续（lim_{x→0}|x|=0=f(0)）。看导数：差商 (|0+h|−|0|)/h = |h|/h。h>0 时是 1，h<0 时是 −1——**左右极限分别是 1 和 −1，不相等，所以极限不存在，不可导！** 折点的左右斜率不一样。"

**老谟**："好，这是'折点'型。再给你一个更阴险的——**f(x)=x·sin(1/x)（x≠0），f(0)=0。** 你先说它连续吗？"

**造物主**："连续。因为 |x·sin(1/x)| ≤ |x| → 0，夹逼，所以 lim_{x→0} f(x)=0=f(0)。那导数呢？差商是 (h·sin(1/h)−0)/h = **sin(1/h)**——h→0 时 sin(1/h) 疯狂震荡，**没有极限**（这正是册02 第 04 章证的 sin(1/x) 无极限！）。所以它在 0 处不可导。"

**老谟**："你把两个'连续但不可导'的样板都造出来了——**一个是折点（|x|），一个是震荡（x·sin(1/x)）。** 记住它们的共同点：**连续只要求'函数值接上'，可导还要求'斜率有一个确定的极限'。** 下一轮，我们把这一章的魂收一收。"

### 📐 知识锚点：不可导的两类样板——判断可导性的完整清单

<blockquote style="background:#e3f2fd">

【概念深挖】**f 在 a 不可导，只有三类可能**（判断可导与否的完整清单）：
1. **f 在 a 不连续**（自然不可导，因为可导⇒连续，逆否）；
2. **左右差商极限不相等**（"折点"型）：如 f(x)=|x| 在 0，左差商→−1、右差商→1；
3. **差商极限不存在（震荡）**：如 f(x)=x·sin(1/x) 在 0，差商 sin(1/h) 无极限。

**判断可导的四步清单**：
1. f 在 a 连续吗？不连续 → 不可导。
2. 写出差商 (f(a+h)−f(a))/h。
3. 化简差商，看 h→0 时极限是否存在（可能分左右）。
4. 左右极限相等且存在 → 可导；否则不可导。

**"可导"与"连续"的关系总结**：可导 ⊂ 连续（可导必连续）；连续不必然可导（折点、震荡都是反例）。**导数是比连续更细的"放大镜"——连续看"值接没接上"，导数看"斜率定没定死"。**

【工程实践】不可导点在工程里的意义：**信号处理中的"尖峰/折点"（如方波的角）、物理中的"速度突变"（碰撞）、优化中的"不可微目标"（L1 范数在 0 处）**——遇到不可导点，梯度类算法（梯度下降）会失效，需要次梯度、平滑近似或专门处理。**"这点的导数不存在"不是学术术语，是工程里"算法在这里会翻车"的警报。**

</blockquote>

**老谟**："把这章收一遍。你最初问'瞬时速度到底是谁的速度'，现在你怎么答？"

**造物主**："……瞬时速度不是'某一段'的速度，是**平均速度（差商）在 h→0 时的极限**。写成标准形式就是 f'(a) = lim_{h→0} (f(a+h)−f(a))/h。它和册02 的 ε-δ 极限是同一套语言，只是把'x 靠近 a'换成了'h 靠近 0'。"

## 严格化走廊

> 位置说明：对话负责"直觉"——为什么瞬时速度是差商的极限、为什么可导就连续。本走廊负责"严谨"——把导数的极限定义落成精确形式，并给出本册第一座**完整可复写**的证明：**可导必连续（定理 1）**。每个证明都标注"证明类型 + 每一步依据"，且给出完整的 ε-δ 推演——这是红线 1 的硬要求：不许用"显然""无限接近"糊弄。

### 定义：导数（极限定义，精确表述）

设 f 在 a 的某邻域内有定义。称 **f 在 a 处可导**，若极限
$$\lim_{h\to 0} \frac{f(a+h)-f(a)}{h}$$
存在（有限实数）。该极限记为 **f'(a)**，即
$$f'(a) = \lim_{h\to 0} \frac{f(a+h)-f(a)}{h}.$$

**等价形式**：令 x = a+h，则 h→0 ⟺ x→a，且 x≠a 对应 h≠0：
$$f'(a) = \lim_{x\to a} \frac{f(x)-f(a)}{x-a}.$$

> **证明类型标注**：本章的核心证明——**定理 1（可导 ⇒ 连续）用直接证明**（从导数定义出发，把差商乘 h 还原成 f(a+h)−f(a)，用"乘积的极限=极限的乘积"推）。它承接册02 的 ε-δ 语言（第 04 章）与"极限四则运算"（册03 后续补充）。**构造性证明的影子**：导数定义本身就是"针对每个可导点，极限存在"的存在性断言。
>
> **关于对话**：本章第 3 轮是读者**第一次**正式接触"可导 ⇒ 连续"的推导，对话做了"引导式推导"（教学示范——为什么想到"差商×h"这个关键一步）。**正式的可复写证明（每一步标依据）在本走廊定理 1**。对话负责"为什么会想到这步"，走廊负责"怎么把它写标准"——与册02 第 03/04 章口径一致。

### 定理 1（可导 ⇒ 连续）：若 f 在 a 处可导，则 f 在 a 处连续

**前提**：f 在 a 的某邻域内有定义，且极限 f'(a) = lim_{h→0} (f(a+h)−f(a))/h 存在（有限）。

**结论**：lim_{h→0} f(a+h) = f(a)（即 f 在 a 连续）。

**证明类型**：直接证明（差商 × h 还原 + 乘积的极限）。

**证明**：
- 第 1 步：**改写目标**：要证 f 在 a 连续，即证 lim_{h→0} f(a+h) = f(a)。等价于证 lim_{h→0} [f(a+h) − f(a)] = 0。（依据：连续的定义（册02 第 05 章）——lim f(a+h)=f(a) ⟺ lim[f(a+h)−f(a)]=0。）
- 第 2 步：**关键改写（差商 × h）**：对 h≠0，
  $$f(a+h)-f(a) = \frac{f(a+h)-f(a)}{h} \cdot h.$$
  （依据：代数恒等式——右边通分即左边，h≠0 时成立。）
- 第 3 步：**取极限**：由已知 f'(a) = lim_{h→0} (f(a+h)−f(a))/h 存在（有限），且 lim_{h→0} h = 0，由**乘积的极限法则**（两极限都存在，则乘积的极限 = 极限的乘积）：
  $$\lim_{h\to 0}\left[\frac{f(a+h)-f(a)}{h}\cdot h\right] = f'(a)\cdot 0 = 0.$$
  （依据：乘积的极限法则 + 代入 f'(a)、lim h=0。）
- 第 4 步：**结合**：由第 2 步恒等式，左边就是 lim_{h→0}[f(a+h)−f(a)]；由第 3 步它 = 0。故 lim_{h→0} f(a+h) = f(a)。（依据：第 2、3 步合并 + 极限的加法法则。）
- 第 5 步：由连续定义，**f 在 a 连续**。∎

> **依据标注**：步 1 用"连续的定义"（把目标翻译成差的形式）；步 2 用"差商×h 恒等还原"（本章的关键一步：把不知道极限的 f(a+h)−f(a)，写成"已知有极限的差商"×"已知趋于 0 的 h"）；步 3 用"乘积的极限法则"（先决条件：两个极限都**存在**——f'(a) 存在是前提，lim h=0 平凡成立）；步 4、5 用极限加法与连续定义收束。
> **读法**：这个证明的发动机是第 2 步——**"把一个东西，写成'已知有极限的量'×'趋于 0 的量'"**。这是分析里最常用的一招：当你不知道某个量的极限时，想办法把它"拆"成你能控制的两块。**注意：如果 f'(a) 是无穷大（极限不存在），第 3 步就不能用乘积法则**——这正是"可导（极限存在且有限）⇒ 连续"里"有限"两字的分量。

### 导数计算的书写格式模板（可复写卡片——对着空白纸照写）

> 这是本章要你抄进脑子的第一张卡。**以后你用定义算导数，就照这个骨架填**：

```text
命题：求 f'(a)（f 在 a 可导）。
计算（用定义）：
  写出差商：(f(a+h) − f(a)) / h。
  化简差商：消去分子里导致 0/0 的因子（通常是 h），把差商化成一个"h 的多项式/可求极限的形式"。
  取极限：令 h→0，看差商趋于谁——这个值就是 f'(a)。∎
```

**填写时的三个检查点**：① **先写差商，不跳步**——(f(a+h)−f(a))/h 写全；② **化简到"h 可以被消掉/可以直接代 h=0"**——若化简后 h→0 仍出现 0/0，说明没化到底；③ **若极限不存在（左右不等或震荡），说"不可导"**，别硬写一个数。

### 反例/边界：导数的适用边界

1. **"可导"要求极限存在且有限**：f(x)=|x| 在 0 左右差商 ±1 不等 → 不可导；"导数为无穷大"不算可导（本册只认有限导数）。
2. **连续但不一定可导**：|x|（折点）、x·sin(1/x)（震荡）都在 0 连续但不可导。**"可导"比"连续"硬。**
3. **导数定义要求 f 在 a 的邻域有定义**：f 在 a 无定义或孤立点，谈不上可导（差商无意义）。
4. **h≠0 是硬约束**：差商在 h=0 处是 0/0，无定义；"h→0"是趋近不是代入。**别把 f'(a) 写成 (f(a+0)−f(a))/0。**
5. **"可导 ⇒ 连续"的反向不成立**：判断可导时，先查连续（不连续必不可导），连续后再查左右差商。

## 知识点总结

### 知识点（本章推出的核心概念）

- **导数（极限定义）**：f'(a) = lim_{h→0} (f(a+h)−f(a))/h（等价：lim_{x→a} (f(x)−f(a))/(x−a)）。**"瞬时变化率"= 差商的极限。**
- **差商**：(f(a+h)−f(a))/h——"平均变化率"；导数就是差商的极限。
- **可导 ⇒ 连续**：f(a+h)−f(a) = 差商 × h → f'(a)·0 = 0。**可导是连续的"加粗"。**
- **连续 ⇏ 可导**：|x|（折点）、x·sin(1/x)（震荡）连续但不可导。
- **导数的几何意义**：f'(a) = 曲线 y=f(x) 在 (a,f(a)) 处切线的斜率。
- **不可导三类**：不连续；左右差商不等（折点）；差商极限不存在（震荡）。

### 历史结论（本章涉及的史料）

- **费马（17 世纪）**：取极小间隔求切线/极值——导数的思想先驱。
- **牛顿（流数法）/莱布尼茨（无穷小）**：各自发明微积分，但"无穷小"引发悖论（贝克莱："已死量的幽灵"）。
- **柯西（1821）/魏尔斯特拉斯（19 世纪）**：用 ε-δ 极限把导数钉死，无穷小悖论消失——**你在册02 学的 ε-δ 正是这把钥匙。**
- **魏尔斯特拉斯（1872）**：构造处处连续、处处不可导的函数，终结"连续就有切线"的直觉。

### 工程实践结论（本章知识在真实工程里怎么用）

- **数值微分**：取小 h 算差商近似导数；h 太小撞浮点舍入误差、太大不够"瞬时"——**与册02 的 machine epsilon 直接相关。**
- **测速/传感器**：GPS 瞬时速度、加速度计积分，都是"差商在 h→0 的极限"的工程近似。
- **不可导点 = 算法翻车点**：梯度下降需要可导；L1 范数在 0 处不可导（用次梯度/平滑近似）；物理碰撞的速度突变要单独建模。
- **"可导 ⇒ 连续"的工程含义**：变化率定义良好 ⟹ 量本身平滑；有折点 ⟹ 变化率在该点不存在。

## 计算训练场

> 位置说明：对话负责"为什么导数=差商的极限"，这里负责"怎么算"。下面三题**必须动笔**，每题 10 分钟以上，先自己写再对答案。**难度递进：易→中→难。** 重点是亲手走"写出差商→化简→取极限"三步。

### 题 1（易→中）：用定义求 f(x)=x³ 在 x=2 的导数

**题干**：老谟让造物主用导数的极限定义（不套求导公式）求 f(x)=x³ 在 x=2 的导数 f'(2)，并写出完整三步。

**完整分步解答：**

- 第 1 步（写差商）：
  (f(2+h)−f(2))/h = ((2+h)³ − 2³)/h = ((2+h)³ − 8)/h。
- 第 2 步（化简）：展开 (2+h)³ = 8 + 12h + 6h² + h³（二项展开，或 (2+h)²(2+h) 乘开）：
  ((2+h)³ − 8)/h = (8 + 12h + 6h² + h³ − 8)/h = (12h + 6h² + h³)/h = **12 + 6h + h²**。（消去 h，0/0 解除了。）
- 第 3 步（取极限）：f'(2) = lim_{h→0} (12 + 6h + h²) = **12**（h→0 时 6h→0、h²→0，多项式极限直接代入 h=0）。
- **答**：f'(2) = **12**。几何意义：曲线 y=x³ 在 (2,8) 处切线的斜率为 12。

**常见错误**：① 展开 (2+h)³ 漏项或算错系数（正确是 8+12h+6h²+h³）；② 消 h 前就急着代 h=0（会得 0/0）；③ 忘了写"h≠0，消 h 后才可代 h→0"——消 h 是代数化简，代 h=0 是取极限，两回事。

### 题 2（中）：用定义求 f(x)=1/x 在 x=3 的导数

**题干**：老谟让造物主用极限定义求 f(x)=1/x 在 x=3 的导数 f'(3)。

**完整分步解答：**

- 第 1 步（写差商）：
  (f(3+h)−f(3))/h = (1/(3+h) − 1/3)/h。
- 第 2 步（化简）：通分：
  1/(3+h) − 1/3 = (3 − (3+h))/(3(3+h)) = −h/(3(3+h))。
  于是差商 = (−h/(3(3+h)))/h = **−1/(3(3+h))**。（消去 h。）
- 第 3 步（取极限）：f'(3) = lim_{h→0} [−1/(3(3+h))] = −1/(3·3) = **−1/9**。
- **答**：f'(3) = **−1/9**。

**常见错误**：① 通分时分子算错（3−(3+h)=−h，别写成 +h）；② 消 h 时把分母 3(3+h) 里的 h 也消了（只能消分子里的公共因子 h）；③ 取极限时忘了 3+h→3（h→0 时 3+h 趋于 3，不是趋于 0）。

### 题 3（难）：分段函数在接点的可导性——f(x)=x·sin(1/x) 在 0

**题干**：设 f(x)=x·sin(1/x)（x≠0），f(0)=0。
(a) 用连续定义证明 f 在 0 连续。
(b) 用导数定义判断 f 在 0 是否可导。
(c) 对比：如果改成 g(x)=x²·sin(1/x)（x≠0），g(0)=0，g 在 0 可导吗？导数是几？

**完整分步解答：**

**(a) 连续**：对 x≠0，|f(x)−f(0)| = |x·sin(1/x)| = |x|·|sin(1/x)| ≤ |x|（因 |sin|≤1）。故 |x|→0 时 |f(x)−f(0)|→0，即 lim_{x→0} f(x)=0=f(0)。**f 在 0 连续。**（也可用夹逼：−|x| ≤ x·sin(1/x) ≤ |x|。）

**(b) 可导性**：差商
  (f(0+h)−f(0))/h = (h·sin(1/h) − 0)/h = **sin(1/h)**。
h→0 时 sin(1/h) 在 −1 与 1 之间疯狂震荡，**没有极限**（这正是册02 第 04 章定理 2 证明的"sin(1/x) 在 0 无极限"，这里 1/h 扮演同样的角色）。故极限不存在，**f 在 0 不可导**。

**(c) g(x)=x²·sin(1/x)**：差商
  (g(0+h)−g(0))/h = (h²·sin(1/h) − 0)/h = **h·sin(1/h)**。
而 |h·sin(1/h)| ≤ |h| → 0（夹逼），故 lim_{h→0} h·sin(1/h) = 0。**g 在 0 可导，且 g'(0)=0。**

**答**：(a) 连续；(b) f 在 0 不可导（差商 sin(1/h) 无极限）；(c) g 在 0 可导，g'(0)=0——**差一个 x 的幂，可导性就从"没有"变成"有"**（x·sin(1/x) 差商是 sin(1/h)，x²·sin(1/x) 差商是 h·sin(1/h)，后者被 |h| 压死）。

**常见错误**：① (b) 以为"f(0)=0 所以可导"——可导看差商极限，不是看函数值；② 把 sin(1/h) 的震荡当成"极限是某个数"——它没有极限，要说"不存在"；③ (c) 漏了夹逼的 |sin|≤1——h·sin(1/h) 是被 |h| 压向 0 的，不是随震荡发散。

## 自测题

> 计算题须动笔完成，附完整解答自核；概念题用于检查理解。

**题 A（计算，易→中）：用定义求导数**

用导数的极限定义求 f(x)=x² 在 x=3 的导数 f'(3)，写全三步。

**完整解答**：差商 ((3+h)²−9)/h = (9+6h+h²−9)/h = (6h+h²)/h = 6+h。取极限 f'(3)=lim_{h→0}(6+h)=**6**。

**题 B（计算，中→难）：分段函数可导性**

设 f(x)=x²（x≥0），f(x)=−x²（x<0）。讨论 f 在 0 处是否可导，并求 f'(0)（若存在）。

**完整解答**：f 在 0 连续（左右极限都是 0=f(0)）。差商：h>0 时 (h²−0)/h=h→0；h<0 时 ((−h²)−0)/h=−h→0。左右差商极限都是 0，相等。故**可导，f'(0)=0**。（对照 |x|：那里左右差商是 ±1 不等，这里 ±h 都压向 0，故可导。）

**题 C（概念，检查理解）**

(a) "瞬时速度"为什么不能直接定义，而要定义为差商的极限？
(b) 可导 ⇒ 连续，反过来成立吗？举一个"连续但不可导"的函数。
(c) 为什么 f(x)=x·sin(1/x) 在 0 不可导，而 g(x)=x²·sin(1/x) 在 0 可导？

**完整解答**：
(a) "此刻"没有时长，没有时长的速度无法直接定义；把它定义为"平均速度（差商）在间隔 h→0 时的极限"，就把直觉落成了可验证的极限。
(b) 不成立。连续不一定可导：f(x)=|x| 在 0 连续但左右差商 ±1 不等，不可导（或 x·sin(1/x) 在 0 连续但差商 sin(1/h) 无极限）。
(c) 差一个 x 的幂：f 的差商是 (h·sin(1/h))/h=sin(1/h)，无极限；g 的差商是 (h²·sin(1/h))/h=h·sin(1/h)，被 |h| 夹逼压向 0，故 g'(0)=0。**分子里 sin 前面那个 x 的幂决定了差商里还剩一个 x 还是被消掉。**
