# 《多元微积分与凸优化》· 第 5 册

> **苏格拉底对话体自学教材**，老谟 ⇄ 造物主一问一答，让读者从零亲手推导多元微积分与凸优化。本册是《数学基础》系列 7 册中的第 5 册，承接第 04 册（线性代数，矩阵工具在此复用），并为第 06 册（概率统计与信息）提供"高维求最优"与二重积分的地基。
>
> **核心立场**：本册正面补上样书《数学基础》最大的逻辑跳跃——"不解释凸性就敢用梯度下降"。全册主线是**高维怎么找最优**：从"一个方向的变化率"（梯度）出发，走到"能用海森判定凸性、能解释为什么凸情形下局部最优=全局最优、能理解深度学习里真正的敌人是鞍点而非浅坑"。**这是深度学习优化者补上"为什么敢用梯度下降"的最后一块地基。**

## 每章标配（继承 skill 升级后的铁律）

- **严格化走廊**：定义 → 定理（带全前提）→ ≥2 个可复写完整证明 → 反例/边界。全册 16+ 个证明逐步标依据，禁止"显然"。
- **计算训练场**：每章 ≥3 道中大型计算题（动笔 10 分钟+），易→中→难递进，附完整分步解答 + 常见错误（数值全部经三专家亲手复核）。
- **对话/证明分离**：对话只推"为什么想到这步"，公式与证明全部交给走廊，不演定理。
- **红线1 全册执行**：完整可复写证明一律在走廊，每步标注所用依据（链式法则/可微定义/克莱罗定理/反证法）。
- **凸性主线**：第 04 章定义凸性 → 第 05 章判定工具 → 第 06 章凸性保证收敛 → 第 07 章海森符号分类，一条主线贯穿全册。
- **工程实践**：反向传播=链式法则、学习率过大发散=误差阶失控、ReLU 折角与"偏导存在≠可微"、鞍点海 vs 浅坑深谷修正、KKT 与影子价格。
- **跨册衔接**：二重积分为册06 联合分布概率 P((X,Y)∈D)=∬_D f dxdy 铺路；第 08 章预告指向册06。

## 创作流程

本册由 **创世游戏团队** 协作完成，执行「创作 → 三专家评审 → 修改 → 复审 → 定稿」循环：
- **主笔（main）**：统筹、起草样板章（第01/02章）、分发评审、统稿
- **严格性首席（rigor-chief）**：严格化走廊把关（定义/定理前提/证明可复写/反例边界）
- **习题与工程设计师（exercise-designer）**：计算训练场数值亲手复核
- **跨学科顾问（cross-advisor）**：历史准确、工程贴切、对话不套路化、节奏平衡
- **作者 ×2（writer-multivar / writer-optim）**：按样板标准并行创作（前者第03–05章，后者第06–08章）

所有章节经三专家逐章评审通过后定稿，数值经亲手核算。第01/02章由主笔亲自起草并经三专家评审定稿，作为全册质量基线锚点。
