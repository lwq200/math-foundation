> **苏格拉底对话体自学教材**，老谟 ⇄ 造物主一问一答，让读者从"0.1 为什么在机器里算不准"这个具体困惑出发，一路走到**能用 ε-N / ε-δ 亲手写一个极限证明**。本册是《数学基础》系列 7 册中的第 **2** 册，也是全系列的**严格性枢纽**——导数、级数、连续，全部建立在这一册的极限定义之上。

## 每章标配（继承 skill 升级后的铁律）

- **严格化走廊**：定义 → 定理（带全前提）→ ≥2 个完整可复写证明 → 反例/边界。**本册是严格性枢纽：每个 ε 证明都必须给出完整的 N(ε)/δ(ε) 构造 + 回头验证，绝不用"无限接近"敷衍。**
- **证明类型标注**：每一章走廊都标明证明的"招式"——反证法（极限唯一性）、直接 ε-N/ε-δ 构造（1/n→0、x²→4）、反证+构造（sin(1/x) 无极限）、构造性证明（IVT 二分法）。**读证明先问"用的哪一招"。**
- **反解 N/δ 四步模板卡（本册特色）**：第 03 章给「设目标→反解→取 N→验证」的 ε-N 卡，第 04 章给「限距放大→反解→取 min→验证」的 ε-δ 卡——这是后续所有逼近类证明的通用脚手架。
- **红线口径统一**：对话只推"为什么想到这步"的直觉（播种式/引导式推导），**完整可复写证明一律在走廊，对话不演证明**（第 03、04、05 章走廊均明确标注"关于对话"口径）。
- **跨章脊柱**：完备性 → 浮点 → ε-N → ε-δ → 连续，五章层层踩实：IVT 靠第 01 章上确界公理，连续靠第 04 章 ε-δ，浮点误差做"逼近"的工程入口。
- **计算训练场**：每章 ≥3 道中大型计算/证明题（动笔 10 分钟+），易→中→难，附完整分步解答 + 常见错误 + 反解 N/δ 实操。

## 创作流程

本册由 **创世游戏团队** 协作完成，执行「创作 → 三专家评审 → 修改 → 复审 → 定稿」循环：
- **主笔（main）**：统筹、起草样板章、统稿
- **严格性首席（rigor-chief）**：严格化走廊把关（ε-N/ε-δ 证明完整构造、证明类型标注）
- **习题与工程设计师（exercise-designer）**：计算训练场数值复核（N/δ 终值、二分法区间）
- **跨学科顾问（cross-advisor）**：历史准确、工程实践、节奏平衡、学派中立
- **统稿员（writer-info）**：答案速查页数值与正文逐章核对、全册统稿
- **作者 ×2（writer-basic/stats）**：按样板标准并行创作

所有章节经三专家逐章评审通过后定稿，数值经亲手核算、并与正文逐一核对一致。
